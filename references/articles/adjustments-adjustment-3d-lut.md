The LUT adjustment

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/6go47NinWnvZv6SOmWxmyJ/7fcba107139f769224e65fbfbcafec73/lut_adjustment_type.svg)

 allows you to emulate image colors used in a variety of media platforms.

![Image 2: 3D LUT after](https://images.ctfassets.net/3p2fxa94bzao/2iu77FkVuRFqKgWahVM4QH/47f26e425244f0ac4671123f5a7faa58/adjustment_LUT_after.jpg)

![Image 3: Black & White before](https://images.ctfassets.net/3p2fxa94bzao/5NXgmzFzXKve50c596UktV/3587c26a6e00f462f4d50c450a098ea1/adjustment_base.jpg)

A LUT (look-up table) remaps pixel color values based on a defined XYZ matrix. This allows you to quickly replicate the appearance of various types of media, such as reproducing the cold, blue tone attributed to science fiction and horror movies.

The look up table is stored within a file previously exported from Affinity or other apps (e.g., video packages). Alternatively, it can be inferred by comparing images.

The following types of LUT files can be loaded: ***.3dl**, ***.csp**, ***.cube**, and ***.look**.

The following settings can be adjusted in the dialog:

*   **Load LUT**—sets the LUT used in the adjustment. In the pop-up dialog, navigate to and select a file, and click **Open**.
*   **Infer LUT**—applies a LUT adjustment without the need of a separate LUT file by comparing a 'source' image and its adjusted exported image. With a new 'target' image loaded, click **Infer LUT**, then in the pop-up dialog, navigate to and select both source and adjusted files in turn, and click **Open**.

The following options are available from the **Adjustment** panel:

*   Category—displays the currently active category. Select from the pop-up menu.

The following options are available from the adjustment's **Options**

![Image 4](https://images.ctfassets.net/3p2fxa94bzao/2XLuXTwmEh714qaYONrPKP/6d26123960257b3233a3eb084188eda7/moremenuicon.svg)

 menu:

*   **Create New Category**—adds a new, custom LUT category to the panel.
*   **Rename Category**—allows you to rename the currently selected category.
*   **Delete Category**—removes the currently selected category (and all its LUTs) from the panel.
*   **Duplicate Category**—adds a second copy of the currently selected category to the panel.
*   **Sort Categories By**—allows you to sort the contents of the Category pop-up menu by **Name** or **Date Added**.
*   [**Import LUT Category**](https://www.affinity.studio/help/addons-importing-addons/)—adds multiple LUTs from an .afluts file to the panel as a new category. 
*   **Export LUT Category**—creates an .afluts file containing the currently selected category and all its LUTs, as a backup or to share.
*   [**Import LUTs**](https://www.affinity.studio/help/addons-importing-addons/)—adds one or more individual LUTs from external files to the currently selected category. 
*   **Sort LUTs By Name**—arranges the currently selected category's contents in alphabetical order.

LUTs within a category can be dragged up or down to set the order in which they are listed. Whether you sort a category's LUTs manually or automatically, their order is remembered for future editing sessions.

The following options are available by **^(ctrl)**-clicking (Mac) / **right**-clicking (Windows) an individual LUT:

*   **Rename**—allows you to rename the LUT.
*   **Delete**—removes the LUT from the panel.
*   **Move To Category**—select a different category in which the LUT should be stored.
*   **Export LUT**—creates a file containing the individual LUT, as a backup or to share.

*   On the **Pixel** menu, select **New Adjustment Layer > LUT**.

The **Adjustment** panel is not visible by default. To enable it, navigate to the top menu and select **Window > Pixel > Adjustment**.
