# Creating packages - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/sharing-creating-packages/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Export, share, and publish](https://www.affinity.studio/help/export-share-publish/)
3.   Creating packages

Use the File menu's Save As Package command to open the Package Document dialog.

The dialog's **Summary** section reports the numbers of fonts, images, linked text files, and CSS files used in your document and alerts you to potential problems.

The total number of images may be larger than the sum of linked, missing, and modified images. This is because it also includes embedded images.

Check your compliance with the licensing terms of all fonts and images used in a document before packaging and distributing them.

You can choose to exclude all fonts and/or all images when creating a package.

To exclude individual items, delete them from the destination folder after the package has been created.

The dialog shows separate counts of missing, modified, and restricted items. Review these before proceeding with packaging.

*   **Missing**—Select **Fonts**, **Images**, **Linked texts**, or **CSS Files** on the dialog's left side to precisely identify missing items. To focus your investigation, click the **Status** column heading to group items by status.
*   **Restricted**—A font is considered restricted if any of three attributes is set within it: _Restricted License Embedding_, _Preview and Print Embedding_, and _Bitmap Embedding Only_. Distribution of the font may require you to obtain a more permissive license or the recipient to have their own license for the font.
*   **Modified**—An image has changed outside of Affinity and has not been updated within the document. Use the Resource Manager to update the document with the latest image data.

For all fonts, even if they aren't listed as _Restricted_, check your licensing terms are compatible with your intentions for the package.

Affinity may show a message indicating the package couldn't be saved and may be incomplete. This may indicate that some files are missing.

If you did not expect any files to be missing, try packaging the document again.

Always check that the package includes all expected content.

With the document open in Affinity:

1.   On the **File** menu, select **Save As Package**.
2.   Set **Include Fonts**, **Include Images**, **Include linked texts**, and **Include CSS files** as needed.
3.   Click **OK**.
4.   Navigate to the folder where you want to create the package.
5.   Click **Package**.

If your chosen folder is not empty, Affinity will ask whether you want to continue (**Yes**), choose a different folder (**No**), or abandon the packaging process (**Cancel**).
