# Text Frame panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-text-frame-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Text Frame panel

The Text Frame panel lets you set up your text frame.

The **Text Frame** panel provides a set of options for adjusting the frame layout, including frame stroke/fill color, number of columns, gutter settings, vertical alignment and baseline grid control.

For more information on frame text, see [Frame text](https://www.affinity.studio/help/text-frame-text/).

For Mac/Windows: On the **Window** menu, select **Text > Text Frame**.

The following options are available on the panel:

*   **Fill**—click the color swatch to display a pop-up panel to update the text frame's fill color.
*   **Frame Stroke Fill**—click the color swatch to display a pop-up panel to update the text frame's stroke color.
*   **Frame Stroke**—click to display a pop-up dialog allowing you to apply a stroke width or a different stroke style to the text frame.
*   **Insets**—specify the inside margins of your text frame.
*   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/2ty4rrvXJAKOQ9A7KNkpeq/3550d3ea165c5089bd090a4a8ece44e2/chainlinkconnected.svg) ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/5tDDIwcwpJRIpRHFMB12xq/ab33de5f69c7cc43582ad4ee5fa201d0/chainlink.svg) **Link Insets**—when enabled, the inset values are adjusted in proportion to each other, maintaining the current aspect ratio. When deselected, they can be adjusted independently.
*   **Hide Overflow**—tick this checkbox to clip overflowing text that does not fit in the frame.
*   **Ignore Text Wraps**—tick this checkbox to stop frame text from wrapping around objects with text wrapping set.
*   **Ignore Baseline Grid**—tick this checkbox to make the text frame ignore any currently set document grid.

*   **Columns**—specify the number of columns in your text frame.
*   **Preserve width**—when enabled and column or gutter widths are changed, adjacent column sizes are automatically adjusted to match them. Adjusting the rightmost column will still change the frame size.
*   **Width**—specify the width of each column.
*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/62Yzxp4Y9TItST5pxNM5RT/1151fa888546d5aa7cd0ec5d4cc3ee28/columnWidth.png) **Evenly Distribute Column Widths**—click to automatically make all columns the same width, calculated from the text frame width minus any inset settings.
*   **Gutter**—specify the gutter size between each column.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/41Zo8Qh3wG3tZ2jgPc0GnM/e8f84c262077f1ffc5699a9ec9427a40/link_gutters.svg) ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/4MqUkAfvuAFZR4SPQStZDN/70de82d5d511892f681930a2f1cfba7f/unlink_gutters.svg) **Link Gutter Widths**—when enabled, gutter widths are adjusted in proportion to each other. When disabled, they can be adjusted independently.
*   **Balance text in columns**—tick this checkbox to automatically balance columns of text regardless of size.

*   **Column Rule Stroke Fill**—click the color swatch to display a pop-up panel to update the rule stroke color.
*   **Column Rule Stroke**—click to display a pop-up dialog allowing you to apply different stroke styles to the rule.
*   **Gap**—specify the amount of vertical space between the **Top** or **Bottom** of the text frame and the column rule.

*   **Alignment**
    *   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/7xsUd82kEC85ekBtg62gGJ/4b2b1945b141f938fcb9bf3b85f0a4d9/top_align.svg) **Top Align**—sets the frame text alignment to adhere to the top margin.
    *   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/XMmT0m595qCnCdknAaMWn/d5b154c09fdd3618978e91aa6a5a9165/centre_vertically.svg) **Center Align**—sets the frame text alignment to be equidistant from the top and bottom margins.
    *   ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/Si1eyJ9VAsBy0qYFwubwC/3440d7511170ad9b4d643b5473f79e00/bottom_align.svg) **Bottom Align**—sets the frame text alignment to adhere to the bottom margin.
    *   ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/2PEvmRXcFHCmIohHt21dl3/a068e141cc9e20da175c74ec7a701f43/justify_vertically.svg) **Justify**—sets the frame text alignment to both the top and bottom margins.

*   **Max Paragraph Space**—specifies the space available to add between paragraphs when calculating vertical justification. Increase to allow more space between paragraphs than between baselines within a paragraph. **Alignment** must be set to **Justify**.
*   **Initial Advance**—sets the spacing between the top of the frame and the first baseline. You can use values like the current **Leading**, a **Fixed** value, the font's **Point size**, or other typographic values. Use this to keep spacing consistent on bordered frames, frames on colored backgrounds, or for precise vertical alignment with other page elements.
*   **Minimum**—sets a global minimum value for Initial Advance.

*   **Use Independent Baseline Grid**—enable to use a baseline grid that's specific to the selected text frame.
*   **Start Position**—sets how far the first grid line is from the origin defined in **Relative To**.
*   **Relative To**—specify what the baseline grid's starting position is in relation to.
*   **Grid Spacing**—specify how far apart consecutive horizontal grid lines are.
*   **Color**—click on the swatch to display a pop-up panel to set the line color. Drag the slider to set the opacity of the line color.

![Image 10](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

 The following options are available on the **Panel Preferences** menu:

*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
