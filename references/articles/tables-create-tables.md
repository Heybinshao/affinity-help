# Creating tables

Affinity lets you create and format tables using the Table Tool.

![Image 4: Using the Table Tool.](https://images.ctfassets.net/3p2fxa94bzao/7qtycbLt2K8TTp7pNX95OA/7d9852688769e7c12c0013c31cdf2e12/tables_01.jpg)

Drawing a table.

Tables allow you to organize and present information in rows and columns rather than in paragraph format.

Table text can be typed manually or pasted directly into a table, and has its own object defaults distinct from artistic and frame text.

Snapping can be used to precisely align table rows and columns to other content on the page.

[](https://www.affinity.studio/help/tables-create-tables/#placing-spreadsheet-files)

## Placing spreadsheet files

Microsoft Excel Workbook spreadsheets (XLSX) can be placed directly in Affinity as tables.

You can select a range of cells in Excel, copy them, and paste them into equivalent cells in Affinity.

The following limitations apply:

*   Formulae are imported as their calculated result values.
*   Local formatting is imported, but global Table Styles currently are not.
*   Overflowing cell content is handled differently. Excel lets it overflow into adjacent empty cells. In Affinity, text wraps to the cell's width and the cell's height adjusts to fit.

[](https://www.affinity.studio/help/tables-create-tables/#tables-and-page-breaks)

## Tables and page breaks

In Affinity, tables are self-contained objects. They are not part of the text flow; they do not automatically split across page breaks.

If you need a table to stay close to specific body text, you can pin it to a position in frame text. See the "Pinning" topic for details.

When creating long tables, you can use the following method:

1.   On the first page where the table will appear, create a table.
2.   In Affinity's Settings, adjust **Background gray level** (in the **User Interface** section) so content in the pasteboard area is more visible.
3.   Move the table onto the pasteboard. Enter your content in the table.
4.   Create duplicates of the table on all pages where parts of it need to appear.
5.   On each duplicate, remove the rows that don't belong on that page.
6.   Restore your usual background gray level.

Keep the pasteboard table as a reference or delete it once your pages are finalized.

[](https://www.affinity.studio/help/tables-create-tables/#how-to-create-a-table)

### How to create a table

Desktop app

1.   Select the **Table Tool**  ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/U9027CHEs8YJPz3HslFFN/21c88099e755bed558908ec8f6cbd427/table_text_tool.svg)       .
2.   In the document view, drag to set the size and position of the table.
3.   (Optional) Adjust the numbers of rows and columns. To add rows/columns, either: 
    1.   drag the arrows at the end of a row or column header. The table's dimensions will change, but existing row heights/column widths are unaffected.
    2.   click the arrows, then adjust the row/column count that appears. The table's dimension are unaffected, but existing row heights/column widths will change.
