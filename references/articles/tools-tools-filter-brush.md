The Filter Brush Tool is available by default in Pixel Studio.

It can be added to other Studios. See 'Customizing tools' for details.

Instead of applying a filter globally to the entire image and then masking out the unwanted areas, the Filter Brush Tool allows for a quick and precise application of effects to specific parts of the composition. This eliminates the need for complicated masking techniques.

With the ability to adjust both opacity and blend mode, you can efficiently target areas of interest, streamlining the editing process and saving time. The Filter Brush Tool also comes with preset parameters, providing an excellent starting point to your edits. By simply adjusting the brush's Size, you can easily target specific image regions and begin painting an effect immediately.

The addition of a live filter layer follows the Assistant option labeled "Adding filter layer to selection" in the app's Settings. By default, this means the filter will be applied as a child layer of the content layer, be it pixel, RAW, or image layer. If the Assistant option is set to "Add filter as new layer," the filter will always be added above the selected layer as a parent layer.

When you begin brushing on a layer that already contains a filter layer of the same type, the existing layer will be selected and brushed on rather than a new one being created. Additionally, if you brush on a filter layer that matches the filter selected via the context toolbar, the brush will affect that layer’s mask instead of generating a new layer.

The following are available on the context toolbar:

*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/1DZ3BiVUNw49gMKmpfsxjY/cd1aedf8a4cd6086f5386c7898ba6846/slider_width.svg) **Size**—sets the width of the stroke.
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/3xN42iDOBeb6NfoMb1Nb3S/676173212d209b96e478c68304a4b2b5/slider_opacity.svg) **Opacity**—controls how visible the painted effect is.
*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/6YT2BTrlyBpYlL2uIKpJtk/b378569b35626974ee7c0f69e47176c7/slider_flow.svg) **Flow**—how fast the brush effect is applied (1% is very slow, 100% is immediate). Type directly in the text box or drag the pop-up slider to set the value.
*   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/3jeAVEQerphjqYhdiT8BLR/00fd4f48c15e79b94b796a70cf1d9838/slider_hardness.svg) **Hardness**—how hard the edges of the brush are. The brush appears softer as the percentage decreases. Type directly into the field or drag the pop-up slider to set the value.
*   **More**—click to display the [Brushes](https://www.affinity.studio/help/painting-raster-modify/) dialog to access advanced brush settings.
*   ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/2G6RXXZFvI6HUYZid36cJo/c0e6d0e34e179a4a70883fb3b37709c7/forcepressure.svg) **Force Pressure**—toggle to control brush size with pressure if using a pressure-sensitive device. This overrides brush defaults.
*   **Filter**—sets the filter to be loaded onto the brush. Choose from the pop-up menu prior to painting.
*   **Add Filter**—duplicates the existing filter and adds it as a new filter layer. Choose the new filter from the pop-up menu prior to painting. If no filter is present, a new one will be added.
*   **Edit Filter**—allows you to edit selected filter parameters after painting.
*   **Blend mode**—changes how the applied pixels interact with existing pixels on a layer. Choose mode type from the pop-up menu.
*   **Tonal Range**—choose whether to target the Full Range, Shadows, Midtones, or Highlights.
*   ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/48gU5vr3XwFWtBjwhAJWTo/28e1a43a4063087555940fbc383932d4/reset-global.svg) **Reset**—resets brush settings to their defaults.

The following settings are available on a pop-up dialog when accessed via right-clicking on the page:

*   **Rotation**—allows to set nozzle rotation.
*   **Blend mode**—sets the blend mode for the strokes.
*   **Size**—sets the stroke size in pixels. Drag the slider or type in a value in the field.
*   **Opacity**—sets the opacity level for the applied strokes. Drag the slider or type in a value in the field.
*   **Hardness**—sets how hard the edges of the brush are. The brush appears softer as the percentage decreases.. Drag the slider or type in a value in the field.
*   **Flow**—controls how fast color is built up under your brush. Drag the slider or type in a value in the field.

*   To apply alternate version of the brush's parameters, hold down the **⌘** key (Mac) / **Ctrl** key (Windows) while applying strokes. The alternate parameters are inversions of the default settings and depend on the filter selected.
*   To modify the brush's Opacity, use numeric keys (**0**-**9**).
*   To erase from the mask, hold the **⌥** key (Mac) / **Alt** key (Windows). This works as an easy alternative to switching to a Paint Brush Tool and painting in black to hide the filter effect from the targeted areas.
*   Hold the **⇧** key (Mac) / **Shift** key (Win) while pressing numeric keys (**0**-**9**) to change layer Opacity.
*   When accessed via right-click on the page, holding the **⇧** key (Mac) / **Shift** (Windows) restricts the on-dialog **Rotation**setting to 45°. Double-click the rotation point to reset it.
