# Measuring

Measuring lets you display the distance between points, objects and page elements on the page. An Area Tool additionally measures the area of one or more objects, plus the perimeter of a shape and open curve lengths.

[](https://www.affinity.studio/help/design-aids-measuring/#measuring-with-the-measure-tool)

## Measuring with the Measure Tool

The tool lets you accurately measure the distance between a fixed point and an object's edge, corner, center or at the intersection of two objects vertically, horizontally or diagonally. Curves and page elements such as page center, edge and edges (corners) can also be measured to. The reverse is also true—you can measure from any page element to any point or an object's edge, corner or at object intersection. You can even measure between placed guides.

![Image 8: Measuring guides with the Measure Tool](https://images.ctfassets.net/3p2fxa94bzao/4e0BG4FH0a81KuIcg3lZRf/d8654c6c9d7d8645263f94b6d69d964c/measuring_measuretool.png)

Measure Tool: (A) Point - Point (horizontally, vertically, diagonally), (B) Point - Curve, (C) Point - Center, (D) Point - Line, (E) Point - Guide, (F) Point - Page center, (G) Point - Page center (tangent; with projection line), (H) Point - Page edge and (I) Point - Page edge at Page center and (J) Along a diagonal straight line.

The Measure Tool is also plane-aware, so measurement can be made along the axes of isometric or axonometric grids.

[](https://www.affinity.studio/help/design-aids-measuring/#measuring-with-the-area-tool)

## Measuring with the Area Tool

This tool displays the area, total perimeter length or specific straight-line segment lengths of an object. For area measurements, linear hatching indicates the targeted object along with the object's area as an overlaid readout.

![Image 9: Measuring single-object areas with the Area Tool](https://images.ctfassets.net/3p2fxa94bzao/6XtqU9v9grMm6TU2kuJerz/6e9a06976d8f9fb51f9b062ab66a7e01/measuring_areatool.png)

Single-object area/perimeter measurement with the Area Tool: (A) Area of a closed object, (B) Perimeter of a object, (C) Straight-line 'cusped' segment length on the object.

You can also calculate the area of multiple objects by selecting an initial object and using modifier keys to include further objects.

![Image 10: Measuring multi-object areas with the Area Tool](https://images.ctfassets.net/3p2fxa94bzao/2KBShceVOZ9QMstqoLJH8Z/a64e62e8808133b55e86c3b05a192309/measuring_multipleareas.png)

Multi-object area measurement of selected objects with the Area Tool.

Overlapping objects will report the Total area on a hover-over readout; nonoverlapping objects will report it on the context toolbar only.

[](https://www.affinity.studio/help/design-aids-measuring/#measuring-between-objects)

## Measuring between objects

Using the **⌘** key (Mac) / **Ctrl** key (Windows) with the Move Tool and shape tools will display measurements between objects as you move your cursor around the page. These relate to the distance between the selected object(s) and other object (or page elements) and will update dynamically as the cursor moves.

![Image 11: Measuring guides between objects](https://images.ctfassets.net/3p2fxa94bzao/70B4WsE2fJlwKvZ2aJ3Axn/b6b70f3855c3350a8a5c73ecf4486182/measuring.png)

'Hover over' measurements displaying the size of the gaps between the selected circle and the square.

![Image 12: Measuring guides with nudge](https://images.ctfassets.net/3p2fxa94bzao/6J5jvuf8RLAGm45AfwQ1Um/8d3ef1563aa62cb88e3f69bbefac80f4/measuring_nudge.png)

'Hover over' measurements displayed when a circle is nudged to the right using the right arrow key.

For example, with a shape selected, measurements will show the distance, using labelled arrows, between the shape and:

*   another shape, when the cursor is positioned over that target shape.
*   the page edges, when the cursor is positioned over a blank portion of the page.

The measurement will then update as the cursor moves over an object to show the size of the horizontal and vertical gaps between this object and the selection.

Measurements are not persistent, are non-printable and are not saved with your document.

[](https://www.affinity.studio/help/design-aids-measuring/#how-to-display-distance-measurements)

### How to display area measurements

Desktop app

1.   With the **Move Tool**  ![Image 15](https://images.ctfassets.net/3p2fxa94bzao/3oigj5SSoPtnSw21egHEvD/b6ac975f2be7b3feb8e3e9867b378345/move_tool.svg)        active, select the object(s).
2.   In the Vector Studio   ![Image 16](https://images.ctfassets.net/3p2fxa94bzao/2Mejuekyv1U5fQVTYLqGud/edc8c0247142081ce0079de3013e815d/persona_vector.svg)       , select the **Area Tool**  ![Image 17](https://images.ctfassets.net/3p2fxa94bzao/14d6btWBQFGQ47vlLEivq0/a94c8bed5a7352ab690975350b7eb48f/area_tool.svg)        from the Measure Tool flyout.
3.   Hover over the target object shown in blue. For multi-object areas, any one of the selected objects (shown temporarily in blue) will report the total area on hover over, as well as the currently hovered-over object area (in blue linear hatching).

Area measurements will also be reported on the context toolbar while the selection remains in place, including the total area of selected objects.

If you click a blue selected area it will be removed from the total area calculation found on the context toolbar. On hover over this excluded area will highlight in red.

[](https://www.affinity.studio/help/design-aids-measuring/#how-to-display-perimeter-measurements)

### How to display perimeter measurements

Desktop app

1.   With the **Move Tool** active, select the object.
2.   In the Vector Studio   ![Image 18](https://images.ctfassets.net/3p2fxa94bzao/2Mejuekyv1U5fQVTYLqGud/edc8c0247142081ce0079de3013e815d/persona_vector.svg)       , select the **Area Tool**  ![Image 19](https://images.ctfassets.net/3p2fxa94bzao/14d6btWBQFGQ47vlLEivq0/a94c8bed5a7352ab690975350b7eb48f/area_tool.svg)        from the Measure Tool flyout.
3.    Do one of the following: 
    *   For an object's full perimeter length: With the context toolbar's **Perimeter Mode** set to **Full Edges**  ![Image 20](https://images.ctfassets.net/3p2fxa94bzao/3zyIW93rBDHAiglcvSbyEW/a5fcc66374ce167a3c9d082c2bb3a991/perimeter_fullEdges.svg)       , hover over the target object's perimeter. The thicker blue highlight will report the object's full perimeter length.
    *   For a specific straight-line segment length(s): With the context toolbar's **Perimeter Mode** set to **Cusped Segments**  ![Image 21](https://images.ctfassets.net/3p2fxa94bzao/1DfjKvROfZ9OSAa4mEiIua/9fef58d989747e60f0eb739280e58b99/perimeter_cuspedSegments.svg)       , hover over a specific segment to report just that segment's length along with the perimeter length. Optionally, you can click the segment (turning it red) and click additional adjacent or non-adjacent segments to make multi-segment perimeter measurements, reported as **Selected edges** on the context toolbar.

Perimeter measurement will also be reported on the context toolbar while the selection remains in place—Total perimeter length is shown, along with length excluding any holes.

[](https://www.affinity.studio/help/design-aids-measuring/#how-to-display-measurements-on-hover-over)

### How to display measurements on hover over

Desktop app

*   With the **Move Tool** active, select one or more objects and then hold down the **⌘** key (Mac) / **Ctrl** key (Windows) while moving the cursor over a target object.

The target object will display measurements from the selected object to the target object (if hovered over) or page element (if no objects are hovered over).

[](https://www.affinity.studio/help/design-aids-measuring/#shortcuts)

### Shortcuts

Desktop app

When using the Measure Tool, the following modifier keys can be used while the measurement is being drawn:

*   The **⇧** key (Mac) / **Shift** key (Windows) constrains the measurement line to 45° intervals. Tangents and equal bisecting angles will also be displayed while the key is pressed. Holding the mouse button down for a slightly longer duration will, on dragging, additionally draw a dashed projection line, whose axis can be toggled by pressing the ~ key.
*   Use either up or down arrow keys to constrain measurements to vertical; left or right arrow keys to constrain to horizontal.
*    Mac only: For keyboard's with numeric keypads, numeric keys can change measurement directions as follows: 
    *   **0** key—reverts back to unconstrained.
    *   **1** key—constrain to 45°.
    *   **2** key—constrain to vertical.
    *   **3** key—constrain to 135°.
    *   **4** key—constrain to horizontal.
    *   **5** key—constrain to equal angles.

*   The **⌥** key (Mac) / **Alt** key (Windows) temporarily switches off snapping.

When using the Area Tool, the following modifier keys can be used:

*   **⇧**-click (Mac) / **Shift**-click (Windows) adds an object to your current selection for area measurement; use it to deselect an included object too. 
*   **⌘**-click (Mac) / **Ctrl**-click (Windows) selects a new object and clears the current selection.
