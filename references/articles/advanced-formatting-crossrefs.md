3.   Formatting cross-references

A cross-reference's text adopts the formatting applied at its position in document text. The formatting can be overridden with your choice of character style.

This can be used, for example, to add emphasis that distinguishes the cross-reference from other text.

Additionally, you can limit the amount of text and which punctuation is displayed by a cross-reference's subfields.

![Image 1: Text options on the Insert Cross-Reference dialog](https://images.ctfassets.net/3p2fxa94bzao/5mtGeQmbeEHXJKsrefmEZ4/d41d1c294721d9d3cfb6065433f0162e/crossrefsInsert.png)

Text and other options on the Insert Cross-Reference dialog.

The following formatting options are available when inserting or editing cross-references:

*   **Style override**—Select an existing character style to override formatting at the cross-reference's position in document text, or apply no override style. You can also create or edit a character style here.
*   **For**—Choose how **Style override** is applied: to _Everything_ (the entire cross-reference), _All Fields_ in the text, or just _Text Fields_ or _Number Fields_.
*   **Limit subfields**—Turn on to use the following options. Turn off to display subfield values in full. 
    *   **Max word count**—Set the maximum number of words for each subfield. If an end character appears first, the subfield stops there.
    *   **Add ellipsis**—Turn on to show an ellipsis (…) at the end if the subfield's text is cut short. Turn off to omit the ellipsis.
    *   **End characters**—Type characters that, if any is encountered, will cause the subfield's text to be truncated, even if the maximum word count has not been reached.
    *   **Include end character**—Turn on to include an encountered end character at the end of the text. Turn off to omit the character.

Turn on **Generate hyperlinks** to make the cross-reference clickable. This works in PDFs and other interactive formats.

Commonly used special characters can be added to **End characters** by clicking the downward-pointing arrow on this option.

To display text in full or until an end character is reached, set **Max word count** to 0.

When inserting or editing a cross-reference:

1.   Check **Limit subfields**.
2.   Set **Max word count**, **Add ellipsis**, **End characters** and **Include end character** as required.

You can use **Limit subfields** only when the cross-reference includes fields that can contain long text, such as **Chapter Name** or **Object Description**.
