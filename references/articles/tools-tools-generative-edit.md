The Generative Edit Tool uses Canva AI to transform artwork through text prompts. It can convert vector graphics — including simple line drawings — into detailed raster images, generate multiple variations to choose from, and modify existing raster images by changing colors, adjusting atmosphere, or adding and removing elements such as objects, animals, or people.

It is particularly useful when you want to explore visual directions quickly, develop concepts, or prepare assets for compositing — without rebuilding artwork manually.

Canva AI features run on secure servers, which means your data is processed online to generate images. However, your personal information stays private and anonymous at all times. Canva does not collect any user data—including hardware details, location, or workflow activity—as part of this process.

Use the Generative Edit Tool to:

*   Convert vector artwork into detailed raster imagery.
*   Generate alternative visual interpretations of a design.
*   Adjust the mood or setting of an image (for example, "Make it winter").
*   Add or remove elements such as objects or furniture (for example, "Remove the sofa").
*   Explore creative variations before committing to manual edits.

The tool is particularly effective when:

*   Building assets for compositing or layered designs.
*   Exploring different visual directions quickly.
*   Adapting an existing image to a new context or narrative.
*   Making structural image changes without extensive retouching.

*   Work on a duplicate layer when modifying existing raster images.
*   Refine generated results using masks, tonal adjustments, or retouching tools for seamless integration.
*   Review lighting, edges, and tonal consistency when adding or removing elements.

When using the **Generative Edit Tool**, you can choose between **Premium** and **Ultra** models, which affect generation behavior and output quality.

*   **Premium**—Flux Kontext; supports continued generation after credits are used, with a short pause between generations.
*   **Ultra**—Nano Banana and SeeDream 4.5; provides uninterrupted generation with enhanced output quality.

Select a model based on your workflow. Use **Premium** for iterative edits where speed matters, or **Ultra** when output quality and uninterrupted generation are the priority — for example, when producing final assets or working with complex scenes.

The following settings can be adjusted in the dialog:

*   **AI Quality**—choose from the available Premium or Ultra models.
*   **Prompt**—the instruction or description you provide to guide AI to create the result you want.
*   **Transparency**—sets transparency behavior of the generated objects; choose from the list.
*   **Protect child layers**—controls whether child adjustment and filter layers are merged into the image layer upon render. Disable to bake them into the layer (default). Enable to keep them editable in their original position.
