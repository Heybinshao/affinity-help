# EPUB panel - Affinity Help Center

3.   EPUB panel

The EPUB panel lets you add custom CSS (Cascading Stylesheet) files to your Affinity document.

For Mac/Windows: On the **Window** menu, select **Layout > EPUB**.

You can add custom CSS to your document to control the presentation of your exported Reflowable EPUBs. For example, you might adjust text styling—such as fonts, colors, and sizes—to suit different screens, or use media queries to reduce margins on smaller devices. You can also include vendor-specific rules to handle quirks on specific devices.

Custom CSS is applied to EPUB content based on class names. For text, class names are assigned in text styles' settings, allowing your CSS rules to target specific styles.

The following options are available on the panel:

*   **Embed on add**—when enabled, adding a CSS file to your document copies it into the document. The embedded copy won't change even if the original file is edited. If disabled, adding a CSS file to your document creates a link to the original file.
*   **CSS Files**—lists all the stylesheets you've added to your Affinity document. Each entry lists a filename and a **Remove File**![Image 1](https://images.ctfassets.net/3p2fxa94bzao/3m8ciDtLqf07Yrma1i0j4x/202c1d508104bbb0a1290c5be7725eae/trash_can.svg)  option.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/3ClTCf0TfFFNLrNypEgdf3/af78c7b52d68eea07490c39dffdcad50/add_item_list.svg) **Add CSS File**—lets you choose a CSS file to add to your Affinity document, which will be used in EPUB exports.

 The following options are available on the **Panel Preferences** menu:

*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
