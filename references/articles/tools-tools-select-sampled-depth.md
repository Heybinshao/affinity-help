With the Select Sampled Depth Tool

, you can create a pixel selection based on the focal range in your image.

![Image 2: Focal Depth pixel selection](https://images.ctfassets.net/3p2fxa94bzao/saV5sH1SzhTe8AWmSepoK/b60508ba0deb09941999fd0262c8d066/selectSampledDepth.jpg)

Quick Mask preview of a pixel selection based on focal distance range.

1.   In the **Canva AI Studio**, on the **Layers**panel, select the image layer you want to sample.
2.   Select the **Select Sampled Depth Tool**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/3L7Gp5MuZUNdSKlpxIt3j7/f3e88e81a44b79fe5173e7a0d1566246/depth_selection.svg) .
3.   Click or drag over the area of the image whose depth you want to sample.
4.   Adjust **Near**to control the closest depth range included in the selection.
5.   Adjust **Far**to control the furthest depth range included in the selection.
6.   Click **Apply**.

**Select Sampled Depth** is a premium feature

![Image 4: Canva Pro Feature](https://images.ctfassets.net/3p2fxa94bzao/3cDfFrl1AFrPewvudOOxnG/2310131f39f4a6dd67092f007be0b1b9/crown.svg)

. To use it, you need to be subscribed to the Canva Pro plan. To learn more about the premium features usage visit the [Canva AI & Affinity ML](https://www.affinity.studio/help/canva-ai-canva-ai-affinity-ml/) topic.

This feature uses depth map inference via Canva AI's intelligent technologies to create selections determined by Near and Far threshold values. It allows you to quickly select parts of an image based on their distance relative to the camera or viewpoint. These initial selections can then be refined for precision and subsequently utilized as masks in your workflow.

*   **Near**—determines the focal distance range start position. Increase the value to control the focal distance range, initially starting from the bottom of the frame.
*   **Far**—determines the focal distance range end position. Increase the value to expand the focal range; decrease it to reduce the range.

*   Try using Select Sampled Depth before applying an adjustment layer. This allows you to target the adjustment directly to the pre-determined area of your image based on focal distance.
*   You can also establish depth selection area by dragging directly on the image.
*   Use Quick Mask to preview the selected focal range with an overlay.
