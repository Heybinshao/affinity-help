3.   Transforming lines, curves and shapes

Just as objects can be transformed, the nodes of lines, curves and shapes can be transformed too.

![Image 1: node transform after](https://images.ctfassets.net/3p2fxa94bzao/62vHoWLO4eN3RFt4do3gtv/dab075460a64c10f33e406bbaedebc7a/node_transform_after.png)

Selection box around selected nodes being transformed

![Image 2: node transform before](https://images.ctfassets.net/3p2fxa94bzao/wCNtQ6t6XyRLtNbLa26ML/a09183ea5161d52a41a29ba5f68d99b2/node_transform_before.png)

Selection box around selected nodes being transformed

Node transformation works by forming a selection box around selected nodes. In doing so the box can be transformed in the same way that an object's selection box can be. As a result, the position of nodes relative to each other is altered in the transformation process which reshapes the curve or shape in different ways.

This feature applies to vector content (not raster content), and specifically to curves or closed shapes drawn with the Pen Tool; the nodes of text objects or geometric shapes can also be manipulated but only after they are converted to curves.

Transformation is possible on both two-dimensional and axonometric designs (e.g., isometric).

1.   With the **Node Tool**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/2Tyrn620F9iCYiF39DxVOc/9de008f998af69eafee088eb5a3c5210/node_tool.svg) , select one or more nodes on a curve or shape.
2.   On the context toolbar, enable **Transform Mode**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/2M4Ydf8gakC0UC2AkzJgb2/27bd3ca0aa29a37a170701e86055aadd/transform_mode.svg) .
3.   Resize, rotate or skew either directly on the curve or shape using selection box handles or use the **Transform** panel for absolute precision.

1.   Select two nodes on the shape previously converted to curves.
2.   On the context toolbar, enable **Transform Mode**![Image 5](https://images.ctfassets.net/3p2fxa94bzao/2M4Ydf8gakC0UC2AkzJgb2/27bd3ca0aa29a37a170701e86055aadd/transform_mode.svg) .
3.   With the **⌘** key (Mac) / **Ctrl** key (Windows) pressed, drag any selected node inwards or outwards.

This is particularly effective on simple shapes such as rectangles.

![Image 6: perspective on shapes](https://images.ctfassets.net/3p2fxa94bzao/2ShvzUiK82z6DE4W8AQB5k/f52bd452cdb385dd9c6e906753144f71/perspective.png)
