# Preflight panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-preflight-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Preflight panel

The Preflight panel lets you analyze the contents of a document to ensure it is ready for print or export.

For Mac/Windows:

*   On the **Window** menu, select **Layout > Preflight**.
*   On the **page navigation bar** at the bottom left of Affinity's window, click the preflight icon.

After checks are completed, the panel displays a list of warnings and errors. This lets you pinpoint and correct specific issues where they appear in the document.

The preset that's selected on the panel determines which issue types are listed. Two different icons may be shown to indicate severity:

*   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/2YKwk3FZYGsWZ8z6wjMKDV/dbdcbf346712ec649f7d4cdcc276790d/preflightWarning.svg)  A yellow icon to the left of an entry is a **warning** of an issue that will not affect export.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/2Pliq5AJ1KXiiPy32gKszN/080134b9100c8eaf63848a4fd7db05b8/preflightError.svg)  A red icon to the left of an entry indicates an **error** in the file that will interrupt export.

You can create preflight profiles that specify which error/warning types you wish to check for and how extensive you would like each check to be.

![Image 3](https://images.ctfassets.net/3p2fxa94bzao/2XLuXTwmEh714qaYONrPKP/6d26123960257b3233a3eb084188eda7/moremenuicon.svg)

The following options are available on the panel:

*   **Profile**—select a profile on the pop-up menu, if applicable. The word **Custom** is shown here if settings are adjusted away from the **Default** profile.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/6UxpXBt5miovw347YaOPUz/6f8e3e8d9b379daa0bdc5a3ac6ff23e8/panel_preferences.svg)  The following options are available on the profile's options menu: 
    *   **Edit profile**—clicking this option opens a dialog, allowing you to tailor preflight checking to your needs. From the dialog, you can control the severity level for preflight issues, set values and thresholds that trigger preflight warnings and errors, and control how placed documents work with preflight.
    *   **Create preset**—clicking this option allows you to enter a name and specify profile options via the **Preflight Profile** dialog.
    *   **Manage presets**—clicking this option opens the **Preset manager**, allowing you to manage, rename, delete, import and categorize profiles.

*   **Check**—click to specify when checks should take place. 
    *   **Never**—preflight checking is only carried out once on document loading (background process is disabled).
    *   **Export**—preflight checking is carried out on document loading and prior to print or export.
    *   **Live**—preflight checking is carried out on a continuous basis.

*   **Check Now**—click to check your document for issues right away. Use when **Check** is set to Never or Export.
*   **Issue list**—displays errors and warnings based on the selected preflight profile. Each entry shows (from left to right): 
    *   **Issue**—provides a description of the preflight issue.
    *   **Fix**—for some issues, a **Fix** button is available to directly resolve the issue in-panel.
    *   **Page number**—Shows the page number on which the issue occurs. **M** indicates a master page. Click the number (or M) to jump directly to the page.

![Image 5](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

 The following options are available on the **Panel Preferences** menu:

*   **Sort by page**—when selected (default), the panel will sort errors by page number.
*   **Sort by error type**—when selected, the panel will sort errors by type.
*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
