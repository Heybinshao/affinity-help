3.   Select Sampled Depth

You can create a pixel selection based on the focal range in your image.

![Image 1: Focal Depth pixel selection](https://images.ctfassets.net/3p2fxa94bzao/saV5sH1SzhTe8AWmSepoK/b60508ba0deb09941999fd0262c8d066/selectSampledDepth.jpg)

Quick Mask preview of a pixel selection based on focal distance range.

**Select Sampled Depth** is a premium feature

![Image 2: Canva Pro Feature](https://images.ctfassets.net/3p2fxa94bzao/3cDfFrl1AFrPewvudOOxnG/2310131f39f4a6dd67092f007be0b1b9/crown.svg)

. To use it, you need to be subscribed to the Canva Pro plan. To learn more about the premium features usage visit the [Canva AI & Affinity ML](https://www.affinity.studio/help/canva-ai-canva-ai-affinity-ml/) topic.

This feature uses depth map inference (Machine Learning) to create selections determined by Near and Far threshold values. It allows you to quickly select parts of an image based on their distance relative to the camera or viewpoint. These initial selections can then be refined for precision and subsequently utilized as masks in your workflow.

The **Depth Estimation** model must be downloaded prior to using the feature. The model is available in **Settings > Machine Learning Models** section.

Affinity's Machine Learning functionality is not generative and advocates human creativity.

*   Try using Select Sampled Depth before applying an adjustment layer. This allows you to target the adjustment directly to the pre-determined area of your image based on focal distance.
*   Use Quick Mask to preview the selected focal range with an overlay.

**Select Sampled Depth** is available from the **Pixel > Pixel Selection** menu.

The following settings can be adjusted from the dialog:

*   **Near**—determines the focal distance range start position. Increase the value to control the focal distance range, initially starting from the bottom of the frame.
*   **Far**—determines the focal distance range end position. Increase the value to expand the focal range; decrease it to reduce the range.
