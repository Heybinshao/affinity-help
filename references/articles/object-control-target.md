# Targeting

Targeting allows you to decide the z-order, or nesting, of an object or layer during creation.

By default, drawn or placed objects or layers are positioned:

*   Directly above the current selection.
*   At the top of the layer stack, if there is no selection.

This default targeting behavior can be overridden so that objects or layers are placed or drawn behind the selection, at the top of the layer stack (regardless of selection), or nested inside the selection.

You can override the default behavior for only the next object that is created, or 'lock' an alternative behavior so it's applied to new objects until you decide otherwise.

After creation, you can reposition or nest objects or layers using the Layers panel.

[](https://www.affinity.studio/help/object-control-target/#how-to-change-targeting-behavior)

Desktop app

*   In the Vector Studio   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/2Mejuekyv1U5fQVTYLqGud/edc8c0247142081ce0079de3013e815d/persona_vector.svg)       , on the Toolbar, select an insertion option: 
    *   **Insert behind the selection**  ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/20BvPUP0KMZCIO0wEQYIC6/001d0950cd428725ffd0e3671013a3b1/insert_behind_selection.svg)       
    *   **Insert at the top of the layer**  ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/7mWZHvE7jrn2U2PeQez333/b06df9dce35bc4acfc87ad0a4a6c3c73/insert_top_of_layer.svg)       
    *   **Insert inside the selection**  ![Image 10](https://images.ctfassets.net/3p2fxa94bzao/cT5REul8CU3m4v6JMvgcY/d86463fecf7ca2ced3a8d96185ac3761/insert_inside_selection.svg)       
    *   (Optional) If you wish to use the 'behind' or 'at the top' behavior on an ongoing basis, hold the **⌥** key (Mac) / **Alt** key (Windows).

*   On the **Layer** menu, select **Arrange > Insert** and choose one of the following: 

To revert to default targeting, select the Default menu option.
