# Saving - Affinity Help Center

3.   Saving

When you save your document all information is preserved, allowing you to edit it at a later date.

Saving preserves your project in Affinity's editable format and keeps any edits you've made to date. The process is not to be confused with exporting which outputs the project to a file format (e.g., JPG, PNG, or PDF) for sharing instead.

Your first ever save will offer to save your document to your Documents folder but you can save to any location. Following this, future saves will overwrite the previous version. When saving as a new document, the last 'saved to' location will always be used in the current and later sessions; the new file will not overwrite the saved version.

For single open documents, unsaved changes to a document are indicated by an asterisk in the bottom-right corner of the app. When multiple documents are open, unsaved changes to a document are indicated by an **[M]** (or **[Modified]**) to the right of the document's name on its document tab.

The Affinity document can be titled by populating the **Title** field in the **Fields** panel (**Document Information** section), then double-clicking the field when you have a text insertion point in your document.

A document's history can be saved along with the document, so earlier edits can be returned to even if the document is closed and reopened.

1.   On the **File** menu, select **Save As**.
2.   Adjust the dialog settings as required.
3.   Click **Save**.

*   On the **File** menu, select **Save**.

If you have only made modifications that are supported by an image file type (for example, a JPEG or PNG), then using the **Save** function will simply save over the top of the current file. If you have made modifications that are not supported, such as adding layers, then you can save the image as a file or flatten and merge the changes to the existing file.

Affinity documents are saved with the file extension of .af.
