1.   In the **Pixel Studio**, select the **Adjustment Brush Tool**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/24qfalDe2RscIbJxr7VAhZ/a3dfadf0d5673b60dd0f0373d0e51fc7/adjustment_brush_tool.svg) .
2.   Choose the adjustment you want to apply from the tool’s available adjustment options.
3.   Paint over the areas of the image where you want the adjustment to appear.
4.   Continue painting to build up or extend the adjustment across the required areas.
5.   To remove the adjustment from an area, hold **⌥**(Mac) /**Alt**(Windows) and paint over the area.
6.   Refine the adjustment from the Layers panel or by editing the adjustment layer and its mask.

The tool offers a straightforward alternative to making global adjustments before masking them in or out of specific areas within a composition. Its intuitive design streamlines the process by pre-defining hardness and color properties, allowing you to focus solely on adjusting the Blend Mode and Opacity.

The Adjustment Brush Tool automatically adds an adjustment layer with its corresponding mask to the Layers panel, which facilitates non-destructive workflows where corrections to the initial application of the adjustment can be made by the conventional brushing in and out method.

When you hold **⌥** (Mac) / **Alt** (Windows) while selecting an adjustment from the **Adjustments** panel, the **Adjustments Brush Tool** activates. The new adjustment layer automatically includes a mask, allowing you to apply that effect only to the parts of the image you brush over.

The following are available on the context toolbar:

*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/1DZ3BiVUNw49gMKmpfsxjY/cd1aedf8a4cd6086f5386c7898ba6846/slider_width.svg) **Size**—the brush (stroke) size in pixels. Type directly in the text box or drag the pop-up slider to set the value.
*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/3xN42iDOBeb6NfoMb1Nb3S/676173212d209b96e478c68304a4b2b5/slider_opacity.svg) **Opacity**—how see-through the brush is. Type directly in the text box or drag the pop-up slider to set the value.
*   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/6YT2BTrlyBpYlL2uIKpJtk/b378569b35626974ee7c0f69e47176c7/slider_flow.svg) **Flow**—how fast the brush effect is applied (1% is very slow, 100% is immediate). Type directly in the text box or drag the pop-up slider to set the value.
*   ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/3jeAVEQerphjqYhdiT8BLR/00fd4f48c15e79b94b796a70cf1d9838/slider_hardness.svg) **Hardness**—how hard the edges of the brush are. The brush appears softer as the percentage decreases. Type directly in the text box or drag the pop-up slider to set the value.
*   **More**—click to display the [Brushes](https://www.affinity.studio/help/painting-raster-modify/) dialog to access advanced brush settings.
*   ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/2G6RXXZFvI6HUYZid36cJo/c0e6d0e34e179a4a70883fb3b37709c7/forcepressure.svg) **Force pressure**—click to control brush size with pressure if using a pressure-sensitive device. This overrides brush defaults.
*   **Adjustment**—sets the adjustment to be loaded onto the brush. Choose from the pop-up menu prior to painting.
*   **Add Adjustment**—duplicates the existing adjustment and adds it as a new adjustment layer. Choose the new adjustment from the pop-up menu prior to painting.
*   **Blend mode**—changes how the applied pixels interact with existing pixels on a layer. Choose mode type from the pop-up menu.
*   **Tonal Range**—choose whether to target the Full Range, Shadows, Midtones, or Highlights.
*   ![Image 10](https://images.ctfassets.net/3p2fxa94bzao/48gU5vr3XwFWtBjwhAJWTo/28e1a43a4063087555940fbc383932d4/reset-global.svg) **Reset**—resets brush settings to their defaults.

The following settings are available on a pop-up dialog when accessed via right-clicking on the page:

*   **Rotation**—allows to set nozzle rotation.
*   **Blend mode**—sets the blend mode for the strokes.
*   **Size**—sets the stroke size in pixels. Drag the slider or type in a value in the field.
*   **Opacity**—sets the opacity level for the applied strokes. Drag the slider or type in a value in the field.
*   **Hardness**—sets how hard the edges of the brush are. The brush appears softer as the percentage decreases. Drag the slider or type in a value in the field.
*   **Flow**—controls how fast color is built up under your brush. Drag the slider or type in a value in the field.

*   To use alternate parameters (pre-set and dependent on the adjustment selected), hold the **⌘** key (Mac) / **Ctrl** key (Windows).
*   To modify the brush's Opacity, use numeric keys (**0**-**9**).
*   To adjust the currently selected layer's Opacity, hold the **⇧** key (Mac) / **Shift** key (Win) while using the numeric keys (**0**-**9**).
*   To erase from mask, hold the **⌥** key (Mac) / **Alt** key (Windows). This works as an easy alternative to switching to a Paint Brush Tool and painting in black to hide the adjustment effect from the targeted areas.
*   Hold the **⌥** key (Mac) / **Alt** key (Windows) while brushing to stop auto adjustment dialog.
*   When accessed via right-click on the page, holding the **⇧** key (Mac) / **Shift** key (Windows) restricts the on-dialog **Rotation**setting to 45°. Double-click the rotation point to reset it.
