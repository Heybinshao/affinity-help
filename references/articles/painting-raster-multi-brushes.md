# Multi-brushes - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/painting-raster-multi-brushes/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Photo editing](https://www.affinity.studio/help/photo-editing/)
3.   Multi-brushes

Multi-brushes allow any brush to have one or more additional sub-brushes attached to it. The sub-brushes draw over the base brush as the stroke is applied.

This feature is only available in Affinity for desktop.

![Image 1: Sub brush examples](https://images.ctfassets.net/3p2fxa94bzao/156QiJPoHY3rTD1d6a5ghW/56041721359d01a113bebd2ae10fbd1f/sub_brushes.png)

Single brush strokes (left) and multi-brush stroke equivalent (right).

Multi-brushes introduce more nib variety, randomness and character to your brush stroke appearance (avoiding repetitive texture tiling) so the results are more varied and natural. Each sub-brush can have a fully separate and customizable set of dynamics. You can control where the sub-brushes are drawn on the stroke and how they blend with the main brush.

1.   On the **Brushes** panel, double-click the brush you'd like to modify.
2.   On the pop-up dialog, switch to the **Sub Brushes** tab.
3.   (Optional) Select **Add Bitmap**to create a sub-brush based on an image texture, or **Add Round**to add a rounded nozzle sub-brush.
4.   Double-click the sub-brush.
5.   On the Brush Editing dialog, change sub-brush settings to control: 
    *   **Drawing**—controls where the sub-brush is drawn in relation to the main brush.
    *   **Blending**—controls how the sub-brush blends with the main brush.
    *   **Sync size**—when checked, sets the default width of the stroke to match that of the main brush.
    *   **Sync spacing**—when checked, sets the distance between each nozzle point to match that of the main brush.

6.   (Optional) On the **Brushes** panel, drag another brush you would like to base your sub-brush on.

Instead of creating a multi-brush from an existing brush, you can create a [custom raster brush](https://www.affinity.studio/help/painting-custom-raster-brushes/).

Sub-brushes are applied in order from top to bottom, with each sub-brush affecting those below it, and the combined result blending with the main brush. Sub-brushes can be reordered by dragging within the Sub Brushes window.
