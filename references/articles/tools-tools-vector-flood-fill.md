The Vector Flood Fill Tool

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/6717bROzuxzr7Dcgy9R7Uk/eac1d16192e41dd39197607785ddf380/vector_flood_fill_tool.svg)

 allows you to fill in areas of your design, creating new shapes with solid, gradient or bitmap fills.

The Vector Flood Fill Tool is available by default in Vector Studio.

It can be added to other Studios. See 'Customizing tools' for details.

Once you've loaded a fill, the tool lets you flood areas formed from pre-selected overlapping shapes or curves. You can drag across multiple areas to flood fill or click/tap on individual areas. You can also quickly recolor individual shapes whether selected or not.

For raster work (via Pixel Studio), an equivalent feature is available by using the Flood Fill Tool.

Tool shortcut key: **R**

The following options can be adjusted on the context toolbar:

*   **Insertion mode**—controls where created shapes are placed in relation to original shapes. 
    *   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/WWEuBIIZw5QHcgod21eF5/709aa24a0fb8268c85a639e7c0c4d03e/fill_inside.svg) **Inside**—creates new shapes and places them inside existing shapes where possible.
    *   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/7iCIEKjJJYGOXe2gGFBGCY/621fb8d9da0314d8773bf758371dbe86/fill_inbetween.svg) **In-between**—creates new shapes from areas formed by overlapping shapes and inserts them between the target shape and the shape above.

*   **Fill mode**—three modes let you control how you flood with _semi-transparent_ fills or bitmaps with alpha. Solid fills will always replace any current semi-transparent fill(s). 
    *   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/1T4wVfLKPpcz66WSviRCt0/157752389afdd5821ca2396a4af9a98c/Fill_add.svg) **Add on top**—flood fills are added on top of the current fill, creating a stack that can be managed via the **Appearance** panel.
    *   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/3lDtQpD0vFqKJMdFkXWBty/4b9909cafe0a30076f6509c62dc24320/Fill_smart_refill.svg) **Smart refill**—like Add on Top, but the same fill can only be applied once to the stack; this is useful to avoid flooding with the same fill twice when dragging across areas. For example, the same 'alpha' bitmap texture can't be used multiple times.
    *   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/EE5BD2hEfYflX1lOSU2AQ/f768ee270429d079b08bf3c31402a759/Fill_replace.svg) **Knockout**—the flood fill replaces the current fill.

*   **Options**—filling options let you set how areas are filled: 
    *   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/4f6wpB2I0qioJCkM9fa6qL/4803567121b00c36a45c46d86281de62/fill_to_boundaries.svg) **Fill to Visible Boundaries**—when enabled, the fill extends to the outline of a shape or a curve's path, ignoring edges formed by overlapping. If the fill color across areas is the same then flooding will extend to the whole area automatically. When disabled (default), the edges created by overlapping can be filled to as well as to the outline of a shape or a curve's path.
    *   ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/1P1B9HM3d0pn1cghleVYao/a8102778950a283898883ccea08d469f/set_bitmap_fill.png) **Set Bitmap Fill**—click to load an image as a bitmap fill from Finder or File Explorer; click to apply the fill to an area.

*   **Fit mode**—only displays for applied bitmap (e.g., raster textures) or gradient fills. These can be scaled according to one of several behaviors: 
    *   **Max Fit**—the bitmap/gradient fill is automatically scaled to fill the entire area without distorting it. Some of its contents may be cropped.
    *   **Min Fit**—the bitmap/gradient fill is automatically scaled to be completely visible within the area.
    *   **Stretch**—the bitmap/gradient fill is automatically scaled to be completely visible and fill the entire area. It may be noticeably distorted, depending on the relative proportions of it and the area.
    *   **None**—the bitmap/gradient fill is not scaled to fit the area.

*   To select the Vector Flood Fill Tool, press the **R** key.
