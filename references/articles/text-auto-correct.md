3.   Auto-Correct and Check Spelling While Typing

Affinity includes powerful features for automatic formatting and error correction of your text.

*   The **Auto-Correct** feature aids formatting, and overcomes typographic and common typing errors.
*   **Check Spelling While Typing** underlines spelling mistakes as you type. This identifies possible problem words in your story text.

If you prefer to address spelling issues in larger passages all at once, you can run the spell checker anytime.

Auto-Correct replaces or formats your text automatically as you type. Several types of correction are possible:

*   Correction Rules—format text as numbered or bulleted lists, and control capitalization, superscript use, quotation marks, and tabs.
*   Auto Replace—provides a preset correction list of common typos, with the option of adding your own letter combinations and substitutions to be applied automatically as you type. Word phrases or combinations are also included in auto-correction.
*   Abbreviations—provides a list of abbreviations with their correct letter cases, to prevent inadvertent capitalization of abbreviations when typed in your publication, again with the option of adding your own abbreviations.

If the setting **Change straight quotes to typographic quotes** is enabled, anytime you type straight quotation marks (i.e. the " or ' characters), Affinity will automatically update this to the appropriate 'curly' version of the quotation mark for the text's language.

For Mac: Alternatively, to override auto-correction, press **⌃(ctrl)'** for a straight single quote or **⇧⌃(ctrl)'** for a straight double quotation mark.

This feature, disabled by default, indicates possible problem words in your text using a wavy red underline, and suggests alternative spellings when you **^(ctrl)**-click (Mac) / **right**-click (Windows) a problem word.

1.   In Affinity's **Settings**, select **Auto-Correct**.
2.   Enable or disable each setting as required.

1.   In Affinity's **Settings**, select **Auto-Correct**.
2.   Below the **Replace text while typing** setting, set the **Language** pop-up menu to the language for which you wish to add replacements.
3.   In the **Replace** box, type the text to be replaced. It must be followed by a space or one of most special characters for replacement to occur.
4.   In the **With** box, type the text you wish to be automatically substituted when you type the Replace text in a document.
5.   Select **Add** to add the new entry to the list.

In Affinity's **Settings**:

1.   Select **Auto-Correct**.
2.   In the list of replacements, select the entry you wish to modify.
3.   Edit the text in the **With** box.
4.   Select **Replace**.

In Affinity's Settings:

1.   Select **Abbreviation**.
2.   Click in the box above the list of abbreviations and type your abbreviation.
3.   Select **Add**.

1.    On the word, **^(ctrl)**-click (Mac) / **right**-click (Windows). 
2.    On the menu that appears, do one of the following: 
    *   To replace the word, select an alternative spelling from the suggestions offered.
    *   To ignore the instance of the word (and unmark it), select **Ignore Spelling**.
    *   To ignore all instances of the word (in all documents), select **Learn Spelling**.
