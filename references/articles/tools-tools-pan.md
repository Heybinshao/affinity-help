# View Tool

The View Tool

![Image 5](https://images.ctfassets.net/3p2fxa94bzao/16xclkZTOokIeWj5LpEvxi/915d082ebd3ac857b57212d382357078/view_tool.svg)

 is used to move the visible portion of your document in the document view.

[](https://www.affinity.studio/help/tools-tools-pan/#how-to-use-the-view-tool:)

### How to use the View Tool:

Desktop app

1.   Select the **View Tool**  ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/16xclkZTOokIeWj5LpEvxi/915d082ebd3ac857b57212d382357078/view_tool.svg)       .
2.   Drag on the page to pan around the document.
3.   (Optional) On the context toolbar, adjust **Pan**to change the current zoom level.
4.   (Optional) Use the zoom slider to zoom in or out of the document.
5.   (Optional) From the **Units**pop-up menu, choose the measurement units used for the document view.
6.   Continue panning or zooming until the area you want to inspect or edit is visible.

If you double-click on the View Tool's icon, the zoom will be set to 'Fit'.

[](https://www.affinity.studio/help/tools-tools-pan/#options)

### Options

Zoom options are changed on the context toolbar.

Desktop app

*   Set a zoom level. Select from the pop-up menu or drag the slider.
*   Set the measurement **Units** on the pop-up menu.

[](https://www.affinity.studio/help/tools-tools-pan/#settings)

## Settings

Related behaviors can be adjusted from the app's settings:

Desktop app

*   **Tools > Use mouse wheel to zoom**—takes advantage of the mouse scroll wheel to zoom.
*   **Tools > Use 'scrubby' zoom**—choose whether dragging with the Zoom Tool zooms around the cursor (scrubby zoom) or creates a 'zoom to' marquee.

[](https://www.affinity.studio/help/tools-tools-pan/#shortcuts)

## Shortcuts

Desktop app

*   To select the View Tool, press the **H** key.
*   With another tool active, hold the **Spacebar**and drag to temporarily pan the view.

[](https://www.affinity.studio/help/tools-tools-pan/#see-also:)
