3.   Liquify Studio

A Studio is a workspace that groups tools and panels specific to a design discipline or way of working. The Liquify Studio is a dedicated image warping and transforming environment that uses a combination of Liquify tools. Masking, for selective and targeted transformations, is also possible.

**^(ctrl)**-click (Mac) / **right**-click (Windows) an image layer and select **Liquify Studio**.

Here's a quick overview of some of the ideas you could explore uniquely with the Liquify Studio:

The tools available here affect the image by painting over the pixels and are great for either corrective purposes or to achieve dramatic effects. They can be used in a vast number of scenarios. For example, in food photography, they can be used to stretch food forms to create a more attractive and indulging appearance.

A twirl effect can add a little extra to your composition, and the best approach is usually to apply it in small increments. Try experimenting with this tool on objects, textures and text for a range of creative results.

Example: The Liquify Twirl Tool can be used to prepare backgrounds, modify objects and even transform text, all as the elements of your composition, in preparation for adverts, publications or campaigns.

Liquify Pinch and Liquify Punch tools affect pixels by either pushing them towards you (the former) or outward (the latter). Pinching/punching either increases or decreases the size of any affected area, respectively.

Example: You can use both the Pinch Tool and the Punch Tool to exaggerate portraits for creative, caricature-like outcomes. Eyes, nose and forehead can be enlarged by using the Liquify Pinch Tool's ability to increase the size of a region, whereas reshaping the jaw lines and lips can be performed with the Liquify Punch Tool, as required.

![Image 5: Liquify Twirl Forward Tool after](https://images.ctfassets.net/3p2fxa94bzao/2D1xHHNzvB8SwKY8oLlnrq/bdd74ab1954cefb136da0743b3177393/pinch_punch_liquify_after.jpg)

You can use both destructive and non-destructive approaches when using the Liquify Studio. The latter is achieved by working on a Live Filter Layer and provides all the tools available in Liquify Studio.
