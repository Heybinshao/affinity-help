3.   Draw pencil lines

Use the Pencil Tool to apply pencil lines, giving a hand-drawn effect to your design.

![Image 1: Pencil drawn example](https://images.ctfassets.net/3p2fxa94bzao/6jupDkvpEQr0QlBVevsHeu/bc423ba944e606c7ed594820a641768e/pencil_example.png)

Sculpt mode allows you to redraw or continue the pencil stroke while the stroke is still being drawn or if it is reselected again for further editing. Redrawing is possible between any two points along the stroke to redefine its path, while continuing the pencil stroke extends the stroke by drawing from either end node.

![Image 2: Pencil Sculpt mode redefine and continue after](https://images.ctfassets.net/3p2fxa94bzao/5GMtTba716E73VW6me94Ss/e75511ad4ae47a84cc490f7d3e70c141/sculpt_after.jpg)

Redefining and continuing a pencil stroke using Sculpt mode.

![Image 3: Pencil Sculpt mode redefine and continue before](https://images.ctfassets.net/3p2fxa94bzao/lApTPhVC2tSQXYoEX3njB/a24869cab8888439260c9f89bbc7eb28/sculpt_before.jpg)

Redefining and continuing a pencil stroke using Sculpt mode.

You can also perform advanced editing of the pencil stroke with the **Node Tool**. For example, node and control handles can be repositioned.

More advanced context toolbar **Settings**

![Image 4](https://images.ctfassets.net/3p2fxa94bzao/7e47FwYJ0eBW8yOWy3elSz/813ccca2419c99817334e5bb65c2a0db/cog_icon_2.svg)

 can be used to autoclose pencil strokes and control pressure sensitivity. See the [Pencil Tool](https://www.affinity.studio/help/tools-tools-pencil/) topic.

The stroke stabilizer smooths pencil lines as you draw, helping you to produce a more aesthetically pleasing stroke.

Two modes can be used: **Rope** stabilizer or **Window** stabilizer; the former drags the stroke end by a 'rope' to smooth the stroke, but lets you introduce sharp corners at increasing rope **Length** (radius) values by redirecting the slackened rope; the latter will smooth the stroke by averaging sampled input positions within a **Window** whose size is configurable.

![Image 5: Stabilization](https://images.ctfassets.net/3p2fxa94bzao/3pOHpCBnf6Q6bKMoaSn5iY/b0d67f6ed88d7931a8d771760b647e3e/stabilisation.png)

(A) Pencil line without stabilization, (B) with Rope mode stabilization, (C) with Window mode stabilization and (D) auto-closed pencil line.

When using the Pencil Tool, the following modifier keys can be used to speed up the workflow as you draw:

*   To decrease or increase stroke width by percentage, use the **[** or **]** keys, respectively. For smaller absolute increments instead, use an additional **⇧** key (Mac) / **Shift** key (Windows) modifier.
*   Drawing with the **⌃(ctrl)** key pressed (Mac) or right-mouse button pressed (Windows) creates a straight pencil stroke. Click to start your initial stroke with the key pressed, then click at the position where your stroke is to end.
*   The **⇧** key (Mac) / **Shift** key (Windows) constrains a straight pencil stroke to 45° intervals, including to horizontal and vertical, including when drawing freeform lines.
*   The **⌘** key (Mac) / **Ctrl** key (Windows) temporarily activates the Node Tool.
*   To reposition the stroke on the page, press the **Spacebar** as you draw.
