# Variable fonts - Affinity Help Center

2.   [Page layout](https://www.affinity.studio/help/page-layout/)
3.   Variable fonts

Affinity supports variable fonts, which let you adjust specific design features—known as axes of variation, or simply axes—across a range of values.

![Image 1: Common axes of variable fonts](https://images.ctfassets.net/3p2fxa94bzao/390yQZE1bYxNApBdumsQRQ/0c15c00b05a40273508eef09ecfff9d2/variableFonts01.png)

Examples of font variations along common axes: (A) weight, (B) optical size, and (C) width.

Each axis can be adjusted individually, which allows for many more possible combinations than are available when using static fonts.

Like static fonts, variable fonts include predefined font styles, which are named combinations of values for a font's various axes. When formatting text, they are available via the context toolbar's **Font Style** setting. Elsewhere, you may see them referred to as **named instances**.

Depending on a font designer's intent, you may be able to make other adjustments to a font's appearance, such as:

*   the height of ascenders and descenders, to better fit your chosen line spacing.
*   the style of stem terminals, to choose between straight and swollen.
*   the width of counters—the enclosed and partially enclosed spaces within glyphs—which can affect legibility at your chosen font size.

A large selection of free variable fonts is available from Google Fonts (https://fonts.google.com/variablefonts).

Some axes described in a font's marketing materials may not initially appear in Affinity if the font designer has hidden them.

Affinity follows the OpenType specification, which lets font designers hide some axes. It hides these axes by default, but you can choose to show them.

Hidden axes are often used internally by a font and controlled indirectly by your choices for other axes. Amending them directly may result in reduced typographic fidelity.

![Image 2: Width and weight matrix](https://images.ctfassets.net/3p2fxa94bzao/4uDXGTcM1nbtQdizPNHaql/f2b6e9e90bc40963772a1794d3369c9b/variableFonts02.png)

A matrix of font variations along the (A) width and (B) weight axes.

When you export a document with variable fonts to PDF, Affinity creates a static instance of the font with fixed settings for each variation used. Affinity names these static instances to help you identify the original variable font when you import or place the PDF in a document.

With text selected that is formatted with a variable font:

1.   Do one of the following: 
    *   On the context toolbar, select **Font Variation Settings**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/1JuTlzTBPvMWQEnWJ0bGEk/89b7da4d1b13583e920d13a6620bd6dc/variable_font.svg) .
    *   On the **Character** panel, select **Font Variations**.

2.   (Optional) Enable **Show Hidden Axes**.
3.   Adjust the axes' settings as required.

When adjusting an axis by dragging its slider, holding the **⌥** key (Mac) / **Alt** key (Windows) overrides snapping to the notches to allow for smaller adjustments.
