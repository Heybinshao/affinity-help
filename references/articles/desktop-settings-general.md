# Desktop settings: General - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/desktop-settings-general/

1.   [Help Center](https://www.affinity.studio/help/)
2.   Desktop settings: General

Change options for opening and saving documents, how linked resources update, which language the app's interface uses, and other behaviors that affect your overall workflow across the app.

The following settings are available:

*   **Reopen document(s) on startup**—Choose whether to restore the last session when launching the app. On Mac, disable **Close windows when quitting an application**in System Settings for this setting to take effect.
*   **Limit initial zoom to a maximum of 100%**—Choose whether to limit initial zoom to a maximum of 100% when loading files.
*   **Documents open in a new floating window**—(For Windows) Choose whether documents open in a floating window separate from the app's main window.
*   **Documents open in the current active group**—(For Windows) Choose whether documents open in the current active group, meaning the most recent floating window, or in the app's main window.
*   **Hide file extension**—(For Mac) Select whether to show or hide file extensions.
*   **Automatically update linked resources when modified externally**—Choose whether to update Affinity with any linked images or documents if they are modified externally in their original file locations.
*   **Save thumbnails with documents**—You can exclude your thumbnail from being stored with your document.
*   **Enable "Save" over imported PSD files**—Choose whether to overwrite imported PSD files when using the **Save**command, rather than creating an .af file. We recommend reading the warning provided in the dialog before selecting this option.

*   **Preserve Unicode breaks on copy plain text**—Choose whether your pasted plain text retains breaks' consistency prior to further formatting.
*   **Insert filler text as text**—Choose whether to insert filler text as editable text.
*   **Import PSD text as text rather than bitmap**—Choose to open PSDs with editable text objects.

*   **Copy items as SVG**—Copies content to the clipboard in SVG format for higher-fidelity pasting as vector objects in other apps. When disabled, objects are copied to the clipboard in Affinity format.
*   **Prefer to keep selection after delete**—Choose whether to keep selection after deleting an object. The object below the deleted object will be selected.
*   **Prefer metafile to raster when pasting from external application**—(For Windows) Choose whether to prefer metafile to raster when pasting from external app.
*   **Load metadata from XMP sidecars**—Choose whether to import metadata from an XMP sidecar file automatically when opening the corresponding image, provided they have the same base filename and the sidecar file has the .xmp file extension (in lower case).
*   **Refine HEIC depth maps**—Choose whether to automatically refine HEIC depth maps.
*   **Apply gain maps**—Loads HEIF and JPG files that contains gain maps as HDR.
*   **Import PSD smart objects where possible**—Choose whether to allow Affinity to import smart objects; by default, Affinity converts Smart Objects in Photoshop documents to pixel layers. Note that smart objects that are linked, meaning their content comes from an external file, are not converted to embedded documents.
*   **Show Home Screen on startup**—Choose whether to display the Home Screen when you launch Affinity.
*   **Additional lens profiles will be loaded from the Lens Profiles folder on startup**—You can open your app's lens profiles folder, where you can view, add and/or remove the currently pre-installed lens profiles.
*   **Store fonts (*.affont) will be loaded from the Affinity Fonts folder on startup**—You can open your app's fonts folder, from which Affinity Font (.affont) files (previously installed by dragging onto the app) can be removed to uninstall them. (Affinity Fonts installed via the Account feature can be uninstalled using that feature.)
*   **Language**—Sets the user interface language independently of the operating system. Select from the pop-up menu.

*   For Mac: From the Affinity app menu, select **Settings**.
*   For Windows: On the **Edit** menu, select**Settings**.
