The Pen Tool

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/5yh8WdvU7rTqDSqQzwd7ds/3dec05a9bf475b37380b1f79e99125ee/pen_tool.svg)

 is used to precisely draw curves, closed shapes and straight lines.

![Image 2: Node Types](https://images.ctfassets.net/3p2fxa94bzao/68nDrXGW0IFv8HUXLC2YKP/14a8753d7c6edea1ae35539da8c50353/node_types.png)

Pen Mode, Smart Mode, Polygon Mode, Line Mode

The Pen Tool is available by default in Vector, Pixel and Layout Studios.

It can be added to other Studios. See 'Customizing tools' for details.

It lets you draw straight lines or curves as a single segment (like a section) or multiple segments. Segments are delimited by 'on-curve' nodes which possess 'off-curve' control handles. These handles can lengthened, shortened and moved to control the shape of the curve.

All Pen Tool General settings are remembered across documents and sessions.

Tool shortcut key: **P**

The following options can be adjusted on the context toolbar:

*   **Mask**—converts the shape into a protected area, masking the remaining layer content.
*   **Selection**—converts the shape into a selection.
*   **Fill**—click the color swatch to display a pop-up panel to update fill color.
*   **Stroke**—click the color swatch to display a pop-up panel to update stroke color.
*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/3rYvQ5X8bUYnIRpXvMBBlv/ee8198bb2731db49a0f3ec426d194fb2/stroke_width.svg) **Stroke width**—set a stroke width for the stroke using direct input or slider.
*   ![Image 4: Edit stroke settings](https://images.ctfassets.net/3p2fxa94bzao/LAIAniI5tfK3bknzYOUQB/9af81e28e315cea94436ab657c986f85/stroke.svg) **Edit stroke settings**—set the stroke style, width, joins, cap ends, order and arrowhead settings via a pop-up panel.
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/5SCWES5nj7i7v5CYh09fON/55f74a43d6e63ed426c7f31952051153/pen_mode.png) **Pen Mode**—the most powerful and precise mode used to create Bézier curves and shapes with smooth or sharp corners and nodes.
*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/5GBJ3hAEklQ9OB7JegR1Mx/ffa029d660ca57f2ba49581c12b758c9/convert_smart.svg) **Smart Mode**—create flowing curves and shapes by clicking and placing nodes.
*   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/7xL3MYnOxsff1SMhZ0KI4Q/6da01dd27dd8522d65c40e3a6ad83deb/polygon_mode.svg) **Polygon Mode**—use to draw straight lines with sharp nodes or shapes with straight edges.
*   ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/4UlRc9n52SzJGlsXOu3fEQ/c2d46fe177a4e49270e62191ff9b1863/line_mode.svg) **Line Mode**—use to draw single-segment straight lines that self terminate.
*   ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/1u8ioE0kk2O3hClti5GNFQ/cac15e5ba603ae52943e4d8e4bf2e2d7/convert_sharp.svg) **Sharp**—converts the selected node to a sharp node (for cusped corners).
*   ![Image 10](https://images.ctfassets.net/3p2fxa94bzao/1GgxCLnnzKXjbBMjq00c4O/c37f54e0eda9d66eaced34ad881c1a37/convert_smooth.svg) **Smooth**—converts the selected node to a smooth node (for a Bézier curve).
*   ![Image 11](https://images.ctfassets.net/3p2fxa94bzao/5GBJ3hAEklQ9OB7JegR1Mx/ffa029d660ca57f2ba49581c12b758c9/convert_smart.svg) **Smart**—converts the selected node into a smart node (for a best-fitting curve).
*   ![Image 12](https://images.ctfassets.net/3p2fxa94bzao/1n9wi7A7Cwn1HEMNhetiwZ/82695e97aeb8e8179cdcb9521ffb7c5b/split_curve_at_selected_node.svg) **Action**—manipulates the curve(s): 
    *   ![Image 13](https://images.ctfassets.net/3p2fxa94bzao/1n9wi7A7Cwn1HEMNhetiwZ/82695e97aeb8e8179cdcb9521ffb7c5b/split_curve_at_selected_node.svg) **Split Curve** adds a new node at the midpoint of one of the curve segments of the currently selected node, depending on the current curve orientation (indicated by a red-line indicator). Use **Reverse Curve** to change this curve orientation.
    *   ![Image 14](https://images.ctfassets.net/3p2fxa94bzao/3iEJTLrCxMb4ZR30sc8BZZ/e167fce74351f40bd361b8f51b32a074/action_break_curve.svg) **Break Curve** opens the shape at the selected node.
    *   ![Image 15](https://images.ctfassets.net/3p2fxa94bzao/2Gq5XAQINSYoHvUFwH5ZP5/b8478e2d20a8db7b1c48fba54d272f78/action_close_curve.svg) **Close Curve** joins the start and end nodes to create an enclosed shape.
    *   ![Image 16](https://images.ctfassets.net/3p2fxa94bzao/5NIosVN2amJnLIl9SsALzs/fa6749b753448d285834853da54cc9ff/action_smooth_curve.svg) **Smooth Curve** modifies a line or shape, by adding and removing nodes, to make it rounder and softer.
    *   ![Image 17](https://images.ctfassets.net/3p2fxa94bzao/6RJ3G6uqVxyuf2swmbJMaY/dd5e0d6f023a5f1e4e7e8e6c964c39a5/action_join_curves.svg) **Join Curves** connects two separate curves together to make one curve. Both curves need to be selected.
    *   ![Image 18](https://images.ctfassets.net/3p2fxa94bzao/4aEenWCp3fgkYVwRQQF18p/5aec5f6e69b82891e16fd078aec2ddf8/action_reverse_curves.svg) **Reverse Curves** reverses the direction the curve was drawn in.

*   ![Image 19](https://images.ctfassets.net/3p2fxa94bzao/6fO8gzxjlWSt51XW7W46Ki/ea5331b1921c1da85958815970e1cd76/fill_stroke.svg) **Use line style**—when enabled, the outer line of the shape drawn can be edited using the options in the **Stroke** panel.
*   ![Image 20](https://images.ctfassets.net/3p2fxa94bzao/XVmIokaRehxGTwCGRU40b/addc7bc4201864a8f25e973bfbb30b88/use_fill_style.svg) **Use fill**—when enabled, the concave area of the line is filled with the color you select from the revealed **Fill** color swatch as you draw.
*   ![Image 21](https://images.ctfassets.net/3p2fxa94bzao/7e47FwYJ0eBW8yOWy3elSz/813ccca2419c99817334e5bb65c2a0db/cog_icon_2.svg) **Settings**—for node snapping and alignment: 
    *   **Align to nodes of selected curves**—aligns any moving node you drag to any other node on the same or a different curve.
    *   **Snap to geometry of selected curves**—will snap moving node to the same or different curve's path or node.
    *   **Snap all selected nodes when dragging**—will snap multiple selected nodes, when dragging, to a "target" node on any selected curves.
    *   **Align handle positions using snapping options**—will snap a control handle using any of the snapping criteria currently set in Global snapping, e.g. to grid, guide, object geometry, key points, spread, margin, etc.
    *   **Perform construction snapping**—allows control handle snapping independently of the global [snapping](https://www.affinity.studio/help/design-aids-snapping/) options: 
        *   inline with adjacent node.
        *   to 90° from inline.
        *   to reflected angle with adjacent control handle.
        *   parallel to adjacent control handle.
        *   90° to parallel control handle.
        *   to logical triangle.

    *   ![Image 22](https://images.ctfassets.net/3p2fxa94bzao/5Gtd0Q6NyDJis4bL5REgP9/ef9966bad46dee0847a3ae15e114c5c4/show_orientation.svg) **Show curve orientation**—displays the segment leading up to the end node in red to help visualize the direction of the closed shape's outline (used for winding fill mode); the drawing direction is away from the red-line indicator.
    *   **Preserve selection when creating new curves**—when enabled, it keeps the previously drawn curve(s) selected so that their nodes and geometry can be more easily snapped to as you draw.
    *   **Add new curve to selected curves object**—when enabled, the mode creates additional curves on the same layer as the initial curve—this gives better management of a multitude of curve layers. For example, the character 'a' is made up of two curves that can be a single 'curve object'. On the **Vector** menu, select **Separate Curves** to separate each curve into separate layers or **Merge Curves** to consolidate selected curves into one layer.
    *   **Rubber band mode**—previews the next segment to be drawn before placement of the new leading node; uncheck to hide the preview. For Mac only, use with the **⌃(ctrl)** key pressed for straight-line segment previews.

*   To select the Pen Tool, press the **P** key.
