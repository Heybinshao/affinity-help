3.   Grids

A non-printing, non-exporting grid can be displayed to help you to lay out items accurately on your page or artboard.

![Image 1: Automatic grid](https://images.ctfassets.net/3p2fxa94bzao/587pEn6uQuHCdxmCBihhFJ/4ecebe47c0ad612f66d9acb7d47474a6/grids_designer.png)

![Image 2: Pixel grid in the Pixel Studio](https://images.ctfassets.net/3p2fxa94bzao/6U1r0408JzQgrqfNoKq3Bp/e53582fdd3690fdf703d3dab3b834944/grids_photo.png)

![Image 3: Fixed grid in the Layout Studio](https://images.ctfassets.net/3p2fxa94bzao/51x4H5gY92CjhlGMk1rGst/292ca9f6485e8edacfa1f06913c0ffde/grids_publisher.png)

The grid is overlaid over your page or artboard to help you align content. They are gray by default but can be any color you choose.

Grids can be **automatic** or **fixed**—the former (as default) changes the frequency of grid subdivisions as you zoom in/zoom out, the latter always keeps the grid frequency constant (irrespective of zoom level).

Grids work best when combined with snapping, in particular when the Snap to Grid option is enabled. They can be based on any document unit and will line up perfectly with [rulers](https://www.affinity.studio/help/design-aids-rulers/) (when switched on).

In the Layout Studio

![Image 4](https://images.ctfassets.net/3p2fxa94bzao/4BbduuJ3zEK1FT2Ohg1aLs/98f305a0ad579187aa758ae37dc956e6/layout_studio.svg)

, grids default to the applied master page or spread grid settings but can be overridden by selecting a page or facing page spread and tweaking grid settings. Optionally, a grid can be applied to an individual page or spread which doesn't use master pages.

*   On the **View** menu, select **Show > Grid**.

With the **Zoom Tool**

![Image 5](https://images.ctfassets.net/3p2fxa94bzao/6jmWPErECQEdSLoFK86wRd/4df92fffdb8d65af90c0a607ed39cdb2/zoom_tool.svg)

 selected, do one of the following:

*   Zoom in to see smaller grid divisions.
*   Zoom out to see larger grid divisions.

At all zoom levels the grid shows as grid 'blocks' further split into grid subdivisions.

1.   On the **View** menu, select**Grid and Axis**.
2.   On the dialog, select **Basic** mode.
3.   Set the **Spacing** and **Divisions** values.
4.   Click **Close**.

1.   On the **View** menu, select **Grid and Axis**.
2.   On the dialog, click the **Grid lines** or **Subdivision lines** swatch to display a pop-up panel to set the line color(s).
3.   Drag the sliders to set the opacity of either, or both, line colors.
4.   Click **Close**.

For a different color or opacity for the subdivision lines compared to the main grid lines, click the **Link the grid colors** symbol next to the swatches.

1.   On the **View** menu, select **Grid and Axis**.
2.   On the dialog, select **Advanced** and uncheck **Uniform**.
3.    Do one of the following: 
    *   Set the **Spacing** and **Divisions** for the first and second axis.
    *   Select **Fixed aspect ratio**, set the **Spacing** and **Divisions** for the first axis and then set the **Aspect ratio** and **Divisions** for the second axis.

4.   Click **Close**.

1.   On the **View** menu, select **Grid and Axis**.
2.   On the dialog, select **Advanced** and uncheck **Uniform**.
3.   On the **Grid type** pop-up menu, select **Two axis custom**.
4.   Set the **Angle** of either axis.
5.   Click **Close**.

You can rotate a grid with the axes handles—useful when adjusting a grid by eye.

When working with images at large magnification levels, zooming in an undetermined amount, a pixel grid serves as a handy visual aid. Pixel art and working with object detail are just a couple of examples of its use. A different grid color can also aid work where there is little color variance in the image.

1.   On the **View** menu, select **Grid and Axis**.
2.   On the dialog, enable **Show Pixel Grid**.
3.   (Optional) Modify **Pixel grid lines** color for better grid visibility.

From **Document > Setup > Snapping**, enable **Force Pixel Alignment** to ensure you are snapping to the pixel grid while working.

*   On the **View** menu, select **Show > Pixel Grid**.
