3.   Building shapes with the Blob and Erase brushes

The Vector Blob Brush Tool and Vector Erase Brush Tool offer a brush-based approach to building vector shapes.

![Image 1: A pink canvas split into two sections. On the left, vector brush strokes form clouds and a bare tree, with the Vector Blob Brush and Vector Erase Brush tool icons visible. On the right, a colourful illustration of a person walking multiple dogs through a purple forest landscape.](https://images.ctfassets.net/3p2fxa94bzao/394mO2HSHWa6RnhNpCoNrx/6643537cc11fce9d6194a9f44d173bd2/vectorBlobBrush.png)

Vector artwork created using the Vector Blob Brush and Vector Erase Brush tools.

The Vector Blob Brush Tool draws filled vector curves directly. Brush strokes that intersect the selected object are added to it, forming a single curve. If the strokes do not intersect the selected object or no object is selected, a new filled curve is created on a new layer.

The Vector Erase Brush Tool removes areas from an existing vector object using the same brush-based approach.

The tools can modify existing vector objects, including those created with the shape tools and the Shape Builder Tool. This lets you use different techniques together.

Brush strokes affect existing objects only if the objects are selected.

The two tools work together. With either tool active, you can hold a modifier key to temporarily use the complementary tool's behavior. This lets you build up or remove areas, correcting and refining as you work.

3.   Drag over the area you wish to remove from the object. Repeat as needed to refine the shape.

*   To draw a straight line constrained to 45° increments, hold the **⇧** key (Mac) / **Shift** key (Windows), then drag on the page with the left mouse button.
*   To draw a straight line at any angle, hold the **⌃(ctrl)** key (Mac) / right mouse button (Windows), then drag on the page with the left mouse button.
*   To decrease or increase the nozzle size, use the **[** and **]** keys.
*   To temporarily use the complementary tool's behavior, hold the **⌥** key (Mac) / **Alt** key (Windows).
*   To temporarily switch to the Node Tool, hold the **⌘** key (Mac) / **Ctrl** key (Windows).
