# Filler text - Affinity Help Center

3.   Filler text

For frame text, if you're designing before meaningful copy has been written, you can use filler text as placeholder copy to help you progress with your project.

Filler text is inserted as a field containing **Lorem Ipsum** text. The text autofills its text frame, even if the frame is resized, and repeats as necessary.

As a field, filler text is not directly editable and can only be selected and formatted in its entirety. Filler text can be changed (expanded) to normal editable text on a per-field basis. Optionally, you can choose to insert filler text as editable text in the first place.

The factory default words that make up filler text can be replaced with your own custom text. For spell-checking purposes, you can set different text for each language.

When filler text is inserted, its starting sentence is chosen randomly. Custom filler text should be multiple sentences and/or paragraphs long to increase the likelihood that different text frames (and linked text frame sequences) begin with different sentences, avoiding a repetitive appearance.

When filler text is customized, it is applied only to the current document by default. Custom filler text can be saved as the default for all new documents, and optionally can be applied to existing documents.

1.   Create an insertion point in a text frame.
2.    Do one of the following: 
    *   On the **Text** menu, select **Insert > Filler Text**.
    *   Within the text frame, **^(ctrl)**-click (Mac) / **right**-click (Windows) and select **Insert Filler Text**.

A check mark next to the option indicates the selected text frame already contains filler text.

1.   Select the text frame containing filler text.
2.   On the **Character** panel, set the **Spelling** option to the required language.

1.   Select the **Frame Text Tool**![Image 1](https://images.ctfassets.net/3p2fxa94bzao/1beIzVbPUpjWtvjB9f9uIQ/9643c257468e143cd018b12cb31d9a4a/frame_text_tool.svg) .
2.    On the filler text, **^(ctrl)**-click (Mac) / **right**-click (Windows) and select **Expand Field**. 

Filler text can be automatically expanded when inserted by enabling **Insert filler text as text** in Affinity's **General** settings.

In Affinity's **Settings**:

1.   Select **Filler Text**.
2.   Select a language from the pop-up menu.
3.   Type or paste your custom text into the text box.

When you customize filler text in this way, existing instances of the previous filler text in the current document auto-update to match.

To manage filler text for the selected language, choose one of:

*   **Save as Default**—Sets the custom text as the default filler text for new text frames in the current document and subsequently created documents. Other existing documents are unaffected.
*   **Revert to Default**—Reverts any modifications to the custom text, and any existing instances of the custom text in the current document, to the saved default.
*   **Factory Reset**—Sets filler text back to Affinity's original Lorem Ipsum text in the current document and subsequently created new documents. Filler text in other existing documents is unaffected.
