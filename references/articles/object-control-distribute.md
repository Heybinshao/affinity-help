# Distributing/spacing - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/object-control-distribute/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Distributing/spacing

Objects and layer content can be distributed or spaced evenly within object selection bounds.

The spacing of objects ensures there is an equal distance between object _edges_.

![Image 1: Spacing](https://images.ctfassets.net/3p2fxa94bzao/59opBCnBAYwzvwKrRwxxfi/1c49464c8d1dd7a16be40c7c4c8d6725/spacing.png)

Before and after spacing.

Instead of spacing being calculated between selection bounds, you can also control spacing in relation to any targeted key object in the current object selection.

![Image 2: Spacing using key objects](https://images.ctfassets.net/3p2fxa94bzao/6OuSufldQtg18WcS5SEoik/f13156585c26d8435975e68f60de0871/keyobject_spacing.png)

A targeted key object (A) used to set spacing horizontally from the rightmost item (B; with ⌥ (Mac) / Alt (Windows) modifier applied) or the leftmost item (C).

1.   Select multiple objects or layer content.
2.   From the **Layer** menu's **Alignment** submenu, select a Space or Distribute option.

1.   Select multiple objects or layer content.
2.   On the Toolbar, click Alignment ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/2sBtuXOz6xHeHKSpdRiV0E/52b485eb1e9c69adb61dfee2adefd40f/arrange.svg) , then choose **Space Horizontally**![Image 4: Space Horizontally](https://images.ctfassets.net/3p2fxa94bzao/7Gf2oAR3MFpAZFPeawdVfN/dc366ff9436d6334d734bf6196634e13/space_horizontally.svg)  or **Space Vertically**![Image 5: Space Vertically](https://images.ctfassets.net/3p2fxa94bzao/7dDWSQAguao9gyl0H9tl9k/8bc96b0f38764f674e2e629518b98a11/space_vertically.svg)  from the end of the icon row.
3.   Click **Apply**.

With **Auto Distribute** selected (default), the items are spaced evenly within the selection bounds. If this option is off, a specified distance between items can be set in an input box adjacent to the option.

1.   Select multiple objects.
2.   With the **⌥** key (Mac) / **Alt** key (Windows) pressed, click the target object. The key object will then possess a strong outline.

1.   Ensure a key object is targeted as above.
2.   On the Toolbar, click **Alignment**![Image 6](https://images.ctfassets.net/3p2fxa94bzao/2sBtuXOz6xHeHKSpdRiV0E/52b485eb1e9c69adb61dfee2adefd40f/arrange.svg) , then:

*   To space in relation to the leftmost object: select **Space Horizontally**![Image 7: Space Horizontally](https://images.ctfassets.net/3p2fxa94bzao/7Gf2oAR3MFpAZFPeawdVfN/dc366ff9436d6334d734bf6196634e13/space_horizontally.svg)  or **Space Vertically**![Image 8: Space Vertically](https://images.ctfassets.net/3p2fxa94bzao/7dDWSQAguao9gyl0H9tl9k/8bc96b0f38764f674e2e629518b98a11/space_vertically.svg) from the pop-up **Alignment** dialog.
*   To space in relation to the rightmost object: with the **⌥** key (Mac) / **Alt** key (Windows) pressed, select **Space Horizontally** or **Space Vertically** from the pop-up **Alignment** dialog.
