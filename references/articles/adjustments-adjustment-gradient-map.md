2.   Gradient map adjustment

The Gradient Map adjustment

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/4QzExLnigChoVDdpYzksaS/ae91e28f115d20a86580d7bb5547bbb1/gradient_map_adjustment_type.svg)

 maps the equivalent grayscale range to a specified color gradient. This provides an effective and creative way of recoloring an image.

![Image 2: Gradient Map after](https://images.ctfassets.net/3p2fxa94bzao/62c1Xj5yS2Z6iohTKzFFRa/e9576a619715878367f6b571a4b4fdbc/adjustment_gradientMap_after.jpg)

![Image 3: Black & White before](https://images.ctfassets.net/3p2fxa94bzao/5NXgmzFzXKve50c596UktV/3587c26a6e00f462f4d50c450a098ea1/adjustment_base.jpg)

*   **Add Preset**—adds custom adjustment settings as a preset for later use.
*   **Merge**—merges the current adjustment layer with the layer immediately below it.
*   **Delete**—closes the settings and deletes the adjustment layer, removing the adjustment.
*   **Reset**—reverts all adjustment settings to their defaults.
*   **Gradient Map Range**—allows you to specify points of color graduation to be applied onto your image.
*   **Position**—sets point position by either using a slider or entering a value.
*   **Insert**—adds a point to the map.
*   **Delete**—deletes the selected point from the map.
*   **Copy**—duplicates the selected point with its original settings.
*   **Reverse**—reverses map points right to left.
*   **Opacity**—sets the level of visibility of the adjustment.
*   **Blend Mode**—controls how the adjustment interacts with the layers below it.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/5aLt8lzEcmovjtpJrbbZFI/521800938c5909fe2677c5c56dc42a30/settings_cog_layers.svg) **Blend Options**—click to access a dialog for setting the blend options, blend gamma and antialiasing settings for the selected layer.

To create a black and white output, ensure the gradient contains only grayscale values.

*   On the **Layers** panel, click **Adjustments**![Image 5](https://images.ctfassets.net/3p2fxa94bzao/4ZFx9I9M7MiUBPmytBqZrt/cad5a29a5e39b1b3faa42c5fa29402f3/add_adjustment_layer.svg)  and select **Gradient Map**.
*   On the **Adjustment** panel, select **Gradient Map**![Image 6](https://images.ctfassets.net/3p2fxa94bzao/4QzExLnigChoVDdpYzksaS/ae91e28f115d20a86580d7bb5547bbb1/gradient_map_adjustment_type.svg)  and then click on a preset to modify, as required.
*   On the **Pixel** menu, select **New Adjustment Layer > Gradient Map**.

The **Adjustment** panel is not visible by default. To enable it, navigate to the top menu and select **Window > Pixel > Adjustment**.
