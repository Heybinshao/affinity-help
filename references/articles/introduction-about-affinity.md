# About Affinity - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/introduction-about-affinity/

Affinity provides an award-winning integrated graphic design, photo-editing and publishing solution on the very latest Mac and Windows desktop platforms.

Affinity development started in 2014 with the intention of offering unparalleled performance on the very latest hardware platforms. Developed natively on Mac, and soon after Windows, the core product set targeted three key creative sectors—graphics design, photo editing and page layout. The product set comprised of:

*   Affinity Designer
*   Affinity Photo
*   Affinity Publisher

Affinity is a multi-discipline design app designed for three main design sectors—vector design, photo editing, and page layout.
