# Color panel - Affinity Help Center

3.   Color panel

The Color panel is used to choose color for various tools, selected objects and layer content.

For Mac/Windows: On the **Window** menu, select **General > Color**.

Using the panel, you can:

*   Choose colors for the stroke and fills of objects, and foreground and background color for layers.
*   Set the color model for applying color.
*   Set opacity and noise for the current color.
*   Pick (sample) color from the current document.
*   Save colors to the Swatches panel for future use.

The following options are available on the panel:

*   Color selectors (Stroke/Fill or Foreground/Background, depending on Studio, with color 'none' swatch and 'swap' arrow)
*   HSL values
*   Switch between opacity/noise
*   Panel Preferences
*   Color picker and picked color swatch
*   Black and white color swatches
*   Recent colors swatches
*   Saturation/Lightness control
*   Hue control
*   RGB Hex value
*   Opacity / Noise control

The following preferences are available on the **Panel Preferences**

 menu:

*   Color space visualisation preferences: 
    *   **Wheel** (HSL Color Wheel).
    *   **Sliders** for RGB, RGB Hex, HSL, CMYK, LAB and Grayscale color modes.
    *   **Boxes** (Hue, Saturation, Lightness only).
    *   **Tint**.
    *   **8 bit**, **16 bit** or **Percentage** (for Sliders only).

*   **Copy Color to Clipboard as Hex**—calculates the current color's Hex value and adds it to the clipboard. This is useful for web developers, to standardize on colors between graphics and HTML coding in a web environment.
*   **Add Color to Swatch**—adds the current color to the currently loaded palette on the Swatches panel.
*   **Add Chord to Swatch** pop-up menu—adds a chord of the current color to the currently loaded palette on the Swatches panel.
*   **Advanced**—presents a flyout of chord types below the panel that changes according to the currently set color. Locking using **Lock**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/52XYdXlyLW1ZAzUYGK6kqf/48bc9cd93adcdbf14804e0cab02cbcf0/lock_layer.svg)  lets you apply colors to objects from a chosen chord type.
*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.

On the **HSL Color Wheel**, **⇧**-dragging (Mac) / **Shift**-dragging (Windows) the outer Hue ring will snap to 45° intervals.

**⇧**-dragging (Mac) / **Shift**-dragging (Windows) a **Color** panel slider will move all of the sliders at once (for RGB and CMYK color space only). This can be useful for deciding on a lighter or darker shade of the color in place.

Set the stroke (background) and fill (foreground) color selectors to black or white, respectively, by pressing the **D** key. This affects any vector objects that are selected.

Switch between the color selectors by pressing the **X** key.

To honor the opacity and/or noise already applied to a vector shape, line or text (i.e. only the color will update), hold down the **⌥** key (Mac) / **Alt** key (Windows) when selecting a new color.
