# Setting bleed - Affinity Help Center

2.   [Export, share, and publish](https://www.affinity.studio/help/export-share-publish/)
3.   Setting bleed

For professional printing, bleed extends the printable area beyond the edges of your intended page size. It allows for printing on larger sheets and then trimming, so your design fills pages from edge to edge.

![Image 1: Bleed guides](https://images.ctfassets.net/3p2fxa94bzao/6IzCuhPV0puAchwiE5OW41/cd20e30eb55c11ccff9dd41b7a0cde44/bleedguide.png)

3 mm bleed guides with a placed image snapped to them.

Affinity lets you set the bleed distance at each page edge, so you can more easily design into the bleed area. You can show bleed guides to help position elements—typically images—in the bleed area. Their color is customizable.

With bleed guides enabled, pages are shown extended by your specified bleed distance. This helps ensure elements fill the bleed area, so they'll run to the edge of the trimmed page.

To allow for inaccuracies in the trimming process in professional printing, it's a good idea to extend elements beyond the 'trim edge' (TrimBox), i.e. the page dimensions defined in Document Setup.

You can also choose whether the bleed area is included when printing or exporting, by enabling the **Include bleed** setting.

![Image 2: Bleed on output](https://images.ctfassets.net/3p2fxa94bzao/2ffRhhSvNPQH9GjLqsaitx/6e1fd586a9bc5805983f09eb791d0592/bleedoutput.png)

Bleed enabled on PDF export, extending over crop marks.

For single pages, the terms “Left” and “Right” bleed are used, while for facing-page spreads the terms “Inner” and “Outer” are used. For the latter, Inner bleed is only relevant for first and last single pages or when exporting (printing) as single pages (rather than spreads).

1.   On the **File** menu, select **New**.
2.   On the dialog that appears: 
3.   Select **Layout** or **Design** as the document type.
4.   In the **Bleed** section, do one of the following: 
    *   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/2ty4rrvXJAKOQ9A7KNkpeq/3550d3ea165c5089bd090a4a8ece44e2/chainlinkconnected.svg)  For the same bleed value on all page/artboard edges: Enable the Link symbol to the right, then set any bleed value. The other values will update to match.
    *   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/5tDDIwcwpJRIpRHFMB12xq/ab33de5f69c7cc43582ad4ee5fa201d0/chainlink.svg)  For different bleed values on each page or artboard's edges: Disable the Link symbol to the right, then set each bleed value independently as needed.

1.   On the **Document** menu, select **Setup > Document Setup**.
2.   On the dialog that appears, select the **Bleed** tab, then do one of the following: 
    *   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/2ty4rrvXJAKOQ9A7KNkpeq/3550d3ea165c5089bd090a4a8ece44e2/chainlinkconnected.svg)  Enable the Link symbol on the right, then set any bleed value. The other values will update to match.
    *   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/5tDDIwcwpJRIpRHFMB12xq/ab33de5f69c7cc43582ad4ee5fa201d0/chainlink.svg)  Disable the Link symbol on the right, then set each bleed value independently as required.

*   On the **View** menu, select **Show > Bleed**.

The guides are shown as an outline that extends beyond the page edges by your chosen bleed values.

1.   On the **Document** menu, select **Setup > Document Setup**.
2.   On the dialog that appears: 
    1.   Select the **Bleed** tab.
    2.   Click the **Color** swatch, then select a color.
    3.   Click back on the dialog, then click **OK**.

1.   On the Toolbar, click the down arrow next to **Snapping**![Image 7](https://images.ctfassets.net/3p2fxa94bzao/4ZvAvUGmRtnDVzuGQvtjnT/77b8a44ec48b78f76d4cc9e53107331d/snapping.svg) .
2.   On the dropdown that appears, check the **Enable snapping** and **Snap to spread** options.

Snap to spread applies snapping equally to spread edge, page edge, and bleed equally.

When printing from your device

1.   On the **File** menu, select **Print**.
2.   Select **Bleed and Marks**. (For Mac: You may need to click **Show Details** to see this.)
3.   Enable **Include bleed**.
4.   Adjust other printer settings as needed.
5.   Click **Print**.

When exporting a PDF for professional printing:

1.   On the **File** menu, select **Export > Export**.
2.   On the dialog that appears: 
    1.   On the left, select your required PDF/X preset.
    2.   On the right, enable **Include bleed**.
    3.   Adjust other export settings as needed.
    4.   Click **Export**.
    5.   Name the file, navigate to the folder you want to save in, then click **Save**.
