# Anchors

Anchors can be used as targets of hyperlinks. They can be inserted into frame, artistic and table text, and on objects such as picture frames.

If you want to create a hyperlink to a specific point in your publication's content, i.e. an object or a position in text, you can insert an anchor at that point in advance.

Anchors are automatically named but can be renamed later.

[](https://www.affinity.studio/help/advanced-anchors/#using-hyperlinks-and-anchors-in-books)

## Using hyperlinks and anchors in books

This feature is only available in Affinity for desktop.

When working with books, a hyperlink's target can be set to an anchor in a different chapter.

On the **Anchors** panel, anchors in chapters other than the one you're editing are indicated by a book icon

![Image 5](https://images.ctfassets.net/3p2fxa94bzao/2vZHfF85BYQNKJnPvjb3Eg/bd02753ed2212132ce3bff5965d97923/anchor_in_another_chapter.svg)

.

![Image 6: Hyperlink Properties](https://images.ctfassets.net/3p2fxa94bzao/32h1q2x0d8Dmq2aBsWPJA2/acc537f5dcbf23fdf4fea05146266560/hyperlinkProperties.png)

The **Hyperlink Properties** dialog and the **Anchors** panel only show anchors from chapters whose documents are currently open—or were opened earlier in the same editing session.

[](https://www.affinity.studio/help/advanced-anchors/#how-to-create-an-anchor)

### How to create an anchor

Desktop app

1.   Select an object or create an insertion point in text where you wish to add the anchor.
2.    Do one of the following: 
    *   On the **Anchors** panel, click **New Anchor**  ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/3acfBIGiUCk7Ogb2AeCimL/e54cca1f37a8b5e117b13c30fc3f5568/new_document_from_snapshot.svg)       .
    *   On the **Text** menu, select **Interactive > Insert Anchor**.

3.   On the dialog that appears: 
    1.   Type a **Name** for your anchor.
    2.   Choose whether the anchor can be exported as a bookmark.
    3.   Click **OK**.

[](https://www.affinity.studio/help/advanced-anchors/#how-to-rename-an-anchor)

### How to rename an anchor

Desktop app

On the **Anchors** panel:

1.   Select the anchor.
2.   Click the anchor's name.
3.    Type a new name and then press the **⏎** key (Mac) / **Return** key (Windows). 

[](https://www.affinity.studio/help/advanced-anchors/#how-to-identify-anchors-in-document-text)

### How to identify anchors in document text

Desktop app

*   On the **Text** menu, select **Interactive > Show Anchors**.

Anchor icons, which are non-printing, will appear in text where anchors have been placed. Select the option again, so it doesn't show a check mark, to hide the icons.

[](https://www.affinity.studio/help/advanced-anchors/#how-to-delete-an-anchor)

### How to delete an anchor

Desktop app

Do one of the following:

*   On the **Anchors** panel, select the unwanted anchor, then click **Remove Anchor**  ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/3m8ciDtLqf07Yrma1i0j4x/202c1d508104bbb0a1290c5be7725eae/trash_can.svg)       .
*    With anchors displayed in your publication's text, create an insertion point directly after the unwanted anchor, then press the **⌫** key (Mac) / **Backspace** key (Windows). 

[](https://www.affinity.studio/help/advanced-anchors/#see-also:)
