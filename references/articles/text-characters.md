# Character formatting - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/text-characters/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Character formatting

Character formatting describes text attributes which are applied at the character level, such as font family and font size.

You can apply character formatting to a single letter, single word, ranges of text, or full paragraphs.

You can also set attributes such as bold and italic. Advanced character positioning and typographic controls include OpenType font features such as ligatures, alternates, and variable font axes.

Rather than setting a finite value for certain text attributes, the **Text** menu offers the following incremental changes:

*   **Size**
    *   **Bigger/Precise Bigger**—increases the size of the text in 1pt / 0.1pt increments, respectively.
    *   **Smaller/Precise Smaller**—decreases the size of the text in 1pt / 0.1pt decrements, respectively.

*   **Spacing**
    *   **Use Default**—sets the character tracking to the font's default setting.
    *   **Use None**—sets the character tracking to zero.
    *   **Tighten/Tighten More**—condenses character tracking by 10‰/50‰ decrements, respectively.
    *   **Loosen/Loosen More**—expands character tracking by 10‰ / 50‰ increments, respectively.

*   **Baseline**
    *   **Raise/Precise Raise**—moves the text upwards in 1pt / 0.1pt increments, respectively.
    *   **Lower/Precise Lower**—moves the text downwards in 1pt / 0.1pt decrements, respectively.

1.   With a text tool selected, do one of the following: 
    *   Create an insertion point within the word you want to format.
    *   Select the range of text you want to format.

2.   Do one of the following: 
    *   On the context toolbar, apply character attributes such as font family, font size, font style, font color, and bold/italic/underline as required.
    *   On the **Character** panel, adjust the above attributes and **Decorations**, **Position & Transform**, **Language**, **Optical Alignment**, and **Typography** options as required.
