# Generate Image panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-canva-ai-generate-image-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   Generate Image panel

The Generate Image panel allows you to enter a prompt which is used to create a new photo, vector graphic or illustration.

For Mac/Windows: On the **Window** menu, select **Canva AI > Generate Image**.

When switching to Canva AI Studio

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/27LBjHSuPkk8IgU8EJlRTG/2b922a6b2594fb1d65d51af81c0daeaa/canva_ai_studio.svg)

, you will be presented with **Generate Image** and **Generation History** panels. It is here that you can specify your output, preview its versions and even modify them.

**Generate Image / Vector**is a premium feature

![Image 2: Canva Pro Feature](https://images.ctfassets.net/3p2fxa94bzao/3cDfFrl1AFrPewvudOOxnG/2310131f39f4a6dd67092f007be0b1b9/crown.svg)

. To use it, you need to be subscribed to the Canva Pro plan. To learn more about the premium features usage, visit the [Canva AI & Affinity ML](https://www.affinity.studio/help/canva-ai-canva-ai-affinity-ml/) topic.

When using **Generate Image/Vector**, you can choose between **Premium** and **Ultra** models, which determine generation behaviour and output quality.

*   **Premium**—supports continued generation after credits are used, with a short pause between generations.
*   **Ultra**—provides uninterrupted generation with support for higher-resolution output, including UHD.

Select a model based on your workflow. Use **Premium** for iterative exploration, or **Ultra** for higher-quality final output.

The following settings can be adjusted on the **Generate Image** panel:

*   **Generation t****ype**—choose between **Image**for raster images or **Vector**for scalable graphics.
*   **AI Quality**—choose from the available Premium or Ultra models.
*   **Prompt**—the description you provide to guide AI to create the result.
*   **More** menu options: 
    *   **Style**—controls the generated image output style; choose from the list.
    *   **Aspect**—determines the output image aspect orientation; select either landscape, portrait, or square.
    *   **Image count**—determines how many images will be created. Use the slider to set the amount.
    *   **Ultra HD generation**—check to produce a high-resolution 4K output.

*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/5AyuqtqoXn6qh8ppFfdOsp/26e530885f575673cf980e4405bfbd0f/add_reference.svg) **Add reference**—allows you to specify a reference image, document or style for your output. Choose from the available pop-up options.
*   **Generate**—runs image generator based on the prompt.
*   **Automatically enhance prompt**—when checked (default), shorter descriptions are expanded to improve outputs.

Additionally, the following settings can be adjusted on the **Generated Image** dialog once the output has been created:

*   **Variations**—displays different versions of the generated image.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/5xxUVazTqnv2Nzh8nAiYzG/a5d1568bcbcb8415a4f6115c498d910e/crown.svg) **Super-resolve**—when clicked, it improves the image quality by increasing its resolution.
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/3m8ciDtLqf07Yrma1i0j4x/202c1d508104bbb0a1290c5be7725eae/trash_can.svg) **Delete**—removes the selected variant from view.

The **Generations** panel displays all the images generated using the feature. With its built-in search facility, it provides easy access to the previously created outputs.

![Image 6](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

 The following options are available on the **Panel Preferences** menu:

*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
