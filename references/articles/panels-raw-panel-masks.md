3.   Masks panel (Develop Studio)

The Masks panel lets you create various masks of differing types that let you apply standard adjustments to isolated areas of a RAW image.

For Mac/Windows: On the **Window** menu, select **General > Masks**.

The following options are available on the panel:

*   **Opacity**—adjusts the opacity of the applied adjustments within the masked area.
*   **Mask type**—indicates the type of mask applied, e.g, pixel, gradient, luminosity mask.
*   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/9rstenG65qWb7jzhC83X9/df6defa0ca6b00f2d4f82ec5823bffa6/visibility_on.svg) **Visible**—disable to hide the mask; enable to make it visible again.
*   **Move Up**—moves the selected mask entry up in the list.
*   **Move Down**—moves the selected mask entry down in the list.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/r2qPaYMZu1PUwNoo8Bluy/10da3cdaad29dff22d89069363829214/mask_layer_type.svg) **Add Mask**—select from a choice of masking methods to create a mask:
    *   **Object Selection Mask**—adds a ML-based selection mask using the **Object Selection Tool**.
    *   **Brush Mask**—adds a brush-based mask created by using a combination of the **Mask Paint**and **Mask Erase**tools.
    *   **Gradient Mask**—adds a gradient mask using the **Mask Gradient Tool**.
    *   **Luminosity Range Mask**—adds a luminosity range mask that masks an image's tonal range based on its luminosity values.
    *   **Hue Range Mask**—adds a hue range mask to automatically mask regions based on a chosen hue.

*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/4ou6QiXmfLb5cTseqcP0do/206ef1ba657b59e211ab09204c0f9a1d/compoundmask_layer_type.svg) **Compound Mask**—creates a compound mask to combine multiple mask (those listed above) non-destructively using Boolean operations (add, subtract, intersect, xor). Click to choose from the pop-up menu to include the mask type you want.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/3m8ciDtLqf07Yrma1i0j4x/202c1d508104bbb0a1290c5be7725eae/trash_can.svg) **Delete Mask**—removes the currently selected overlay set.

![Image 5](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

 The following options are available on the **Panel Preferences** menu:

*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
