# Settings - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/workspace-settings/

Affinity's settings control how the app behaves and how you work. They are grouped into the following categories.

Change how documents open and save, how linked files update, which language Affinity uses, and other default behaviors that affect your overall workflow across the app. [Learn more about General.](https://www.affinity.studio/help/desktop-settings-general/)

Choose which Machine Learning models are installed on your device, enabling you to use features like the Object Selection Tool and the Portrait Blur, Colorize, and Super Resolution filters. [Learn more about Machine Learning Models.](https://www.affinity.studio/help/desktop-settings-machine-learning-models/)

As part of [MCP setup](https://www.affinity.studio/help/ai-connector-setup/), enable the MCP server and choose what the Affinity MCP server is allowed to do to complete tasks from an AI assistant, e.g. access files on your desktop, use network connections, and save scripts to the Scripts panel for reuse. [Learn more about Model Context Protocol.](https://www.affinity.studio/help/desktop-settings-model-context-protocol/)

Choose default color profiles, control HDR display behavior, and determine how color conversions and EXR data are handled. [Learn more about Color.](https://www.affinity.studio/help/desktop-settings-clr/)

Adjust memory usage, graphics handling, display quality, undo limits, and recovery behavior to suit your hardware and project demands. [Learn more about Performance.](https://www.affinity.studio/help/desktop-settings-performance/)

Adjust how Affinity's interface looks and behaves, including brightness, contrast, cursor feedback, displayed accuracy of measurement units, and other interaction settings. [Learn more about User Interface.](https://www.affinity.studio/help/desktop-settings-user-interface/)

Choose the order in which recent documents, favorites, presets, and templates are shown on Affinity's Home Screen, and hide any you don't need. [Learn more about Home Screen.](https://www.affinity.studio/help/desktop-settings-home-screen/)

Control how tools behave by default, including selection rules, modifier key behavior, zoom and rotation controls, nudge distances, and whether tool settings are remembered between documents. [Learn more about Tools.](https://www.affinity.studio/help/desktop-settings-tools/)

Set your preferred keyboard shortcuts for commands and tools to streamline your workflow and improve efficiency. [Learn more about Shortcuts.](https://www.affinity.studio/help/desktop-settings-shortcuts/)

Decide how the Assistant responds to specific editing actions, including whether it takes automatic corrective steps, displays alerts, and records multi-step actions as a single undo step. [Learn more about Assistant.](https://www.affinity.studio/help/desktop-settings-assistant/)

Use Photoshop-compatible plugins and control where Affinity looks for them on your device. [Learn more about Photoshop Plugins.](https://www.affinity.studio/help/desktop-settings-plugins/)

Control how text is automatically corrected and formatted as you type. [Learn more about Auto-Correct.](https://www.affinity.studio/help/desktop-settings-auto-correct-and-other-text/)

Manage abbreviations to prevent unwanted capitalization after typing shortened terms. [Learn more about Abbreviations.](https://www.affinity.studio/help/desktop-settings-auto-correct-and-other-text/)

Replace Affinity's default placeholder text with custom content for different languages. [Learn more about Filler Text.](https://www.affinity.studio/help/desktop-settings-auto-correct-and-other-text/)

Specify words that should retain specific capitalization in titles, overriding automatic title case rules. [Learn more about Title Exceptions.](https://www.affinity.studio/help/desktop-settings-auto-correct-and-other-text/)

Connect to supported cloud storage services so linked files remain accessible across devices. [Learn more about Linked Services.](https://www.affinity.studio/help/desktop-settings-linked-services/)

Choose how often Affinity checks for updates or turn off automatic update checking. [Learn more about Software Update.](https://www.affinity.studio/help/desktop-settings-software-update/)

Return selected resources and user defaults to their original factory settings. [Learn more about resetting Affinity.](https://www.affinity.studio/help/desktop-settings-misc/)
