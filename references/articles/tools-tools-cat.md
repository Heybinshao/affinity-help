# Cat Tool - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/tools-tools-cat/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Cat Tool

Cats are cool. Everyone loves cats, especially the guys here on the Affinity team! So if you need a cat to add to your images, the Affinity Cat Tool

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/4n0hHVOosb0yli9lTXRXcW/bed4f0649a4c800e4a6ec8ad2e9ddbf7/cat_tool.svg)

 comes to the rescue!

This feature is only available in Affinity for desktop.

![Image 2: Cat Tool](https://images.ctfassets.net/3p2fxa94bzao/28DEtWqxQyHT6xVPpgpAk5/4c7dd35a5955633b7f76a7d67effcb3d/shapes_cat.png)

The Cat Tool is available in all Studios.

To use the Cat Tool, hold the **⌥** key (Mac) / **Shift** key (Windows) and long press the **Shapes** flyout, then select the tool from the list.

The tool can be added directly to the Tools. See 'Customizing tools' for details.

The Affinity Cat shape tool can't be customized. Well, not unless you convert him to curves first. We think he's cool enough.

You can add text inside or along the edges of objects created with this tool and Affinity's other shape tools. See the "Shape text" and "Text on a path" topics for details.

The following settings can be adjusted from the context toolbar:

*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/4VogDhXOgqw0F83jmJq0G8/6909b686388d52610397775cc0bbc4d7/multiple_transform.svg) **Transform Objects Separately**—when selected, where multiple objects are selected, they can be be resized, rotated and sheared independently of each other instead of transforming the bounding box.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/3TbUr2Rcs8WORkpB9F1k0k/ac87f174562fc2ec8a5e5ceb73693b92/convert_to_curves.svg) **Convert to Curves**—converts the selected object into a series of connected lines and nodes.
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/58wNyMZl0DuNFi96wwd2r6/c8656fa6079dda8976d13873f64e0565/keep_selected.svg) **Keep selected**—when enabled (default), the new shape layer will be selected on creation. When disabled, the new object is deselected which prevents it from adopting the next object’s stroke/fill properties.
*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/7e47FwYJ0eBW8yOWy3elSz/813ccca2419c99817334e5bb65c2a0db/cog_icon_2.svg) **Settings**—for general tool settings:
    *   **Enable Transform Origin**—displays a movable transform origin about which the shape can be rotated.
    *   **Hide Selection while Dragging**—when selected, the object's selection box is temporarily hidden when transforming the object. If this option is off, the selection box remains visible during transformation. The selected behavior persists across all objects unless it is manually switched.
    *   **Show Alignment Handles**—when selected, displays alignment handles at the center and edges of the selected object. Hovering over these handles displays a floating guideline across the page. You can drag the handles to position the center or edges of the selected object in line with this guide.

Related behaviors can be adjusted from the app's settings:

*   **Tools > Tool Handle Size**

*   The Cat Tool has no keyboard shortcut by default, but one can be assigned via the app's settings.
