3.   Object removal using stacks

Object removal solves the problem of moving subjects appearing in your images — passing crowds, vehicles, birds flying, or other distractions. By combining multiple shots of the same scene into a stack, the **Median** blend mode removes anything that moves between frames while keeping only what stays still.

*   To allow for perfect image alignment, use a tripod or ensure your camera is in a fixed position.
*   Take a pragmatic approach and be realistic. Scenes full of moving objects cannot be completely emptied, nor will stationary objects magically disappear (but can be made to using the Inpainting Brush Tool later!).

1.   On the **File** menu, select **New Image Process > New Stack**.
2.   From the dialog, click **Add** to locate and select your images. Click **Open** to add the images to the stack list.
3.   Click **OK**.
4.   On the **Layers** panel, select the **Median**![Image 6](https://images.ctfassets.net/3p2fxa94bzao/2dBbxjKizPoQwjjJnwuk7I/943a885370a07ac33fd61784efd6a532/median.png)  stack mode from the Stack mode pop-up menu on the Live Stack Group layer.

Be prepared to selectively retouch images in your stack if ghosting occurs. This may be due to the same or different objects overlapping in more than one image. To resolve, add a mask to your problem image in the stack (hide/show each image layer to locate the ghosting effect).

1.   Add a **Pixel Layer** above the stack.
2.   From the toolbar, select the **Inpainting Brush Tool**.
3.   On the context toolbar, select **Current Layer & Below**.
4.   Set brush size and hardness, as required, then paint over the elements of composition to be removed.
