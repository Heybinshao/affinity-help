3.   Basic panel (Develop Studio)

The Basic panel provides standard adjustments which can be applied to an image.

For Mac/Windows: On the **Window** menu, select **Basic**.

*   Exposure—adjust the overall exposure of the image, changes black point and overall brightness.
*   Tone Curve—adjust how tones are treated; offers a great starting point to further tonal edits.
*   Enhance—adjust contrast, clarity, texture, saturation and vibrance.
*   White Balance*—remove undesirable color casts from a photo by adjusting the 'temperature' of the light. The default value is the 'As shot' White balance setting from your camera.
*   Shadows & Highlights—apply tonal adjustment to the darkest and/or lightest areas in a photo.
*   Profiles—set a system-installed ICC **Output Profile** for color managing the developed image.

*The White Balance adjustment can be set automatically using the White Balance Tool.

The following options are available on the panel:

*   **Preset**—manages adjustment presets via a pop-up menu. 
    *   **Add Preset**—saves the current adjustment settings as a named preset for later use. The pop-up menu populates with the preset name on saving.
    *   **Delete Preset**—deletes the preset currently checked in the Preset pop-up menu.
    *   **Default**—reverts the current adjustment settings back to default settings.

 The following options are available on the **Panel Preferences** menu:

*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
