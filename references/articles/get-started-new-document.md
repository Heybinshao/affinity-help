3.   Creating new documents

New documents can be created from presets, templates, or customized to meet your specific needs.

When creating a new document, the document units define the exact size of your document on screen. For example, if you chose 'pixels', your document will display at its exact pixel size when exported and viewed on screen at 100%. For physical document units (e.g., millimeters) you'll get the exact print size at 50% zoom (due to Retina screen). The print size is determined by the dpi set when creating the new document.

The **New Document** dialog provides common document presets organized by type. Save your most-used built-in or custom presets to the **My Presets** section for quicker access.

The **New Document** dialog also presents separate tabs which allow you to customize your current preset's settings.

*   **Document units**—displays your rulers and object dimensions in pixels, points, picas or using physical measurement units.
*   **DPI**—sets the resolution of your document. For example, for professional print quality, set your resolution to 300 dpi.
*   **Page width**—sets the new document's width. Change these values to make a custom page size.
*   **Page height**—sets the new document's height. Change these values to make a custom page size.
*   **Color format**—sets the color mode to RGB (8, 16 or 32 bit HDR), Grey (8 or 16 bit), CMYK (8 bit), or Lab (16 bit).
*   **Color profile**—sets the color gamut for the previously chosen color format.
*   **Transparent background**—check to set your page background to be transparent.
