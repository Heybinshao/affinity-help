3.   What can I do to fix damaged Affinity documents?

While most Affinity users never encounter document issues, rare instances of damage can occur due to data loss and corruption from viruses, Trojans, hard drive failures, power outages, and other unforeseen events. Therefore, it is advisable to regularly back up critical files using strategies like the 3-2-1 backup method or backup versioning, which allows for multiple archived versions of files.

Before contacting the Affinity Support team, check for existing document backups. If your document is synced with cloud storage, you might be able to retrieve an earlier version of the file using its File History feature.If you don't have any document backups and want the Affinity Support team to investigate your damaged Affinity document, please submit a support ticket and attach a copy of your document. We would also appreciate additional information to help us determine the cause of the problem and prevent it from happening again. To assist us, please provide the following details along with your document:

1.   Which Operating System and version are you using?
2.   What error message is shown when trying to open the file? Please include a screenshot of this error if necessary.
3.   Are you saving to an internal drive, external drive, USB stick/Memory card, or network location?
4.   Is the folder you're saving to syncing to Google Drive, OneDrive, iCloud, Dropbox, or other Cloud services?
5.   Do you have any Anti-virus and/or Anti-malware software running on your machine? If so, which one(s)?
6.   Was this file a new document, or are you trying to save to an existing document when the damage occurred?
7.   Are you able to save a new document to the same location without an error?
8.   Can you remember what you were working on or the functions most recently used within the affected document before the damage occurred?
9.   Any other information you think would help us try to find the problem?

We will inform you of our findings as soon as the investigation process is complete.
