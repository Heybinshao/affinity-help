# Export to Canva  - Affinity Help Center

2.   [Export, share, and publish](https://www.affinity.studio/help/export-share-publish/)
3.   Export to Canva 

You can export your document or a selected area directly to a specific folder within your Canva workspace.

Affinity Studio allows you to easily edit your projects and export them directly to Canva, either in full or as individual sections, right into a folder of your choice. This smooth integration ensures a faster, simpler workflow, helping you save valuable time while creating professional-quality content using the best tools available.

To keep your workflow organized and efficient, create dedicated folders in Canva before exporting from Affinity Studio.

You can export your projects directly to Canva using either the Export dialog or the Quick Export dialog. Both options include the To Canva export choice, allowing you to easily select the exact folder where your asset or project will be saved.

For quick tasks, use the **Quick Export** dialog located in the top right of the UI to save time and speed up your workflow.

1.   On the **File** menu, select **Export > Export**.
2.   On the dialog that appears: 
    1.   On the left, select a preset.
    2.   On the right, adjust settings as needed.
    3.   At the bottom right: 
        1.   Select _To Canva_ as the export location.
        2.   Select the folder your **Uploads** folder or a **Projects** folder.
        3.   (Optional) To view the file in your Canva account after export, enable **Show in Browser**.

    4.   Click **Export**.
    5.   Name the file, choose where to save it, then click **Save**.

1.   On the **Layers** panel, select the layer containing the content you wish to export.
2.   On the Toolbar, click the arrow next to the Quick Export option (which reads **Export PNG** or similar).
3.   On the dialog that appears: 
    1.   Set the filename, dimensions, preset, and scale as required.
    2.   Select what to export, e.g. _Whole Document_ or _Selection Only_.
    3.   Select _To Canva_ as the export location.
    4.   Select either your **Uploads** folder or a **Projects** folder.
    5.   (Optional) To view the file in your Canva account after export, enable **Show in Browser**.

4.   Click **Export**.

When you import the file, it shows up as a static image or graphic. You can move, resize, or add Canva elements around it, but you can’t change any original Affinity layers.

Canva files cannot be opened directly in Affinity, but you can export them in formats that work great.

1.   In Canva, open the design you want to move.
2.   Select **Share**, then **Download**.
3.   Under **File type**, choose one of these formats:

*   **PDF**—for multi-page layout and print.
*   **SVG**—for editable vector elements.
*   **PNG or JPG**—for raster image edits.

4. Back in Affinity, open the exported file to complete your edits.

Use **SVG** if you want to keep things editable. **PDF** and **PNG**file formats may flatten layers.

Export your Canva design as a **PDF**, **SVG**, or **PNG/JPG** to edit it in Affinity. When you’re done, export it back to Canva to keep designing.
