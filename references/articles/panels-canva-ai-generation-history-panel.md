# Generation History panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-canva-ai-generation-history-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   Generation History panel

The Generation History panel allows you to search and locate your previously generated images.

For Mac/Windows: On the **Window** menu, select **Canva AI > Generation History**.

The **Generation History** panel helps you keep track of every image variation you create in Canva AI Studio

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/27LBjHSuPkk8IgU8EJlRTG/2b922a6b2594fb1d65d51af81c0daeaa/canva_ai_studio.svg)

. It provides a visual showcase of your generated results, making it easy to compare versions, revisit previous outputs, and choose the one that works best for your design. This is especially helpful when experimenting with different prompts or styles, as you can quickly review your creative path without losing any of your earlier ideas.

**Generation History**is a premium feature

![Image 2: Canva Pro Feature](https://images.ctfassets.net/3p2fxa94bzao/3cDfFrl1AFrPewvudOOxnG/2310131f39f4a6dd67092f007be0b1b9/crown.svg)

. To use it, you need to be subscribed to the Canva Pro plan. To learn more about the premium features usage, visit the [Canva AI & Affinity ML](https://www.affinity.studio/help/canva-ai-canva-ai-affinity-ml/) topic.

The following settings can be adjusted on the **Generation History** panel:

*   **Search**—provides easy access to the previously created outputs; especially useful once a large number of outputs has been created .
*   **Type**—allows you to specify the previously generated image type; choose between Images and Vectors.
*   **Versions**—displays thumbnail previews of all previously generated imagery; double-click or drag one onto the page to open use it.

![Image 3](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

 The following options are available on the **Panel Preferences** menu:

*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
