# Applying layer effects - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/layer-fx-create-layer-fx/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Graphic design](https://www.affinity.studio/help/graphic-design/)
3.   Applying layer effects

Layer effects can be applied in two ways:

*   Via the **Layers Effects** dialog, offering all settings plus the ability to create multiple instances* of the same effect (for outline, shadows and overlays); effect instances can also be sorted to achieve different results.
*   Via the **Quick FX** panel, using a simplified set of more commonly used settings.

1.   Select the object or layer that you want to apply the effect to.
2.   Do any of the following: 
    *   On the **Layers** panel, click **Layer Effects**![Image 1](https://images.ctfassets.net/3p2fxa94bzao/4WJylimiHvA29KOENvEUQC/80598198347d79f39cf98c4f303dc8de/add_fx_layer.svg) .
    *   Switch on the **Quick FX** panel via the **Window** menu (**Vector** flyout).

3.   On the panel or dialog, select the checkbox of the effect that you want to apply.
4.   Adjust the settings as desired—options vary for each effect. Many layer effects rely on setting a **Radius** value to see the effect initially applied.
5.   (Optional) On the Layer Effects dialog, click **Duplicate effect**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/2AqQYUHrFhUB9WTauRmbyi/2959a1b38ca89574636f0a78de788d78/duplicate_effect.png)  to create another instance of an outline, shadow or overlay effect; click **Delete effect**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/5Rt8xCz7iLCtUpDm9BfDvd/a92c1ea49a21cc0b4c6ef80a3769fcb5/remove_effect.png)  to remove any multi-instance effect.
6.   If required, select any other effects and adjust the settings.

When a layer has one or more effects applied, the FX icon

![Image 4](https://images.ctfassets.net/3p2fxa94bzao/51x5cDOMAqNEHlOklrGeQO/20150f9c80420c7ec623ced52bb1ed1f/fx_on_layer.svg)

 appears to the right of the layer’s name in the Layers panel.

Use Move up

![Image 5](https://images.ctfassets.net/3p2fxa94bzao/55AXziV0sIyunisH9fjWvn/918917b42baa66058a6fa8c078a1fba5/move_up.png)

 or Move down 

![Image 6](https://images.ctfassets.net/3p2fxa94bzao/2uH8h41p5vsv0ZzHRBzoXv/5733b7e1581ad80b10df77807189fa76/move_down.png)

 to rearrange instances of a layer effect.

If you create a set of layer effects that you want to use again you can save time and effort by saving them as a style to the Styles panel. This way they can be applied to any new layer content with a single click.

1.   Select the layer that you want to edit. 
    *   On the **Layers** panel, click **Has layer effects**![Image 7](https://images.ctfassets.net/3p2fxa94bzao/4WJylimiHvA29KOENvEUQC/80598198347d79f39cf98c4f303dc8de/add_fx_layer.svg)  on the layer entry.
    *   On the **Quick FX** panel, choose the effect to expand the options you want to edit.

2.   Adjust the settings as desired—options vary for each effect.
3.   If required, repeat for any other effects.
