# Sampling colors - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/clr-sampling-clr/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Sampling colors

The act of color picking lets you sample colors within or outside Affinity, then use them throughout your design.

![Image 1: Sampling colors](https://images.ctfassets.net/3p2fxa94bzao/4rYxhNnt6FCpcuFW7NeSYJ/d637be9fb839c7c78ce738d023b61b1b/sampling_clrs.png)

Color sampling appears in two slightly different forms within Affinity:

*   Using a standalone **Color Picker Tool**.
*   Using a color picker on the **Color** panel (and other color-related panels).

Regardless of which you use, a sampled color is stored in the swatch next to the color picker's icon on the **Color** panel, ready for application. By default, you apply the picked color directly to any selected object as you pick; this behavior can be disabled.

The first time you sample color, your operating system may ask whether to grant permission for Affinity to record the screen. If you deny it, you can still sample from the app's windows but not other screen areas. Refer to your operating system's documentation if you need to grant permission at a later time.

1.   Select the **Color Picker Tool**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/2lcYpUSuuMpRjhKGSFgJwC/ecc58c08ce83957c9dcd488a4d51fd8f/Colour_picker_tool.svg) .
2.   Adjust the settings on the context toolbar.
3.    Do one of the following: 
    *   (For on-page sampling) Hover the magnification loupe over a color you want to sample on the page, then click to pick it up.
    *   (For screen-wide 'magnified' sampling) Drag to select any color under a magnifier anywhere within or outside the app.

If **Apply to Selection** is enabled (default), the sampled color is instantly applied to any currently selected object.

1.   (Optional) Select an object to adopt the picked color on picking.
2.   Click the stroke/fill color selector you want to apply the color to.
3.   Drag the **Color Picker**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/2lcYpUSuuMpRjhKGSFgJwC/ecc58c08ce83957c9dcd488a4d51fd8f/Colour_picker_tool.svg)  to the color you want to sample and release.

With brush, shape, pencil and fill tools, you can sample color by dragging with the **⌥** key (Mac) / **Alt** key (Windows) pressed.

Press the **⌥** key (Mac) / **Alt** key (Windows) as you are picking, to apply the picked color directly to an object selection.

Press the **⇧** key (Mac) / **Shift** key (Windows) as you are picking, to swap to a crosshair cursor to sample with instead of a magnification loupe.

Press the **⌘** key (Mac) / **Ctrl** key (Windows) to add the sampled color directly to the active Document palette in the **Swatches** panel. A new Document palette will be created if one doesn't exist.
