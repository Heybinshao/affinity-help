# Hyperlinks - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/advanced-hyperlinks/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Page layout](https://www.affinity.studio/help/page-layout/)
3.   Hyperlinks

Hyperlinks allow readers of digital publications to jump to specific pages, files or web addresses (URLs) with a single click or tap.

Hyperlinks make it easy to navigate between areas in your publication or to access external resources—web pages, or files stored on the reader's local storage. You can also link to email addresses. Such links open the reader's email app with a new message ready to send.

If text is selected in Affinity and you paste a URL beginning with a protocol (e.g. https:// or http://), the selected text is converted into a hyperlink to that URL.

Hyperlinks can be included when your document is exported as a PDF. If you create a TOC or index, Affinity can hyperlink its entries on export.

Links to files aren't included in EPUB output. They are not allowed due to potential security concerns.

It is important to note that not all varieties of PDF support interactive features. Additionally, not all PDF viewers support the full range of interactive features; for example, hyperlinks to files do not work in Apple's Preview app.

1.   To tell Affinity what to link, do one of the following: 
    *   Make an insertion point within the word you want to hyperlink.
    *   Select the full text to hyperlink.
    *   Select an object to hyperlink.

2.   To begin adding a link, do one of the following: 
    *   On the **Text** menu, select **Interactive > Insert Hyperlink**.
    *   On the **Hyperlinks** panel, click **Add Hyperlink**![Image 1](https://images.ctfassets.net/3p2fxa94bzao/3v0tdiCwdl7bufnVuTysQB/1593f5e1939732c7866074a28242c777/add_item.svg) .

3.    On the dialog that appears: 
    1.   Choose a hyperlink **Type**.
    2.   Specify the destination: A page number, section, anchor or file. Or, type or paste a web or email address.
    3.   (Optional) When inserting a hyperlink in a data merge layout and the target is a URL, an anchor, an email address or a file referenced in a field of a data merge source, check **From Data Merge** and then select the **Field** that contains target information.
    4.   (Optional) For a file link, check **Include File on Export** to copy the file next to the PDF.
    5.   (Optional) If the link is applied to text, choose a **Character Style** for the text.
    6.   Click **OK**.

Including an https:// or mailto:// prefix when hyperlinking to a web or email address is optional.

When **Include File on Export** is checked, Affinity copies the relevant file to the same location as the exported PDF. The hyperlink in the PDF is made relative and will work as long as the PDF and file are in the same folder. If the option is unchecked, the file's full original location is stored in the PDF. The file must be in the same place on the reader's device.

1.   On the **Hyperlinks** panel: 
    1.   Select the hyperlink.
    2.   Click **Edit Hyperlink**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/23CneVu18qTh3wnrwnc9Xo/76f729a90bff1330cc4817a1cf7d6fdb/edit_item.svg) .

2.   On the dialog that appears: 
    1.   Update the hyperlink's settings as required.
    2.   Click **OK**.

If the hyperlink source is selected, simply double-click the hyperlink on the panel to edit it.

On the **Hyperlinks** panel:

1.   Select a hyperlink you wish to rename.
2.   Click the hyperlink's name, edit it, then press the **⏎** key (Mac) / **Return** key (Windows).

On the **Hyperlinks** panel:

1.   Select a hyperlink.
2.   Click **Go to Source**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/6C90BouHwFxFl82bZZvk3/696f828f5efc492b08ef10070576a51c/hyperlink_source.svg) .

On the **Hyperlinks** panel:

1.   Select a hyperlink.
2.   Click **Go to Target**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/5grPbvG9WnXROMUhAuXFGM/b7d75d85c045b68fbf1f17a124561cdb/hyperlink_target.svg) .

On the **Hyperlinks** panel:

1.   Select the unwanted hyperlink.
2.   Click **Remove Hyperlink**![Image 5](https://images.ctfassets.net/3p2fxa94bzao/3m8ciDtLqf07Yrma1i0j4x/202c1d508104bbb0a1290c5be7725eae/trash_can.svg) .
