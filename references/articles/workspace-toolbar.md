# Toolbar - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/workspace-toolbar/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Getting started](https://www.affinity.studio/help/getting-started/)
3.   Toolbar

The Toolbar hosts commonly used tools and functions to keep them at your fingertips. Options are placed in logical groups to improve ease of use.

This feature is only available in Affinity for desktop.

The following options are available from the Toolbar.

*   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/1FXt4CgId9c6cB6pkuLgkO/72468b125cd31b88eb9fb59dec9011a6/native_view_mode.svg) **Vector view mode**—activates Vector view mode where drawn objects are displayed as vectors with smooth vector edges and transitions by default. This is regardless of the current zoom level.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/1n4pRbyrMjCqUBj05YUCGh/b0af3ab206306e133be4873c26c7872b/pixel_view_mode.svg) **Pixel view mode**—activates Pixel view mode to display vector designs as individual pixels.

**^(ctrl)**-click (Mac) / **right**-click any view mode option for **Advanced** options, including a wireframe option.

*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/4te5ffuV7wlxfLHZjXBYE3/f298c15617667ceaccc59fc7dea44ef2/add.svg) **Add**—creates a new object from the sum of the selected objects.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/78M32Z31jTOkYaHWxegJxj/2a64fc0c16a52868678cbfe53c6f4a34/subtract.svg) **Subtract**—removes sections from the lowest object based on the overlap with objects higher up in the selection. All other selected objects are discarded.
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/6G1NAmj6MzCJXPT8lRurlW/3a85ee7d014cb268e5c2a732cc8f9b19/interesect.svg) **Intersect**—creates a new object from the overlapping sections of selected objects.
*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/5PMX28cvECFZr0WBI5g2Qw/cdaaf4d90c20d9ec601f121bf45ad9ae/combine.svg) **Xor**—merges selected objects into a composite object with transparent area where filled regions overlap.
*   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/01rSjRwpBCN0vFvVz1zEdP/6d2f80a42ab8db370c8f57338c8d2ed3/divide.svg) **Divide**—splits object areas into separate objects; the object from the intersecting area retains the color of the upper object.

*   ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/3qIc44t953zqavuqJNDMPV/d3b725af50e15debbc2284805530c8a8/preview_mode.svg) **Toggle Preview Mode**—previews the document without any visible design aids such as guides, grids and margins.

*   ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/1QIM2hudO0XQiU5I3LmMS5/8f2509d1e2758def9bbba9302bbbf8ed/move_to_back.svg) **Send to Back**—repositions the selected object(s) at the bottom of the layer.
*   ![Image 10](https://images.ctfassets.net/3p2fxa94bzao/1fs2FjgUbNRpgly34SUjMa/1b6827df2b7885bc08d1410f138722b6/back_one.svg) **Back One**—moves the selected object(s) down one position in the layer.
*   ![Image 11](https://images.ctfassets.net/3p2fxa94bzao/3pmUOWuYG9wEM0ObnF9MHv/37a012753b8d30074da0433a454cb54c/forward_one.svg) **Forward One**—moves the selected object(s) up one position in the layer.
*   ![Image 12](https://images.ctfassets.net/3p2fxa94bzao/1oANgUVUQRW0i0Lo7QDply/d2badae8e5f5dbd7306f3c8e7f1da8a9/move_to_front.svg) **Move to Front**—repositions the selected object(s) at the top of the layer.

*   ![Image 13](https://images.ctfassets.net/3p2fxa94bzao/541aRuYiF7eIgtDrj9CFX1/c51a045db40a8a4111e102e93208d273/flip_horizontal.svg) **Flip Horizontal**—flips the selected object(s) left to right.
*   ![Image 14](https://images.ctfassets.net/3p2fxa94bzao/7aOzOZSVD253Abyns5yQ16/1af6da91cf8555db3f1e7e2ade5a4717/flip_vertical.svg) **Flip Vertical**—flips the selected object(s) top to bottom.
*   ![Image 15](https://images.ctfassets.net/3p2fxa94bzao/73up4JuucZLXfBEQE0olfn/f56bf04a7639929dda5122be2e69688d/rotate_anti_clockwise.svg) **Rotate Counter-clockwise**—rotates the selected object(s) to the left by one 90° increment.
*   ![Image 16](https://images.ctfassets.net/3p2fxa94bzao/70cW2mT2huOcqo25GiVPH3/85c6cb26c9c31ed9e8ae521d0a0dcfaf/rotate_clockwise.svg) **Rotate Clockwise**—rotates the selected object(s) to the right by one 90° increment.

*   ![Image 17](https://images.ctfassets.net/3p2fxa94bzao/2sBtuXOz6xHeHKSpdRiV0E/52b485eb1e9c69adb61dfee2adefd40f/arrange.svg) **Alignment**—displays a pop-up dialog allowing you to align and distribute selected object(s). The **Align to** pop-up menu sets the alignment criteria for the operation. For example, you can align in relation to Selection Bounds, page Spread, page Margin or the first (or last) object selected during a multi-object selection (by marquee drag over or selection with **⇧** key (Mac) / **Shift** key (Windows). If margins are not set, alignment is to the page edge instead. 

*   ![Image 18](https://images.ctfassets.net/3p2fxa94bzao/20BvPUP0KMZCIO0wEQYIC6/001d0950cd428725ffd0e3671013a3b1/insert_behind_selection.svg) **Insert behind the selection**—when selected, new objects are added below the currently selected object(s).
*   ![Image 19](https://images.ctfassets.net/3p2fxa94bzao/7mWZHvE7jrn2U2PeQez333/b06df9dce35bc4acfc87ad0a4a6c3c73/insert_top_of_layer.svg) **Insert at the top of the layer**—when selected, new objects are added at the top of the layer.
*   ![Image 20](https://images.ctfassets.net/3p2fxa94bzao/cT5REul8CU3m4v6JMvgcY/d86463fecf7ca2ced3a8d96185ac3761/insert_inside_selection.svg) **Insert inside the selection**—when selected, new objects are added (clipped) inside the current selection.

*   ![Image 21](https://images.ctfassets.net/3p2fxa94bzao/4ZvAvUGmRtnDVzuGQvtjnT/77b8a44ec48b78f76d4cc9e53107331d/snapping.svg) **Snapping**—when selected, selected objects will obey the snapping rules defined by the current snapping options. If this option is off (default), snapping is disabled.
*   Snapping options—customize settings from the pop-up menu.

*   ![Image 22](https://images.ctfassets.net/3p2fxa94bzao/3ZNIvbf9elGuqztIRdlpTg/668d432b321e6aa08f2648c5df478518/reset_mesh.svg) **Reset Mesh**—applies a new mesh and removes all currently applied effects from the underlying image.
*   ![Image 23](https://images.ctfassets.net/3p2fxa94bzao/6lAkdpnoMyo82fMMTzbzMq/8b5880cb4055d0d63c6f17160fcbfe77/save_mesh.svg) **Save Mesh**—saves the current mesh for future application.
*   ![Image 24](https://images.ctfassets.net/3p2fxa94bzao/2hVL5h2pnctQnvrqBk1dE4/80a4880486470b7874b611730efa5f73/load_mesh.svg) **Load Mesh**—applies a previously saved mesh.

*   ![Image 25](https://images.ctfassets.net/3p2fxa94bzao/6tAbLV0VMVMSs1zPQ33Uw3/ae46d2142ceb2095a210582ee2a305cf/clear_mask.svg) **Clear Mask**—removes the mask from the image.
*   ![Image 26](https://images.ctfassets.net/3p2fxa94bzao/ihA65j8EK6SuLtjjXIyEr/cff54ac7e6c6dcdf1227f5d9b31db597/mask_all.svg) **Mask All**—applies a new mask to the entire image.
*   ![Image 27](https://images.ctfassets.net/3p2fxa94bzao/7EvrHs0D7aRZyfd5rTJYgB/dfb8d9070a85cb73a814c4c0c173c755/channel_invert.svg) **Invert Mask**—reverses which areas are masked and which areas are not.

*   ![Image 28](https://images.ctfassets.net/3p2fxa94bzao/64YJgmKSUbLdSuf5GsGqvK/db4f634044988a695cc7da9cde6a964b/standard_view.svg) **None**—displays in full view.
*   ![Image 29](https://images.ctfassets.net/3p2fxa94bzao/SWhhcyi7P9xZaJXlyOFDE/56a0c275bb369631b3c5564fb9f24c83/split_view.svg) **Split**—displays in split view for side-by-side 'Before - After' comparison.
*   ![Image 30](https://images.ctfassets.net/3p2fxa94bzao/3oYRYc43vhHLh1fSgVmMxu/7a99e5a811f9fe9ef886c16980d7b95b/mirror_view.svg) **Mirror**—displays a split mirrored view for side-by-side 'Before - After' comparison.

*   ![Image 31](https://images.ctfassets.net/3p2fxa94bzao/4qGnijHjcPbYBF6PKJWX6b/a031862fb862b695b89363215dd89307/sync_before_develop.svg) **Sync Before**—updates the 'Before' view using the settings applied in the 'After' view.
*   ![Image 32](https://images.ctfassets.net/3p2fxa94bzao/1E4pwiAUoGrHvqKLdfZknN/c2507c4494dd30ddeb078f66c40f344e/sync_after_develop.svg) **Sync After**—removes all the settings applied in the 'After' view to return the image to the 'Before' view.
*   ![Image 33](https://images.ctfassets.net/3p2fxa94bzao/eET9eah4IyOH6j2H0osAG/63d45fa80cf4b0a27beb537e5105dfba/swap_develop.svg) **Swap**—switches the applied settings of the 'Before' and 'After' views.

*   ![Image 34](https://images.ctfassets.net/3p2fxa94bzao/6yVmnnwjh0HjAeRiqo5Jh1/947997e1084e5316c0ae86468dbc84f9/show_clipped_highlights.svg) **Show Clipped Highlights**—when selected, highlight areas which suffer from loss of detail due to clipping are displayed on the image in red.
*   ![Image 35](https://images.ctfassets.net/3p2fxa94bzao/hz1W7gRPMocIkJ7TGTlVY/7f1c40c1fe31feda5c0d0d0591761028/show_clipped_shadows.svg) **Show Clipped Shadows**—when selected, shadow areas which suffer from loss of detail due to clipping are displayed on the image in blue.
*   ![Image 36](https://images.ctfassets.net/3p2fxa94bzao/6EEyFmuUJU0GHlsO4oAGL3/e98b9226e7895b02cc6b23b4e55060b3/show_clipped_tones.svg) **Show Clipped Tones**—when selected, midtone areas which suffer from loss of detail due to clipping are displayed on the image in yellow.
