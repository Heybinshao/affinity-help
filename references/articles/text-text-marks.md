# Text marks - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/text-text-marks/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Page layout](https://www.affinity.studio/help/page-layout/)
3.   Text marks

Text marks are non-printing characters that can be shown within your document. They can help confirm the positions of anchors, indexed words and phrases, invisible characters, and more.

Affinity can draw your attention to:

*   marks inserted into a publication's text for managing its anchors (targets for hyperlinks), endnotes, and index entries.
*   fields, which look like regular text but whose content is dynamic.
*   special characters, notably invisibles that affect text flow, such as right indent tabs and line, column, frame, and page breaks.
*   spelling mistakes, as determined by a text object's **Spelling** setting on the **Character** panel's **Language** section.

Text marks are shown only in the document view, not in the output of your document.

You might show special characters to identify why text is not flowing as expected.

For example, page breaks and non-breaking spaces in a Microsoft Word document are preserved when the document is placed in Affinity. They may improve the readability of content in its original file format, but they may produce undesirable text flow in Affinity.

Unwanted characters from placed documents can be removed or replaced using the **Find and Replace** panel.

On the **Text** menu, do one of the following:

*   For anchors, select **Interactive > Show Anchors**.
*   For fields, select **Highlight Fields**.
*   For index marks, select **Index > Show Index Marks**.
*   For note marks, select **Notes > Show Note Marks**.
*   For special characters, select **Show Special Characters**.
*   For spelling mistakes, select **Spelling > Check Spelling While Typing**.
