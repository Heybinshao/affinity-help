3.   Using masks (Develop Studio)

Mask tools allow you to apply standard adjustments to isolated areas of a RAW image.

![Image 1: Using Mask Gradient in the Develop Studio](https://images.ctfassets.net/3p2fxa94bzao/4RHx7Ft8Th9PR8CkFtmnHv/24b4ea0b8968e56fcd7d35e092ff3c5a/using_overlays_develop.jpg)

Mask Gradient applied in the Develop Studio to target the sky.

Masks are used within the **Develop Studio** to mark areas for localised edits—any adjustment applied to a mask affects the targeted regions. They can have a varying level of visibility, which alters the impact its adjustments have on the underlying image.

Each mask can have one or more adjustments applied.

The transparent areas of a mask ignore the adjustments, while opaque areas display the applied adjustments fully. The semi-transparent regions (such as those created with the Mask Gradient Tool) will display the adjustments' effects with a varying degree.

There are a range of mask tools available.

*   **Object Selection Tool**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/C3NB8httu4Ctqf1QkQHGD/1e133e366f542b290d41d8557e790e0a/object_selection_tool.svg) —uses ML technology to create intelligent selection-based masks from areas of your image.
*   **Mask Paint Tool**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/3locI94qeasHTEGWfhYhbg/c851457b3a254b6f26745e88f61f2107/overlay_brush_tool.svg) —use to create a brush-based mask; erase away the mask using the **Mask Erase Tool**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/7FntY0YnpexlxtRDjssV90/cba51f14d527051511fc8084b602267a/overlay_eraser_tool.svg)  if needed.
*   **Mask Gradient Tool**![Image 5](https://images.ctfassets.net/3p2fxa94bzao/tzzGrTQ7p5FvQcfAmtArv/6be070c9a1a9961164de6d472af375e1/gradient_overlay_tool.svg) —use to create a gradient mask (linear, elliptical or radial) from transparent to opaque.

When any of the above tools are used, the created mask is shown in the **Masks Panel**. The panel lets you manage your masks including controlling the mask visibility and mask deletion.

The panel also lets you create more advanced types of masks:

*   **Luminosity Range Mask**—adds a luminosity range mask that masks an image's tonal range based on its luminosity values.
*   **Hue Range Mask**—adds a hue range mask to automatically mask regions based on a chosen hue.
*   **Compound Mask**—combines multiple mask (those listed above) non-destructively using Boolean operations (add, subtract, etc.).

*   **Size**—sets the size of the mask brush in pixels.
*   **Hardness**—controls how hard the edges of the brush are. The painted mask appears softer and more feathered as the percentage decreases.
*   **Edge Aware**—when checked, it enables edge detection, which allows for easier mask painting around the edges without having to zoom in and reduce the brush size.
*   **Show Mask**—keep checked to display a strong pink mask to identify an area for targeted editing; uncheck to hide the mask and make your edits directly without this aid.
*   **Show All Layers**—when checked (default), enables the visibility of all layers for the project.

A pixel or gradient mask is created, respectively.
*   On the **Masks**panel, click **Add Mask**![Image 8](https://images.ctfassets.net/3p2fxa94bzao/4q6OWVN4MyCGmeC0NuhiCI/696babeff770d207d6c4866c36cafb06/add_mask_layer.svg) and select either **Brush Mask**or **Gradient Mask**. Drag on the image to apply.

*   On the **Masks**panel, click **Add Mask**![Image 9](https://images.ctfassets.net/3p2fxa94bzao/4q6OWVN4MyCGmeC0NuhiCI/696babeff770d207d6c4866c36cafb06/add_mask_layer.svg) and select a mask option from the pop-up menu.

*   On the **Masks**panel, click **Compound Mask**![Image 10](https://images.ctfassets.net/3p2fxa94bzao/4ou6QiXmfLb5cTseqcP0do/206ef1ba657b59e211ab09204c0f9a1d/compoundmask_layer_type.svg) and select a mask option from the pop-up menu.

This adds the first mask to the compound. You can add further masks of the same type by repeating the operation or add a mix of different mask types. At any time a different Compound Mask mode can be used instead of the default Add operation.

3.   Drag the adjustment slider to set the value.
