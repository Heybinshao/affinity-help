# Detect Vertical Edges filter - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/filters-filter-detect-vertical-edges/

1.   [Help Center](https://www.affinity.studio/help/)
2.   Detect Vertical Edges filter

The Vertical Edges filter isolates and strengthens vertical edges while darkening the rest of the image. It’s useful for analysing structure, enhancing outlines, or creating stylised effects where vertical forms—such as buildings, text, or architectural details—need to stand out.

![Image 1: After](https://images.ctfassets.net/3p2fxa94bzao/2nyp3wv5h6tu1ZyHn2dOo8/10b7be93cfecd72ec3d3dfa00aae68b0/filter_detectedgesvertical_after.jpg)

![Image 2: Before](https://images.ctfassets.net/3p2fxa94bzao/5yWJii6lqpxyAcVMWutB0v/2b9cf2d4017e78a564e848033b80a605/filter_detectedgesvertical_before.jpg)

Because the filter focuses specifically on vertical direction, it isolates features like upright lines, columns, frames, and edges without equally emphasising horizontal detail.

You may want to use this filter to help identify vertical lines in architectural or technical images, to assess alignment, symmetry or distortions, or to guide your perspective corrections.

Use Detect Vertical Edges to guide your next editing steps—as the filter extracts outlines that can be reused as masks or overlays, it helps define areas for targeted adjustments or compositing.

Experiment with layer blend modes at reduced opacity for optimal stylistic purposes.

The filter can be used in the following example scenarios:

*   **Architectural Enhancement**—Use the filter to emphasise building edges, windows, or columns before applying contrast, sharpening, or perspective adjustments.
*   **Stylized Illustrations**—Combine the detected edges with blend modes or color overlays to create sketch-like, blueprint, or poster-style visuals.
*   **Texture and Pattern Creation**—Isolated vertical edges can be reused as graphic textures, repeating patterns, or design elements in layouts and mockups.
*   **Mask Generation**—Convert the edge results into a mask to selectively apply effects—such as color grading or lighting—only along vertical edges.
*   **Abstract Effects**—Layer the edge output over the original image at low opacity to add visual rhythm and structure without overwhelming detail.

This filter can be found on the **Pixel > Filters > Detect** menu.

This filter has no customizable settings.

This filter works by detecting changes in RGB values. This means that some images will work better than others.
