# Using assets - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/assets-assets/

1.   [Help Center](https://www.affinity.studio/help/)
2.   Using assets

Assets are stored design elements which can be accessed from any document you have open.

![Image 1: Using assets](https://images.ctfassets.net/3p2fxa94bzao/6f2wor9s3rsSQcTmQSE1oX/efe5846b596bb905b10cb655e070cc4c/using_assets_no_ui.png)

Assets are created from objects or groups of objects. Once selected on the page, these objects and groups can be added to the **Assets** panel. When a new assets category is created, this creates a subcategory for you, ready to drag objects to.

Categories can be created at any time to help you organize your assets. They are then listed in the pop-up menu at the top of the Assets panel. Each category can accommodate an unlimited number of subcategories.

Subcategories and assets by default are sorted by the time they were added. They can both be sorted by name however, if preferred.

Assets cannot exist directly in categories, they must reside in subcategories. This is why categories are always created with a default Assets subcategory.

Assets in the panel can be displayed as thumbnails in a grid (default) or as a named list. Tooltips display the name of an asset.

You can share assets with collaborators who are using Affinity, by exporting and importing asset categories.

If you can't find the Assets panel, it can be switched on via the **Window** menu (**General** flyout).

1.   On the **Assets** panel, click **Panel Preferences**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)  and choose **Create New Category**.
2.   On the dialog, give the category a name, e.g. MyAssets.

*   On the **Assets** panel, click **Panel Preferences** and choose **Create Subcategory**.

From **Panel Preferences**

![Image 3](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

 or the **Options**

![Image 4](https://images.ctfassets.net/3p2fxa94bzao/2XLuXTwmEh714qaYONrPKP/6d26123960257b3233a3eb084188eda7/moremenuicon.svg)

menu, you can also delete and rename the selected category or subcategory, respectively.

This feature is only available in Affinity for desktop.

Do one of the following:

*   On the **Assets** panel, click the **Options**![Image 5](https://images.ctfassets.net/3p2fxa94bzao/2XLuXTwmEh714qaYONrPKP/6d26123960257b3233a3eb084188eda7/moremenuicon.svg)  menu for the subcategory and choose **Move Up**/ **Move Up** depending on where you wish your subcategory to appear.
*   Drag a subcategory name and place it where required.

1.   Select one or more objects or groups on the page.
2.    Do one of the following: 
    *   Drag the selection into the **Assets** panel (the cursor will change to show a plus icon) and release when you see a vertical insertion point or highlight.
    *   On the **Assets** panel, click a subcategory's options menu and select **Add from Selection**.

Each item in the selection is added as a separate asset and placed in the subcategory with a default name.

If you want a selection of layer content or objects to be added as a single grouped asset, they must be grouped first.

*   Do one of the following, from your operating system: 
    *   From **Panel Preferences**![Image 6](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg) , select **Import Assets**, then select and open the file.
    *   Double-click on the assets file in a folder.
    *   Drag the assets file directly onto the **Category** pop-up menu on the **Assets** panel.

The assets will be imported into a new category named using the imported file name.

*   On the **Assets** panel, drag an asset's thumbnail directly onto the page or an artboard.

If an asset has constraint properties and you wish to activate these properties on placement, hold down the **⌘** key (Mac) / **Ctrl** key (Windows) when you drag out the asset.

Dragging an asset from the panel onto the title bar opens it as a separate document.

*   On the **Assets** panel, **^(ctrl)**-click (Mac) / **right**-click (Windows) an asset thumbnail and select **Rename Asset** or **Delete Asset**. If renaming, type a new name for the asset in the dialog and click **OK**.
