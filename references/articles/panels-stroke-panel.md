# Stroke panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-stroke-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Stroke panel

The Stroke panel lets you set the properties of lines and curves, as well as shape outlines and path brush strokes.

For Mac/Windows: On the **Window** menu, select **Vector > Stroke**

Every object can take a stroke around its outline which can take on various properties, e.g. width, color, opacity, line style, etc.

The following options are available on the panel:

*   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/5myw2cBhwRcxBUsS7YXdVc/fb04f0527ff125631f5d1546227d9c67/no_line_style.svg) ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/1W8CcLGbF7EjvIQ15sU7Qu/74ef6c2b84f12f71f57a576adccc58f3/solid_line_style.svg) ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/4RrSHVIOLLbR5Re5f4JCjy/9d9585a3f346cfcce7128c42b4536023/dash_line_style.svg) ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/8ttAa67zCFKKVMLx0XdmR/9b872ed86d4c50f4123de81eadb25bc0/Texture_Line_Style_3.svg) **Style**—select a line style button to change how the line is drawn. Choose from None, Solid Line Style, Dash Line Style, and Path Brush Line Style, respectively. The last option applies the brush that's selected on the Path Brushes panel to the stroke.
*   **Width**—drag to change the width (thickness) of the selected line or enter absolute values, expressions and formulas (percentages).
*   **Cap**—select one of the cap style buttons (Round, Butt, or Square) to vary the contour of the line end.
*   **Join**—select a setting (Round, Bevel, or Miter) to determine the contour of sharp corners on the stroke. With **Miter** joins, the **Miter** setting dynamically controls if beveling occurs by extending each line at the junction by the number of line widths. If the outer edges meet within the limit, the corner is sharp; if not, it's flat (beveled).
*   **Miter**—sets the length of the extension of Miter joins to create either sharp or flat corners.
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/VfAcbkeZeDZvaHCwE9hEk/6185417c6f572e3b21bd32fc4c6e16e0/align_stroke_centre.svg) ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/5ureZmHTCXjKs4HAqxhHdI/be5121166c0589e243b76fefd49221b5/align_stroke_inside.svg) ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/12l2uGLhLKqMJUbq3M3XQe/17c96a7f908e742b4993054bccad80d8/align_stroke_outside.svg) **Align**—select one of the align buttons to control where the stroke is placed in relation to the object edge, i.e. centered, or on its inside or outside.
*   ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/6sVJzmua6VEMuCJPuRXwRZ/a6a3fb57b3200000eeb452b9aec0c58a/line_draw_back.svg) ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/48I7ickQQEm8rvtpxCJ366/de2c7edfbbc1f06568f1da11acc403c4/line_draw_front.svg) **Order**—select one of the order buttons to control where the stroke is placed in relation to the object. **Draw stroke behind** hides the inner half of the object's outline behind a closed shape—useful with very small objects or when shrinking outlined text. **Draw stroke in front** always reveals the whole line.
*   **Scale with Object**—check to scale both line and shape together when resizing a closed shape. Uncheck to keep line width constant.
*   **Start**/**End**—select an arrowhead style for the start/end stops of the stroke from the pop-up menu.
*   **Percentage**—with styles selected, type a percentage size for the arrowheads in proportion to the stroke width.
*   ![Image 10](https://images.ctfassets.net/3p2fxa94bzao/4ovru5tVWJ5iuDrO7UvFB4/7f2aea7b265b7931b3ac620f16e4996c/arrowhead_inside.svg) ![Image 11](https://images.ctfassets.net/3p2fxa94bzao/4Iz9W9HjMmLN3ViR6YfPBW/5433be7a44624a87e7e0b871e4b16b39/arrowhead_outside.svg) **Place arrow within the line** / **place arrow at the end of the line**—choose where to position the start and end styles at the end of the line.
*   ![Image 12](https://images.ctfassets.net/3p2fxa94bzao/2ty4rrvXJAKOQ9A7KNkpeq/3550d3ea165c5089bd090a4a8ece44e2/chainlinkconnected.svg) ![Image 13](https://images.ctfassets.net/3p2fxa94bzao/5tDDIwcwpJRIpRHFMB12xq/ab33de5f69c7cc43582ad4ee5fa201d0/chainlink.svg) **Link**—when enabled, the selected **Start** and **End** arrowheads are adjusted in proportion to each other, maintaining the current aspect ratio. When deselected, they can be adjusted independently.
*   ![Image 14](https://images.ctfassets.net/3p2fxa94bzao/3M2d5eMwr98NZJE9CDP30X/b74977a4478981774d07bf298700e003/arrowhead_swap.svg) **Swap arrowhead with tail**—select to swap the **Start** and **End** arrowhead styles.
*   ![Image 15](https://images.ctfassets.net/3p2fxa94bzao/3m8ciDtLqf07Yrma1i0j4x/202c1d508104bbb0a1290c5be7725eae/trash_can.svg) **Clear arrowheads**—select to clear arrowhead settings.
*   **Properties**—click to edit the brush used as your Path Brush Line Style via a Brush dialog.
*   **Pressure**—displays your current pressure profile after applying a line or brush stroke. Clicking the profile lets you edit the profile and save it for future use.
*   **Dash**—when Dash Line Style is selected, the three 'Dash - Gap' pairings displayed allow you to set the design of the dot or dash. You can configure the dash design by typing values or dragging on the individual light (dash) and dark (gap) strips below the numbers. (See [Draw lines, curves and shapes](https://www.affinity.studio/help/curves-shapes-draw-lines-and-shapes/).)![Image 16: Dash pattern control (Desktop)](https://images.ctfassets.net/3p2fxa94bzao/53MjLP7er5Zc9G3BbFKOVD/dcb6634ba90c8b3ffd987923650b606a/strokepanel_dashpattern.png) 
*   **Phase**—when Dash Line Style is selected, this option allows you to manually offset the starting point of the dash design if **Balanced Dash Pattern** is disabled.
*   ![Image 17](https://images.ctfassets.net/3p2fxa94bzao/2pa1m9JU2Z61nbbU6QDlIz/df3da2c1a7b23220f8931638d09cf74c/balanced_dash.png) **Balanced Dash Pattern**—when enabled, the dash pattern is applied to the shape's outline so it appears seamless along the outline and is symmetrical at all corners. When disabled, the pattern starts at the first drawn node of the curve or closed shape, or the geometric shape's 'start' node.

To change the line color, use the Color or Swatches panel.

![Image 18](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

 The following options are available on the **Panel Preferences** menu:

*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
