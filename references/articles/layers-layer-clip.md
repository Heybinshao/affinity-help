## About clipping

Clipping involves positioning one object inside another, creating a parent - child layer relationship. The path of the parent object becomes the new boundaries for the child object. Any areas of the child object which lie outside the parent object's path are masked (hidden).

Clipping can also be used to confine an adjustment or mask to a single layer or layer group.

When scaling a parent object, child (clipped) objects scale to maintain the correct aspect ratio. Scaling a clipped object has no effect on the parent object. A clipped object can be edited independently from its parent, e.g. adjusting color, opacity and/or blend mode.

Any object can act as a parent or child in clipping relationships. Therefore both vector objects and pixel layers can be either clipped or clipping.

[](https://www.affinity.studio/help/layers-layer-clip/#how-to-clip-manually)

### How to clip manually

Desktop app

1.   In the document view, position the object to be clipped so it overlaps the object which will perform the clipping.
2.    Do one of the following, with the object to be clipped being selected: 
    *   On the **Layers** panel, drag it on top of the object's name which is to perform the clipping. A blue highlight appears to target the layer.
    *   On the **Layer** menu, select **Arrange > Move > Inside**. This moves the object inside the object above it on the **Layers** panel.

The clipped object is nested within the clipping object in the Layers panel. The clipped object becomes a child of the clipping object.

[](https://www.affinity.studio/help/layers-layer-clip/#how-to-clip-an-object-on-creation)

### How to clip an object on creation

Desktop app

1.   Select the object which will perform the clipping.
2.   Do one of the following:

*   On the context toolbar, select **Insert inside the selection**  ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/cT5REul8CU3m4v6JMvgcY/d86463fecf7ca2ced3a8d96185ac3761/insert_inside_selection.svg)       .
*   On the **Layer** menu, select **Arrange > Insert > Inside**. 

3. Draw your object over the selected object to auto-clip.

Raster brush strokes will automatically clip inside any selected object.

[](https://www.affinity.studio/help/layers-layer-clip/#how-to-select-clipped-objects)

### How to select clipped objects

Desktop app

1.   On the **Layers** panel, expand the clipping object's contents (if needed) by clicking the layer's arrow.
2.   Click to select the clipped object.

Alternatively, you can select clipped objects directly on the page using **⌘**-click (Mac) / **Ctrl**-click (Windows).

The clipped object can now be moved and edited as needed.

[](https://www.affinity.studio/help/layers-layer-clip/#how-to-remove-clipping--unclip-)

### How to remove clipping (unclip)

Desktop app

Do one of the following:

*   On the **Layers** panel, drag the clipped object to a new position outside its parent's entry on the layer stack.
*   Select the clipped object, then select **Layer > Arrange > Move > Outside**.

[](https://www.affinity.studio/help/layers-layer-clip/#how-to-resize-an-object-without-scaling-its-child-layer-content)

### How to resize an object without scaling its child layer content

Desktop app

1.   Select the parent object with the **Move Tool**.
2.   On the tool's context toolbar, enable **Lock Children**.
3.   Resize the parent object to your chosen size.

As you resize the parent, you can press the **Spacebar** on your hardware keyboard to temporarily override the current Lock Children state while the key remains pressed.
