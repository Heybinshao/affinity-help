# Duplicating - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/object-control-duplicate/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Duplicating

Affinity lets you make identical copies of objects, layers or groups in your designs. Once duplicated, you can modify the duplicate to create design variations.

Do one of the following:

*   On the **Layers** panel, **^(ctrl)**-click (Mac) / **right**-click (Windows) a layer, group or object and select **Duplicate**.
*   On the **Layers** panel, press the **⌥** key (Mac) / **Alt** key (Windows) down and drag the object or layer you would like to duplicate into its position.
*   With an object or layer selected, select **Edit > Duplicate > Selection**.

Each duplicate is added above its corresponding original item.

*   Hold down the **⌘** key (Mac) / **Ctrl** key (Windows) key and drag the item to duplicate it.

This feature is only available in Affinity for desktop.

As well as moving, rotating and sizing an individual object precisely, Move data entry lets you create any number of copies of an object in one operation which, when combined with move, rotate and scale operations, leads to some striking object transformations.

Move data entry has the following characteristics:

*   You can duplicate curves and text as well as shapes.
*   It is controlled via a dialog.
*   Your chosen transformation is previewed on the page.
*   You can edit the properties of the object being transformed (affecting its its previewed duplicates) as well as its transform origin while the dialog remains open.
*   The duplicate(s) can be placed in front of or behind the original object.
*   The previous settings can optionally be used.
*   Scaling is cumulative, e.g. 80% scaling is applied to each duplicate in turn.

Effects of Insertion mode when set to add duplicates in front of (A) or behind (B) the original item

Try repositioning the object's transform origin on the page before using Move data entry—this lets you rotate duplicated objects around the origin to create ringed designs.

1.   With the **Move Tool** active, select one or more objects, layers or groups.
2.   Press the **⏎** key (Mac) / **Return** key (Windows) to display a **Move / Duplicate** dialog.
3.   Enter new settings that will offset the duplicate(s) from its original position, with optional **Angle**, **Rotation** and **Scale** settings. The **Distance** setting is the measurement between duplicate object midpoints. 
4.   Check **Duplicate** and set the **Number of copies** you want.
5.   (Optional) Choose an **Insertion mode** to add duplicate objects either in front of (**Insert new items in front**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/7mWZHvE7jrn2U2PeQez333/b06df9dce35bc4acfc87ad0a4a6c3c73/insert_top_of_layer.svg) ) or behind (**Insert new items behind**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/20BvPUP0KMZCIO0wEQYIC6/001d0950cd428725ffd0e3671013a3b1/insert_behind_selection.svg) ) the original object.
6.   Click **OK**.

Click **Reset** to clear previously applied settings and remove the duplicates.

Pressing the **Esc** key will cancel the operation; the entered settings will still be remembered.

If you swap to another tool while the dialog is open, the dialog and any object previews will disappear.

If you duplicate an item and then transform the copy, you can immediately duplicate this transformed content. If you do, the newly created content will adopt the transform of the duplicate and will be also transformed again using the same settings. In other words, the transform is applied accumulatively to subsequent duplicates.

![Image 5: Power duplicate](https://images.ctfassets.net/3p2fxa94bzao/2C35LWPM5WcEGmuyEJ8AwV/a2db1de7f68fc66b1061063e82c135d5/power_duplicate.png)

(A) original, (B) original duplicated and rotated by 15°, (C) transformed duplicate duplicated numerous times.

1.   With an object, layer or group selected, select **Edit > Duplicate > Selection**.
2.   Move the duplicated object, layer or group.
3.   Perform the Duplicate operation again. A duplicate is created and the transform is automatically applied to the duplicate.
4.   Repeat step 3 to create more duplicates with the transform accumulatively applied.
