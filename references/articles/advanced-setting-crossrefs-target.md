3.   Setting a cross-reference's target

Each cross-reference links to one target. The target can be on the same page, a different page in the same document or, on desktop, in another book chapter.

![Image 1: Text options on the Insert Cross-Reference dialog](https://images.ctfassets.net/3p2fxa94bzao/5mtGeQmbeEHXJKsrefmEZ4/d41d1c294721d9d3cfb6065433f0162e/crossrefsInsert.png)

Text and other options on the Insert Cross-Reference dialog.

When inserting or editing a cross-reference, the following options are available for selecting a target:

*   **Link to**—Select the type of targets—_Anchor_, _Paragraph_, or _Index Mark_—to show in the targets list.
*   (Desktop only) **Target chapter**—Select the chapter that contains the target. This option appears only when your document is part of a book open on the **Books** panel. You can only select chapters whose documents are also open.
*   **Filter style**—When linking to a paragraph, select a paragraph style the target must use to appear in the list.
*   (Desktop only) **Search Scope**—Select whether the filter text must appear at the target's start or anywhere in the first 100 characters.
*   **Filter text**—When linking to a paragraph, enter text that a target must contain for it to be shown in the targets list.
*   **Targets list**—Shows all targets of the selected type and matching the filter criteria. Select an entry to link the cross-reference to it.

Cross-references to paragraphs or index marks link to anchors. Affinity uses an existing anchor at the target or adds one if needed.

You can use anchors to target non-text content like picture frames, shapes, and placed documents.

Cross-references cannot be linked to targets within placed documents.

When inserting or editing the cross-reference:

1.   On the **Link to** pop-up menu, select the type of targets to display in the targets list: _Anchor_, _Paragraph_ or _Index Mark_.
2.   (Optional) Select the **Target chapter** that contains the required target.
3.   (Optional) When linking to a paragraph, use the filter options to limit what appears in the targets list.
4.   From the targets list, select the required target.

The targets list can be sorted by clicking a column heading. Each click toggles between ascending and descending order.

When inserting or editing a cross-reference:

*   Based on text formatting: Select a paragraph style or _[Any Style]_ on the **Filter style** pop-up menu.
*   Based on text content: Type in the text box and select from **Filter Options** whether the text must appear at the start or anywhere within a paragraph's first 100 characters.

The filter style and text options can be used individually or in conjunction.
