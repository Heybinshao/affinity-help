# Access and manage Affinity Store add-ons - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/access-and-manage-affinity-store-add-ons/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Installation and setup](https://www.affinity.studio/help/installation-setup/)
3.   Access and manage Affinity Store add-ons

After linking your existing Affinity Store ID directly from within Affinity by Canva, it’s possible to access and manage Affinity Store add-ons.

An add-on contains custom content, such as assets, brushes, fonts, styles, swatches palettes or document templates.

The easiest way to install add-ons registered to your Affinity Store account is via your app's Account feature.

Add-ons installed in-app are automatically available in all of Affinity's Studios on the same device.

*   On Affinity’s Welcome screen, select **Canva Profile Name**>**Advanced**>**Link Affinity ID**.

1.   Sign in with the Affinity Store ID you used for your original purchase. If you've forgotten your password, you can reset it[here](https://store.serif.com/reset-password/).
2.   Once successfully linked, select **Canva Profile Name**>**Advanced**>**Manage Purchased Content**.
3.   Choose which content is installed, and customize your app’s installation behaviour if needed.

Note: The default behaviour is never to automatically download content, which avoids unwanted use of any metered data allowance.

You might choose automatic installation if your Internet connection is unmetered and your device has plenty of free storage. Optionally, you can impose a maximum size for each add-on that is automatically installed and manually install larger items from the Affinity Store as needed.

Choose manual installation if you want full control of which add-ons are taking up storage and to manage the amount of content that is presented to you in Affinity’s user interface.

On the **Affinity Store** window, below the **My add-ons** list, check **Always install available content**.

Do one of the following:

1.   Click the cloud icon next to each required add-on or bundle to download the item.
2.   On the **Options** menu ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/2XLuXTwmEh714qaYONrPKP/6d26123960257b3233a3eb084188eda7/moremenuicon.svg) , select **Download All** to download all items currently registered to your Affinity ID. 

*   On the **Options** menu, select **Uninstall All**.

1.   On the Welcome screen, select **Canva Profile Name**>**Advanced**>**Manage Purchased Content**.
2.   On the**Options**menu, select**Unlink Affinity ID**.

Each add-on listed on the Affinity Store window displays an icon that indicates its current installation status.

Some items in the list are bundles that contain multiple add-ons. You can install all or some items from a bundle. To see a bundle’s contents, so you can choose what to install, click the arrow on its left side.

*   Click the cloud icon to download the add-on or bundle. (A green dot on the icon means only some add-ons from the bundle are installed.)
*   Green tick indicates the item is installed and ready to use.
*   Red cross indicates the item failed to download. Click the icon to retry.
*   An arrow indicates the add-on is provided in a file format that does not install into a panel. Click the icon to download the add-on from the Affinity Store in your web browser and then follow any included instructions on how to use it.

Various advanced features for managing your add-ons and Affinity Store account are available from the **Options** menu’s **Diagnostics** submenu.

*   **Show Search Bar**: a handy search feature helps you discover your add-ons more easily.
*   **Show Incompatible Packs**: displays packs which may not be compatible with your current app version.
*   **Check Connectivity**: tests your Internet connection to check your access to the Affinity Store.
*   **Check Credentials**: manually verifies your current session by checking your login details. 

For most types of add-on, the import process creates one or more categories or application palettes on the panel that correspond to an add-on's type.

You can create add-ons (except for fonts) by exporting your documents and custom content from Affinity.

See the Exporting add-ons and Importing add-ons for instructions on how to use add-ons from other sources.

*   [**Importing add-ons**](https://www.affinity.studio/help/addons-importing-addons/)
*   [**Exporting add-ons**](https://www.affinity.studio/help/addons-exporting-addons/)
