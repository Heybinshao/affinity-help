# Deform Tool

The Deform Tool

allows you to distort areas of your image based on one or more set anchor points.

After

Before

After warping: using the Deform Tool to rework the model's chin area.

[](https://www.affinity.studio/help/tools-tools-deform/#where-to-find-it)

### Where to find it

The Deform Tool is available by default in Pixel Studio.

It can be added to other Studios. See [Customizing tools](https://www.affinity.studio/help/workspace-customizing-tools-panel/) for details.

You can assign a custom shortcut in Affinity's settings. See [Customizing keyboard shortcuts](https://www.affinity.studio/help/workspace-customizing-shortcuts/) for details.

[](https://www.affinity.studio/help/tools-tools-deform/#about-the-deform-tool)

## About the Deform Tool

This tool provides an alternative to traditional filter-based warping. It allows you to reshape specific regions of an image while keeping other areas protected from distortion. The Deform Tool works in the following way:

*   **Anchor Points**—add anchor points to define which parts of the image should remain fixed.
*   **Warping**—drag other points to distort or reshape the selected area.
*   **Reference Point**—the first anchor point you set usually acts as the pivot around which the warp is applied.

Use this tool when you want fine-grained control over image warping—such as bending an object, adjusting perspective, or reshaping elements—without altering the surrounding areas.

[](https://www.affinity.studio/help/tools-tools-deform/#settings)

### Settings

The following are available on the dialog:

Desktop app

*   **Master**—controls intensity of the warp when dragging points. Type directly in the text box or drag the slider to set the value.
*   **Linear Constraints**—choose from the pop-up menu. **Rigid** only allows the pixels directly related to the anchor point to change. The pixels can rotate and move, but not stretch. **Similarity** affects surrounding pixels and allows them to stretch as well as rotate.

[](https://www.affinity.studio/help/tools-tools-deform/#how-to-warp-an-image-using-the-deform-tool)

### How to warp an image using the Deform Tool

Desktop app

1.   On the **Layers**panel, select the pixel layer you want to warp.
2.   In Pixel Studio, select the **Deform Tool**          from the **Move Tool**'s flyout.
3.   Click on the image to place one or more anchor points on the areas you want to keep fixed. The first anchor point placed acts as the reference pivot for the warp.
4.   Click and drag on the image to warp the surrounding area.
5.   (Optional) Adjust **Master**and **Linear Constraints**on the dialog to control the intensity and behavior of the warp.
6.   Click **Apply**to commit the transformation.

[](https://www.affinity.studio/help/tools-tools-deform/#see-also:)
