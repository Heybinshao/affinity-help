The Crop Tool

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/1h7jiPUfGZiR8vLhdYmJdR/75ae8719b5cd1c4c33776fa9eab8995d/raster_crop_tool.svg)

 allows you to remove portions of your photo or image. Crops can be non-destructive or can resample, and can use specific aspect ratios as required.

The Crop Tool is available by default in Pixel Studio.

It can be added to other Studios. See 'Customizing tools' for details.

Tool shortcut key: **C**.

The Crop Tool lets you reframe your image by removing unwanted areas from any edge of the canvas. Crops can be applied in two ways:

*   **Non-destructive**—the cropped area is hidden rather than deleted, so pixel data outside the crop boundary is preserved. It can be recovered at any time using **Reveal canvas**.
*   **Resample**—the image is permanently resampled to the specified dimensions and resolution. Use this when you need a precise output size.

Use the **Mode** setting on the context toolbar to control how the crop area is constrained — from freeform and original-ratio crops through to custom ratios, photographic paper sizes, and fully specified output dimensions.

The following settings can be adjusted from the context toolbar:

*   **Apply**—applies the crop to your image once you've defined the crop area (based on the positioned overlay).
*   **Cancel**—cancels the crop operation without applying changes to your image.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/3r0nypKaA5WwUhRidZ60F7/e75a1a686b28be34e9d4c8e77fc52f00/presets.svg) **Presets**—opens a list of presets and also allows access to the **Preset manager**.
*   **Mode**—sets the aspect ratio of the crop area. Select one of the following from the pop-up menu: 
    *   **Unconstrained**—allows you to size the crop area freely.
    *   **Original Ratio**—retains your image's original aspect ratio.
    *   **Custom Ratio**—uses the adjacent input boxes to set the ratio—width in the left box, height in the right box. Can be saved as a preset.
    *   **Resample**—use the adjacent **Width** and **Height** settings to set dimensions for the crop area at your chosen **DPI** and your measurement **Units**.

*   Crop dimension boxes—for **Custom Ratio** and **Resample** modes, sets the width and height, respectively.
*   **Units**—sets the units used by the crop area.
*   **DPI**—choose the DPI for resampling to unit measurements.
*   **Crop**—lists the current pixel resolution based on the unit measurements and DPI value.
*   **Rotate**—rotates the crop area by 180°.
*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/45glqwtrDUGOPkswrWPoTT/780888e8bed6386a2864c890e62457cd/straighten-image.svg) **Straighten**—switches to Straighten mode to align crooked photos horizontally or vertically.
*   **Overlay**—offers various overlays for better photo composition.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/48gU5vr3XwFWtBjwhAJWTo/28e1a43a4063087555940fbc383932d4/reset-global.svg) **Reset**—resets all settings to their defaults.
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/2VMsdKtajST4k7gHoexXSg/8d7b07ec0e3432fdeadbddb2b78fc586/crop-darken.svg) **Darken border**—renders areas outside of the crop boundary darker for easier previewing.
*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/7ndnrtmxX8WQ3yZuB2B2K3/32a0f0f21c949fe98d982051d44ba1d9/crop-reveal.svg) **Reveal canvas**—when checked, displays areas of the document outside of the current crop. Useful if you have already cropped the canvas and need to expand it again.

1.   From the Pixel Studio's toolbar, select the **Crop Tool**![Image 7](https://images.ctfassets.net/3p2fxa94bzao/1h7jiPUfGZiR8vLhdYmJdR/75ae8719b5cd1c4c33776fa9eab8995d/raster_crop_tool.svg) .
2.   On the context toolbar, choose a **Mode**to set the aspect ratio constraint.
3.   Drag the handles of the crop overlay to define the crop area. Drag inside the overlay to reposition it on the image.
4.   Click **Apply**on the context toolbar to apply the crop.

1.   From the Pixel Studio toolbar, select the **Crop Tool**![Image 8](https://images.ctfassets.net/3p2fxa94bzao/1h7jiPUfGZiR8vLhdYmJdR/75ae8719b5cd1c4c33776fa9eab8995d/raster_crop_tool.svg) .
2.   On the context toolbar, set **Mode**to **Custom Ratio**.
3.   Enter the desired width and height values in the ratio input boxes — width in the left box, height in the right box.
4.   Drag the handles of the crop overlay to define the crop area.
5.   Click **Apply**on the context toolbar.

If the ratio input boxes appear greyed out, check that **Mode** is not set to **Original Ratio** on the context toolbar.

*   To select the Crop Tool, press the **C** key.

The following shortcuts can be used while applying a crop:

*   To constrain the current aspect ratio while cropping in the **Unconstrained**mode, hold down the **⇧**key (Mac) / **Shift**key (Windows).
*   To nudge the area in single-pixel increments, use the **left arrow**and **right arrow**keys.
*   To nudge the crop area in 10-pixel increments, hold down the **⇧**key (Mac) / **Shift**key (Windows) while using the **left arrow**and **right arrow**keys.
*   To temporarily disable global snapping, hold down the **⌥**key (Mac) / **Alt**key (Windows).
*   For Mac: To recompose the image around its center, hold down the **⌘**key and drag on one of the crop area overlay's handles.
*   For Mac: To toggle the crop area overlay and enter the **Straighten**mode, hold down the **⌘**key and drag on the page (not the overlay's handles).
*   For Mac: To rotate the crop area around a handle, press the **⌃(ctrl)**key and drag the opposite handle.
*   For Windows: To rotate the crop area around a handle, drag the opposite handle and then hold down the right mouse button while dragging.
*   To quickly toggle between overlay modes, press the **O**key.

These shortcuts can be used in combination.
