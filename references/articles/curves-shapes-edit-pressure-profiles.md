# Edit on-page pressure profiles

The Stroke Width Tool lets you edit the pressure profile of curves created with line tools, typically the Pencil Tool, but also the Pen Tool and Path Brush Tool.

[](https://www.affinity.studio/help/curves-shapes-edit-pressure-profiles/#about-editing-pressure-profiles)

## About editing pressure profiles

The pressure profile at any position along a drawn stroke can be adjusted by creating placed _pressure points_. At these points you can adjust symmetrically using point handles to edit the profile that runs the length of the curve.

The benefits include:

*   Precise editing control of the pressure profile
*   Designing of the stroke's profile to be more in context with other elements on the page
*   Better visibility of the pressure profile for longer stroke lengths compared to the profile shown in the Stroke panel’s Pressure chart

The pressure profile is traditionally represented on the Stroke panel’s Pressure chart. The points on the chart are the same pressure points you add by selecting the curve with the **Stroke Width Tool** active. Conversely, if you add a point to the Pressure chart, it will appear on the curve in a position relative to that on the chart.

![Image 4: Pressure chart and edited on-page pressure profile](https://images.ctfassets.net/3p2fxa94bzao/19KNGxVr6VeZfsAj2UYTfy/7380d6a55088e6556d1196c7c265fe3c/edit_pressureprofile.jpg)

Correlation between the Stroke Panel's Pressure chart and the equivalent on-page pressure profile. The stroke width at a pressure point (A) can be increased or decreased by dragging point handles (B) while any pressure point can be repositioned by dragging (C).

[](https://www.affinity.studio/help/curves-shapes-edit-pressure-profiles/#snapping-while-profile-editing)

## Snapping while profile editing

The tool's context toolbar hosts several snapping controls that snap pressure points onto existing nodes or existing stroke widths on the curve.

[](https://www.affinity.studio/help/curves-shapes-edit-pressure-profiles/#profile-editing-and-painting)

## Profile editing and painting

Path brush strokes can have their pressure profile edited just like with strokes created with the Pencil and Pen tools. It's important to understand that these brush strokes have **Size Variance** and **Opacity Variance** settings that control how much the stroke size and opacity responds to pressure. If you edit the pressure profile with the Stroke Width Tool you may see size and/or opacity changing because of these settings.

[](https://www.affinity.studio/help/curves-shapes-edit-pressure-profiles/#how-to-create-a-pressure-point)

### How to create a pressure point

Desktop app

1.   In the Vector Studio   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/2Mejuekyv1U5fQVTYLqGud/edc8c0247142081ce0079de3013e815d/persona_vector.svg)       , select the **Stroke Width Tool**  ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/26i6Uzx1eWDjuowdFl4f2b/460655f9052a2bc725639c880897383f/line_width_tool_mono.svg)        from the **Pencil Tool** flyout.
2.   Click on a position on the curve.

The point’s handles extend symmetrically outwards from the ‘on-curve’ point to the current stroke width.

[](https://www.affinity.studio/help/curves-shapes-edit-pressure-profiles/#how-to-adjust-the-stroke-width-at-a-pressure-point)

### How to adjust the stroke width at a pressure point

Desktop app

Do one of the following:

*   Drag either point handle.
*   For a precise width, **⌃(ctrl)**-click (Mac) / **Ctrl**-click (Windows) on the point and set a value in the **Set Line Width at Point** dialog.

[](https://www.affinity.studio/help/curves-shapes-edit-pressure-profiles/#how-to-adjust-the-pressure-point-width-and-position)

### How to adjust the pressure point width and position

Desktop app

*   Select a point's handle (either of the pair) and drag to anywhere along the curve.

[](https://www.affinity.studio/help/curves-shapes-edit-pressure-profiles/#how-to-lock-a-pressure-point-s-position-but-adjust-the-stroke-width)

### How to lock a pressure point’s position but adjust the stroke width

Desktop app

*   With the **⇧** key (Mac) / **Shift** key (Windows) held, drag the point’s handle inwards or outwards.

[](https://www.affinity.studio/help/curves-shapes-edit-pressure-profiles/#how-to-lock-a-pressure-point-s-width-and-adjust-its-position)

### How to lock a pressure point’s width and adjust its position

Desktop app

*   With the **⌃(ctrl)** key (Mac) / **Ctrl** key (Windows) held, drag the point's handle to anywhere along the curve.

[](https://www.affinity.studio/help/curves-shapes-edit-pressure-profiles/#how-to-unlink-stroke-widths-on-a-closed-curve-s-start-end-point)

### How to unlink stroke widths on a closed curve's start/end point

Desktop app

*   **⇧**-drag (Mac) / **Shift**-drag (Windows) out from the pressure point.

To adjust the width on the opposite end of the closed curve, swap the curve direction using **Reverse Curves**

![Image 7](https://images.ctfassets.net/3p2fxa94bzao/4aEenWCp3fgkYVwRQQF18p/5aec5f6e69b82891e16fd078aec2ddf8/action_reverse_curves.svg)

 on the Node Tool's context toolbar before adjustment.

[](https://www.affinity.studio/help/curves-shapes-edit-pressure-profiles/#how-to-set-equal-stroke-widths-on-a-closed-curve-s-start-end-point)

### How to set equal stroke widths on a closed curve's start/end point

Desktop app

*   Double-click on either point handle to link the stroke widths. This sets the smaller stroke width to be equal to the larger stroke width.

[](https://www.affinity.studio/help/curves-shapes-edit-pressure-profiles/#how-to-delete-a-pressure-point)

### How to delete a pressure point

Desktop app

*   Double-click on a point (or its handle).

[](https://www.affinity.studio/help/curves-shapes-edit-pressure-profiles/#how-to-save-a-pressure-profile)

### How to save a pressure profile

Desktop app

*   On the **Stroke** panel, click **Pressure**.
*   Under the chart, click **Save Profile**. The profile shows under the chart.

[](https://www.affinity.studio/help/curves-shapes-edit-pressure-profiles/#shortcuts)

### Shortcuts

Desktop app

When using the Stroke Width Tool, the following modifier keys can be used to speed up the workflow as you draw:

*   When held, the **⇧** key (Mac) / **Shift** key (Windows) locks the pressure point’s position allowing just line width adjustment.
*   Double-click a start/end point on a closed curve to set equal line widths; use **⇧**-drag (Mac) / **Shift**-drag (Windows) to unlink. 
*   Press the **⌃(ctrl)** key (Mac) / **Ctrl** key (Windows) and click on a pressure point to set a precise line width via dialog.

[](https://www.affinity.studio/help/curves-shapes-edit-pressure-profiles/#see-also:)
