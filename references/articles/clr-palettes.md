# Color palettes - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/clr-palettes/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Color palettes

Color palettes in the Swatches panel store colors that can be reused. They can be supplied with the operating system, from the Affinity app or created from scratch.

The **Swatches** panel stores your solid colors or gradients and lets you access a range of predefined palettes, each containing solid or gradient fill swatches. These can be selected for use with various tools and for applying directly to objects.

You can also create and store your own swatches as custom color palettes; they can be created from your document's colors, from an image or added manually. You can also import Affinity .afpalette from other users, Adobe Swatch Exchange (ASE) palettes, and AutoCAD hatch pattern (.pat) files.

Although you can add colors to any of the predefined palette categories, we recommend that you always create your own.

The following types of palette are available:

*   **Document**—these palettes are saved within the current document.
*   **Application**—these palettes are saved within Affinity. These palettes are available to any Affinity document.
*   **System** (For Mac)—these palettes are saved to your operating system. These palettes are available within Affinity and other apps installed on your system.
*   **PANTONE®**—these palettes are based on PANTONE® Colors. These palettes are available to any Affinity document.

*   Click **Panel Preferences** and choose an **Add Palette** option.

From **Panel Preferences**, you can also rename, delete, and duplicate the selected palette.

1.   On the **Swatches** panel, select a palette from the palette pop-up menu.
2.    Do one of the following: 
    *   **^(ctrl)**-click (Mac) / **right**-click (Windows) an object, then from the pop-up menu, click **Add to Swatches** and choose to add color from fill, stroke or both. 
    *   Select **Add current color to palette**, or **Add current color to palette as a global color** (if you would also like to make this color a global color). Use the Stroke/Fill color selector to target the color.

*   Double-click a saved swatch.

*   **^(ctrl)**-click (Mac) / **right**-click (Windows) the swatch you want to remove and choose **Rename Fill** or **Delete Fill**. 

1.   Select the **Color Picker Tool**.
2.   Hold the **⌘** key (Mac) / **Ctrl** key (Windows) and click on colors on the page (or from outside the app).

A new Document palette is created which contains all the picked colours.

*   Click **Panel Preferences** and choose an option from **Create Palette from Document**.

A new palette is created (named after the document) using all the colors currently in the document.

*   Click **Panel Preferences** and choose **Create Palette From Image**.
*   On the **Create Palette From Image** dialog, click **Select Image** or click-drag an image onto the dialog to load it.
*   Change the **Number of Colors** slider to generate more or fewer colors from the selected image.
*   Use the **Location** option to specify whether the generated palette should be system-wide (Mac only), app-wide, or limited to the current document. You can also add the colors to the current active palette too.
*   Click **Create** to complete the palette generation.

Custom color palettes can be exported to and imported from external files (add-ons) via the **Panel Preferences** menu. For more information see the [Importing add-ons](https://www.affinity.studio/help/addons-importing-addons/) or [Exporting add-ons](https://www.affinity.studio/help/addons-exporting-addons/) topic.

Any palette can be set as the default used for specific color formats. For example, you can set **RGB/8** documents to have a different default palette to **CMYK/8** documents.

1.   On the **Swatches** panel, select a palette from the palette pop-up menu.
2.   Click **Panel Preferences** and choose a color format option from the **Set as Default for** from the pop-up menu.

To revert to using a system palette, choose **Remove Default for <color format>** from **Panel Preferences**.
