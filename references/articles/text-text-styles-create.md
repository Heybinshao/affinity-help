3.   Creating and managing text styles

Text styles can be created via the context toolbar or on the Text Styles panel, ready for applying to text. You can manage and edit them at any time.

There are several ways to create a new text style:

*   Build it from scratch—the new text style will have no initial connection to any other text style.
*   Duplicate it from another style—the new text style will initially be exactly the same as the existing text style but has no ongoing relationship to it. Both styles can be edited without affecting each other.
*   Base it on an existing style—the new text style will have the same settings as the existing text style and has an ongoing relationship to it. Changes to the existing style may affect the new style created from it.

A text style can be modified in two ways:

*   Editing the text style directly.
*   Updating the text style to match some selected, locally formatted text.

You can also assign your own keyboard shortcuts to individual text styles, usually to those you apply often.

The following options are available on the **Style** section of the **Text Style Editor** dialog:

*   **Based on**—sets the default settings for this style. The selected text style acts as a master for the new style.
*   **Next style**—for paragraph styles, this determines the text style automatically applied to the following paragraph (see note below).
*   **Next level**—for multi-level paragraph styles (e.g., those that use 1, 1.1 and 1.1.1 auto-numbering prefixes) this determines the style that is used for the subordinate level.
*   **Shortcut**—sets the keyboard shortcut that will apply this text style.
*   **Type**—determines the predominant nature of the text style, i.e. whether it is considered a character, paragraph, or group style.
*   **Show in both panels**—if this option is off (default), the text style can only be applied in its predominant way (determined by the Type option). When selected, a paragraph or group style can be applied as a character style.
*   **Reset Formatting**—removes all the settings applied in the Character, Typography, and Paragraph sections of the dialog. The settings in the Style section remain unchanged.

The **Next style** feature is only activated when you press the **⏎** key (Mac) / **Return** key (Windows) when typing text, or when you select **Apply "<style name>" Then Next Styles** on a text style's options menu on the **Text Styles** panel.

You can store character and paragraph formatting in text styles. Other sections of the dialog mirror the options available on the **Character** and **Paragraph** panels.

When a text style attribute is set to _[No change]_, its value will be inherited from the text style selected for the **Based on** option.

*   **Style name**—defines the name the text style will use throughout the app.
*   **Character**—adds character-level attributes or overwrites those determined by the **Based on** style. See [Character panel](https://www.affinity.studio/help/panels-character-panel/) for details.
*   **Typography**—activates OpenType features for the text style or overwrites those determined by the **Based on** style. See [OpenType font features](https://www.affinity.studio/help/text-opentype-fonts/) for details.
*   **Paragraph**—assigns paragraph-level attributes to the text style or overwrites those determined by the **Based on** style. See [Paragraph panel](https://www.affinity.studio/help/panels-paragraph-panel/) for details.
*   **Style settings**—summarizes all the attributes applied to the current text style.
*   **Apply style to selection**—applies the current text style to any selected text (if text was selected prior to entering the dialog) when you select **OK**.

*   The next dialog that appears lists text styles you can import.![Image 13: Imported Text Styles dialog](https://images.ctfassets.net/3p2fxa94bzao/3oMInsM128hBUoQZVVgbgG/2913fcf5f14c29db7a36e1a8ba70d572/importedTextStyles.png) Select a style's row to inspect the differences between the current version and the one that can be imported. The **Conflicts** column alerts you to potentially unwanted outcomes, e.g. "Replace existing style" appears if you rename an imported text style to something that's already in use. For each style, do one of the following as needed:
    *   To include a style for import, put a check mark in the first column. Where the style has the same name as one already in your document and you want to replace it, leave the checkbox next to **Rename To** unchecked.
    *   To import the style under a new name instead, check the box next to Rename To. Affinity suggests a name; click it to type your own.
    *   To ignore a style so it isn't imported, uncheck it in the first column.

*   Click **OK**.

The imported text styles replace existing styles or are added to the Text Styles panel as new styles.
