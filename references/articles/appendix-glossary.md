# Glossary - Affinity Help Center

3.   Glossary

On this page you can find an alphabetical list of terms that you may come across when using this software.

*   [**Adjustment**](https://www.affinity.studio/help/adjustments-adjustment-applying/)—an effect which can be applied to your design as a new layer for creative or corrective purposes.
*   [**Alignment**](https://www.affinity.studio/help/object-control-align/)—positioning objects to the left, right, center, top or bottom.
*   [**Anchor**](https://www.affinity.studio/help/advanced-hyperlinks/)—an inserted text marker that can be jumped to from a hyperlink.
*   [**Artboard**](https://www.affinity.studio/help/artboards-artboards-about/)—a portion of your work area within your document, of any shape or size, on which you can place design elements.
*   [**Asset**](https://www.affinity.studio/help/assets-assets/)—a stored design element which can be accessed from any document you have open.
*   **Baseline**—determines the position of the bottom of text characters in page layouts.
*   [**Baseline grid**](https://www.affinity.studio/help/design-aids-baseline-grids/)—a grid which is overlaid over your page to help you align text vertically.
*   [**Batch job**](https://www.affinity.studio/help/macros-batch-batchjobs/)—a feature that allows automatic processing of a number of image files.
*   [**Bézier curve**](https://www.affinity.studio/help/curves-shapes-about-lines-and-shapes/)—a vector curve that is defined mathematically, appearing smooth even when resized or transformed.
*   **Bitmap**—a raster image made up of a grid of pixels, where each point on the grid corresponds to an individual pixel.
*   [**Bleed**](https://www.affinity.studio/help/sharing-bleed/)—the area of the page that goes beyond the page edge to be trimmed off at commercial printers in the event of paper movement or design inconsistencies.
*   [**Blend mode**](https://www.affinity.studio/help/layers-layer-blend-modes/)—a mode applied to your layer which changes how the applied pixels interact with existing pixels on the layer below.
*   [**Blend range**](https://www.affinity.studio/help/layers-layer-blend-options/)—let you blend layers in a project by controlling opacity across the tonal range of the currently selected layer or the underlying layer(s).
*   **Body text**—the main text on a page, not including headlines.
*   [**Boolean operations**](https://www.affinity.studio/help/object-control-compound/)—methods of joining vector shapes together to create composite shape variations which can be fully edited as curves.
*   **Bounding box**—a temporary frame around a selected object showing its outer dimensions.
*   **Clipboard**—a memory space used for short-term storage and transfer of content during cut, copy and paste operations.
*   [**Clipping**](https://www.affinity.studio/help/layers-layer-clip/)—the act of positioning one vector object inside another to non-destructively 'mask' its content.
*   [**Closed shape**](https://www.affinity.studio/help/curves-shapes-about-lines-and-shapes/)—a shape created by closing an open curve drawn with the Pen Tool.
*   [**CMYK**](https://www.affinity.studio/help/clr-clr-spaces/)—a color model that is often used for commercial process printing.
*   [**Color picker**](https://www.affinity.studio/help/clr-sampling-clr/)—a tool used to select and sample colors.
*   [**Color space**](https://www.affinity.studio/help/clr-clr-spaces/)—the range of colors used to display and print colors in your file.
*   [**Column guide**](https://www.affinity.studio/help/design-aids-guides/)—a series of non-printing filled or outlined columns that can be used as a design aid for columnar projects.
*   **Contour**—the line that is used to define the shape of a vector object.
*   [**Control handle**](https://www.affinity.studio/help/curves-shapes-about-lines-and-shapes/)—extending from nodes as a pair of opposing handles, these can be dragged in different directions and extended to different lengths to adjust the shape and length of the segments between individual nodes.
*   **Cusp**—a point where two branches of a curve meet and the tangents of each branch are equal.
*   **Embedded file**—a placed copy of an original file that is embedded into a document. If the original file is moved or updated, the embedded copy will remain unchanged.
*   [**Fill mode**](https://www.affinity.studio/help/curves-shapes-fill-mode/)—determines how self-intersecting segments of a shape will be filled.
*   [**Filter**](https://www.affinity.studio/help/filters-filters-applying/)—an effect which can be applied to an image for corrective or creative purposes.
*   [**Global color**](https://www.affinity.studio/help/clr-global-clr/)—a color that can be created, applied, and updated for different objects across your design from a single place.
*   [**Glyph**](https://www.affinity.studio/help/text-characters/)—a specific shape of a letter presented in a particular typeface.
*   **Gradient**—a gradual blend from one color to another.
*   [**Grid**](https://www.affinity.studio/help/design-aids-grids/)—a pattern of lines which is overlaid over your page to help you align objects.
*   [**Guide**](https://www.affinity.studio/help/design-aids-guides/)—non-printing, non-exporting lines that float over page objects and assist with object positioning.
*   **Gutter**—a blank space that runs between text columns.
*   **HSL**—an alternative representation of the RGB model that more closely aligns with the way human vision perceives colors mixing together.
*   **HSV**—an alternative representation of the RGB model that more closely aligns with the way human vision perceives colors appearing under light.
*   [**Hyperlink**](https://www.affinity.studio/help/advanced-hyperlinks/)—a link that allows you to jump to specific pages, anchors, files or web addresses (URLs).
*   [**Index**](https://www.affinity.studio/help/advanced-index/)—a list of keywords (or topics) used in a publication which contain referenced page numbers.
*   **Justification**—parameters determining how spaces between words and characters should be adjusted.
*   [**Kerning**](https://www.affinity.studio/help/text-tracking-kerning/)—controlling the space between two characters which, due to each character's geometry, might otherwise leave an unappealing gap.
*   **LAB**—a color model that is designed to approximate human vision.
*   [**Layer effect**](https://www.affinity.studio/help/layer-fx-create-layer-fx/)—an effect that can be applied to either selected objects or the entire layer, changing its appearance.
*   [**Layer mask**](https://www.affinity.studio/help/layers-layer-masks/)—used to reveal a portion of a layer while the rest of the layer remains hidden.
*   [**Leading**](https://www.affinity.studio/help/text-leading-spacing/)—space added between lines of text.
*   **Ligatures**—presents two adjacent characters in a more creative way in advanced typography.
*   **Linked file**—a placed file containing a link between the document and the file on disk to allow it to update if it is changed on disk.
*   **Linking layers**—a way of linking layer attributes (such as blend mode and opacity) between layers.
*   [**Liquify**](https://www.affinity.studio/help/liquify-persona-liquify/)—the process of accurately warping an image.
*   [**Live filter**](https://www.affinity.studio/help/filters-filters-applying/)—a filter that can be applied to an image non-destructively.
*   **Luminance**—a measure of light emitted by raster layer content.
*   **Luminosity**—a perceived level of brightness by a human eye.
*   [**Macro**](https://www.affinity.studio/help/macros-batch-macros/)—a recorded operation that can be applied with a single click.
*   [**Margin**](https://www.affinity.studio/help/design-aids-margins/)—the area between the main content of the page and the page edges.
*   [**Master page**](https://www.affinity.studio/help/pages-master-pages/)—an underlying page that can be used to automatically apply formatting to other pages during page layout.
*   **Marquee**—a shape drawn around an object in order to make a selection.
*   [**Node**](https://www.affinity.studio/help/curves-shapes-about-lines-and-shapes/)—a connection point between segments of a vector curve or shape that controls the direction, length and curvature of its connected segments.
*   **Orphan**—in page layout, a stray opening line of a paragraph that appears by itself at the end of a page/text column, separated from the rest of the paragraph.
*   **Outline**—see **Path**.
*   [**Overprinting**](https://www.affinity.studio/help/clr-overprint/)—printing one ink color on top of another instead of the underlying color being removed.
*   **Palette**—a selection of stored color swatches.
*   **Pasteboard**—the area around the document or artboard where you can pastem create and arrange content.
*   **Path**—an outline representing a series of smooth vector lines.
*   **Picture frame**—a frame which content (such as images and documents) can be inserted into.
*   **Placeholder text**—a section of text that can temporarily be inserted into a frame to test the formatting and layout before the final copy is ready.
*   [**Preflight check**](https://www.affinity.studio/help/sharing-preflight/)—a final check of page layout, fonts, graphics and colors before exporting or printing.
*   [**Process color**](https://www.affinity.studio/help/clr-spot-clr/)—colors that are mixed by varying the percentages of Cyan, Magenta, Yellow and Black ink. See **Spot color**.
*   **Raster**—a type of graphic made up of a grid of pixels.
*   [**Raw image**](https://www.affinity.studio/help/raw-raw/)—an image format produced by a digital camera that contains minimal processed data.
*   [**Registration color**](https://www.affinity.studio/help/sharing-publish-pdffiles/)—a color (100%C:100%M:100%Y:100%K) used in professional CMYK printing to assign to an object that is used as a registration mark.
*   [**RGB**](https://www.affinity.studio/help/clr-clr-spaces/)—a color model that is often used for digital work.
*   [**Ruler**](https://www.affinity.studio/help/design-aids-rulers/)—guideline used to accurately place objects or guides in the document view.
*   [**Ruler guide**](https://www.affinity.studio/help/design-aids-guides/)—a non-printing guide that can be aligned to any point on the ruler.
*   [**Segment**](https://www.affinity.studio/help/curves-shapes-about-lines-and-shapes/)—the path between two nodes on a curve.
*   [**Snapping**](https://www.affinity.studio/help/design-aids-snapping/)—aligning images, brush strokes, lines, shapes, and selection areas to nearby grid lines, guides, margins, artboards or spreads, or any combination of these.
*   [**Spot color**](https://www.affinity.studio/help/clr-spot-clr/)—a color that can be used when your artwork contains a very limited color set, reducing print costs significantly and allowing you to accurately reproduce colors otherwise impossible with process colors.
*   [**Spread**](https://www.affinity.studio/help/pages-about-pages/)— a single page or left/right page pairings displayed at the same time (when **Facing pages** is checked).
*   [**Stack**](https://www.affinity.studio/help/stacking-stacks/)—a blended series of images based on the same scene or almost identical subject matter.
*   [**Stop**](https://www.affinity.studio/help/clr-gradient-editor/)—a point where a specific color is introduced in a gradient.
*   **Stroke**—a drawn line that can have different defined attributes such as weight, color, and style (solid, dotted, or dashed) applied to it.
*   **Studios**— customizable workspaces that can be swapped between; they offer different design disciplines, tools and environments.
*   **Swashes**—a more ornate alternative for a glyph in advanced typography, often appearing more exaggerated and calligraphic in nature.
*   [**Symbol**](https://www.affinity.studio/help/object-control-symbols/)—an intelligent object that can be placed repeatedly in your document. Editing one symbol will edit all other placements of that symbol (unless they have been unsynced).
*   [**Table of contents**](https://www.affinity.studio/help/advanced-toc/)—a list of chapter or section headings, usually found at the start of a document and normally annotated with page numbers.
*   [**Text frame**](https://www.affinity.studio/help/text-frame-text/)—a frame containing paragraph text which uses a formalized structure and layout.
*   [**Text style**](https://www.affinity.studio/help/text-text-styles/)—a set of text attributes and properties which can be applied to text.
*   [**Tracking**](https://www.affinity.studio/help/text-tracking-kerning/)—in page layout, the letter spacing between any two characters in your text. This can be increased or decreased equally.
*   [**Transform**](https://www.affinity.studio/help/object-control-transform/)—a general term for resizing, moving, rotating or shearing objects.
*   **Vector**—a type of graphic made up of mathematical paths.
*   [**Vector curve**](https://www.affinity.studio/help/curves-shapes-about-lines-and-shapes/)—in graphic design, an open path with a distinct start and end.
*   [**Vector shape**](https://www.affinity.studio/help/curves-shapes-about-lines-and-shapes/)—a closed path with no discernible start or end.
*   **White space**—areas of the design that contain no images or text.
*   **Widow**—in page layout, a stray line at the end of a paragraph that falls at the start of the next page/text column, separated from the rest of the paragraph.
