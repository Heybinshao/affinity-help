# Customizing tools

Tools are hosted on the Tools panel. The panel can be docked, floated, shown or hidden depending on your preference.

This feature is only available in Affinity for desktop.

The Tools panel can also be customized to fit your workflow. By removing tools, you can slim down the panel and add available tools when needed.

[](https://www.affinity.studio/help/workspace-customizing-tools-panel/#how-can-i-customize-a-tool-itself-)

### How can I customize a tool itself?

This topic covers customizing which tools appear on the panel, and their relative order. Instead, the customization of a specific tool's behavior may be possible via [Desktop settings: Tools](https://www.affinity.studio/help/desktop-settings-tools/).

[](https://www.affinity.studio/help/workspace-customizing-tools-panel/#how-to-undock-dock-the-tools-panel)

### How to undock/dock the Tools panel

Desktop app

*   On the **View** menu, select **Tools > Dock** to undock; select again to dock.

[](https://www.affinity.studio/help/workspace-customizing-tools-panel/#how-to-hide-show-the-tools-panel)

### How to hide/show the Tools panel

Desktop app

*   On the **View** menu, select **Tools > Show** to toggle the panel on or off.

[](https://www.affinity.studio/help/workspace-customizing-tools-panel/#how-to-hide-show-sub-tools)

### How to hide/show sub tools

Desktop app

*   On the **View** menu, select **Tools > Sub Tools** to toggle the sub tools on or off.

[](https://www.affinity.studio/help/workspace-customizing-tools-panel/#how-to-add-or-remove-a-tool)

### How to add or remove a tool

Desktop app

1.   On the **View** menu, select **Tools > Customize**.
2.   Do one of the following:

*   To add: Drag a tool icon from the dialog to a position on the Tools panel.
*   To remove: drag the tool to anywhere in the document view and release.

*   To locate a tool by name, use the search field at the top of the dialog.

If a tool is grayed out in the dialog and can't be dragged, the tool is already present on the Tools panel, but may be hidden in a flyout. Note that if you change to a different Studio, the tool availability may change because the toolset changes between Studios.

[](https://www.affinity.studio/help/workspace-customizing-tools-panel/#how-to-reset-the-tools-panel)

### How to reset the Tools panel

Desktop app

1.   On the **View** menu, select **Tools > Customize**.
2.   On the dialog, click **Reset Tools**.

[](https://www.affinity.studio/help/workspace-customizing-tools-panel/#how-to-set-the-number-of-columns)

### How to set the number of columns

Desktop app

1.   On the **View** menu, select **Tools > Customize**.
2.   On the dialog, select the **Number of Columns** pop-up menu and choose a value.

[](https://www.affinity.studio/help/workspace-customizing-tools-panel/#see-also:)
