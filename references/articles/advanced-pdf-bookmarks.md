# Bookmarks - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/advanced-pdf-bookmarks/

3.   Bookmarks

PDF and EPUB files can include bookmarks that help the reader jump to important content without scrolling or searching.

For example, the start of every chapter of a book, major articles in a magazine, or important text or figures in a report.

There are two methods for creating bookmarks:

*   Manually, by adding anchors to text or objects, such as a picture frame, table, or shape.
*   Automatically, by creating a table of contents (TOC) for your document.

The two methods can be used together in the same document.

Bookmarks can be created manually using the **Anchors** panel, by enabling the **Export as Bookmark** option.

If you tell Affinity to create bookmarks for your table of contents, it creates one for each item.

You can use the bookmark icons on the corresponding entries on the Anchors panel to disable bookmarks for TOC levels you don't want them for. For example, you might want bookmarks only for Heading 1 and Heading 2 text styles.

Anchors can be arranged in a hierarchy, with any anchor acting as the parent of others. This hierarchy is used when exporting to PDF.

The hierarchy is displayed as a tree in PDF viewers, similar to a table of contents. Parent anchors are exported as top-level bookmarks, with child anchors appearing as nested bookmarks beneath them.

To organise bookmarks created from manually added anchors, drag an anchor on the Anchors panel and drop it onto another anchor. You can nest anchors multiple levels deep.

When bookmarks are created from a table of contents, their hierarchy is automatically applied based on the TOC structure.

When exporting to EPUB, the output automatically includes bookmarks.

When exporting to PDF, you can choose whether bookmarks are included. These presets include bookmarks by default:

*   PDF (digital - small size)
*   PDF (digital - high quality)
*   PDF (flatten)

Where to find bookmarks when viewing a PDF or an EPUB file depends on your reader.

In Acrobat Reader on desktop, for example, they're in the Bookmarks pane (**View > Show/Hide > Side Panels > Bookmarks**). In Apple's Preview app, for example, select **View > Table of Contents**.

For EPUB readers, bookmarks from Affinity are usually shown with the interactive table of contents (the navigation document) when exported as a Reflowable EPUB.

1.   Select the text or object to which you want to add an anchor.
2.   On the **Anchors** panel, click **New Anchor**![Image 1](https://images.ctfassets.net/3p2fxa94bzao/3acfBIGiUCk7Ogb2AeCimL/e54cca1f37a8b5e117b13c30fc3f5568/new_document_from_snapshot.svg) .
3.   On the dialog that appears: 
    1.   Check **Export as Bookmark**.
    2.   (Optional) Rename the anchor.
    3.   Click **OK**.

1.   Select the text frame that contains your table of contents (TOC).
2.   On the **Table of Contents** panel, check **Include as bookmarks**.

If you change your mind about including TOC bookmarks, unchecking the option removes all related entries from the **Anchors** panel.

1.   Select **File > Export > Export**.
2.   Select the required PDF preset.
3.   (Optional) Customise the preset's options as needed.
4.   Make sure **Include bookmarks** is enabled.
5.   Click **Export**.
6.   Type a name for the output file, navigate to where you want to save it, then click **Save**.
