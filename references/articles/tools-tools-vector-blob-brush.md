# Vector Blob Brush Tool - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/tools-tools-vector-blob-brush/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Graphic design](https://www.affinity.studio/help/graphic-design/)
3.   Vector Blob Brush Tool

The Vector Blob Brush Tool is used to draw filled vector curves directly, without having to draw an outline.

The selected object determines what the brush acts on. Select the objects you want to combine or extend before you paint with the tool.

Brush strokes that intersect the currently selected object are added to it. Otherwise, a new filled curve is created on a new layer.

The tool adds to any existing vector object, including those drawn with other tools such as the shape tools or the Shape Builder Tool.

Brush strokes are combined with existing curves only if the curves are selected.

The Vector Erase Brush Tool subtracts from a filled area. You can temporarily use its behavior by holding a modifier key.

The following options are available on the context toolbar:

*   **Nozzle**—sets the shape of the brush tip: Round or Square.
*   **Size**—sets the diameter of the brush tip.
*   **Stabilizer**—enables stroke stabilization using one of two modes:
    *   **Rope mode**—drags the stroke end by a 'rope' to smooth the stroke, but lets you introduce sharp corners at increasing rope _Length_(radius) values by redirecting the slackened rope.
    *   **Window mode**—smoothes the stroke by averaging sampled input positions within a _Window_ whose size is configurable.

*   **Rope Length**/ **Window Size**—sets the length of the rope or size of the window used by the stabilizer.
*   **Controller**—sets how the brush stroke responds to various inputs:
    *   _Brush Defaults_—the brush variance and controller settings stored with the currently selected brush are used. Click **More**on toolbar to access.
    *   _Automatic_—the input device (pen tablet, Force Touch device, mouse) is detected and the brush will work automatically with that device, using the brush variance settings but ignoring the brush controller setting. You can operate devices interchangeably.
    *   _Pressure_—brush stroke is only responsive to pressure from a pen tablet, using the brush variance settings but ignoring the brush controller setting.
    *   _Velocity_—brush stroke is only responsive to speed of mouse movement.

*   To draw a straight line constrained to 45° increments, hold the **⇧** key (Mac) / **Shift** key (Windows), then drag on the page with the left mouse button.
*   To draw a straight line at any angle, hold the **⌃(ctrl)** key (Mac) / right mouse button (Windows), then drag on the page with the left mouse button.
*   To decrease or increase the nozzle size, use the **[** and **]** keys.
*   To temporarily switch to the Vector Erase Brush Tool, hold the **⌥** key (Mac) / **Alt** key (Windows).
*   To temporarily switch to the Node Tool, hold the **⌘** key (Mac) / **Ctrl** key (Windows).
