# Desktop settings: User Interface - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/desktop-settings-user-interface/

1.   [Help Center](https://www.affinity.studio/help/)
2.   Desktop settings: User Interface

Adjust how the interface looks and behaves, including brightness, contrast, font size, cursor feedback, measurement display preferences, and other interaction settings.

The following settings are available:

*   **Background gray level**—Controls the grayscale level of the pasteboard surrounding the document.
*   **Artboard background gray level**—Controls the grayscale level of the pasteboard surrounding artboard(s).
*   **Text contrast**—Adjusts the luminance of text in the user interface.
*   **UI brightness**—Adjusts the luminance of window backgrounds in the user interface.
*   **UI Contrast**—Instantly sets Text Contrast and UI Brightness for high contrast between text and window backgrounds, or to their default values.
*   **UI font size**—(For Mac) Optionally increase the font size of UI text.
*   **Accent color**—(For Windows) Sets the color used to highlight selected buttons and menu items. Choose from:
    *   _Default_—Affinity's factory settings.
    *   _System_—To use the system accent color shared by Windows apps, as set in Windows Settings, under **Personalization > Colors**.
    *   _Custom_—To choose your own color without affecting other apps.

For Mac, Affinity does not provide an Accent Color setting. The app uses the system accent color set in System Settings, under **Appearance**.
*   **Custom color**—(For Windows) Available when **Accent Color**is set to _Custom_. Click the swatch and select a color.
*   **Tooltip delay**—Set the length of time before a tooltip appears when hovering over a UI element.
*   **UI style**—Displays the user interface in a dark or light style. (Mac only: the **Default OS**option matches Affinity to your operating system's appearance setting.)
*   **Decimal places for unit types**—Controls the number of decimal places allowable for each document measurement unit and degree readouts.
*   **Default view mode**—Choose from Vector, Pixel, or Automatic. Automatic opens in Vector view mode for documents with physical measurement units, and Pixel view mode for documents measured in pixels or when opening images.
*   **Automatically lock background layer on import**—Locks (or keeps unlocked) an imported image as a background layer.
*   **Show Lines in points**—Choose whether line width (thickness) displays in points or in the document's measurement units.
*   **Show Text in points**—Choose whether text is expressed in points or in the document's measurement units.
*   **Show brush previews**—Choose whether the brush cursor display a preview of pixels to be placed. When enabled, a circular preview of the current brush's nozzle is displayed; disable the option to hide the nozzle preview if the preview obscures existing page content. When **Force pressure**on the brush tool's context toolbar is enabled, previews are automatically disabled.
*   **Always show brush crosshair**—Overlays a cross-hair over the brush cursor for better targeting.
*   **Auto commit filters**—In Pixel Studio, choose whether to commit filters if subsequently carrying out a new operation while the Apply dialog is still open or whether to receive a prompt to Apply or Discard the filter instead. Clicking Apply will always commit the filter, irrespective of the this setting.
*   **Always use white background for font dropdown**—Choose whether to preview fonts on a white (default) or black background in the font selection dropdown list.
*   **Enable touch bar support**—(For Mac) Choose whether to activate Touch Bar support. Enabling this option requires app restart.
*   **Enable pointer support**—(For Windows) Choose whether to enable pointer support. Enabling this option requires app restart.
*   **Ask for name when creating Layers and Groups**—Choose whether you would like to be prompted to name a new layer, group or warp group upon creation.
*   **Allow trackpad to scroll numeric fields**—Enables field scrolling to enter numeric input when using a multitouch trackpad or Magic Mouse.
*   **Hide document tabs with one document open**—When selected, the document tab is hidden. The filename, zoom percentage, and file modification status (a star indicates unsaved changes) can still be seen at the bottom-right of Affinity's main window.

*   For Mac: From the Affinity app menu, select **Settings**.
*   For Windows: On the **Edit** menu, select**Settings**.
