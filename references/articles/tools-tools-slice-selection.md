# Slice Selection Tool

The Slice Selection Tool

![Image 6: Slice Selection Tool](https://images.ctfassets.net/3p2fxa94bzao/5JtBNhm1xFgv2cQ5VdylPu/9a13a35dde2356d562b8cdc70ec0a617/slice_selection_tool.svg)

 allows you to select objects on the page to be slice candidates for export.

[](https://www.affinity.studio/help/tools-tools-slice-selection/#where-to-find-it)

### Where to find it

The Slice Selection Tool is available by default in Slice Studio.

It can be added to other Studios. See 'Customizing tools' for details.

Selecting objects on the page with the **Slice Selection Tool**

![Image 7: Slice Selection Tool](https://images.ctfassets.net/3p2fxa94bzao/5JtBNhm1xFgv2cQ5VdylPu/9a13a35dde2356d562b8cdc70ec0a617/slice_selection_tool.svg)

 is an alternative to selecting them using the Export Layers panel. 
Selection is made by either drawing a marquee over one or more objects or selecting individual objects with the **Shift** key pressed.

[](https://www.affinity.studio/help/tools-tools-slice-selection/#shortcuts)
