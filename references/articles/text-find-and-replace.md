# Find and replace - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/text-find-and-replace/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Page layout](https://www.affinity.studio/help/page-layout/)
3.   Find and replace

You can search text for as little as a specific character or for long, complex phrases and patterns.

Search terms and replacement text can include invisible characters like frame breaks and non-breaking spaces, inbuilt fields such as page numbering, and custom fields.

It's even possible to specify formatting that must be applied to the text you want to find or its replacement.

Affinity can locate document text that matches a pattern. See [Regular expressions](https://www.affinity.studio/help/extras-regex/) for more information.

1.   On the **Edit** menu, select **Find > Find**.
2.   On the **Find and Replace** panel, do one of the following: 
    *   To find text: Type the text to be found in the **Find** box and its replacement text (if any) in the **Replace with** box.To use special characters or fields: select the magnifying glass icon at the left of the **Find** or **Replace** box and then select the required item from the menu that appears. 
    *   To find formatting: Select **Formatting**![Image 1](https://images.ctfassets.net/3p2fxa94bzao/3r0nypKaA5WwUhRidZ60F7/e75a1a686b28be34e9d4c8e77fc52f00/presets.svg)  and then select **Format** to specify precise text formatting using a dialog, or select **Character Style** or **Paragraph Style** and then the required style.

To clear formatting criteria so it doesn't affect future searches, select **Formatting**

![Image 2](https://images.ctfassets.net/3p2fxa94bzao/3r0nypKaA5WwUhRidZ60F7/e75a1a686b28be34e9d4c8e77fc52f00/presets.svg)

 next to the **Find** or **Replace** box as appropriate, and then select **Reset Format**.

3.   Select the **Scope** you wish to search: _Document_, _Section_, _Spread_, _Page_, _Story_ or _Selection_. A selection can be a text range or one or more text objects.
4.   Click **Find** to display a list of results at the bottom of the panel. The number of matching results is shown next to the **Scope** setting.
5.   Select any result in the list to focus the document view on the corresponding text on its page.
6.   (Optional) Do one of the following: 
    *   Click **Replace** to replace the selected result in your document using the settings specified in the **Replace with** setting. Repeat from the previous step as required.
    *   Click **Replace All** to replace every instance listed.

Use **Find > Next** and **Find > Previous** on the **Edit** menu to jump to the next or previous search result. Keyboard shortcuts can be assigned to these commands in Affinity's Settings.

On the **Find and Replace** panel:

1.   Next to the **Find** box, select **Formatting**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/3r0nypKaA5WwUhRidZ60F7/e75a1a686b28be34e9d4c8e77fc52f00/presets.svg)  and then: 
    1.   Select **Regular Expression** or **Locale Aware Regular Expression**.
    2.   (Optional) On the same menu, hover over **Regular Expression Options** and enable **Single Line Mode** and **Dot Matches Paragraph Break** as needed.

2.   Type a regular expression in the **Find** box.
3.   Click **Find** to search for instances of matching text in the selected scope.
