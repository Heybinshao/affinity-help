# Layers panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-layers-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Layers panel

The Layers panel lets you create a tiered document that can be edited more easily by layer management.

For Mac/Windows: On the **Window** menu, select **General > Layers**.

Layers are composited together to form your complete design which shows up on your page.

The panel can be used to build up your design as multiple layers, with each layer devoted to a particular type (e.g., pixel, shape, text, adjustment, artboard, etc.).

The Layers panel in the Slice Studio looks similar to that in other Studios. The key difference is that it is not intended to help edit items on the page but instead to select layers to create exportable slices from.

The following options are available on the panel:

*   **Opacity**—adjusts opacity of the selected item.
*   **Blend Mode**—changes how the applied pixels interact with existing pixels on the layer below. Choose mode type from a pop-up menu.
*   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/5aLt8lzEcmovjtpJrbbZFI/521800938c5909fe2677c5c56dc42a30/settings_cog_layers.svg) **Blend Options**—click to access a dialog for setting the blend options, blend gamma and antialiasing settings for the selected layer.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/52XYdXlyLW1ZAzUYGK6kqf/48bc9cd93adcdbf14804e0cab02cbcf0/lock_layer.svg) **Lock/Unlock**—click to lock or unlock selected items to prevent accidental selection and transformation.
*   **Layer entry**—the layer for the created item, comprised of: 
    *   **Layer type**—the layer's type, identified by a unique symbol.
    *   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/CXYwh0ow0MP0BdGHPkm0d/80e303839696248b5af0c91ad33dcf35/ArrowsRight.svg) **Expand/Collapse**—click to expand/contract the item, revealing nested content. **^(ctrl)**-click (Mac) / **right**-click (Windows) the item for options that let you affect a currently expanded parent layer(s) and group(s) using **Expand Selection**/**Collapse Selection** or affect all parents in the layer stack using **Collapse All Parents** (or **Layer > Collapse All in Layers Panel**). Alternatively, it is possible to expand or collapse layers in a stack or group by pressing the **⌥**key (Mac) / **Alt** key (Windows) while clicking on the Expand/Collapse chevron. 
    *   **Layer thumbnail**—visual representation of the layer contents on a checkerboard transparent background.
    *   **Layer name/type description**—text description of the layer type if unnamed; a double-click will let you name the item (removing the layer type description). For text layers, the text used on the page will be shown, while placed documents will show their filenames.
    *   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/7HxpRtMyF1dKpVk78Z0ZZE/6c4c14b63bb1f9686949de09071ed820/brush_on_layer.svg) **Recent brushes**—for pixel layers with pixel brush strokes already applied, clicking the icon offers the previously used brushes on that layer for reselection and further painting. For the current session only.
    *   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/9rstenG65qWb7jzhC83X9/df6defa0ca6b00f2d4f82ec5823bffa6/visibility_on.svg) **Toggle Visibility**—disable to hide the item; enable to make it visible again. **^(ctrl)**-click (Mac) / **right**-click (Windows) the item for options to hide selected layers (**Hide**), hide all other unselected layers (**Hide Others**), show other hidden layers (**Show Others**) or color tag the layer for easy layer identification. Hidden layers will not print or export.

*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/7Mk5jz4pzwPhVhM6CPJAOg/b3d17c0013c768b2e5861e717791947e/edit_all_layers.svg) **Edit within current container**—allows selection and editing of content across all artboards and layers (rather than the current layer).
*   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/4WJylimiHvA29KOENvEUQC/80598198347d79f39cf98c4f303dc8de/add_fx_layer.svg) **Layer Effects**—applies a layer effect to the currently selected layer.
*   ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/4q6OWVN4MyCGmeC0NuhiCI/696babeff770d207d6c4866c36cafb06/add_mask_layer.svg) **Mask Layer**—creates a layer mask to reveal a portion of a layer while the rest of the layer remains hidden.
*   ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/6jrlitTLwUvWbBWmQ3gUls/95c943cf10acdb62f3053cf6dff7aaa9/add_live_filter_layer.svg) **Filters**—creates a layer with the selected live filter.
*   ![Image 10](https://images.ctfassets.net/3p2fxa94bzao/4ZFx9I9M7MiUBPmytBqZrt/cad5a29a5e39b1b3faa42c5fa29402f3/add_adjustment_layer.svg) **Adjustments**—adds a non-destructive adjustment layer to the current layer for tonal and color correction. Each [adjustment type](https://www.affinity.studio/help/adjustments-adjustment-applying/) has its own symbol to uniquely identify it from other adjustment types.
*   ![Image 11](https://images.ctfassets.net/3p2fxa94bzao/1spd7cWUc4OJw0BrJfmq22/fb5b386d6dde2ceb509bbde9b50c19ab/add_layer.svg) **Container Layer**—creates an empty container layer above the currently selected layer or at the top of the layer stack if a layer is not selected. Container layers can store a mix of vector and raster content.
*   ![Image 12](https://images.ctfassets.net/3p2fxa94bzao/3SI2jKJJGRnBGX6iUjAWt6/c334b6d1ae0708e3e693164d907c238c/add_group_layer.svg) **Group**—creates an empty layer group if no layers are selected, or groups the selected layers together.
*   ![Image 13](https://images.ctfassets.net/3p2fxa94bzao/2tb2Y3kgsXSew9BPP8NUN1/278302d8ad7b533abc80d931474e9069/add_pixel_layer.svg) **Pixel Layer**—creates an empty new pixel layer above the currently selected layer or at the top of the layer stack if a layer is not selected.
*   ![Image 14](https://images.ctfassets.net/3p2fxa94bzao/3m8ciDtLqf07Yrma1i0j4x/202c1d508104bbb0a1290c5be7725eae/trash_can.svg) **Remove Layer**—deletes the currently selected layer.

The following options are available on the **Panel Preferences** menu

![Image 15](https://images.ctfassets.net/3p2fxa94bzao/6UxpXBt5miovw347YaOPUz/6f8e3e8d9b379daa0bdc5a3ac6ff23e8/panel_preferences.svg)

:

*   **Auto-scroll**—when selected (default), the selected object's layer entry immediately comes into view on the **Layers** panel.
*   **Show Group Thumbnails**—when selected (default), each group layer’s thumbnail displays a preview of all the group’s contents. When deselected, a folder icon is shown instead.
*   **Show Object Type**—when selected (default), each layer entry displays an icon to identify its type. When deselected, icons are hidden.
*   **Thumbnail Background**—when selected, layer thumbnail backgrounds will display a checkerboard which can be darkened/lightened.
*   **No Thumbnails**—when selected, removes thumbnails from view.
*   **Small Thumbnails**—when selected (default), displays small thumbnails.
*   **Medium Thumbnails**—when selected, displays medium thumbnails.
*   **Large Thumbnails**—when selected, displays large thumbnails.
*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
