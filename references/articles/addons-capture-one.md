# Editing Capture One content in Affinity

Affinity supports direct editing workflows with Capture One, allowing you to open, edit, and return images without losing key project information. Using the Affinity's native **.af** file format, you can transfer image data and continue working in Affinity while preserving important editing context.

This workflow requires Capture One version 16.7.7 or newer with **.af** file support. No additional setup is required in Affinity.

The feature is currently available only on Macs with Apple silicon.

![Image 4: Edit With Affinity option in Capture One.](https://images.ctfassets.net/3p2fxa94bzao/3nrICKrnMOLrjdf1PFtDA4/9c8ca8d156a1f678446dfe1677372ded/affinityCaptureOne.png)

Edit With Affinity option in Capture One.

[](https://www.affinity.studio/help/addons-capture-one/#about-capture-one-workflows)

## About Capture One workflows

Capture One provides two workflows for working with Affinity:

*   **Edit With**—opens the selected image directly in Affinity for immediate editing.
*   **Export + Open With**—exports the image and opens it in Affinity as a new document.

Both workflows allow you to edit the image in Affinity and return the updated result to Capture One.

[](https://www.affinity.studio/help/addons-capture-one/#what-is-transferred)

### What is transferred

When opening an image in Affinity from Capture One, the following data is preserved:

*   Metadata
*   Overlays and annotations
*   Watermarks (only available through the Export module)
*   Masks (preserved as alpha channels)
*   Watermarks
*   Guides

This allows you to continue editing with access to key structural and organizational elements from your Capture One project.

[](https://www.affinity.studio/help/addons-capture-one/#why-use-this-workflow)

### Why use this workflow

Using the native **.af** format provides a more complete editing pipeline compared to traditional export methods.

*   Retains masks and editing context without flattening the image
*   Avoids loss of metadata and project information
*   Enables non-destructive editing using Affinity layers and adjustments
*   Supports more advanced retouching and compositing workflows

This is particularly useful for photographers and retouchers who use Capture One for image management, batch exporting and Affinity for detailed, layer-based editing.

[](https://www.affinity.studio/help/addons-capture-one/#working-with-layers)

### Working with layers

Once the image is opened in Affinity, you can:

*   Apply adjustments and filters non-destructively
*   Add new layers for retouching or compositing
*   Use imported alpha channels to recreate or refine masks

After editing, save the document to update the image in Capture One.

[](https://www.affinity.studio/help/addons-capture-one/#color-support)

### Color support

The workflow supports standard color management, including **CMYK** color profiles when working with compatible files.

Importing supports 8-bit and 16-bit .af files, which aids workflows where you'd want to bring the final Affinity file back to Capture One and export it alongside other images.

[](https://www.affinity.studio/help/addons-capture-one/#how-to-port-an-image-from-captureone-to-affinity:)

### How to port an image from CaptureOne to Affinity:

Desktop app

1.   In Capture One, select the image you want to move to Affinity.
2.   Do one of the following:
    1.   Right-click the image and choose **Edit With**, then select **Affinity.**
    2.   On the Export tool tab, navigate to **Export Format & Size**and select **Affinity.**

The image opens in Affinity with transferred metadata, overlay, annotations, and alpha masks.

3. Edit the image using layers, adjustments, filters, or retouching tools, as required.

4. Save the document to return to the updated result in Capture One.

[](https://www.affinity.studio/help/addons-capture-one/#see-also:)
