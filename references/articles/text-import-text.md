# Importing text - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/text-import-text/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Importing text

Text stored in external files can be imported into Affinity documents.

Typically text is imported into a text frame, but it can also be imported into artistic text or path text.

Text files in Rich Text Format (.rtf) and plain text (.txt) formats can be imported. If your text editor saves as or can export to one of these formats, you can use the files in Affinity.

Microsoft Word (.docx) files can also be imported. Text styles are imported and applied to text as in the original document.

When text is imported, the current selection determines its placement. When:

*   a text frame is selected, all existing content in the frame, and any frames linked to it, is replaced.
*   a range of text is selected, it is replaced. Text before and after the selection is unaffected.
*   an insertion point exists in text, the imported text is inserted at its position. Text before and after the insertion point is unaffected.
*   neither a text object nor a range of text is selected, Affinity waits for you to click/tap or drag as indication of where to place the imported text.

1.   (Optional) Do one of the following: 
    *   If you want to replace all of an existing text frame's contents, use the **Move Tool**![Image 1](https://images.ctfassets.net/3p2fxa94bzao/3oigj5SSoPtnSw21egHEvD/b6ac975f2be7b3feb8e3e9867b378345/move_tool.svg)  to select the frame.
    *   If you want to insert text into a text frame, create an insertion point in the frame or select a text range to replace.

2.   On the **File** menu, select **Place**.
3.   Navigate to the file whose contents you want to import. Select it and click **Open**.
4.   If you didn't create an insertion point and nothing is selected, do one of the following: 
    *   Click an existing text frame.
    *   Click elsewhere in the document view to create a text frame of the default size.
    *   Drag to create a text frame of the required size.

 The file's _contents_ are placed in the text frame. 

Although the Place feature is most commonly used with text frames, it can also import into artistic text and path text.

Selecting multiple text files to import will load them onto the **Place** panel. To place the currently selected item from the panel, click a text frame or drag to create a new one.

Instead of using the Place feature, you can use the following methods:

*   Import a file by dragging it from Finder (Mac) / File Explorer (Windows) and dropping it: 
    *   onto a text frame to append to the existing contents.
    *   otherwise, onto the page to create a text frame of the default size.

*   Import text from the Clipboard by selecting **Paste > Paste** or **Paste > Without Format** on the **Edit** menu.

1.   On the **Document**menu, select **Setup > Document Setup**.
2.   On the dialog that appears, in the **Resources**section, enable **Import text as linked**.
3.   Place your text using the **Place Tool**or **File > Place.**

Affinity maintains links to any text files placed in your document while this setting is enabled. You can review their status in the **Resource Manager**.
