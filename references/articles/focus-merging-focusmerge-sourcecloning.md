# Focus merge source cloning

Once a set of images have been focus merged, Affinity will display the Sources panel populated with a list containing the final merged result and all the individual images used to create the focus merge. This gives you the option of re-editing areas of the result using the Clone Brush Tool.

This feature is only available in Affinity for desktop.

[](https://www.affinity.studio/help/focus-merging-focusmerge-sourcecloning/#how-to-edit-a-merged-result-using-the-sources-panel)

### How to edit a merged result using the Sources panel

Desktop app

1.   In the Pixel Studio   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/x0qUKV0QmljBpXjlKaAyD/48b1503c7d6cc8f05d91c6af70f31b85/persona_photo.svg)       , select the **Clone Brush Tool**.
2.   In the **Sources** panel, double-click the added image from the layer stack to set it as the current clone source.
3.   You can enable the **Toggle source preview** eye icon which will allow you to preview each image and find the best source to clone from. When you have chosen the correct source, disable this option in order to edit the merged result again.
4.   Using the realtime preview as a guide, paint over the areas of the focus merged image you wish to replace with the clone source.

The **Sources** panel is off by default. To enable it, navigate to the top menu and select **Window > Pixel > Sources**.
