# Creating an index - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/advanced-index/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Page layout](https://www.affinity.studio/help/page-layout/)
3.   Creating an index

Affinity can create an index of topics from your publication's text. The index lets the reader look up these topics and the pages that mention them.

An index is a valuable reader aid in a long publication, such as a report or manual.

![Image 1: An example index](https://images.ctfassets.net/3p2fxa94bzao/2IyE2fK1Nw1nycbIeZRurc/6a5c3463cd2ed4879b3f6af4006306c4/indexExample.png)

An example index.

For Affinity to create an index, you'll need to add index marks to your document.

The index usually appears at the end of your publication and contains **index entries**. Each index entry has a topic name and either or both:

*   a list of page numbers on which the topic is referenced.
*   cross-references which suggest to the reader to look at a related entry.

You can organize entries in a hierarchy. A parent topic can have sub-topics with their own references.

When the index is generated, it will list, in alphabetical order, all topics and sub-topics that have at least one reference.

Affinity is flexible about how index entries are created. You can either:

*   create topics on the Index panel, then insert index marks in text and associate them with topics.
*   insert index marks in text and create new index topics (or associate with existing topics) at the same time.

To insert an index, you'll need one entry with a page reference.

Building the index is straightforward. To summarize:

1.   On the **Index** panel, add a topic you wish to appear in your publication's index.
2.   Wherever related text appears in your publication, use the Index panel to insert an index mark.
3.   Repeat steps 1 and 2 until you've created topics and index marks for all entries you wish to appear in the index.
4.   Create an insertion point in your document where you wish the index to appear, then use the Index panel to insert the index.

The inserted index will list, in alphabetical order, all topics for which there is at least one index mark, and page numbers for related index marks.

From any topic on the panel, you can tell Affinity to show all instances of the topic's name in document text.

From the list, you can choose which instances you want to associate with the topic. Affinity inserts index marks at your selected instance's positions, quickly building up the index's content.

A parent topic can be set for any existing topic or sub-topic, creating a hierarchy that is visually reflected in the index.

You can add cross-references to suggest related topics to the reader.

You can rename existing topics and sub-topics. This affects their position in the index.

If you edit topics, sub-topics or index marks after inserting the index, you will need to update the inserted index to reflect these changes.

Normally, Affinity sorts index topics by their literal topic names. So, topic names that begin with _A_ or _The_, for example, will appear in the index under _A_ or _T_, respectively.

You can change the default sort order by setting a topic's **Sort By** name. For example, if a topic's name is _The Great Wall of China_, set the Sort By name to _Great Wall of China_ to make the topic appear under _G_ in the index.

You can also use **Sort By** text to override order without changing topic names. For example, you might wish to convey the hierarchical importance of sub-topics rather than list them alphabetically.

1.   In document text, select the word or phrase to be indexed.
2.   On the **Index** panel, select **Insert Marker**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/2ATQ7T79i1gahgbto1qWnl/3b4481d2d153ee3eea821f86ac458a82/insertIndexMarker.svg) .
3.   On the dialog that appears: 
    1.   **Topic** shows the topic (or sub-topic) the mark belongs to. It automatically contains your selected text. Do one of the following to associate the index mark with: 
        *   an index entry that matches the selected phrase, do not change the value.
        *   a different existing entry, click the setting's pop-up menu and select the required topic name.
        *   a new topic name that does not already exist, replace the value with the required topic name.

    2.   To make the new entry a sub-topic, either select an existing **Parent Topic** or type the name for a new one in the box.
    3.   Click **OK**.

Alternatively, create an insertion point or select some text in your document, then double-click an existing topic or sub-topic on the Index panel.

1.   On the **Index** panel, click **Add Topic**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/2GmKBYdrnZmTrZlI4AB88/c38aab7d52f247673152b4a01ef6fe26/addIndexTopic.svg) .
2.   On the dialog that appears: 
    1.   Type the **Topic Name** you want to add to the index.
    2.   (Optional) To control the topic's position in the index, e.g. to omit an initial article such as 'The' when sorting entries, type the topic's key title in the **Sort By** box.
    3.   (Optional) Amend other topic settings as required.
    4.   Click **OK**.

The topic will not be listed in the inserted index unless you assign index marks to it.

1.    On the **Index** panel, do one of the following: 
    *    On an existing topic or sub-topic, **^(ctrl)**-click (Mac) / **right**-click (Windows) and select **Add sub topic**. On the dialog that appears, **Parent Topic** is automatically set to the clicked topic. 
    *   When adding or editing a topic, select the required parent from **Parent Topic**'s pop-up menu.

2.   Click **OK**.

On the **Index** panel:

1.    On the topic or sub-topic's index entry, **^(ctrl)**-click (Mac) / **right**-click (Windows) and select **Edit Topic**. 
2.   On the dialog that appears: 
    1.   Edit the settings as required.
    2.   Click **OK**.

To simply rename a topic or sub-topic, select its index entry on the panel and then click its name.

1.    On the **Index** panel, **^(ctrl)**-click (Mac) / **right**-click (Windows) an existing topic or sub-topic and select **Add cross reference**. 
2.   On the dialog that appears: 
    *   Select the required topic to cross-reference from **See**'s pop-up menu.
    *   Click **OK**.

On the **Index** panel:

1.    On a topic or sub-topic's index entry, **^(ctrl)**-click (Mac) / **right**-click (Windows) and select **Find in document**. 
2.   Instances of the topic name are listed on the panel. Check the box to the right of any you wish to add to the index or check **All**.
3.   Click **Done**.

The checked instances are added to the topic/sub-topic.

1.   Create an insertion point in a text frame.
2.   Do one of the following: 
    *   On the **Index** panel, click **Insert Index**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/4Csq0TONKvChwqOje6T7Ql/62b36e35c441244839867e478d1c66a5/insertIndex.svg) .
    *   On the **Text** menu, select **Index > Insert Index**.

You can then use the Index panel to add topics and index marks to the index and adjust the index's formatting.

Do one of the following:

*   On the **Index** panel, click **Update**.
*   On the **Text** menu, select **Index > Update Index**.

*   On the Index panel, double-click the corresponding index entry, i.e. an item listed below a topic or sub-topic.

An insertion point is created at the index mark and the document view focuses on it.

Do one of the following:

*   On the **Index** panel, click **Show/Hide Index Marks**![Image 5](https://images.ctfassets.net/3p2fxa94bzao/60hEgHYP3DeFxTNiUgd45S/f95549d0f57202841f5b779acda21b7c/show-index.svg) .
*   On the **Text** menu, select **Index > Show Index Marks**.

Do one of the following:

*   On the **Index** panel, select the entry for the index mark, then click **Delete**![Image 6](https://images.ctfassets.net/3p2fxa94bzao/3m8ciDtLqf07Yrma1i0j4x/202c1d508104bbb0a1290c5be7725eae/trash_can.svg) .
*   In the document view, create an insertion point immediately after the index mark, then press the **⌫** key (Mac) / **Backspace** key (Windows).

1.   On the **Index** panel, select the unwanted topic or sub-topic.
2.   Select **Delete**![Image 7](https://images.ctfassets.net/3p2fxa94bzao/3m8ciDtLqf07Yrma1i0j4x/202c1d508104bbb0a1290c5be7725eae/trash_can.svg) .
