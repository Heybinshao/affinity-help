# New features in Affinity by Canva for Affinity 2.x upgraders - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/introduction-new-features/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Getting started](https://www.affinity.studio/help/getting-started/)
3.   New features in Affinity by Canva for Affinity 2.x upgraders

For Affinity Designer 2, Affinity Photo 2, and Affinity Publisher 2 users, the following features are available in Affinity by Canva for the very first time.

*   Innovative new concept
*   Graphic design, photo editing and publishing - all in one app
*   Seamlessly switch between design disciplines by switching Studios
*   Explore powerful cross-Studio workflows
*   Avoid app switching and tedious export/import cycles
*   No more export/import lossy conversions
*   More efficiency, more time to create
*   Boost creative techniques from lesser-known disciplines

*   Formerly Personas, [Studios are workspaces](https://www.affinity.studio/help/workspace-about-studios/) designed for specific design disciplines and tasks
*   Default Studios include: 
    *   [Vector](https://www.affinity.studio/help/workspace-vector-studio/): for graphic design
    *   [Pixel](https://www.affinity.studio/help/workspace-pixel-studio/): for photo editing and raster digital art
    *   [Layout](https://www.affinity.studio/help/workspace-layout-studio/): for page layouts and publishing
    *   [Canva AI](https://www.affinity.studio/help/workspace-canva-aistudio/): for artificial intelligence and machine learning tools

*   Switch on additional Studios for [exporting slices](https://www.affinity.studio/help/workspace-slice-studio/), [retouching](https://www.affinity.studio/help/workspace-retouching-studio/) and [color grading](https://www.affinity.studio/help/workspace-color-grading-studio/)
*   Switch Studios using Function [shortcut keys](https://www.affinity.studio/help/workspace-shortcuts-workspace/) for faster workflows

*   [Create custom Studios](https://www.affinity.studio/help/workspace-customizing-studios/) for specific tasks, brands, clients and campaigns
*   Studio management 
    *   Switch on/off Studios
    *   Rename Studios
    *   Reorder Studios
    *   Cloning any existing Studios
    *   Assign your own Studio name, icon and differentiating color
    *   Import/export Studios

*   ‘In-Studio’ customization - add, remove and reorder tools
*   Customize [Tools panel](https://www.affinity.studio/help/workspace-customizing-tools-panel/) and [Toolbar](https://www.affinity.studio/help/workspace-customizing-toolbar/) to your liking

*   [Restyled impactful monochromatic iconography throughout](https://www.affinity.studio/help/workspace-interface/)
*   Floating context toolbars can be repositioned or pinned to workspace areas
*   Cleaner look by hiding more advanced tool options
*   Unified menus and shortcuts
*   [Export dialog](https://www.affinity.studio/help/sharing-export-dialog/) now offers all file formats to view

*   [Canva AI](https://www.affinity.studio/help/canva-ai-canva-ai-affinity-ml/)
    *   Generative Image/Vector
    *   Remove Background
    *   Select Subject
    *   Create Depth Map
    *   Generative Expand Tool
    *   Generative Fill Tool
    *   Generative Edit Tool

*   [Machine Learning](https://www.affinity.studio/help/machine-learning-system-requirements/)
    *   Portrait Blur Tool
    *   Portrait Lighting Tool
    *   Colorize Tool
    *   Super Resolution Tool
    *   Select Sampled Depth Tool

*   [AI-driven help](https://www.affinity.studio/help/panels-ask-ritson-panel/) via the Ask panel

*   Aka vector trace, auto trace
*   [Convert opened or placed images to vector art](https://www.affinity.studio/help/object-control-imagetrace/)
*   Adjust threshold for image edge tracing
*   Control curve fitting to image edges
*   Split view for comparative pixel/vector views

*   [Apply customizable vector mesh fills](https://www.affinity.studio/help/clr-gradient-mesh/)
*   Great for realistic shadows and colors
*   Add and adjust junction nodes
*   Adjust control handles to fine tune

*   [Edit the hatch fills](https://www.affinity.studio/help/clr-hatch-fills/) of imported CAD documents
*   Import hatch pattern files (.pat) as palettes
*   Vectorize as a polycurve or individual curves
*   Apply hatch multi-fills via Appearance panel

*   [Locks the gradient’s position to the page](https://www.affinity.studio/help/tools-tools-gradient/) rather than the object.

*   [Offers a subset of the most popular adjustments](https://www.affinity.studio/help/panels-quick-adjustments-panel/)
*   Apply adjustments one by one without leaving the panel

*   [Apply any adjustment by painting](https://www.affinity.studio/help/tools-tools-adjustment-brush/)
*   Takes a simple approach to applying adjustments
*   Brush strokes create a mask as you paint
*   Change flow, opacity and blend modes as you paint
*   Creates a non-destructive adjustment layer

*   All the benefits of the [Adjustment Brush Tool but for filters](https://www.affinity.studio/help/tools-tools-filter-brush/)
*   Creates a non-destructive Live filter layer

*   [An alternative to the Tone Mapping Studio](https://www.affinity.studio/help/adjustments-adjustment-tone-compression/)
*   Non-spatial tone mapping (“compression”) of HDR to standard dynamic range
*   Faster for real-time rendering
*   Applies as a non-destructive adjustment layer

*   For Astrophotography, the adjustment [controls the stacked image’s exposure by stretching the tonal range](https://www.affinity.studio/help/adjustments-adjustment-tone-stretch/)
*   Choice of stretching methods
*   More uniform control compared to Curves and Levels adjustments.

*   [Choose between a saturated “bloom” or desaturated glow effect](https://www.affinity.studio/help/filters-filter-bloom/)
*   Affect saturation, midtones and highlights independently
*   Ideal for infrared photography and 3D rendering
*   Non-destructive behavior

*   [20 glitch effects](https://www.affinity.studio/help/filters-filter-glitch/) including chromatic aberration, static noise, pixelation, pixel displacement
*   Realtime previewing
*   Stack glitch filter layers for even more creativity
*   Non-destructive behavior

*   [For subtle detail enhancement](https://www.affinity.studio/help/filters-filter-multi-band-sharpen/)
*   Avoids ringing and haloing at high-contrast edges
*   Ideal for portraiture and astrophotography
*   Non-destructive behavior

*   [Set up and click for immediate export](https://www.affinity.studio/help/sharing-quick-export/)
*   Export Preview
*   [Export as Canva](https://www.affinity.studio/help/sharing-export-to-canva/)
*   Customize favourite export file format list
*   Create custom presets
*   Place ‘pre-export’ images by dragging from Export Preview
*   Optional standalone [Quick Export panel](https://www.affinity.studio/help/panels-quick-export-panel/)

*   [Deliver professional EPUB files](https://www.affinity.studio/help/sharing-about-epub/) in fixed and reflowable formats
*   [Fixed Layout](https://www.affinity.studio/help/sharing-fixed-layout-epub/): accurately reproduce page layouts, preserving the designer’s intent. Great for magazines and ‘coffee table’ books
*   [Reflowable](https://www.affinity.studio/help/sharing-flowing-epub/): allow content to adapt to the size of the device on which it’s displayed. For novels and publications less reliant on graphics

*   [Manage data merges](https://www.affinity.studio/help/panels-data-merge-panel/)from a dedicated panel
*   View, filter, sort, and process merge data using Advanced Data Tools
*   Insert data merge fields directly from panel

*   [Edit external text sources](https://www.affinity.studio/help/text-import-text/) placed in page layouts
*   Linked content updates as you modify original files (like linked images)
*   For DOCX, RTF and TXT files

*   [Access Affinity using Canva login credentials](https://www.affinity.studio/help/free-affinity-access/)
*   Export individual objects and entire designs to Canva folders

*   [Preflight checking](https://www.affinity.studio/help/sharing-preflight/) for graphic design/photo editing (Window > Layout > Preflight)
*   [International-language-aware line breaking](https://www.affinity.studio/help/panels-paragraph-panel/)
*   Updated handling of vertical font metrics for line spacing
*   [Selection refinement now decontaminates residue colors](https://www.affinity.studio/help/selections-selections-refine/) for super accurate edge detection
*   [Mixbox (pigment)](https://www.affinity.studio/help/layers-layer-blend-modes/) blend mode
*   [Color tagging](https://www.affinity.studio/help/layers-tag-layers/) has menu options for macro inclusion
*   Optimized rasterization behavior when working with pixel selections on image and Raw layers
*   [Pixelate filter](https://www.affinity.studio/help/filters-filter-pixelate/) is now a Live non-destructive filter
*   [Generate color chords](https://www.affinity.studio/help/clr-clr-chords/) and apply directly without saving to palettes
*   Open JPEG/HEIF files with gain maps as [HDR images](https://www.affinity.studio/help/panels-32bit-panel/)
