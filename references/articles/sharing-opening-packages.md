# Opening packages - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/sharing-opening-packages/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Export, share, and publish](https://www.affinity.studio/help/export-share-publish/)
3.   Opening packages

When opening an .afpackage file, the Package Document dialog shows you its contents and any issues that may need resolving.

In each dialog section after **Summary**, the **Package** column confirms which files are included in the package.

Before opening a package stored in the cloud, download all other files in its folder. Otherwise, some resources may be reported as missing.

In the **Fonts** section, the Package column may show a font as restricted. See the statuses in the [Creating packages](https://www.affinity.studio/help/sharing-creating-packages/) topic. Talk to the package's provider or recipient about font licensing.

A yellow warning icon is shown next to any font that is restricted or not included in the package.

If a font is listed as missing in the **Status** column, it is not installed on the current device. In this case, if the font is in the package, you can put a check mark in the **Install** column. This lets Affinity use the font for the current session—other apps can't use it—and the document looks as intended even if the recipient exports or prints it.

Even if font files are provided in a package, it is your responsibility to investigate and adhere to their licensing terms before installing them on your device.

Consult the package's provider if an image (or any other file) is reported as missing. They may have left it out because licensing restrictions prevent sharing it.

You will not need to locate images listed as present. When packaging, Affinity updates a document's links to use the copies of files included in the package's Images folder.

1.   On the **File** menu, select **Open**.
2.   Navigate to the .afpackage file, select it, then click **Open**.
3.   On the dialog that appears: 
    1.   Review the summary of fonts, images, linked text files, and CSS files.
    2.   (Optional) To install fonts from the package that you don't have, select **Fonts**. Put a check mark under **Install** next to any font listed as _Missing_.
    3.   Click **OK**. The packaged document opens. You can edit it, but changes either need to be saved as a new package or a new Affinity document.

4.   (Optional) If Affinity warns about missing CSS files, do one of the following: 
    *   Click **Yes**, navigate to the file named on the dialog, select it, then click **Open**. Repeat if additional files couldn't be found alongside.
    *   Click **No**. Optionally, remove the files from the EPUB panel. You can do this permanently or to simply re-add the files from a new location if needed.

5.   (Optional) Select **File > Save As**. Name the file, navigate to where you want to save it, then click **Save**. This creates an .af file to easily save your edits, even across multiple sessions.
6.   (Optional) On the **Document** menu, select **Resource Manager**. Relink any images and linked texts marked as _Missing_.
