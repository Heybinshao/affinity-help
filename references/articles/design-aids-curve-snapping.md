3.   Curve snapping

Curve snapping lets you align any moving node (or control handle) to an already placed node or curve's geometry.

You can take advantage of curve snapping either as you draw with the Pen Tool or when editing the curve with the Node Tool. Curve snapping gives you accurate positional control of nodes where a more symmetrical approach to curve drawing is needed.

Curve snapping operates independently of global snapping but can be used conjunction with it.

The curve snapping options are hosted on the Pen or Node Tool's context toolbar. Snapping options can be used in combination with each other.

![Image 1: Align to nodes of selected curves](https://images.ctfassets.net/3p2fxa94bzao/5UKZSa58T2LICDdDUYeq9b/9c699ec07c9c44bc7fa1a8ea7b22ef14/curve_align_node.png)

Aligns moving node horizontally (shows in red) or vertically (in green; not shown) to another node

![Image 2: Snap to geometry of selected curves](https://images.ctfassets.net/3p2fxa94bzao/4HS41ElWF27K1l6wsOGta1/91c54503a073f9589071f7b8df7d7ac6/curve_snap_geometry.png)

Snaps moving node to the same or different curve's path (shown in yellow) or node

![Image 3: Snap all selected nodes when dragging](https://images.ctfassets.net/3p2fxa94bzao/1lUBG0t7yj1fY4dgwT9Kfm/900878bab14fb5ab7114f55edc0d5cff/curve_all_nodes.png)

Snaps multiple selected nodes (shows in red and green) when dragging, to a 'target' node (yellow) on any selected curves

![Image 4: Align handle positions using snapping options](https://images.ctfassets.net/3p2fxa94bzao/3pG7XpSgL17BLfNdOTOaj6/2f0645a7bc6b7314723bb5aa249cfb4c/curve_align_handles.png)

Snaps control handle using any of the snapping criteria currently set in Global snapping, e.g. to grid, guide, object geometry/node (shown in yellow), key points, etc.

![Image 5: Perform construction snapping](https://images.ctfassets.net/3p2fxa94bzao/1oQyWOLI8xqLiKq0rK64zz/a33030e1d0dcd63ff737f30c2d8c4030/curve_align_triangle.png)

Snaps control handles to suggested angles and alignments for precise geometry and positioning. See separate Construction snapping topic

When drawing, you can also snap the moving node to any curve intersection point or node on the same or different curve if the global snapping option **Snap to object geometry** is enabled.
