# Frame text - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/text-frame-text/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Frame text

Use frame text to present structured paragraphs. It supports layouts with multiple columns in a single frame.

Using the **Frame Text Tool**, frame text can be created within rectangular frames or within any curve or closed shape.

![Image 1: Frame text](https://images.ctfassets.net/3p2fxa94bzao/aO1zlMCMbXjQgXRf3C2xT/11ba05379373edf9529dd54a73225abe/frame_text.png)

Text frames can be positioned and resized at any time. When a frame is resized, its text reflows automatically within the new dimensions.

The **Text Frame** panel lets you apply properties to text frames, such as:

*   insets—the distances of text from the frame's top, bottom, left, and right edges.
*   fill—the frame's background color.
*   stroke—the frame's border. You can set its width, color, and line style.
*   columns—the number of columns within the frame through which text flows. Widths can be equal or set individually, and you can set a gutter between columns.

The default appearance of new text frames can be customized using the _Object defaults_ feature.

If there's too much text to fit in a frame, the frame's triangular Text Flow icons turn red and an eye icon is displayed alongside it. This indicates there is **overset text**, i.e. text that is overflowing the frame.

Overset text is stored in an overflow area that can be shown or hidden by selecting the eye icon. When shown, overset text is included in printed and exported output.

![Image 2: Overflowing text](https://images.ctfassets.net/3p2fxa94bzao/5RYmsHgPr3MTLg16zrQEaD/85106c0173ff6aa8f1e8db7b042c5592/overflowingtext.png)

Even when text frames are not selected, the object's outline is highlighted in blue. To hide frame outlines and lines between frames that indicate they are linked, on the **View** menu select **Show > Text Flow**.

1.   Select the **Frame Text Tool**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/1beIzVbPUpjWtvjB9f9uIQ/9643c257468e143cd018b12cb31d9a4a/frame_text_tool.svg) .
2.    Drag on the page to set the text frame's initial size. Optionally, hold the **⇧** key (Mac) / **Shift** key (Windows) while dragging to create a square frame. 
3.   Type, paste, or import text.
4.   (Optional) To flow text through multiple columns in the frame, adjust **Columns** on the context toolbar.

When pasting text from another app, selecting **Paste Without Format** on the **Edit** menu applies the formatting at the insertion point to the pasted text.

1.   Select the **Move Tool**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/3oigj5SSoPtnSw21egHEvD/b6ac975f2be7b3feb8e3e9867b378345/move_tool.svg) .
2.   Click the text frame to select it.
3.   Drag from within the text frame.

1.   Select the **Move Tool**![Image 5](https://images.ctfassets.net/3p2fxa94bzao/3oigj5SSoPtnSw21egHEvD/b6ac975f2be7b3feb8e3e9867b378345/move_tool.svg) .
2.   Click the text frame to select it.
3.   Do one of the following:
    *   To edit height and width without constraint, drag a corner or edge handle.
    *   To edit height and width, maintaining the frame's current aspect ratio, hold a second finger on the document view while dragging a corner or edge handle.

The opposite handle is used as the anchor point.

With a text frame selected, on the **Text Frame** panel:

1.   To edit the background color, select the **Fill** swatch and select a color.
2.   To edit the border:
    *   Select the **Stroke** swatch, then select a color.
    *   Select the **Frame Stroke** preview, then apply a width or a different style.

With the frame text selected:

*   On the **Layer** menu, select **Convert > To Art Text**.

Artistic text may flow differently from frame text because the two text types behave differently. Formatting applied to text ranges—such as horizontal alignment̬is retained after conversion. However, the changes may not be discernible in your design. For example, an artistic text object is only as wide as its longest line of text.

When using the Frame Text Tool, the following modifier keys can be used:

*    The **⇧** key (Mac) / **Shift** key (Windows) constrains frame's proportions at the time of creation (to a square) or when resizing. 
*    The **⌘** key (Mac) / **Ctrl** key (Windows) resizes the frame from its center. 
*    The **⌃(ctrl)** key (Mac) / right mouse button (Windows) allows frame text to be rotated about the opposite handle.
