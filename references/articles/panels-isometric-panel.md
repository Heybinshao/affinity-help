# Isometric panel - Affinity Help Center

2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Isometric panel

The Isometric panel lets you create an isometric grid on which you can draw objects in-plane, make '2D' objects fit to plane and transform planar objects between planes.

For Mac/Windows: On the **Window** menu, select **Vector > Isometric**.

Using the panel, you can draw and edit objects across three planes on an isometric grid. The panel also provides several transformation operations which can be applied to selected objects (shapes, text or images).

If you haven't set up a grid previously, you'll be prompted to initially modify the settings (e.g., grid Spacing) for your new isometric grid; you can then make the grid visible.

If an isometric or other type of axonometric grid was already set up, the you won't be prompted for settings.

The following options are available on the panel:

*   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/7DFKTgnCIpPTf9b0CX32oP/7cf99a2d64be1bf14b7328ab06059dc2/planar_front.png) **Front**—when selected, all **Plane editing** options will be applied to the front plane.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/23cSrutKfFjSCCAc0Q9chG/a0fa9e964bf49a28110d74710b1945ba/planar_side.png) **Side**—when selected, all **Plane editing** options will be applied to the side plane.
*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/2PZJfoFeo8NEONxsxRfKRz/d0f4e8f4736738bda0022df1bf6de06d/planar_top.png) **Top**—when selected, all **Plane editing** options will be applied to the top plane.

Press the apostrophe (') key to toggle between planes as you edit.

*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/3UkNjnbCvnagUzuVafSujg/4292b7659eb9886b136ecc13b3548bd6/edit_in_plane.svg) **Edit in plane**—when selected, any object created is automatically fitted to the currently active plane.
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/WWGtlONhid0csCrYmwuXl/63e81077c9afd98a34bb6aa84ca01c99/correct_to_plane.svg) **Fit to plane**—fits either a selected two-dimensional object or object on another plane to the currently active plane.
*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/7AD9HsRKpwFPDNimdbcYMP/16337df2e4a29579cfd8afc1bdd56079/planar_flip_horizontal.png) **Flip horizontal in plane**—flips the selected object horizontally within the currently active plane.
*   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/3DK526cn0HcLggLpBOMUf3/25f4ea9fa7809ee0945f943fc58dcbf1/planar_flip_vertical.png) **Flip vertical in plane**—flips the selected object vertically within the currently active plane.
*   ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/2hQDltUSPhJtuGK9FbZg46/6a9faf5cac72d67209986e05a86d2b45/planar_rotate_anti_clockwise.png) **Rotate anticlockwise in plane**—rotates the selected object 90 degrees anticlockwise within the currently active plane.
*   ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/673ExutZRSvUkoPenGYPlt/fcb21dadccb16ba867df8e97a5f4547d/planar_rotate_clockwise.png) **Rotate clockwise in plane**—rotates the selected object 90 degrees clockwise within the currently active plane.

![Image 10](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

 The following options are available on the **Panel Preferences** menu:

*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
