# Place panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-place-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Place panel

The Place panel is shown when you choose to place multiple files in your Affinity document.

For Mac/Windows, the Place panel appears when you:

*   Hold the **⌥**key (Mac) / **Alt**key (Windows) and drag and drop a file on your document.
*   Begin to place multiple files at once using the **Place Tool** or **File > Place**.

The following options are available on the panel:

*   **Item list**—shows thumbnails and filenames/page numbers of every item awaiting placement. Click an item's thumbnail to select it as the next for placement.

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

 The following options are available on the **Panel Preferences** menu:

*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.

When the **Place** panel is shown, the following options are available on the context toolbar:

*   **Repeat**—Specify the number of times you want the selected items to be repeated upon placement. 
    *   Each repeated item is placed once per page, starting with the page where you tap or drag.
    *   New pages will be added to your document if necessary.
    *   If you select multiple items, each one is repeated before the next is placed.

*   **Replace Existing**—When this setting is enabled, autoflow is allowed to change the contents of populated picture frames that are unlocked, whereas it will ignore locked picture frames. When disabled, autoflow populates only picture frames that are currently unpopulated.

To cancel placement, select a tool other than the **Place Tool**.

After selecting an item on the panel, click/tap or drag in the document view to place it.

*   To select an item to place next, click it in the list.
*   To select multiple items for autoflow, hold the **⌘** key (Mac) / **Ctrl** key (Windows) and click each one. (Unavailable if your document contains artboards.)
*   To select all items for autoflow, click one, then press **⌘****A** (Mac) / **Ctrl**+**A** (Windows).
*   To cancel further placement, select a tool other than the **Place Tool**.
