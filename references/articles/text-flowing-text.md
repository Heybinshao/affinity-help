# Flowing text through frames - Affinity Help Center

3.   Flowing text through frames

If you have more text than will fit into its text frame, Affinity provides several ways to resolve it, including automatically creating additional pages and linked text frames.

Affinity stores the **overset text** in an overflow area that's initially hidden.

The frame's Text Flow buttons—triangular icons near the upper-left and lower-right of the frame—become red. The adjacent eye icon lets you show or hide the overset text.

![Image 1: Text Flow](https://images.ctfassets.net/3p2fxa94bzao/1vAFmZaTOw5yhio12JL2fL/1225d8b3e56c6fffe3b2c10a27e3bb40/textflow.jpg)

Any of the following methods can be used to resolve the problem:

*   Reduce the text's font size to fit the frame.
*   Manually create and link multiple frames.
*   Use AutoFlow to automatically create and link new frames for you.

AutoFlow adds new pages and linked text frames, matching the original in size, after the page with the overflowing text frame. It can do this one page and frame at a time, or automatically until no more text is overset.

![Image 2: After](https://images.ctfassets.net/3p2fxa94bzao/2wGduVAZOKDf2vTKJZmsjG/239dd2f9a9780cfed7d52eee272fb4c0/textflow_after.jpg)

![Image 3: Before](https://images.ctfassets.net/3p2fxa94bzao/29PEoTEU4zNrS4IOXi3eQ2/0ef723947f5f104b68b8900801c9a992/textflow_before.jpg)

AutoFlow is a "one-off" operation. If you add more text to a story while editing, or have reduced the size of a frame, text may again become overset. You can decide whether and how to resolve the issue.

If you reduce the amount of text in the story, any resulting empty frames and pages will remain in your document until you delete them manually.

AutoFlow can't be used to link and fill existing text frames.

*    Hold the **⌥** key (Mac) / **Alt** key (Windows) and click the overflowing text frame's lower-right Text Flow button. 

A new text frame is created on a new page with the same dimensions and properties as the original, overflowing text frame. The text frames are linked.

Note that the new text frame may still have overset text. You can repeat the procedure on each new text frame as required. This procedure is appropriate when a known number of extra pages are available for your publication.

*    Hold the **⇧** key (Mac) / **Shift** key (Windows) and click the overflowing text frame's lower-right Text Flow button.
