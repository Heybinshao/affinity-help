# Key features - vector design - Affinity Help Center

3.   Key features - vector design

Vector design is an integral part of Affinity. If your focus is mainly on this design discipline you'll be spending most of your time in the Vector Studio where you'll find the following features.

*   [Pen and Node tools](https://www.affinity.studio/help/curves-shapes-draw-lines-and-shapes/)
    *   Apply pressure, scaling, drawing, mitre and line end settings for organic strokes
    *   Instinctively and quickly draw curves in a few clicks
    *   Multi-node selection, alignment and transform on curve
    *   Switch between drawing and editing lines with a key press
    *   Crisp curve and construction snapping

*   [Pencil Tool](https://www.affinity.studio/help/curves-shapes-draw-pencil-lines/)
    *   Draw lines with an intuitive balance of accuracy and smoothing
    *   Sculpt mode for repeating and continuing strokes
    *   Stabilization for smooth pencil strokes
    *   Auto-closing options

*   [Shape tools](https://www.affinity.studio/help/curves-shapes-about-geometric-shapes/)
    *   Create perfect squares and circles by constraining primitives
    *   [Customize cogs, stars, arrows, pies](https://www.affinity.studio/help/curves-shapes-draw-geometric-shapes/), and 14 other smart shapes
    *   Presets for shapes or save your own shapes

*   [Flexible Path Brushes](https://www.affinity.studio/help/painting-path-painting/)
    *   Change path, weight, color, fill, pressure gradient, opacity, and blend mode
    *   [Edit path brush strokes](https://www.affinity.studio/help/painting-path-stroke-modify/), pen lines and pencil lines any time
    *   Natural media line styles include watercolor, ink, paint and pastels

*   [Vector warp](https://www.affinity.studio/help/object-control-warp/) to distort any vector object non-destructively
*   Shape Builder Tool to [create complex shapes](https://www.affinity.studio/help/object-control-join-shape-builder/) by addition and subtraction
*   Knife Tool to [cut curves and text](https://www.affinity.studio/help/object-control-cutting/)
*   Vector Flood Fill Tool to [fill with solid color, gradients and bitmaps](https://www.affinity.studio/help/object-control-flooding-areas/)
*   Contour Tool to [offset a curve or shape's outline and stroke](https://www.affinity.studio/help/curves-shapes-contouring-shapes/)
*   Corner Tool to [round corners on shapes and lines](https://www.affinity.studio/help/curves-shapes-cornering-shapes/)
*   [Text-on-a-Path](https://www.affinity.studio/help/text-path-text/) makes text follow any curve’s path

*   [Live boolean geometry](https://www.affinity.studio/help/object-control-join/)
    *   Boolean operations are editable ([Compound Shapes](https://www.affinity.studio/help/object-control-compound/)) without using Undo
    *   Join, intersect, subtract, intersect, divide and combine shape outlines
    *   Nominate a Key Object to subtract from using the **⌥** key (Mac) / **Alt** key (Windows)

*   [Clip artwork](https://www.affinity.studio/help/layers-layer-clip/) within shapes by layer drag-and-drop
*   [Convert primitives, imported vectors, and text](https://www.affinity.studio/help/object-control-converttocurves/) to editable curves
*   [Expand Stroke](https://www.affinity.studio/help/curves-shapes-expand-stroke/) to detach outlines from vector objects to create new shapes
*   Use [Power Duplicate](https://www.affinity.studio/help/object-control-duplicate/) to repeat, scaling and rotate objects (with transforms) all in one go
*   [Symbols](https://www.affinity.studio/help/object-control-symbols/) for simultaneous and automatic editing of repeating design elements

*   [Create multiple artboards](https://www.affinity.studio/help/artboards-artboards-about/) within one document
*   Create design variants all in one design (print stationery, device mockups, branding)
*   Apply custom grids and guides per artboard

*   Draw [gradients](https://www.affinity.studio/help/clr-gradient-editor/) live in your design, instantly and smoothly
*   Apply color and [transparency gradients](https://www.affinity.studio/help/clr-transparency-editor/) to fills and outlines
*   Easily adjust the nodes and rates of change for gradients
*   Use solid colors, linear, elliptical, radial, and conical gradients, and[bitmap fills](https://www.affinity.studio/help/clr-bitmap-fills/)
*   Add textured noise to object fills and outlines, also as a gradient
*   Blend color washes and overlays with opacity

*   On-page brush preview sets width, hardness, nozzle spacing and rotation
*   Pick up brush color as you paint
*   Mimic natural media including watercolors
*   [Stabilization](https://www.affinity.studio/help/curves-shapes-draw-pencil-lines/) for super smooth brush strokes
*   [Edit path brush strokes](https://www.affinity.studio/help/painting-path-stroke-modify/), pen lines and pencil lines any time
*   Refine stroke properties including pressure, opacity, and blend mode
*   Natural media path brushes include watercolor, ink, paint and pastels
*   [Import](https://www.affinity.studio/help/addons-importing-addons/) and [export](https://www.affinity.studio/help/addons-exporting-addons/) brushes
*   [Edit Pressure Profiles](https://www.affinity.studio/help/curves-shapes-edit-pressure-profiles/)
    *   Create pressure profiles for strokes on the page or with a pressure chart
    *   Store pressure profiles for reuse
    *   Edit profiles directly on the stroke
