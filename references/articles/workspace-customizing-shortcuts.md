# Customizing keyboard shortcuts - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/workspace-customizing-shortcuts/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Getting started](https://www.affinity.studio/help/getting-started/)
3.   Customizing keyboard shortcuts

Affinity's default keyboard shortcuts broadly follow industry standards and common use in other apps, but can be customized to your liking.

You can customize shortcuts on an app-wide or on a per-Studio basis. Shortcuts can be customized for tools, menu items, panel switch on/off, tool operations, and blend modes, either being added as new shortcuts or replacing existing shortcuts.

You can optionally save your customized shortcuts to a file (.affshortcuts for Mac; .afshort for Windows) that can be shared with other users or backed up for safe keeping.

Available settings are as follows:

*   Studio—the pop-up menu sets the Studio for shortcut customization.
*   UI Element—the pop-up menu displays the menus, commands and operations for the currently selected Studio. A Miscellaneous category groups shortcuts for commonly performed operations and lets you switch on/off panels via shortcuts.
*   **Apply to all**—if checked, the shortcut applied to a UI element is shared across every Studio. If unchecked, you can uniquely assign a custom shortcut to work just within the currently selected Studio in the initial Studio pop-up menu.
*   **Ignore Modifier**—lets you create shortcuts using a single letter designation instead of using keyboard shortcuts.
*   **Load**—loads a previously saved shortcuts file (.affshortcuts for Mac; .afshort for Windows). This will overwrite your current keyboard shortcut allocations.
*   **Save**—saves the current set of shortcuts to a shortcuts file (.affshortcuts for Mac; .afshort for Windows) for sharing or backup.
*   **Clear All Shortcuts**—all default and customized shortcuts are removed.
*   For Mac: **Apple Defaults**—all customized shortcuts are reset back to default with some exceptions: shortcuts for adjusting character spacing, baseline and paragraph leading, moving the insertion point within text and selecting text are set to macOS defaults.
*   For Mac: **Affinity Defaults**—all customized shortcuts are reset back to default.
*   For Windows: **Reset**—all customized shortcuts are reset back to default.

1.   Do one of the following: 
    *   For Mac: On the **Affinity** menu, select **Settings**.
    *   For Windows: On the **Edit** menu, select **Settings**.

2.   On the dialog that appears: 
    1.   Select **Shortcuts**.
    2.   From the first two pop-up menus, filter shortcuts by **Studio** and then by **UI Element**, respectively.
    3.   From the lower shortcut list, click in the box (containing empty or existing shortcut) at the end of a shortcut entry for the shortcut you want to change.
    4.   Press your chosen keyboard key(s) to assign. This adds the new shortcut or overwrites the assigned shortcut.

If your chosen shortcut has already been assigned, a warning triangle (

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/3RNXZ2vNXGiAMikGWbCq1h/1d8a79db53a284e99e8b5f57824913d3/pref_keyboardShortcutsWarning.png)

) shows next to the shortcut. To resolve, assign a different shortcut.

Some shortcuts show a symbol (

![Image 2](https://images.ctfassets.net/3p2fxa94bzao/4ioXEAmQa6AA1fBSRe1CHT/8f9563f76612d1b9efde39fc8ec9516d/pref_keyboardShortcutsSharedShortcut.png)

) next to them. This indicates that the shortcut is shared between several tools. Hover over the symbol to see other tools.

1.   Do one of the following: 
    *   For Mac: On the **Affinity** menu, select **Settings**.
    *   For Windows: On the **Edit** menu, select **Settings**.

2.   On the dialog that appears: 
    1.   Select **Shortcuts**.
    2.   In the shortcuts list, click the cross icon ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/7pTY0oph1P3nj0wuvjMY4v/cf7609d6e963c87ad8f02e343f41e671/pref_keyboardShortcutsRemove.png)  on the unwanted shortcut's entry.
