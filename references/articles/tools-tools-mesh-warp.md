# Mesh Warp Tool - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/tools-tools-mesh-warp/

3.   Mesh Warp Tool

The Mesh Warp Tool allows you to distort an image (or portion of an image) using a highly customizable grid comprising nodes and lines.

After warping the image using the Mesh Warp Tool.

Base image before warping.

The Mesh Warp Tool is available by default in Pixel Studio.

It can be added to other Studios. See [Customizing tools](https://www.affinity.studio/help/workspace-customizing-tools-panel/) for details.

A mesh warp can be applied as a [non-destructive, live filter](https://www.affinity.studio/help/layers-livefilters/). It can be accessed via the **Pixel** menu by selecting **New Live Filter Layer > Distort > Mesh Warp**. Its provides the same context toolbar settings as the Mesh Warp Tool.

The live filter allows the effect to be edited (or removed) at any time after its initial application, using all of the original image's pixel data.

In contrast, the Mesh Warp Tool can be reapplied but each time it uses the already warped image and so useful pixel data may have been lost.

The following settings can be adjusted from the context toolbar:

*   **Apply**—accepts the current warp applied to the image and exits the warp operation.
*   **Cancel**—exits the dialog without applying the warp to your image.
*   Choose between **Destination** and **Source** mode from the pop-up menu. **Source mode** allows you to set default mesh points that can then be restored with **Synchronize**.
*   **Synchronize**—restores the original, unwarped image while maintaining any adjusted mesh grid.
*   **Reset**—restores the grid to a uniform rectangular shape. Nodes which have been added are distributed evenly across the grid.
*   **Hide Mesh**—hides/shows the grid. The warp mesh can still be adjusted when hidden (indicated by the cursor change).
*   **Convert**—switches the selected node to **Sharp** or **Smooth**.

1.   On the **Layers**panel, select the layer to warp.
2.   Select the **Mesh Warp Tool**to apply a non-destructive Mesh Warp live filter to the layer.
3.   On the canvas, drag the mesh nodes to distort the image. Drag the lines between nodes to warp a broader area.
4.   (Optional) To add more nodes for greater precision, click on any mesh line.
5.   (Optional) To switch a node between smooth and sharp, select it and click **Convert**on the context toolbar.
6.   When satisfied, click **Done**on the context toolbar to accept the warp.

*   The **Mesh Warp Tool**has no keyboard shortcut by default, but one can be assigned via the app's settings.
