# New document from clipboard

You can create a new document based on the current contents on the clipboard.

This 'paste as new document' feature allows you to start a new project from a range of sources, e.g. from another project or from copied or captured imagery.

[](https://www.affinity.studio/help/get-started-new-from-clipboard/#results-from-copied-vector-objects--or-layers-)

## Results from copied vector objects (or layers)

If you've copied a vector object to the clipboard, then the command will create a new document that is sized to the vector object. The copied object will _remain as a vector object_ in the new document.

[](https://www.affinity.studio/help/get-started-new-from-clipboard/#results-from-copied-pixel-selections)

## Results from copied pixel selections

If you've copied a drawn pixel selection, the command will paste those pixels into a new 96dpi document in a _pixel layer_.

[](https://www.affinity.studio/help/get-started-new-from-clipboard/#results-from-copied-images-or-captured-screenshots)

## Results from copied images or captured screenshots

If you copy images from Internet web pages or capture a screenshot to clipboard, the new document creates an _image layer_, not a pixel layer, from the copied data. The advantage being that the layer is non-destructive, i.e. it avoids rasterization and loss of the image's original resolution and color space. You can still manually rasterize it.

[](https://www.affinity.studio/help/get-started-new-from-clipboard/#how-to-create-a-new-document-based-on-clipboard-contents)

### How to create a new document based on clipboard contents

Desktop app

*   On the **File** menu, click **New from Clipboard**.

You can use this feature without having any document open.

[](https://www.affinity.studio/help/get-started-new-from-clipboard/#see-also:)
