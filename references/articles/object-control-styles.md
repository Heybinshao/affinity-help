# Styles - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/object-control-styles/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Styles

Instead of having to create effects, fills, colors and line/text attributes from scratch, you can apply a predesigned style to objects.

Styles include a range of attributes that can also be saved as a custom style for future use.

Styles can be copied and pasted between objects by using the **Style Picker Tool**.

If you plan to save some styles, create a custom category in the panel first.

1.   On the **Styles** panel, select a category from the pop-up menu.
2.   Click on your chosen style with an object selected, or drag the style onto your object.

1.   Click **Panel Preferences**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)  and choose **Add New Category** from the menu.
2.   On the dialog, give the category a name, e.g. MyStyles.

1.   Choose the category you want to rename from the category pop-up menu.
2.   Click **Panel Preferences**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)  and choose **Rename Category** from the menu.
3.   Type a new name for the category in the dialog and click **OK**.

1.   On the **Styles** panel, select a category to save the style into.
2.   Do one of the following: 
    *   Select the object whose style you want to save, click **Panel Preferences**![Image 5](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)  on the **Styles** panel, then choose **Add Style from Selection** from the menu.
    *   **^(ctrl)**-click (Mac) / **right**-click (Windows) the object and select **Create Style**.

1.   On the **Color Picker Tool** flyout, select the **Style Picker Tool**![Image 6](https://images.ctfassets.net/3p2fxa94bzao/6po4wOSvY5gMywHyYOPCkP/c4adfef55a04dd8bee680ae265da5618/format_picker_tool.svg) .
2.   In the document view, select an object or a character in text.

After sampling a style:

1.   On the context toolbar, select the style attributes you wish to apply.
2.   In the document view, click an object or a word, or select a text range.
3.   Repeat for any additional objects you wish to style.

1.   In the document view or on the **Layers** panel, select the objects you wish to style.
2.   Select the **Style Picker Tool**![Image 7](https://images.ctfassets.net/3p2fxa94bzao/6po4wOSvY5gMywHyYOPCkP/c4adfef55a04dd8bee680ae265da5618/format_picker_tool.svg) .
3.   On the context toolbar, select the attributes you wish to apply.
4.   Sample the style of an object or a character in text.

Do one of the following:

1.   Click **Unload** on the context toolbar.
2.   Press the **Esc** key. The tool is then ready to sample from a new object or text.
3.   Hold down the **⌥** key (Mac) / **Alt** key (Windows) and immediately sample from a new object or text.

Related behaviors can be adjusted from [the app's settings](https://www.affinity.studio/help/workspace-settings/):

*   **Miscellaneous > Reset Object Styles**
