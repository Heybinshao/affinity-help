3.   Tabs

Use tabs to position text at specific horizontal locations, known as tab stops, in a text frame.

The positions of tab stops are displayed on the text ruler and on the **Paragraph** panel's **Tab Stops** section.

![Image 7: tab stop types](https://images.ctfassets.net/3p2fxa94bzao/1zmBHslFc7mUcItv750pMj/3becbe69aa3860f5a6aaf220626de6ef/tabstops.jpg)

Tab stops for: left alignment (A), center alignment (B), right alignment (C), and decimal alignment (D).

The insertion point or selection in a text frame determines which tab stops are shown on the text ruler and Paragraph panel.

When you select multiple paragraphs, the first one's tab stops are shown. Any changes you make are applied to all of them.

When the insertion point is at the start of a paragraph, pressing the **⇥** key (Mac) / **Tab** key (Windows) increases the paragraph's indentation level rather than typing a tab character. The first-line indent marker (aligned to the top of the text ruler) reflects this and can be dragged to fine-tune indentation.

To always insert a tab character, disable **Use tab to alter paragraph level instead of inserting a tab** in Affinity's **Auto-Correct** settings. You can still drag the first-line indent marker to set paragraph indentation precisely.

*   On the **View** menu, select **Show > Text Ruler**.

The text ruler is displayed above the frame that contains the insertion point. Tab stops won't appear on the ruler until you add them.

1.   Do one of the following to indicate where you want to set tab stops: 
    *   Position the insertion point in a paragraph.
    *   Make a selection that includes all the paragraphs.

2.   Click on the text ruler where you want to create a tab stop.
3.   Edit the tab stop: 
    *   To amend its alignment type, double-click it until it changes to the type you want: left, center, right, or decimal.
    *   To edit its other settings, **^(ctrl)**-click (Mac) / **right**-click (Windows) on it.
    *   To reposition it, drag it to a new position on the ruler.
    *   To delete it, drag it off the ruler.

To create a tab stop whose position is measured relative to its text frame's right edge instead of the left, click/tap at the top of the text ruler. This is useful for text frames that you'll resize from their left edges.

To reposition an existing tab stop so its position is relative to the left or right edge of the ruler, drag it to the ruler's bottom or top edge, respectively. Alternatively, set the tab's **From Right** option as needed.

1.   Do one of the following to indicate where you want to set tab stops: 
    *   Position the insertion point in a paragraph.
    *   Make a selection that includes all the paragraphs.

2.   On the **Paragraph** panel's **Tab Stops** section: 
    1.   Select **Add new tab stop**![Image 8](https://images.ctfassets.net/3p2fxa94bzao/5Bi5j5RpX8dhsHuPx6HxCY/a853755c830ec5c50dd480eb8c4d2ca1/add-new-tab-stop.svg) .
    2.   Adjust the tab stop's numerical position.
    3.   (Optional) Set the tab stop type, leader type and related options as required.

The same settings are available when editing a text style. On the dialog's **Paragraph** section, select **Tab Stops**.
