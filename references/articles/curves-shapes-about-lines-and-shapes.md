# About lines, curves and shapes - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/curves-shapes-about-lines-and-shapes/

When you want to draw lines, curves and shapes you'll need to use the Pen or shape tools.

![Image 1: Line example](https://images.ctfassets.net/3p2fxa94bzao/3ixcxA0UHxfoCNa8Y48vu8/935dd389627a85d667468f24c2a0b5b1/line_example.png)

Editing of lines, curves and shapes is done with the Node Tool.

Curves and shapes have both stroke and fill properties. These can be defined before creation and can be modified at any point afterwards.

A curve is an **open** path that has a distinct start and end. These end stops are defined by **nodes**. A curve with just two nodes is referred to as a **line**.

The path between nodes is known as a **segment** and can be straight (A) or arched (B). Complex curves are created from multiple nodes connected by segments (C). Lines and curves generally have a stroke applied.

![Image 2: Segment types](https://images.ctfassets.net/3p2fxa94bzao/2CLnflLIDaP10LqtLAjzgd/aa015e33978ed2c214915d1acd79d300/path_straightOrCurved.png)

The type of node controls the connected segments. There are three basic types of node:

*   Sharp (A)—causes an abrupt change in direction between segments, creating a point.
*   Bézier (smooth) (B)—creates a continuous curve between segments.
*   Smart (C)—creates a continuous curve but uses a line of best fit.

![Image 3: Node types](https://images.ctfassets.net/3p2fxa94bzao/3BejDd8QkrSRF0rQZ6wXhN/324fe9a5531d2d39a68d71852891b3f5/path_nodeTypes.png)

When drawing curves, any combination of nodes can be used. Each node also has **control handles**. These appear when the node is selected. The length and slope of the control handles determine the shape of the segment. A node can be edited at any time.

![Image 4: Control handles](https://images.ctfassets.net/3p2fxa94bzao/6MRu20lMHqQEAa1YHbbWRh/680b30034dec95111df29be9ef51f4ec/path_directionHandles.png)

A shape is a **closed** path with no discernible start or end. It is made up of multiple nodes and segments.

![Image 5: Close curve](https://images.ctfassets.net/3p2fxa94bzao/3TspqoVI1K1nPzVKvQIMvO/0d427ba3295a628ef3d81d563990b9d8/path_closing.png)

You can also easily create geometric shapes using the Shape tools. These have special properties that enable you to quickly create otherwise difficult to draw shapes, such as circles, rectangles and polygons.
