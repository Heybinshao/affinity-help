3.   Using Surface Dial (Windows)

Quickly invoke Affinity menu commands and adjust tool settings by clicking and rotating Surface Dial.

This feature is only available in Affinity for desktop.

To use it with Affinity, first follow Microsoft's instructions (https://support.microsoft.com/help/4023515) to connect it to your PC. Then, in Affinity's settings, select **Tools** and check **Enable Dial support**.

After restarting the app:

*   Rotating the Dial while the **Move Tool** is selected will rotate the document in the view.
*   Clicking the Dial resets the document's orientation.

With a pixel-based brush tool selected:

*   Clicking the Dial chooses which attribute—brush width, accumulation, flow, and hardness—will be adjusted by rotating the Dial.
*   A large on-screen overlay provides clear feedback about settings.

Examples of on-screen displays when controlling brush attributes (left) and selecting custom commands (right).

If a tool does not provide predefined Surface Dial gestures, you can assign choices in Windows' Settings app. Your custom commands will appear in an on-screen menu when you press and hold the Dial.

Some Affinity commands do not have default keyboard shortcuts. You will need to give them shortcuts in the Affinity's settings before configuring Surface Dial to control them.

Below are examples of how you might use Surface Dial in your workflow to control brush size and layer order. The walkthroughs at the bottom of this page explain how to implement these and other personalizations.

![Image 2: An example setup of a Brush Size command for Surface Dial](https://images.ctfassets.net/3p2fxa94bzao/2Fgfvkf086oHmxe29EL4QC/ad01e7c502ae7629b0d05959772fed1f/surfaceDialCommands.png)

Example custom commands for controlling layer order and image brush size using Surface Dial.

Layer order control (left example):

1.   Rotating the Dial moves the current layer backward or forward in the layer stack.
2.   Clicking the Dial sends the layer all the way to the back.

Path brush size control (right example):

1.   Rotating the Dial adjusts the brush size (with the appropriate tool selected).
2.   Clicking the Dial toggles the Path Brushes Panel. Normally there is no keyboard shortcut assigned to this action, so you'll need to set the same key combination in Affinity's settings.

1.    Do one of the following: 
    *   Select **Settings** from the **Start menu**, select **Devices** and then select **Bluetooth & other devices**.
    *   Click the Bluetooth icon in the taskbar's notification area and select **Show Bluetooth Devices**.

2.   On the left, select **Wheel**.
3.   Under **App tools** on the right, click **Add an app**.
4.   Select Affinity from the list.
5.   Select **Add a tool**.
6.   Type a custom tool name. This will be displayed in Surface Dial's on-screen menu.
7.   Beneath **Rotate right shortcut**, **Rotate left shortcut**, or **Click shortcut**, set the keyboard shortcut for the Affinity tool/command you want to access using Surface Dial's on-screen menu.
8.   (Optional) Repeat the previous step for the other two gestures.
9.   Click **Done**.

1.   Click the Surface Dial.
2.   Rotate the Dial so your command is highlighted.
3.   Click the Dial to select the command.
4.   Rotate left, rotate right or click the Dial to invoke the required command. Repeated rotation is interpreted as a repeated key press.
