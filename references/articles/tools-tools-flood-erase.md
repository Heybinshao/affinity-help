The Flood Erase Tool

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/3Ojlm9AUrsMcrOb267zl70/ff4cce0f7f55874521811253d0e415f7/flood_eraser_tool.svg)

 enables you to erase pixels of a similar color with a single click.

This feature is only available in Affinity for desktop.

The Flood Erase Tool is available by default in Pixel Studio.

It can be added to other Studios. See 'Customizing tools' for details.

Tool shortcut key: **E**.

Flood Erase Tool works by replacing the color of pixels on the current layer with fully transparent pixels. The pixels affected are determined by the following:

*   The color of the pixel under the tool when you click on your page.
*   Whether the pixels are within the same selection area.
*   The pixels are directly connected to the clicked pixel or any others that are affected.
*   The tool's **Tolerance** settings (see below).

The following settings can be adjusted from the context toolbar:

*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/3c6bcFKU8dGvWvVeezWFGK/57add34659ed6eb94ff823207e420513/slider_tolerance.svg) **Tolerance**—sets the range of pixels affected when a pixel is clicked. For lower tolerance settings, pixels must be very close in value to the clicked pixel. For higher tolerance settings, pixel color can vary widely from the clicked pixel.

*   To select the Flood Erase Tool, press the **E** key. This key cycles through related tools.
*   Drag to set Tolerance and flood erase.
