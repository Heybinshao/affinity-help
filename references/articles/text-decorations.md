# Decorations

Paragraph decorations can be used to differentiate blocks of text. They always move relative to their corresponding text.

You can use decorations to give special presentation to paragraphs—for example, with pull-quotes, note styles, colored heading fills, and colored underlines.

![Image 8: Decorations](https://images.ctfassets.net/3p2fxa94bzao/7juRHaD4Q9idStwthFL00C/f46438bda3d12386cbc8742de25cb536/decorations.png)

Paragraph decorations on a pull-quote and an inline note.

[](https://www.affinity.studio/help/text-decorations/#about-decoration-components)

## About decoration components

A decoration consists of any combination of lines at a paragraph's edges and a background fill, each of which is optional. Each component's position, indent, stroke, fill, and transparency can be set independently.

Decorations can be applied directly to paragraphs using the **Paragraph** panel's **Decorations** section. They can also be added to paragraph and group styles.

Each paragraph automatically has a decoration added to it, listed as _Decoration 1_ on the Paragraph panel. By default, this decoration does not add any edge lines or a background color. It can be ignored if not needed or edited as required. Editing the decoration affects only the paragraphs that are selected at that time.

[](https://www.affinity.studio/help/text-decorations/#example-decorations)

### How to create/edit a decoration

Desktop app

1.   Select a text range or make an insertion point in the paragraphs to be decorated.
2.   On the **Paragraph** panel's **Decorations** section, do one of the following: 
    *   To create a new decoration, click the **+** button.
    *   To edit an existing decoration, select it on the first pop-up menu.

3.   Adjust the decoration's settings as needed. See [Paragraph panel](https://www.affinity.studio/help/panels-paragraph-panel/) for more information on the available settings.

Multiple decorations can be added to a paragraph. For example, you could have two decorations that each add a different colored line at different indent levels to a paragraph's bottom edge.

The same settings are available when editing a text style. On the dialog's **Paragraph** section, select **Decorations**.
