3.   Cropping objects and groups

Cropping can be applied to objects (or grouped objects) within a document, without affecting the overall composition of your design.

![Image 1: After](https://images.ctfassets.net/3p2fxa94bzao/1tQbBWqkT5NmOtXmSLow6e/744c7d5209849ba774e0a574eb7e77cb/vector_crop_after.png)

![Image 2: Before](https://images.ctfassets.net/3p2fxa94bzao/3AI4Wgc5yM8EWGLCMW92nP/40dc4a2d19499dbca28842e2cf89676b/vector_crop_before.png)

Use the **Vector Crop Tool**

![Image 3](https://images.ctfassets.net/3p2fxa94bzao/3QyTMp0n5N2Qd7TxaPU9pU/a01cd6c89955102929954130a1234f29/vector_crop_tool.svg)

 to remove portions of a selected object or group.

When you crop an object or group using the tool, Affinity creates a clipping mask on the object’s layer. The clipping mask hides the cropped areas while keeping the original object content intact, so the crop can be adjusted again later. This allows you to refine the visible area without permanently deleting any part of the object or group.

The process is non-destructive, meaning you can later use the tool to restore the cropped content if required.
