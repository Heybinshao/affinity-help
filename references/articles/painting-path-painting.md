# Painting path brush strokes - Affinity Help Center

3.   Painting path brush strokes

Use the Path Brush Tool to apply path brush strokes to your design.

![Image 1: Path brush strokes](https://images.ctfassets.net/3p2fxa94bzao/3fMDAj4dRqlaJbW2az5YZ9/e062a852a32f1b52d8fbc46b42611c90/painting_vector_brush_strokes.png)

The appearance of brush strokes are determined by a combination of the Path Brush Tool, the Path Brushes panel and the tool's context toolbar.

The panel includes an impressive selection of categorised path brushes for use with the Path Brush Tool.

A key characteristic of path brush strokes is that they can be edited using the Node Tool after applying to the page.

1.   In the Vector Studio ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/2Mejuekyv1U5fQVTYLqGud/edc8c0247142081ce0079de3013e815d/persona_vector.svg) , select the **Path Brush Tool**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/4h6tAPjAsi96tS2iGpCxqP/cd04d47c9325109c475ad317cbfdeaa0/vector_brush_tool.svg) .
2.   On the **Path Brushes** panel, select a brush thumbnail of your choice.
3.   Adjust the context toolbar settings, as required.
4.   Drag on the page in the direction that you want the brush stroke to follow.

*   On the context toolbar, enable the **Stabilizer** option and choose one of the following: 
    *   **Rope mode**—drag the stroke end by a 'rope' that smooths the stroke but lets you introduce sharp corners at increasing **Length** (radius) values by redirecting the slackened rope.
    *   **Window mode**—smooths the stroke by averaging the stroke's position over a **Window** whose size is configurable.

1.   On the **Path Brushes** panel, select a brush from a brush category.
2.   Double-click the brush entry and edit the brush's properties.

*   Press the **⌘** key (Mac) / **Ctrl** key (Windows) to move displayed nodes and adjust control handles. Color and opacity can be altered from the **Color** panel.

To change brush size, press the **⌃(ctrl)⌥** keys (Mac) / **Ctrl**+**Alt** keys (Windows) and drag on the page. Dragging left or right will also decrease or increase the brush size, respectively. Alternatively, use the **[** or **]** keys, respectively.

*   With the **⌥** key (Mac) / **Alt** key (Windows) pressed, select a new brush from the **Path Brushes** panel.

The following can be used:

*   The **⌃(ctrl)** modifier, while it remains pressed, converts a freehand brush stroke to a straight line stroke as you draw; release the modifier to continue freehand painting.
*   The **⇧** modifier constrains a straight brush stroke to 45° intervals, including to horizontal and vertical.
*   Press the **⌥** key (Mac) / **Alt** key (Windows) and hold down the left mouse button, then drag to pick up a new color under the brush to paint with.

Related behaviors can be adjusted from [the app's settings](https://www.affinity.studio/help/workspace-settings/):

*   **User Interface > Always show brush crosshair**
