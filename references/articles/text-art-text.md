# Artistic text - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/text-art-text/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Artistic text

Artistic text is best suited to single prominent words (or phrases) or decorative typographical design.

![Image 1: Artistic text](https://images.ctfassets.net/3p2fxa94bzao/1w7ldMluWdcrqRlZXe2SKk/789e4dff1417e4634674dce72c969a2a/artistic_text.png)

When artistic text is resized, it stretches or contracts to fit its new dimensions. Its relative font size automatically updates on the context toolbar.

Artistic text can be modified in many of the same ways as drawn objects, while still retaining standard text attributes. This makes it ideal for single words, headlines, pull quotes, etc.

Although paragraph attributes can be set for artistic text, it is more likely modifications will be to character attributes and on-page positioning using design aids and a creative eye.

1.   Select the **Artistic Text Tool**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/3II7Q664u7QvdkQOEMJ4QP/d7b8ffe9e49063e8a5419ec5c90e1dac/Artistic_Text_Tool.svg) .
2.   In the document view, either: 
    *   click/tap on the page to create text of the default size.
    *   drag on the page to create text of your required size.

3.   Type or paste text.

When pasting text from another app, selecting **Page > Paste Without Format** on the **Edit** menu applies the formatting at the insertion point to the pasted text.

For more design freedom, you can convert artistic text to curves by selecting **Convert to Curves** on the **Vector** menu. Afterward, it can no longer be modified like text.

With the artistic text selected, do one of the following:

*   To resize height and width simultaneously (constraining the aspect ratio), drag any of the object's corner or edge handles.
*   To resize height and width independently (unconstrained), hold the **⇧ key** (Mac) / **Shift key** (Windows) and drag any of the object's corner or edge handles.

With the artistic text object selected, do one of the following:

*   On the object, **^(ctrl)**-click (Mac) / **right**-click (Windows) and select **Convert to Text Frame**.
*   On the **Layer** menu, select **Convert > To Text Frame**.

When using the Artistic Text Tool, the following modifier keys can be used:

*    The **⇧** key (Mac) / **Shift** key (Windows) reverses the resize conventions (as described above). 
*    The **⌘** key (Mac) / **Ctrl** key (Windows) resizes the text from its center. 
*    The **⌃(ctrl)** key (Mac) / right mouse button (Windows) allows text to be rotated about the opposite handle.
