# Customizing Studios - Affinity Help Center

3.   Customizing Studios

Studios can be customized to fit your individual way of working.

For total flexibility, you can create your own Studio that suits your design needs. For example, you may want to reduce the number of tools or panels on display to just the ones you use or, conversely, add extra tools from other Studios. The order of tools and the arrangement of panels might also be altered. Another option would be to create a Studio for a specific project that lends itself to that set of tools.

The Studio’s arrangement will be saved automatically and will be remembered the next time you visit the Studio.

If you like your current Studio arrangement you can update your defaults to this arrangement. This allows you to experiment with further customization knowing that you can revert back to this preferred setup. The option to revert the Studio to its default master settings is also possible.

1.   Select the Studio you want to customize.
2.   Do one or more of the following: 
    *   switch on/off tools in the Studio.
    *   move tools between Studios.
    *   change the Toolbar arrangement and switch on/off its options.
    *   change the context toolbar position.
    *   change panel visibility, grouping and positioning.

*   Right-click the Studio’s icon and select **Update <studio name>**.

*   Right-click the Studio’s icon and select **Revert <studio name>**.

*   Right-click the Studio’s icon and select **Reset <studio name> to Master**.

*   Click **Studio Manager**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/7Hu0cvRLYlLOr92OfbxbF8/0890713fd47bb10637197141cdc62f77/studio_manager_help.svg) , and disable or enable the Studio entry.

*   Right-click any Studio’s icon and select **Icon and Text**, **Icon Only** or **Auto**. The **Auto** option only shows the Studio name when that Studio is active.

2.   Navigate to the file’s location in Finder/File Explorer.

Instead of customizing the existing Studios you can create you own studios based on any currently active Studio.

1.   Select a Studio on which to base your new Studio.
2.   Click the **Studio Manager**![Image 6](https://images.ctfassets.net/3p2fxa94bzao/7Hu0cvRLYlLOr92OfbxbF8/0890713fd47bb10637197141cdc62f77/studio_manager_help.svg) , and select **Create Studio**.
3.   On the dialog, do one or more of the following: 
    *   Click the empty 'camera' icon to add a image for the Studio by clicking or drag and drop. Alternatively, select a Studio icon preset. The **Remove icon****color** option makes the icon monochromatic.
    *   Set the **Studio color** that will be the Studio's background color when selected. Use a preset color or, for more colors, use the fill swatch above the presets.
    *   Enable **Show fill context as fill and stroke** to display fill and stroke color selectors (as in the Vector and Layout Studios), or disable it to show foreground and background selectors (as in the Pixel Studio).
    *   Enter text in the text box to describe the purpose of the Studio when its icon is hovered over.

4.   Click **Create**.

A Function key (e.g., F5) will automatically be assigned to the new Studio (this can be customized in Keyboard shortcuts).

1.   Click **Studio Manager**![Image 7](https://images.ctfassets.net/3p2fxa94bzao/7Hu0cvRLYlLOr92OfbxbF8/0890713fd47bb10637197141cdc62f77/studio_manager_help.svg) , then select **Create Studio**. 
2.   On the dialog, configure settings ensuring **Clone from** is set to _None_.

*   Click **Studio Manager**![Image 8](https://images.ctfassets.net/3p2fxa94bzao/7Hu0cvRLYlLOr92OfbxbF8/0890713fd47bb10637197141cdc62f77/studio_manager_help.svg) , then right-click the Studio entry, and select **Delete**.

Within each Studio you can customize the default set of panel uniquely for that Studio. These customized panel arrangements are saved with the Studio. You can:

*   Hide or show an individual panel
*   Hide or show all panels simultaneously
*   Collapse or expand a panel
*   Undock/dock a panel
*   Reposition an undocked panel group or individual panel

A panel can be standalone or in a panel group; panel groups can be presented at the left or right of the document view.

*   On the **Window** menu, click the panel's name. To show/hide again, click the panel's name again.

*   On the **Window** menu, click **Hide** on the **Panels** submenu. To show the panels, click **Hide** again.

1.   If the panel is in a panel group, click its name.
2.   Do one of the following: 
    *   If the panel is docked, select **Close** from its **Panel Preferences** menu.
    *   If the panel is undocked, click the cross at its top-left (Mac) or top-right (Windows) corner.

Do one of the following:

1.   If the panel group is docked, select **Close Panel Group** from its **Panel Preferences** menu.
2.   If the panel group is undocked, click the cross at its top-left (Mac) or top-right (Windows) corner.

*   Double-click on the active panel label.

*   Click on the label of the panel that you want to view.

*   Drag the panel label to its new position, either: 
    *   As a free floating panel.
    *   As an item in an existing panel group.
    *   As a new panel group between existing panel groups.

*   Drag any corner of a panel.

Do one of the following:

*   Drag the panel label to a panel group.
*   Drag the panel label to an area of the studio. A highlight indicates where the panel can be docked.

For Mac: To stop panels from being docked, press the **⌥** key (Mac) / **Alt** key (Windows) as you drag.

*    Drag the panel group using the vertical bar to the left of panel labels to a new position, either: 
    *   As a free floating panel group.
    *   As new items in an existing group.

Do one of the following:

*   Drag the panel group to another panel group.
*   Drag the panel group to an area of the studio. A highlight indicates where the panel can be docked.

*   On the **Window** menu, select **Panels > Show Left** or **Panels > Show Right**.

The visibility of left and right panel groups can be set independently for each Studio.

*   On the **Window** menu, select **Panels > Add Preset**.

For future selection, the named preset you save will be shown in the same submenu as the above command.

1.   On the **Window** menu, select **Panels > Manage Presets**.
2.   Select a preset from the list, then choose **Load**.

1.   On the **Window** menu, select **Panels > Manage Presets**.
2.   Select a preset from the list, then choose **Rename** or **Delete**.

1.   Select the Studio that you want to reset the panels for.
2.   On the **Window** menu, select **Panels > Reset**.
