# Mesh gradients - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/clr-gradient-mesh/

2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Mesh gradients

A mesh gradient is a grid of horizontal and vertical lines displayed over a vector object (e.g., a shape), with color stops at each intersection. It can be applied to an object's fill or stroke.

![Image 1: A mesh gradient example](https://images.ctfassets.net/3p2fxa94bzao/YevR7HJu8xW1sCnazdwdv/abda5caecfc289d3f0a90999a38b2f47/meshFillExample.png)

A vector shape with a mesh gradient, giving a sense of depth with a light reflection.

Mesh gradients let you create a highly customizable 360° blend of colors.

With a color stop in a mesh selected, you can:

*   edit its color, which then affects the blend of colors between nearby stops.
*   change its position and control handles, which affect the flow of color between nearby nodes.

You can add (or remove) stops. This creates (or deletes) the nodes at all the places the corresponding mesh line intersects with others.

Custom mesh gradients are reusable. Like solid colors and other types of fills, you can add meshes to a palette on the Swatches panel. Wherever you apply the swatch, the mesh can be edited independently.

*   The feature is suited to vector objects only and not to raster content (e.g., pixel layers, image layers, and raster brushwork). 

1.   Select an object.
2.   Select the **Fill Tool**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/4AbVamuwkW3QLOJP3GQiV1/254daa0b4c76a58d6ef299e8068f0519/fill_tool.svg) .
3.   On the context toolbar: 
    *   Set **Context** to _Stroke_ or _Fill_ as needed.
    *   Set **Type** to _Mesh_.

4.   Edit the mesh that appears on the object.

With the **Fill Tool**

![Image 3](https://images.ctfassets.net/3p2fxa94bzao/4AbVamuwkW3QLOJP3GQiV1/254daa0b4c76a58d6ef299e8068f0519/fill_tool.svg)

 and a suitable object selected:

1.   On the context toolbar, set **Context** to _Fill_ or _Stroke_ as needed.
2.   On the mesh shown on the object, do any of the following: 
    *   To select a color stop, click it.
    *   To select multiple stops, either: 
        *   Hold the **⇧** key (Mac) / **Shift** key (Windows) and click each required stop.
        *   Drag a selection marquee around them. You can hold the **⇧** key (Mac) / **Shift** key (Windows) and click stops or drag around them to add them to the selection.

    *   To edit a stop's color, click it, then select a color on the **Color** or **Swatches** panel.
    *   To position a stop, drag it.
    *   To adjust the blend of color between a stop and those around it, select it, then drag the control handles that appear.
    *   To add stops, click at the required position on an existing mesh line. A stop is added at each intersection along the line.
    *   To remove stops, click one to select it, then press the **⌫** key (Mac) / **Backspace** key (Windows). This removes the selected stop and all others along the same internal mesh line(s).

Mesh gradients can be saved for reuse via the **Swatches** panel's **Add current fill to palette** option. They can also be sampled from one object and applied to others using the **Style Picker Tool**.

When editing a mesh gradient, the following shortcuts can be used:

*   To constrain movement of a stop along lines at 45° intervals, hold the **⇧** key (Mac) / **Shift** key (Windows) when dragging the stop.
