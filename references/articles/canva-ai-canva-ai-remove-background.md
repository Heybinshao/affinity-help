Before running Remove Background (Canva AI).

1.   Do one of the following:
    *   In the **Canva AI Studio**, select **Remove Background**.
    *   On the top menu, select **Pixel >**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/5xxUVazTqnv2Nzh8nAiYzG/a5d1568bcbcb8415a4f6115c498d910e/crown.svg) **Remove Background.**

2.   (Optional) On the **Layers**panel, add a **Mask Layer** and use the **Paint Brush Tool** to refine the output by painting. See [Layer masking](https://www.affinity.studio/help/layers-layer-masks/) to learn more.

Use the feature on a duplicate layer if you wish to keep your original image layer with the background retained.

. To use it, you need to be subscribed to the Canva Pro plan. To learn more about the premium features usage visit the [Canva AI & Affinity ML](https://www.affinity.studio/help/canva-ai-canva-ai-affinity-ml/) topic.

Canva AI's Remove Background lets you quickly and accurately isolate subjects by automatically removing backgrounds. It efficiently handles both simple and complex images, significantly reducing the time compared to traditional methods.

Canva AI features run on secure servers, which means your data is processed online to generate images. However, your personal information stays private and anonymous at all times. Canva does not collect any user data—including hardware details, location, or workflow activity—as part of this process.

If the layer you are targeting is not an image/pixel layer, Affinity will rasterize it for you.

The feature has no customizable settings but the result is fully editable afterward. The cut-out is produced directly on the original pixel layer, so you can refine or further erase the result at any time by adding a mask to the layer and using the **Paint Brush Tool** or the **Erase Brush Tool**. If you're used to the restore-paint workflow on the Canva web app, this is the Affinity equivalent — handled through Affinity's standard layers and masks rather than a single in-tool control.
