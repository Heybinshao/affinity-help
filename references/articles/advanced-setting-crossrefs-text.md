3.   Setting a cross-reference's text

A cross-reference's text tells the reader where to find related information.

A publication's style guide may specify exact phrasing. In Affinity, the phrase can contain a mix of regular text and subfields that describe a cross-reference's target.

You can use more than one subfield. For example, the text "_For further information, see 'Deciduous vines' on page 226_" includes **Section Name** and **Page Number**.

Subfields allow Affinity to keep cross-references up to date as a document's content changes, with little or no effort on your part.

Text and other options on the Insert Cross-Reference dialog.

When inserting or editing a cross-reference, the following options are available for setting the cross-reference's text:

*   **Preset**—Use a saved setting to fill in the **Text** option.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/2XLuXTwmEh714qaYONrPKP/6d26123960257b3233a3eb084188eda7/moremenuicon.svg) **Preset Actions**—the following options are available: 
    *   **Language**—Select the language whose presets you want to use or manage.
    *   **Create Preset**—Creates a new preset from the current text and formatting settings.
    *   **Save Preset**—Updates the selected preset with the current text and formatting settings.
    *   **Rename Preset**—Changes the selected preset's name.
    *   **Delete Preset**—Deletes the selected preset.

*   **Text**—Type the phrase to appear in your document. It can include regular text and subfields.

Selecting a preset replaces the current Text and formatting settings. If the settings are edited, _[modified]_ is displayed after the selected preset's name as a reminder in case you wish to update it.

The following subfields can be inserted into a cross-reference's text:

*   **Page Number**—Shows the publication page number that contains the cross-reference's target.
*   **Section Name**—Shows the name of the section that contains the target. (If the section is unnamed, nothing appears.)
*   **Chapter Name**—Shows the current document's name as it appears on the **Books** panel. The document must be a chapter of an open book.
*   **Object Description**—Shows the name of the cross-reference target's entry on the **Layers** panel.
*   **Anchor Name**—Shows the name of the cross-reference's targeted anchor.
*   **Above/Below**—Shows whether the target appears above or below the cross-reference.
*   **Numbered Paragraph**—Shows the target paragraph's text. If the target is a numbered list item, its item number/letter is included.
*   **Paragraph Body**—Shows the target paragraph's text. If the target is a numbered list item, its item number/letter is excluded.
*   **List Number**—Shows the target's item number/letter, if the target is a numbered list item. (Otherwise, 0 is displayed.)
*   **Note Number**—Shows the target's note reference, if the target is a note body. (Otherwise, 0 is displayed.)

Special characters including tab and various kinds of dash and space can also be inserted via the arrow at the left of the Text box (desktop).

The text displayed by **Above/Below** subfields can be customized per language by selecting **Edit Strings** on the **Cross-References** panel's Preferences menu

When inserting or editing the cross-reference, in the **Text** option:

1.   Create an insertion point at the required position.
2.   Click the arrow on the left.
3.   Select the subfield or special character you wish to insert.

Any cross-reference's text and formatting can be preserved as a preset for reuse. Presets you create are available for use in all your documents.

Presets keep cross-references consistent. They're especially useful when different types of targets—like chapters, headings, and figures—need different phrasing.

When inserting or editing a cross-reference:

1.   Set the **Text** and formatting options as required.
2.   Click **Preset Actions**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/2XLuXTwmEh714qaYONrPKP/6d26123960257b3233a3eb084188eda7/moremenuicon.svg) , then select the **Language** for the preset, and then select **Create Preset**.
3.   Type a name for the preset.
4.   Click **OK**.

When inserting or editing a cross-reference:

1.   Click **Preset Actions**![Image 5](https://images.ctfassets.net/3p2fxa94bzao/2XLuXTwmEh714qaYONrPKP/6d26123960257b3233a3eb084188eda7/moremenuicon.svg) , then select the **Language** of the required preset.
2.   Select the **Preset** you want.

The preset replaced the current text and formatting settings.

When inserting or editing a cross-reference:

1.   Click **Preset Actions**![Image 6](https://images.ctfassets.net/3p2fxa94bzao/2XLuXTwmEh714qaYONrPKP/6d26123960257b3233a3eb084188eda7/moremenuicon.svg) , then select the **Language** of the preset.
2.   Select the **Preset** you want.
3.   Adjust the **Text** and formatting options as required.
4.   Click **Preset Actions**, then select **Save Preset**.

When inserting or editing a cross-reference:

1.   Click **Preset Actions**![Image 7](https://images.ctfassets.net/3p2fxa94bzao/2XLuXTwmEh714qaYONrPKP/6d26123960257b3233a3eb084188eda7/moremenuicon.svg) , then select the **Language** of the preset.
2.   Select the **Preset** you want.
3.   Click **Preset Actions**, then select **Rename Preset**.
4.   Type the required name.
5.   Click **OK**.

When inserting or editing a cross-reference:

1.   Click **Preset Actions**![Image 8](https://images.ctfassets.net/3p2fxa94bzao/2XLuXTwmEh714qaYONrPKP/6d26123960257b3233a3eb084188eda7/moremenuicon.svg) , then select the **Language** of the preset.
2.   Select the **Preset** you want.
3.   Click **Preset Actions**, then select **Delete Preset**.
4.   Click **Yes** to confirm deletion.
