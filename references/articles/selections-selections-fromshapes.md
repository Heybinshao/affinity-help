# Pixel selections from curves and shapes

You can convert a curve or shape (path) drawn using the **Pen Tool** into a pixel selection.

![Image 4: Selection from shape](https://images.ctfassets.net/3p2fxa94bzao/5rFr3QQ8L4AVNpZOaqz3b2/905ef2560e3d41cc3cbd97eb4fda359b/selection_from_shape.jpg)

Paths created around the door and window using the Pen Tool and saved as selection.

The feature is ideal for leveraging drawn content for use on pixel layers. Some benefits include:

*   Creation of masks based on a previously drawn curve or shape.
*   Painting within (or filling) a drawn area without affecting the surrounding pixels

When created from a curve, the resulting selection will be closed using a straight line between the end nodes. If you want to avoid this straight line, ensure the curve is closed as it is being drawn with the Pen Tool.

The original line or shape will be discarded when the selection is created. Ensure you keep a copy of your original line or shape if you wish to use it later in your project.

[](https://www.affinity.studio/help/selections-selections-fromshapes/#how-to-create-a-pixel-selection-from-a-drawn-line-or-shape--path-)

### How to create a pixel selection from a drawn line or shape (path)

Desktop app

1.    Do one of the following: 
    *   Using the **Pen Tool**  ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/5yh8WdvU7rTqDSqQzwd7ds/3dec05a9bf475b37380b1f79e99125ee/pen_tool.svg)        draw a curve or closed shape on your page.
    *   Select a previously drawn curve or shape and then select the **Pen Tool**.

2.   From the context toolbar, click **Selection**.

You can convert geometric shapes created using the shape tools into selections by [converting them to curves](https://www.affinity.studio/help/object-control-converttocurves/) and then using the procedure above or [creating a selection from the shape's layer](https://www.affinity.studio/help/selections-pixel-selections-fromlayers/).
