3.   Picture Frame Rectangle Tool

The Picture Frame Rectangle Tool

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/146bEWkL7iva3iAHK7wM3v/e4b3a2f7664d2112b708aa32ef7f1134/box_picture_frame_tool.svg)

 adds a rectangular picture frame to your document into which you can place content.

The Picture Frame Rectangle Tool is available by default in Layout Studio.

It can be added to other Studios. See 'Customizing tools' for details.

Captions can be added to objects, including picture frames—see the 'Object captions' topic for details.

Tool shortcut key: **K**.

The following options can be adjusted from the context toolbar:

Before drawing the picture frame, its fill and stroke properties can be set in advance. These can be applied to drawn picture frames too:

*   **Fill**—click the color swatch to display a pop-up panel to update fill color.
*   **Stroke**—click the color swatch to display a pop-up panel to update stroke color.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/3rYvQ5X8bUYnIRpXvMBBlv/ee8198bb2731db49a0f3ec426d194fb2/stroke_width.svg) **Stroke width**—set a stroke width for the stroke using direct input or slider.
*   ![Image 3: Edit stroke settings](https://images.ctfassets.net/3p2fxa94bzao/LAIAniI5tfK3bknzYOUQB/9af81e28e315cea94436ab657c986f85/stroke.svg) **Edit stroke settings**—click to change stroke style, width, and alignment.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/4VogDhXOgqw0F83jmJq0G8/6909b686388d52610397775cc0bbc4d7/multiple_transform.svg) **Transform Objects Separately**—when selected, where multiple objects are selected, they can be be resized, rotated and sheared independently of each other instead of transforming the bounding box.
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/58wNyMZl0DuNFi96wwd2r6/c8656fa6079dda8976d13873f64e0565/keep_selected.svg) **Keep selected**—when enabled (default), the picture frame will be selected on creation. When disabled, it is deselected.
*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/7e47FwYJ0eBW8yOWy3elSz/813ccca2419c99817334e5bb65c2a0db/cog_icon_2.svg) **Settings**—for general tool settings:
    *   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/5krfOq8r5Vnk8qE0zpecXE/f66f66d96c880ca1832af3cc2cea9e4b/rotationctr.svg) **Enable Transform Origin**—displays a movable transform origin about which the frame can be rotated.
    *   ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/yidHpEw4ai5NUXJKhxsjg/c95d4e824fecdf3a0691457adb8968b8/hide_selection_while_dragging.svg) **Hide Selection while Dragging**—when selected, the object's selection box is temporarily hidden when transforming the object. If this option is off, the selection box remains visible during transformation. The selected behavior persists across all objects unless it is manually switched.
    *   ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/r5jhdqkf0IHpsjOf39WC0/d08a2687c3652304bd7057dddc9498b2/alignment_mode.svg) **Show Alignment Handles**—when selected, displays alignment handles at the center and edges of the selected object. Hovering over these handles displays a floating guideline across the page. You can drag the handles to position the center or edges of the selected object in line with this guide.

The following options can be only be set on selected picture frames:

*   **Replace Image**—click to display a pop-up panel from which you can select an updated file to insert inside the picture frame.
*   **Properties**—click to display the advanced property settings for your picture frame.
*   ![Image 10](https://images.ctfassets.net/3p2fxa94bzao/31t8LXlutgQNFzsWytC7CY/4c3c36d54f3b716371efc64b26e97575/pictureframeclearfillonpopulate.svg) **Show/Hide Fill with Content**—click to remove the background fill on population (useful when framing transparent PNGs).
*   ![Image 11](https://images.ctfassets.net/3p2fxa94bzao/5sRu6KkKgkCGsoZOgJzL33/b4345dc2eb42874209e634937cfb4569/pictureframesizetocontent.svg) **Size Picture Frame to Content**—If the frame dimensions are different to those of its framed image, click this option to resize the picture frame to make it fit the frame content.
*   ![Image 12](https://images.ctfassets.net/3p2fxa94bzao/3r0nypKaA5WwUhRidZ60F7/e75a1a686b28be34e9d4c8e77fc52f00/presets.svg) **Presets**—click to display a pop-up panel from which you may select an existing preset (if any are available) or create a new preset.
*   **Single radius**—when selected (default), allows you to modify all four corners simultaneously by setting one radius. If this option is off, you can set each corner radius individually to create independent rounded (fillet) corners.
*   **Absolute sizes**—by default, the corner radius is specified as a percentage of the object and scales as the object is resized. When selected, this option allows you to specify the corner radius in units. If the object is resized, the corner radius remains the same instead of scaling with the object.
*   **Corner**—sets the style and radius of the picture frame's corners. You can choose a Rounded (fillet), Straight (chamfer), Concave (scallop) or Cutout option. You can also alter the radius of your selected corner type by adjusting the percentage slider or manually entering a new percentage.
*   ![Image 13](https://images.ctfassets.net/3p2fxa94bzao/3TbUr2Rcs8WORkpB9F1k0k/ac87f174562fc2ec8a5e5ceb73693b92/convert_to_curves.svg) **Convert to Curves**—converts the selected object into a series of connected lines and nodes.

*   To select the Picture Frame Rectangle Tool, press the **K** key. This key cycles through related tools.
