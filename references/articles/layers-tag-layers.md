# Tagging layers

Layers can be tagged with a color to help differentiate specific layer content in the Layers panel. Each layer can be assigned a single color.

Desktop app

![Image 5: Layer color tagging](https://images.ctfassets.net/3p2fxa94bzao/5A2MEf1rDvEHRj55BFKN0E/9c3e9ad16af29e66db0d3727c854f2ec/layers_tagging.jpg)

Layers showing color tagging at the end of each entry.

Tagging provides a useful additional means of organizing layer content beyond grouping layers, as it allows you to organize a set of layers without affecting the layer order. All layers that share the same tag color can additionally be selected all at once by using Selecting by attribute.

Color tagging layers can also be recorded as part of your **Macro** actions. To learn more, visit the dedicated topic.

[](https://www.affinity.studio/help/layers-tag-layers/#how-to-assign-a-tag-color-to-layers)

### How to assign a tag color to layers

Desktop app

1.   (Optional) On the **Layers** panel, select multiple layers.
2.    Do one of the following: 
    *   Right-click **Toggle Visibility**  ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/9rstenG65qWb7jzhC83X9/df6defa0ca6b00f2d4f82ec5823bffa6/visibility_on.svg)       , and select a color tag from the pop-up menu. Any of the selected layers can be targeted by right-clicking.
    *   On the **Layer** menu, select from the **Layer > Color Tag menu**.

When you assign a tag color to a layer group, it is also applied to layers within the group _except_ any that have a color tag already.

[](https://www.affinity.studio/help/layers-tag-layers/#how-to-remove-tag-colors-from-layers)

### How to remove tag colors from layers

Desktop app

*   With a layer (or multiple layers) selected, on the **Layers** panel, **^(ctrl)**-click (Mac) / **right**-click (Windows) and choose the first color swatch (white with a red line through it). Tag colors are removed from the selected layers.

When you remove a tag color from a layer group, it is also removed from any layers of the same color within the group.

[](https://www.affinity.studio/help/layers-tag-layers/#how-to-select-all-sharing-a-tag-color)

### How to select all sharing a tag color

Desktop app

*   With an object or layer selected, on the **Layers** panel, **^(ctrl)**-click (Mac) / **right**-click (Windows) and choose **Select Same Tag Color** from the pop-up menu.

[](https://www.affinity.studio/help/layers-tag-layers/#see-also:)
