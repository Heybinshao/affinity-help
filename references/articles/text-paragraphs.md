# Paragraph formatting

Paragraph formatting describes text attributes which are applied at the paragraph level. You can use it to improve readability and maintain visual consistency.

Paragraph formatting includes alignment, leading, and indents. These attributes can only be applied to full paragraphs.

You can apply paragraph formatting to artistic text, but it works best with frame text.

[](https://www.affinity.studio/help/text-paragraphs/#how-to-apply-paragraph-formatting)

### How to apply paragraph formatting

Desktop app

1.   Choose one of the following methods to identify what to format: 
    *   For individual paragraphs: With a text tool selected, place the insertion point in a word or select a range of text in the paragraphs you want to affect.
    *   For all paragraphs: Select the **Move Tool**  ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/3oigj5SSoPtnSw21egHEvD/b6ac975f2be7b3feb8e3e9867b378345/move_tool.svg)        and then select the text frames you want to affect.

2.   Next, choose one of the following ways to apply formatting: 
    *   On the context toolbar, apply commonly used paragraph formatting, such as alignment, bulleted or numbered list format, and indents.
    *   On the **Paragraph** panel, adjust these and other settings, such as **Tab Stops**, **Hyphenation**, **Drop Caps**, and **Decorations**.
