# Accessible PDFs - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/sharing-accessible-pdfs/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Export, share, and publish](https://www.affinity.studio/help/export-share-publish/)
3.   Accessible PDFs

Affinity lets you make exported PDF files accessible to users of assistive technologies including screen readers. It helps you ensure that text and image descriptions appear in a logical order.

When exporting to a PDF file, select **Tagged PDF** to include accessibility information—alt text, reading order, and export tags—in the file.

Objects in Affinity documents can be tagged with **alt text** (meaning alternative) so that assistive technology can describe them to the publication's reader.

You can add your own alt text, or use XMP metadata from placed images. For example, the provider of an image may have embedded a title or description in it.

Objects that are not part of your main content can be marked as decorative so that they are not described by screen readers.

You can specify the order in which content will be presented to the reader when exported to PDF.

Entries for the following types of objects are automatically included in the reading order:

*   Text objects, meaning frame text, artistic text, shape text, and path text.
*   Other objects for which you’ve specified alt text.

By default, reading order follows object positions on the page—top to bottom, and left to right when objects share the same vertical position.

The default reading order might not be ideal. It can be changed by dragging listed items into the required order.

Group objects into articles to help manage the reading order. You can rename articles to help organize content in Affinity, but these names won't appear in exported PDFs.

Any item can be excluded from the reading order. It will remain in the reading order list with a cross to indicate exclusion, and will be re-included if you change your mind.

You can show the importance of each text fragment by assigning export tags to paragraph styles.

Each paragraph style can be tagged as a heading (levels 1 to 6) or a paragraph.

1.   Select the object.
2.   On the **Tags** panel, do one of the following: 
    *   To provide your own alt text, set **Alt Text Source** to _Custom_, then type your alt text in the box below.
    *   To use metadata from the placed image as alt text, select the field to use: _XMP:Title_, _XMP:Description_, _XMP:Headline_, _XMP:Alt Text (Accessibility)_, or _XMP:Extended Description (Accessibility)_.

1.   Select the object.
2.   On the **Tags** panel, enable **Mark as Decoration**.

On the **Reading Order** panel:

1.   Drag an entry up or down the list.
2.   Drop when a blue highlight appears in the required position. This can be a blue line displayed between items, or a blue highlight on an article’s entry.
3.   If you dropped on an article and the item is in an incorrect position within it, repeat these steps.

On the **Reading Order** panel:

*   Click the check mark at the right of the item's entry. It will change to a cross, indicating exclusion.

On the **Reading Order** panel:

1.   (Optional) Select the items you wish to group by **⌘**-clicking (Mac) / **Ctrl**-clicking (Windows) each one.
2.   Select **Add Article**.
3.   (Optional) To give the article a more meaningful name: 
    1.   Click the article's entry to select it.
    2.   Click the article's name.
    3.   Type a new name, then press the **⏎** key (Mac) / **Return** key (Windows).

Items in an article can be reordered by dragging them up or down the list.

To remove an item from an article, drag it out of the article in the list, or delete the article to move all its contents to the list's top level.

1.   On the **Text Styles** panel, click on the required style's options menu ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)  and select **Edit "<style name>"**.
2.   On the dialog that appears: 
    1.   Select **Export Tags**.
    2.   Under **PDF**, set **Export Tag** as needed: _P_, one of _H1_ to _H6_, or _[No change]_ to inherit from the parent style, if this style has one.
    3.   Click **OK**.

On the **Export** dialog:

1.   In the **PDF** section on the left, select a preset.
2.   On the right: 
    1.   Ensure **Tagged** is checked.
    2.   Adjust other PDF export settings as required.

3.   Click **Export**, then on the dialog that appears: 
    1.   Name the file.
    2.   Navigate to where you want to save the file.
    3.   Click **Save**.
