> 官方来源：https://www.affinity.studio/help/appendix-fileformat/

1 Multi-page design files can be imported, with each page being placed on its own artboard.

2 Multi-page Freehand files open with each page concatenated onto a single page. For Mac, add file extension .fh10 or .fh11 in Finder to import. Text import is not supported.

3 For iPhone images, the HEIC file may include an upsampled depth map, loaded as an editable second layer. For Canon EOS models (1 DX MkIII, R5 and R6), HIF files (HDR 10-bit PQ-encoded) can be opened.

4 Supports transparency.

5 For a comprehensive up-to-date list of RAW file support, please see the following links:

*   [Affinity RAW](https://www.affinity.studio/help/supported-raw-files/) (Mac & Windows)
*   [Apple Core Image RAW](https://affin.co/rawapple) (Mac only)

6 12 bit TIFF (RGB or Mono) included, plus legacy TIFF files exported from Photoshop with CICP data embedded in an ICC profile.

7 JBIG2 PDF encoding is supported.

8 Text will be rasterized on export.

9 Includes JPEG-XR 101010 (e.g. XBOX screen captures).

10 DWG (R12-R14, 2000-2018) and DXF (R9-R14, 2000-2018). It is not recommended that you interchange files between Affinity and CAD software.

11 Apple ProRAW DNG support (from Apple iPhone12 Pro onward) is supported.

12 When exporting from InDesign, choose **File > Save As** and select the **InDesign CS4 or later (IDML)** option. INDD import is not supported.

13 Imported file has to be saved as an Affinity file.

14 Includes 32-bit HDR support (PNG specification - Third edition, https://www.w3.org/TR/png-3/) for interchanging HDR broadcast imagery in a lossless format. Legacy PNG files exported from Photoshop with CICP data embedded in an ICC profile can be imported.

15 Flexible Image Transport System files commonly used in astrophotography, with a .fit or .fts file extension.

16 EPS files created in some apps may include proprietary data that only those apps can interpret. When opened in Affinity, they may appear flattened or at reduced quality. For best results, re-export from the original app as PDF, SVG, or AI (with PDF compatibility enabled).
