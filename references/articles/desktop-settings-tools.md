# Desktop settings: Tools - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/desktop-settings-tools/

1.   [Help Center](https://www.affinity.studio/help/)
2.   Desktop settings: Tools

Control how tools behave by default, including selection rules, modifier key behavior, zoom and rotation controls, input device settings, nudge distances, and tool synchronization between documents.

The following settings are available:

*   **Tool handle size**—Makes selected layer content's bounding box handles and curve nodes (and handles) smaller or larger.
*   **⌃-Click show context menu**—(For Mac) Choose whether **⌃(ctrl)**-click displays context menus (alternative to right-click with a multi-button mouse).
*   **Force Touch context menu**—(For Mac) Enable or disable the Force Touch context menu; when enabled, the menu is accessed by a strong-press on a Force Touch-compatible trackpad.
*   **Use ⇧ key to cycle tool groups**(Mac) / **Use Shift modifier to cycle tools**(Windows)—When enabled, cycling between tools with a shortcut key requires holding an additional key. Affects text and shape tools, and Pixel Studio's Paint Brush/Pixel, Selection and Dodge/Burn tool cycles.
*   **Use mouse wheel to zoom**—Choose whether the middle mouse button will allow scrolling or zooming.
*   **Use 'scrubby' zoom**—Choose whether dragging with the Zoom Tool zooms around the cursor (scrubby zoom) or creates a 'zoom to' marquee.
*   **Enable Dial support**—(For Windows) Check the option to use Surface Studio's Surface Dial (or equivalent radial device).
*   **Touch for gestures only**—(For Windows) When enabled, only your connected tablet pen can use tools on the canvas but you can still use gestures. Useful for preventing accidental tool use when interacting with the canvas. When disabled, you have full touch control plus gestures, with or without a tablet pen.
*   **Enable canvas rotation with trackpad**—(For Mac) Choose if the canvas can be rotated using a trackpad.
*   **Enable canvas rotation with ⌘+scroll wheel**(Mac) / **Enable canvas rotation with Alt+scroll wheel**(Windows)—Choose whether the canvas can be rotated using a scroll wheel and a key.
*   **Marquee selection behavior**—Choose how objects are selected when using marquee selection: when touched, when fully enclosed, or a combination of both depending on drag direction.
*   **Move Tool aspect constrain**—Controls the default constraining behavior when resizing objects using the Move Tool. Select from the pop-up menu.
*   **Tablet input method**—(For Windows) Choose whether your tablet pen should use the best quality high resolution input data (if supported), low resolution input data (the system cursor position—this setting is switched on by default), or enable Windows Ink in your drivers.
*   **Create Text with Blend Gamma**—Controls the default blend gamma applied to text on creation.
*   **Nudge Distance**—Sets the nudge amount by which an object is moved when using the arrow keys. Select measurement units from the pop-up menu.
*   **Modifier Nudge Distance**—Sets the amount by which an object is moved when using the arrow keys along with the **⇧**key (Mac) / **Shift**key (Windows).
*   **Synchronize tools between documents**—Makes tool settings persistent between different documents.
*   **Additional dictionary folder**—(For Windows) Add an additional folder that you can copy dictionary files into. The directory is scanned during start-up and found dictionaries will be added.

*   For Mac: From the Affinity app menu, select **Settings**.
*   For Windows: On the **Edit** menu, select**Settings**.
