# Shape text

Shape text is a type of frame text contained within a drawn shape, geometric shape, or concave area of a curve.

![Image 6: Shape text](https://images.ctfassets.net/3p2fxa94bzao/1xZxlTLoCPhWmDaigECgOs/48efd98cfe48b6f79404266d8459edcf/shapetext.png)

Shape text can be positioned, resized, edited and formatted using the same techniques as for frame text. This includes applying a background and border.

[](https://www.affinity.studio/help/text-shape-text/#how-to-create-shape-text)

### How to create shape text

Desktop app

1.   Select a previously drawn curve or shape.
2.   Select the **Frame Text Tool**  ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/1beIzVbPUpjWtvjB9f9uIQ/9643c257468e143cd018b12cb31d9a4a/frame_text_tool.svg)       .
3.   Click within the bounded area of the curve or shape. It becomes a text frame and an insertion point is created in it.
4.   Type, paste, or import text.

Alternatively, select a previously drawn line, curve, or shape and then, on the **Layer** menu, select **Convert > To Text Frame**.

Even though the shape is now converted to a text frame, it can be reshaped using the **Node Tool**

![Image 8](https://images.ctfassets.net/3p2fxa94bzao/2Tyrn620F9iCYiF39DxVOc/9de008f998af69eafee088eb5a3c5210/node_tool.svg)

 at any time.
