# Indents - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/text-indents/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Page layout](https://www.affinity.studio/help/page-layout/)
3.   Indents

Indents align text inward from the left and right sides of its frame. Aligning the first line of a paragraph with indents improves formatting compared with using tab stops or spaces.

![Image 1: After](https://images.ctfassets.net/3p2fxa94bzao/253IgZiM5Sw41Jh6mbESKx/4397f4112d56b530e230511dd54de5cd/indents_after.jpg)

![Image 2: Before](https://images.ctfassets.net/3p2fxa94bzao/5EdIT7MZSQZrjhmla2DTYK/18545e4b48550e397c2c7cd076931bdc/indents_before.jpg)

When text is selected, markers displayed on the text ruler indicate the left indent, first line indent, right indent, and last line outdent of the current paragraph. You can adjust the markers directly on the ruler to set paragraph indents and outdents, or use the **Paragraph** panel to position them numerically.

![Image 3: indent types](https://images.ctfassets.net/3p2fxa94bzao/6Q4PBU5xgGMv3dYZO2LAMi/f02209c070444817e3b25b213fd07a04/indents.jpg)

*   The first line indent (A) is in relation to the left indent.
*   The left indent (B) is set in relation to the object's left margin (or text frame edge if the margin is not set).
*   The right indent (C) is set in relation to the object's right margin (or text frame edge if the margin is not set).

*   On the **View** menu, select **Show > Text Ruler**.

The text ruler is displayed above the frame that contains the insertion point. The indent markers on the ruler show the indent positions for the current paragraph.

*   Do one of the following: 
    *   To set visually: Drag the relevant indent markers on the text ruler.
    *   To set numerically: On the **Paragraph** panel's **Spacing** section, set values for the required indents.

Tab stops are also available when editing a text style. On the dialog's **Paragraph** section, select **Tab Stops**.

1.   Create an insertion point in frame text.
2.   On the **Text** menu, select **Insert > Spaces and Tabs > Right Indent Tab**.

For left-aligned text, for example, text to the right of the inserted character becomes aligned to the text ruler's right indent marker.

1.   Create an insertion point at the required indent position in frame text.
2.   On the **Text** menu, select **Insert > Spaces and Tabs > Indent to Here**.
