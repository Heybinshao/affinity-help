# Document setup (Desktop only) - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/get-started-document-setup/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Getting started](https://www.affinity.studio/help/getting-started/)
3.   Document setup (Desktop only)

The document setup you chose when creating a document can be modified at any time.

Use the Document Setup dialog to change settings for your document or artboards, or for selected pages, spreads, or master pages in a multi-page document.

Options shown on the Document Setup dialog (and the Spread Properties dialog) change depending on what your document contains. For example, you'll see a reduced set if your document contains artboards.

*   On the **Document** menu, select **Setup > Document Setup**.
*   On the dialog that appears:
    *   Make sure **Whole Document** is selected.
    *   Modify settings on the right as needed.
    *   Click **OK**.

1.   On the **Pages** panel, **^(ctrl)**-click (Mac) / **right**-click (Windows) a spread or page, then select **Spread Properties**.
2.   On the dialog that appears, do one of the following to choose which pages to modify:
    1.   To affect the whole spread, click **Spread**.
    2.   To affect specific pages, click **Selected Pages**, then **^(ctrl)**-click (Mac) / **Ctrl**-click (Windows) each individual page to add to/remove from the selection.

3.   Modify settings on the right as needed.
4.   Click **OK**.

The following categories and options are available on the dialog, though some may be unavailable or hidden in certain contexts.

*   **Document Units**—displays your rulers and object dimensions in pixels, points, picas, or physical measurement units.
*   **DPI**—sets document resolution (e.g. 300 dpi for professional print).
*   **'Actual size' zoom**—sets which device is mimicked when presenting the document at 'Actual Size' (on the View menu). This option is available only when document units are set to pixels or points.

*   **Show Dimensions of**—sets which part of the spread to size. Spread encompasses all pages in a multi-page spread.
*   **Page Preset**—offers standard page sizes for quickly setting page width and height. Custom indicates non-standard dimensions have been set.
*   **Page width** / **Spread width** / **Page height** / **Spread height**—change these values to set a custom page size.When you resize a master page, you will be asked whether to also resize pages to which it is applied or leave them as they are. 
*   **Orientation**—select **Portrait**![Image 1](https://images.ctfassets.net/3p2fxa94bzao/2IB213r6Yr6juMW7vnCWTV/46e18e7cb4f84d17d30feb7af1b8a913/portrait_doc_on.svg)  or Landscape ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/1jwNkOhUuf4yOKzt6tLYrD/50b0a771c86c290d3fb77a046053ed29/landscape_doc_on.svg) .
*   **Rescale**—scales object dimensions as page/spread size changes. When enabled, use the menu that appears to the right to choose a resampling method for objects.
*   **Anchor to page** / **Anchor to spread**—keeps object dimensions unchanged as page/spread size changes. Use the diagram on the right to set the anchor point for objects as the page/spread is rescaled.

*   **Facing pages**—arranges pages in spreads, giving the document a spine.
*   **Arrange**—sets whether the spread's pages are arranged horizontally or vertically. Only available when **Facing pages** is enabled.
*   **Start on**—specifies which side of the spine the first page is on. Only available when **Facing pages** is enabled.
*   **Reflow Pages**—choose whether Affinity can automatically reflow your document's pages to the document model. (This setting is equivalent to **Move Page Options > Reflow Pages** on the **Pages** panel's preferences menu.)

*   **Color format**—sets the color mode to RGB or Grey (8 or 16 bit), CMYK (8 bit), or Lab (16 bit).
*   **Color profile**—sets the color gamut for the previously chosen color format.
*   **Profile conversion**—when a different color profile is selected above, **Assign** adopts the new profile but leaves the values of the colors/pixels as is. **Convert** converts each color from the old profile to the new one—color/pixel values may change as a result.
*   **Transparent background**—enable to set your page background to be transparent.

*   **Image placement**—determines whether placed images will be embedded or linked in the document.
*   **Import text files as linked**—allows placed text to quickly be updated using Resource Manager after its source file is modified.
*   **Preserve text styles**—when enabled, text uses styles defined in the Affinity document. This is useful if the Affinity document has a well-defined stylesheet. When disabled, the document's styles update to match those in the placed file.

*   **Left**1, **Right**2, **Top**, **Bottom**—sets the printer margins, shown as non-printing blue lines.
*   **Color**—sets the color of the margin guide.

1**Inner** in documents with facing pages.

2**Outer** in documents with facing pages.

*   **Left**1, **Right**2, **Top**, **Bottom**—for professional printing, bleed extends the printable area beyond the page edge to allow artwork to be trimmed.
*   **Color**—sets the color of the bleed guide.

1**Inner** in documents with facing pages.

2**Outer** in documents with facing pages.

*   **Scale**—sets the scale factor by selecting a preset from the menu or by entering a custom value.
*   **Readout Units**—sets whether values are displayed in document units or another unit of your choice.
