# Cross-References panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-crossrefs-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Cross-References panel

The Cross-References panel allows you to insert and manage cross-references to anchors, paragraphs and index marks in your publication.

For Mac/Windows: On the **Window** menu, select **References > Cross-References**.

A cross-reference is a field in your text that shows information about its target, such as its page number, section name, or relative position (above or below).

The panel shows all cross-references in the current document. You can filter the list to show cross-references on a specific spread or master page.

The following options are available on the panel:

*   **Source Spread**—selects the scope of cross-references listed on the panel. Choose from _All Spreads_, _Current Spread_, or a specific spread or master page.
*   **Cross-references list**—shows each cross-reference's page number, name, and value as it appears in text. Click a cross-reference to select it, or **^(ctrl)**-click (Mac) / **right**-click (Windows) to select more than one.

*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/5aTh6Tstw55CJPGXwiWXQH/5b1e2d1926b56a90966fb745d6439e82/cross_reference_target.svg) **Go to Target**—focuses the document view on the selected cross-reference's target.
*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/6XPtcMeQlUh8KquozxyStX/4a3c0b99a5017eb42ef0d629268ccf53/update.svg) **Update Cross-Reference**—updates the value of the selected cross-references on the panel and in their fields.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/1pMorKRcRu6WurDelronke/05f8333aca67d2295ad1e7d770a6332e/update_all.svg) **Update All Cross-References**—updates the values of all cross-references in the current document.
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/665YKq8jcBR3ikEaRtacni/a988199c33634ac644564cddad8df35e/add_item.svg) **Insert Cross-Reference**—adds a new field at the insertion point and opens a dialog for you to set up the cross-reference.
*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/1M3Etf1yFAmmqIVBlHrPj9/36fb6363c058d1e134dc486b6a132dab/edit_item.svg) **Edit Cross-References**—displays a dialog on which you can amend the selected cross-reference's settings.
*   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/3qZ39scQTi6VW2IkIYeZWE/0e401420ef8c61d56f0e4daa744bc730/remove_cross_reference.svg) **Remove Cross-References**—removes the cross-reference from the panel and converts its field to regular text.

*   **Edit Strings**—opens a dialog where you can set the words used by the Above/Below field to describe the relative position of a cross-reference's target.
*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.

The following information is displayed, from left to right, on each cross-reference's entry:

*   **#**—the page number containing the cross-reference.
*   **Name**—the beginning of the cross-reference target's text.
*   **Value**—the cross-reference's text.
*   ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/4zoYHEPqNazACEv2nlc69n/5c100d1f9d7f2ff82dda188813ad6dd1/target_ok.svg) ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/1RXZd4cy5dmfc9Uf4HiujE/98aeb9ddf2ba0f1623e5c538f7776e86/target_missing.svg) **Status**—indicates whether the target is OK (still exists in the document) or is missing (i.e. it has been deleted).
