# Character panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-character-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Character panel

The Character panel lets you apply local formatting to individual letters, words, sentences and paragraphs as well as entire stories.

For Mac/Windows: On the **Window** menu, select **Text > Character**.

The **Character** panel lets you:

*   List typefaces within particular collections (including Missing Fonts).
*   Apply double underline or strikethrough as well as controlling their color independently of text color.
*   Set kerning and shearing.
*   Apply horizontal and vertical scaling.

The following options are available on the panel:

*   **Font Collection**—sets the typefaces which are accessible via the panel. Select from the pop-up menu.
*   **Font Family**—sets the typeface for the selected text. Select from the pop-up menu.
*   **Font Size**—controls the point size of characters.
*   **Font Style**—controls which typeface style is applied to the selected text.
*   **Font Variations**—when a variable font is applied to the selected text, click to reveal settings for each of the font's adjustable axes.
*   **Font Color**—sets the color of the text. Select from the pop-up panel.
*   **Background Color**—sets the color applied behind the selected text, creating a highlight effect. Select from the pop-up panel.
*   **Specify which font color palette to use for multicolor fonts that support palettes**—shown when a multicolor font with palette support is selected.
*   **Color FX**—shown when a color font is applied. Sets how the font color is blended: _Blend Color_, _Blend Hue_, _Blend Alpha_, or _Off_.
*   **Character Style**—allows a character [text style](https://www.affinity.studio/help/text-text-styles/) to be applied to selected text.

*   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/5q4J95eor7D2LSh0XKBgXo/690641ad4ea0e87ba22308d314dc0fb1/nounderline.svg) ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/5t1NMgx271vWxFOqdYULFq/c9747b3a1f54ca314d8f798083dc3ecb/singleunderline.svg) ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/3aGyM3yeHTOa9i8QO3zGl8/d1046a6d04b0fa300df416289256e51f/doubleunderline.svg)  Underline—select whether the text has **No Underline** or a single or double underline.
*   **Underline color**—sets the color of the text underline. If set to “None”, the underline uses the font color. Select from the pop-up panel.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/417qYd5qXhpyczEX2Fi0i3/a9597e9122790a09dfb9d1a8e93f2050/nostrikethrough.svg) ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/yW9pxMt6Mzvi0xT3rMhVy/d0debf60fc4cca33b04e2af9f01121cf/singlestrikethrough.svg) ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/ehV7RCY863IZspLCXYjuK/7152a141ae050c67576494cda73c4ab4/doublestrikethrough.svg)  Strikethrough—select whether the text has **No Strikethrough** or a single or double strikethrough.
*   **Strikethrough color**—sets the color of the text strikethrough. If set to “None”, the strikethrough uses the font color. Select from the pop-up panel.
*   **Outline Stroke**—sets the outline stroke style and width, along with stroke cap, join and alignment.
*   **Outline Color**—sets the color of the outline stroke. If this is set to “None”, the outline color will match the font color. Select from the pop-up panel.

*   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/qJlAdXboHkaI0VClcBgZO/34340da6a39ff45635093c09a448db0b/char_kerning.svg) **Kerning**—controls the kerning (distance) between characters. **Auto** will automatically kern characters by default. Positive values give expanded kerning, negative values give condensed kerning. This setting is expressed in per mille (thousandths of an em space).
*   ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/6KwrcFKswnVZXVgMtahwYA/b04b5849b7aeef9f5bbf119caf40e621/char_tracking.svg) **Tracking**—controls the spacing between characters. This setting is expressed in per mille.
*   ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/79eYQSsL6YnlVCigpcXGjQ/42af30324527e946584987a86d5e1e48/char_baseline.svg) **Baseline**—controls where characters naturally sit on a line. Increasing the value lowers the baseline, decreasing the value raises the baseline.
*   ![Image 10](https://images.ctfassets.net/3p2fxa94bzao/4slL7FfHW3qvZxH68ALjai/ab691e8c832ab20f6660e94fe124ea57/char_leading.svg) **Leading Override**—increases the space between lines for selected text, overriding the paragraph's default setting.
*   ![Image 11](https://images.ctfassets.net/3p2fxa94bzao/1e5rATWiwpCuRfyiHnJRLR/60cf072839ca616c87ee6cef25d423b0/char_shear.svg) **Shear**—controls the extent of text slant. Positive values will tilt text to the right, negative values will tilt text to the left.
*   ![Image 12](https://images.ctfassets.net/3p2fxa94bzao/6gQJXcZBbODIYxIHoUCkWm/238ab2ea95605ba6087ae7760f314f5d/char_horz_scale.svg) **Horizontal Scale**—stretches the characters and spacing width with regard to point size.
*   ![Image 13](https://images.ctfassets.net/3p2fxa94bzao/6jEiCAdmiHvgXXhR78SXpK/e402e2eb7ed5a486aceae335973b38a2/char_vert_scale.svg) **Vertical Scale**—stretches the characters with regard to point size.
*   ![Image 14](https://images.ctfassets.net/3p2fxa94bzao/nh6kiJMJBRegqMJrd4XMR/42aca8f23dad13d16eaacef999bd37c0/super_subscript.svg) **Super/Subscript**—converts text characters to superscript or subscript, i.e. characters are set higher or lower than neighboring characters, respectively, and font size is decreased.
*   **No break**—tick this checkbox to ensure lines will not be broken at the ends. Soft hyphens will still be honored.

*    Choose the language whose conventions you would like your text to follow for each available pop-up menu. Separate languages can be specified for: 
    *   **Spelling**—specifies the language dictionary to be used for spelling. This will be the default used by the other language options if they are unmodified (set to **Auto**). It also determines which user-defined filler text, if entered in Settings, is displayed in the selected text frame.
    *   **Hyphenation**—specifies the language dictionary to be used for hyphenation. This can be used if a specific hyphenation dictionary is not available for the spelling language, but a suitable substitute is available. For example, it is possible to use **English (Australian)** spelling with **English (United Kingdom)** hyphenation.
    *   **Typography script**—specifies the language script to be used when applying OpenType rules. For example, the Ordinals OpenType feature ‘ordn’ applies mainly to Latin script, and the Petite Caps feature ‘pcap’ only applies for scripts with both upper- and lowercase forms (e.g. Latin, Cyrillic, Greek). The list of available scripts will depend on the current typeface.
    *   **Typography language**—specifies the language to be used when applying OpenType rules. For example, several OpenType features should only be applied to Japanese or Chinese text.

Optical Alignment determines how certain characters in your document (for example, punctuation marks or particular letters) will fit in relation to the text frame; this can be used to automatically extend lines beginning or ending with certain characters when text frames are snapped to page margin. Adjust the settings to ensure the characters you choose are aligned to your liking.

*   ![Image 16](https://images.ctfassets.net/3p2fxa94bzao/o30JypC9dqdXMt30Bqs2e/5c3f5ba78398e79cb445cbaf965ef8f2/contextual_alternatives.svg) **Contextual Alternatives**—applies any alternative typeface designs available for glyphs depending on their relative position within a word or with respect to neighboring glyphs.
*   ![Image 17](https://images.ctfassets.net/3p2fxa94bzao/1hn8JJukUXU0rKBPJ5Bhq9/390d3036943dd210b9e3303b8119fa27/ordinals.svg) **Ordinals**—automatically applies a superscript to letters which are part of an ordinal number.
*   ![Image 18](https://images.ctfassets.net/3p2fxa94bzao/2LY6EULCF3hdWNM3tWSvTc/feac807983d1f81f491dd99f5c8b823a/fractions.svg) **Fractions**—dynamically converts fractions into a single glyph.
*   ![Image 19](https://images.ctfassets.net/3p2fxa94bzao/6wP7JC0EFHAjRmXD4SUPIJ/54cf8ccd46164c684b9049350b684d2a/superscript.svg) **Superscript**—converts text characters to superscript, i.e. characters are set higher than neighboring characters and font size is decreased.
*   ![Image 20](https://images.ctfassets.net/3p2fxa94bzao/7kTKNHGZuNhbcQ93MHmimB/3798bcae957eb09ae6b1c42f92198ef0/subscript.svg) **Subscript**—converts text characters to subscript, i.e. characters are set lower than neighboring characters and font size is decreased.
*   ![Image 21](https://images.ctfassets.net/3p2fxa94bzao/7rwXT2E5iT02eBzpVkaBTm/98429b02dbcf09fbb997b25ef1baebef/allcaps.svg) **All Caps**—displays all selected text as upper case (or small caps, if **Small Caps** option selected).
*   ![Image 22](https://images.ctfassets.net/3p2fxa94bzao/5dh8XvnBeQCc2NPUbmEyyY/eba76ab54ff76c5a9e40f3402dd6d8c6/smallcaps.svg) **Small Caps**—displays lower case letters as miniature upper case. If using an OpenType font that does not define small-caps characters, normal capitals are scaled down to the appropriate height.
*   ![Image 23](https://images.ctfassets.net/3p2fxa94bzao/27JItPl8DLsME6TZNH3RyV/c498f04e1ac409de4bfe16f8558eb043/character_variants.svg) **Character Variants**—allows specific character variants within the text.
*   ![Image 24](https://images.ctfassets.net/3p2fxa94bzao/3sNmqm7Fucug8YNj06di72/247d0bd305630329fb96f8320c75948d/stylistic_sets.svg) **Stylistic Sets**—automatically applies a font's alternate characters to the text.
*   ![Image 25](https://images.ctfassets.net/3p2fxa94bzao/1Oxlli8mc1wfsdOLSK8CN3/e28042be8f2d690713be1c948dd2ff21/swash.svg) **Swash**—applies stroke extensions to characters.
*   ![Image 26](https://images.ctfassets.net/3p2fxa94bzao/2Xj6DkKEdxDPgNytg5SLXB/494b275dbed9d69db2ae85cc1d7605a6/show_typography.svg) **Show Typography Panel**—provides access to additional typography settings.

 The following options are available on the **Panel Preferences** menu:

*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
