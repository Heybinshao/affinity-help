# Mask Erase Tool

The Mask Erase Tool

![Image 5](https://images.ctfassets.net/3p2fxa94bzao/7FntY0YnpexlxtRDjssV90/cba51f14d527051511fc8084b602267a/overlay_eraser_tool.svg)

 allows you to remove previously isolated areas of a RAW image.

![Image 6: Mask Erase Tool](https://images.ctfassets.net/3p2fxa94bzao/389Ed5gIBb7ts7B8pV6uwO/a6dfeabe073b55688f731326d2c605e4/erase_overlay.jpg)

Erasing an area between buildings using the Mask Erase Tool.

[](https://www.affinity.studio/help/tools-tools-mask-erase/#where-to-find-it)

### Where to find it

The Mask Erase Tool is available only in **Develop Studio**.

Tool shortcut key: **E**.

[](https://www.affinity.studio/help/tools-tools-mask-erase/#about-the-mask-erase-tool)

## About the Mask Erase Tool

The Mask Erase Tool is used to remove from the isolated image areas previously set by painting with the Mask Paint Tool in preparation for precise targeting of RAW image regions. These can then be addressed by the adjustments made via the Basic panel and are visible when moving the image to other Studios for further editing.

[](https://www.affinity.studio/help/tools-tools-mask-erase/#options)

### Options

Desktop app

*   **Size**—sets the width of the stroke.
*   **Hardness**—sets how hard the edges of the brush are. The brush appears softer as the percentage decreases.
*   **Edge Aware**—when checked, it enables edge detection, which allows for easier painting around the edges without having to zoom in and reduce the brush size.
*   **Show Mask**—keep checked to display a strong pink overlay to identify an area for targeted editing; uncheck to hide the overlay and make your edits directly without this aid.
*   **Show All Layers**— if checked, all layers' adjustments applied in Pixel Studio will be displayed if the RAW image is redeveloped. Uncheck to hide other layers.

[](https://www.affinity.studio/help/tools-tools-mask-erase/#shortcuts)

## Shortcuts

Desktop app

*   To select the Mask Erase Tool, press the **E** key.
