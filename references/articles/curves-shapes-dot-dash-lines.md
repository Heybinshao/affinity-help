# Dot/dash line styles - Affinity Help Center

3.   Dot/dash line styles

Dot and dash line styles can be applied to objects as strokes and further customized to create a variety of different patterns.

![Image 1: Dash pattern control (Desktop)](https://images.ctfassets.net/3p2fxa94bzao/53MjLP7er5Zc9G3BbFKOVD/dcb6634ba90c8b3ffd987923650b606a/strokepanel_dashpattern.png)

A number sequence sets the line's pattern using three number pairs:

*   The first two **dash** and **gap** values set the length of the initial dot/dash and subsequent space, respectively. This gives a uniform pattern. Ensure the third/fourth and fifth/sixth pairs are set to _0_ (as shown above).
*   The third/fourth and fifth/sixth pair values, when set, introduce a more complex pattern by setting a different size for additional dots/dashes and spaces.

![Image 2: Dash Line Style Pattern](https://images.ctfassets.net/3p2fxa94bzao/6lp6hAw2MVVUxyoRhjcpq3/01165aaac29f0ed1c08afd2cf6fafe83/dashlinestyle_pattern.png)

Dashed line style with Butt Cap and Balanced Dash Pattern enabled.

![Image 3: Dotted line style](https://images.ctfassets.net/3p2fxa94bzao/BySAOfXQEGeahx9Ez9MVu/0cb84d0c7a2317e8cc5832fe4a0b94fe/dashlinestyle_dot.png)

Dotted and dashed line style with Round Cap and Balanced Dash Pattern enabled. The value 0 shows as a dot because it is zero length and formed from a pair of round caps.

![Image 4: Dash Line Style Phase](https://images.ctfassets.net/3p2fxa94bzao/2V8m6m8zP6lacSTy1OeR3z/a530d895c1c7b7d2f8d7e049801fbf8b/dashlinestyle_phase.png)

Dashed line style with Butt Cap enabled, Balanced Dash Pattern disabled and Phase settings 0 (left) and 2 (right), respectively.

1.   With a line or curve selected, do one of the following: 
    *   In the Vector Studio![Image 5](https://images.ctfassets.net/3p2fxa94bzao/2Mejuekyv1U5fQVTYLqGud/edc8c0247142081ce0079de3013e815d/persona_vector.svg)  or Layout Studio![Image 6](https://images.ctfassets.net/3p2fxa94bzao/4BbduuJ3zEK1FT2Ohg1aLs/98f305a0ad579187aa758ae37dc956e6/layout_studio.svg) , on the **Stroke** panel, select **Dash Line Style**![Image 7](https://images.ctfassets.net/3p2fxa94bzao/4RrSHVIOLLbR5Re5f4JCjy/9d9585a3f346cfcce7128c42b4536023/dash_line_style.svg) .
    *   In the Pixel Studio![Image 8](https://images.ctfassets.net/3p2fxa94bzao/x0qUKV0QmljBpXjlKaAyD/48b1503c7d6cc8f05d91c6af70f31b85/persona_photo.svg) , select **Edit stroke settings**![Image 9: Edit stroke settings](https://images.ctfassets.net/3p2fxa94bzao/LAIAniI5tfK3bknzYOUQB/9af81e28e315cea94436ab657c986f85/stroke.svg) on the context toolbar, then click **Dash Line Style**.

2.   Use the **Dash Pattern** controls to configure the dotted or dashed line (described in Dot/dash line style examples above).

To configure, you can enter values directly or drag the dash (white) or gap (black) strips under the number sequence to the left or right to adjust in 0.1 increments.

When enabled, **Balanced Dash Pattern**

![Image 10](https://images.ctfassets.net/3p2fxa94bzao/2pa1m9JU2Z61nbbU6QDlIz/df3da2c1a7b23220f8931638d09cf74c/balanced_dash.png)

 applies the pattern to the shape's outline so it appears seamless along the outline and is symmetrical at all corners. When **Balanced Dash Pattern** is disabled, you can set the **phase** value to manually 'shift' the dot/dash line style along so the design begins at a different point in the style's sequence.

You can choose between dots or dashes by setting the **Cap** type. Use **Round Cap** for dots and rounded dashes, **Butt Cap** for squared dashes.

All values are based on the current line width, e.g. a value of _2_ is twice the line width.
