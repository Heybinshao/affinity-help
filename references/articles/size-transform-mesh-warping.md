3.   Mesh warping

Mesh warping lets you distort specific areas of your image without affecting other areas. It can be used for dramatic warping effects or for more subtle retouching of facial features.

![Image 1: After warping the image using the Mesh Warp Tool.](https://images.ctfassets.net/3p2fxa94bzao/3ygHwGIUTt2tgGzl3PvJIc/a32ad5c5c4a49513b898d058b4c51c4e/warp_after.jpg)

After warping the image using the Mesh Warp Tool.

![Image 2: Base image before warping.](https://images.ctfassets.net/3p2fxa94bzao/3eVuPnnrqln4VgJRbheEJU/330cafe7f4fb536b78d2900c340b2156/warp_before.jpg)

Base image before warping.

The **Mesh Warp Tool** and **Mesh Warp** live filter each provide a flexible mesh grid which can warp your image by repositioning the grid's lines, nodes, and patches—the underlying pixels are transformed under the line, node or patch. The extent of warping you want to carry out is governed by the complexity of the grid.

You'll initially start with a mesh grid without any lines. Adding your own lines and nodes lets you warp with ease. Position lines adjacent to areas in your image that you want to apply warping to.

The **Mesh Warp Tool** and **Mesh Warp** live filter provide the same settings on their context toolbars.

1.    In the Pixel Studio ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/x0qUKV0QmljBpXjlKaAyD/48b1503c7d6cc8f05d91c6af70f31b85/persona_photo.svg) , do one of the following: 
    *   To apply a non-destructive mesh warp, select **the Mesh Warp Tool**.
    *   To apply a destructive mesh warp, hold the **⌥**key (Mac) / **Alt** key (Windows) and select the **Mesh Warp Tool**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/69zY6h3w1EXHDvWO830a1Q/1d6102dc66162a52c2fc7f0bb66aafff/mesh_warp_tool.svg) .

2.   Double-click on the edge of the mesh grid to add a line (top edge: vertical; side edge: horizontal), or double-click inside the grid to add intersecting lines.
3.   Repeat for as many lines as you need.

If you want to start again, click **Reset** on the context toolbar.

In other Studios (Vector Studio, etc), a mesh warp can be applied via the menu bar.

*   To apply a destructive filter: On the **Pixel** menu, select **Filters > Distort > Mesh Warp**.
*   To apply a non-destructive live filter: On the **Pixel** menu, select **New Live Filter Layer > Distort > Mesh Warp**.

*   Double-click anywhere within the grid.

Do one of the following:

*    Press the **⇧** key (Mac) / **Shift** key (Windows) and click each node in turn. 
*   Drag across multiple nodes to create a marquee selection.

1.   (Optional) On the context toolbar, use the **Mode** option to manipulate just the grid (Source) or both grid and image simultaneously (Destination).
2.   Drag a node, a node's corner handle, line or patch. Patch warping is achieved by clicking in an area contained by mesh lines and dragging the circle—this warps the entire area.
3.    Select **Apply** or press the **⏎** key (Mac) / **Return** key (Windows). 

The mesh is really just an assembly of bendable curves. When you alter these curves, distorting the grid, the underlying image deforms accordingly.
