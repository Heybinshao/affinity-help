The Frame Text Tool

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/1beIzVbPUpjWtvjB9f9uIQ/9643c257468e143cd018b12cb31d9a4a/frame_text_tool.svg)

 allows you to add a text frame which acts as a container for paragraph text.

The Frame Text Tool is available by default in Vector, Pixel and Layout Studios.

It can be added to other Studios. See 'Customizing tools' for details.

Frame text is best suited to working with text which will be presented in paragraphs with a formalized structure and layout. If you want to present text in columns, frame text is the ideal solution.

Text frames can be linked, so that text flows through them in a particular sequence—see the 'Flowing text through frames' topic for details.

The Artistic Text Tool and Frame Text Tool are grouped together on the **Tools** panel. Click the triangle in the bottom-right of the displayed icon to access the alternative tool.

Tool shortcut key: **T**.

The following options can be adjusted from the context toolbar:

*   **Font Family**—sets the font of the text. Select from the pop-up menu.
*   **Font Style**—click to display a pop-up menu with optional formats for the selected font.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/1JuTlzTBPvMWQEnWJ0bGEk/89b7da4d1b13583e920d13a6620bd6dc/variable_font.svg) **Font Variation Settings**—when a variable font is applied to the selected text, click to reveal settings for each of the font's adjustable axes.
*   **Font Size**—type directly in the text box or drag the pop-up slider to set the value.
*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/1OXVn5b1tGl1qWblIRRaqs/bbdc8d1ad1d4f59725b9e1367594ece5/fontsize_increase.svg) **Increase Font Size**/ ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/193jXaSW3xfEIeUFq7JEsc/d35f9123e36cd0419b57b4ad0620226f/fontsize_decrease.svg) **Decrease Font Size**—adjusts the font size to the nearest whole number above/below its current value.
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/3pXaQrSIzPrfsyyHaMl8re/28c3e06e89ac786d6513588b977c2ca8/changecase.svg) **Change Case**—sets the capitalization of the selected text to upper case, lower case, sentence case, or title case.
*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/NWla3vZ5p9AoLWLkeOYYg/1c04989ccb3ebf61bcddb5a61841c9e4/Bold.svg) **Bold**/ ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/3pi6Jjivd2ItndPnKXGmU9/e394a9c0e7cbd88bb48857863dae109c/Italic.svg) **Italic**/ ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/7HQokyM5PwU2WZpXVl9oph/7cda2dc8410e65b47bc2303c2074fe3f/Underline.svg) **Underline**/ ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/6RlXBtB9Uw2gqDmto3WEoU/daa068942bb2df4d1ee88b8f0cc05806/singlestrikethrough.svg) **Strikeout**/ ![Image 10](https://images.ctfassets.net/3p2fxa94bzao/6wP7JC0EFHAjRmXD4SUPIJ/54cf8ccd46164c684b9049350b684d2a/superscript.svg) **Superscript**/ ![Image 11](https://images.ctfassets.net/3p2fxa94bzao/7kTKNHGZuNhbcQ93MHmimB/3798bcae957eb09ae6b1c42f92198ef0/subscript.svg) **Subscript**—select one or more of these to apply these properties to your text.
*   ![Image 12](https://images.ctfassets.net/3p2fxa94bzao/1iTVE2d1aqGoFWLyLIrLMh/80c87601d9407021e5a03ac538733e96/text_colour.svg) **Font Color**—click the color swatch to display a pop-up panel to update fill color.
*   ![Image 13](https://images.ctfassets.net/3p2fxa94bzao/1FvIaC8IBkIoeBcv6Vp6nq/c13b48a08a59dfad47e5b1d9f1ad9111/text_highlight.svg) **Highlight Color**—sets the background color behind the text.
*   Horizontal Align—sets how the selected text is aligned within its frame width. Available options are:
    *   ![Image 14](https://images.ctfassets.net/3p2fxa94bzao/3Yg1cAkoCjBhZXnTWr9CEy/1b6042b3e9036f6b2bac6c8e4bd9df90/Left_Align.svg) **Left Align**—sets the paragraph alignment to the left margin.
    *   ![Image 15](https://images.ctfassets.net/3p2fxa94bzao/7DgY2h36jUExYrknd04NOI/f6a97d0eeb0a00ca2c0d583ff0ea31f2/Centre_Align.svg) **Center Align**—sets the paragraph alignment to the center.
    *   ![Image 16](https://images.ctfassets.net/3p2fxa94bzao/3GXvijUk3QLtkbULoPJ3gM/e547ce40491e7fce92db645db050d6c9/Right_Align.svg) **Right Align**—sets the paragraph alignment to the right margin.
    *   ![Image 17](https://images.ctfassets.net/3p2fxa94bzao/6x2A1VvmSdRXw02xIYd045/baba075519fa0055b6bf745c14396d11/Justified_All.svg) **Justified** (with additional pop-up menu options).
    *   ![Image 18](https://images.ctfassets.net/3p2fxa94bzao/26uR5fox6QLP7Kq8nI1TYS/94651ece3a437d40291b5f00680b9160/Justified_Left.svg) **Justified Left**—sets the paragraph alignment to both the left and right margins. The last line of a paragraph is left aligned.
    *   ![Image 19](https://images.ctfassets.net/3p2fxa94bzao/1QGiMGDfSCZSuoSvxFHbrD/5d78801c9531ef29361ba51f08a0feb2/Justified_Centre.svg) **Justified Center**—as with Justified Left, however, the last line of a paragraph is center aligned.
    *   ![Image 20](https://images.ctfassets.net/3p2fxa94bzao/4EZrpWEwFXFpF2JAzkVxx/e2e6a20c7c772e65a10704804bf2d17c/Justified_Right.svg) **Justified Right**—as with Justified Left, however, the last line of a paragraph is right aligned.
    *   ![Image 21](https://images.ctfassets.net/3p2fxa94bzao/6x2A1VvmSdRXw02xIYd045/baba075519fa0055b6bf745c14396d11/Justified_All.svg) **Justified All**—as with Justified Left, however, the last line of a paragraph is justified regardless of length (sometimes known as Force-Justified).

*   Vertical Align—sets the paragraph alignment of the selected text within the height of its frame. Available options are:
    *   ![Image 22](https://images.ctfassets.net/3p2fxa94bzao/7xsUd82kEC85ekBtg62gGJ/4b2b1945b141f938fcb9bf3b85f0a4d9/top_align.svg) **Top Align**—sets the cell text alignment to adhere to the top margin.
    *   ![Image 23](https://images.ctfassets.net/3p2fxa94bzao/XMmT0m595qCnCdknAaMWn/d5b154c09fdd3618978e91aa6a5a9165/centre_vertically.svg) **Center Vertically**—sets the cell text alignment to be equidistant from the top and bottom margins.
    *   ![Image 24](https://images.ctfassets.net/3p2fxa94bzao/Si1eyJ9VAsBy0qYFwubwC/3440d7511170ad9b4d643b5473f79e00/bottom_align.svg) **Bottom Align**—sets the cell text alignment to adhere to the bottom margin.
    *   ![Image 25](https://images.ctfassets.net/3p2fxa94bzao/2PEvmRXcFHCmIohHt21dl3/a068e141cc9e20da175c74ec7a701f43/justify_vertically.svg) **Justify Vertically**—sets the cell text alignment to both the top and bottom margins.

*   ![Image 26](https://images.ctfassets.net/3p2fxa94bzao/4slL7FfHW3qvZxH68ALjai/ab691e8c832ab20f6660e94fe124ea57/char_leading.svg) **Paragraph Leading**—controls the distance between text baselines (vertical gap between lines) within the paragraph. Type directly in the text box or select from the pop-up menu.
*   ![Image 27](https://images.ctfassets.net/3p2fxa94bzao/5zWAd2dqBX9xxThhCAljcd/6d16d802c3f109ac744342e7347d51eb/listbullet.svg) **Bulleted List**—inserts a bulleted list.
*   ![Image 28](https://images.ctfassets.net/3p2fxa94bzao/6cIBromcUhIt2nNi8DcrAK/7f1704a16e5296f168b429672c0ec360/listnumber.svg) **Numbered List**—inserts a numbered list.
*   ![Image 29](https://images.ctfassets.net/3p2fxa94bzao/3ojXYhdxvRLsbZZYnnrCJZ/4f01dcefbc54ae718461dcec1302f9c1/columns.svg) **Choose the number of columns**—sets how many columns text in the frame flows through.
*   **Gutter Width**—sets the distance between columns in the text frame.
*   ![Image 30](https://images.ctfassets.net/3p2fxa94bzao/1nHoGYVttr4C3Z54kFH7UW/8dfe64cb7b31ba7b5552f09cafd95338/textframe_page.svg) **Text Frame**—provides access to the **Text Frame** panel for advanced text frame settings.
*   ![Image 31](https://images.ctfassets.net/3p2fxa94bzao/4hKMUdZBV3R8Tmn6ccwtC0/7339f35fc8b2df6e2980ce066f61220d/typography_page.svg) **Typography**—provides access to the **Typography** panel for advanced typography settings.
*   ![Image 32](https://images.ctfassets.net/3p2fxa94bzao/R97XM9crqv3UurHHF1bPX/4c1fd0431e7e8aee8d95f10c540d0df5/ruler.svg) **Frame text ruler—**shows or hides the ruler shown across the top of the active text frame.
*   ![Image 33](https://images.ctfassets.net/3p2fxa94bzao/2ss8ZOyTFWE38mzVCw1Eno/b1a1e3024aec7fdcc606ed03ed38a08d/character_page.svg) **Character**—provides access to the [Character](https://www.affinity.studio/help/text-characters/) panel for advanced text settings.
*   **Character Style**—applies a character style to the selected text. Select from the pop-up menu.
*   ![Image 34](https://images.ctfassets.net/3p2fxa94bzao/5kKiluiIpzqKK4E0ZBXd4o/4c284e1e554eb8ea5eded382b6c4a6ee/UpdateCharacterStyle.svg) **Update Character Style**—updates the character style of the selected text.
*   ![Image 35](https://images.ctfassets.net/3p2fxa94bzao/9ur1eMw9E6VsAylxkKT6V/6f851f38bafac1ebced796bdf1521608/paragraph_page.svg) **Paragraph**—provides access to the [Paragraph](https://www.affinity.studio/help/text-paragraphs/) panel for advanced paragraph settings.
*   **Paragraph Style**—applies a paragraph style to the selected text or to the paragraph in which the insertion point currently resides. Select from the pop-up menu.
*   ![Image 36](https://images.ctfassets.net/3p2fxa94bzao/4VpmZEGkkKhSMFt9KASE4k/88e5a75d1d83895f9c7815f799d7c2de/UpdateParagraphStyle.svg) **Update Paragraph Style**—updates the paragraph style of the selected text.

When setting the Leading, specifying a unit of measurement (i.e., mm or inches) will set an **Exact** distance, while specifying a percentage will set a **% Height** based on the text's font size.

The following shortcuts can be used:

*   To select the Frame Text Tool, press the **T** key. This key cycles through related tools.
