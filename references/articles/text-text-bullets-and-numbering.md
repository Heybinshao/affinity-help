3.   Bullets and numbering

A series of paragraphs can be turned into a bulleted, numbered or multi-level list.

![Image 1: A bulleted list, a numbered list, and a multi-level list](https://images.ctfassets.net/3p2fxa94bzao/6Xg65dTX5WzoqCjUiEG1dA/1f688c4174e35b087d5f591a8815f46e/list_types.png)

A bulleted list, a numbered list, and a multi-level list.

Bulleted lists are especially useful when listing items that have no specific order of preference.

Numbered lists are useful for presenting step-by-step procedures, with each step prefixed with a serialized number or letter.

Use multi-level lists to show hierarchy, using numbers, symbols, or both. See [Using multi-level lists](https://www.affinity.studio/help/text-text-multi-level-lists/).

To turn paragraphs into a list, you can apply local formatting using the context toolbar or the **Bullets and Numbering** section on the **Paragraph** panel. They can also be styled as a list by applying a suitably configured text style, which is better for documents with multiple lists to ensure they look consistent.

Each list item starts with a **list item marker** that follows a specified format.

Affinity provides several preset formats for list item markers, including:

*   bulleted—with the ability to replace the default • with your choice of glyph.
*   numbered—with or without leading zeroes, or as Roman numerals, e.g. _1,2,3,4…_, _001, 002, 003, 004…_, or _I, II, III, IV_.
*   lettered—in upper- or lower-case, e.g. _a, b, c, d_ or _A, B, C, D…_.

You can customize list item markers to use your choice of glyph instead of numbers or the default bullet. Markers can also be colored differently than list items' text by specifying a character style to apply to them.

You can use an image file instead of a standard bullet glyph. The image is automatically scaled to match the list’s font size.

![Image 2: A two-level bulleted list on a bold orange background, demonstrating the use of an image for the bullet points.](https://images.ctfassets.net/3p2fxa94bzao/44tjEmhlViXQj3h9AXLvm4/29bab5605cfc388689d49b332eee8c2b/image_bullets.png)

A multi-level bulleted list that uses image bullets.

You can adjust the scale and position of the image bullet relative to the list's font size. Scaling is relative to the bullet's left-centre anchor point. Vector image files usually stay vector when you export the document. Complex Affinity features may rasterize during import or export. Some SVG files match the font fill color automatically. If the color does not change, the SVG uses fixed colors.

To make part of an SVG match the font fill color, edit the file in a text editor. Set its fill or stroke to _currentColor_.

You can use image bullets in object defaults and text styles.

1.   Create an insertion point where you want the list to begin, or select existing paragraphs to turn into a list.
2.   Do one of the following: 
    *   On the context toolbar, select **Bulleted List**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/5zWAd2dqBX9xxThhCAljcd/6d16d802c3f109ac744342e7347d51eb/listbullet.svg)  or **Numbered List**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/6cIBromcUhIt2nNi8DcrAK/7f1704a16e5296f168b429672c0ec360/listnumber.svg) .
    *   On the **Paragraph** panel's **Bullets and Numbering** section, select a **Type**.

1.   Select existing paragraphs to turn into a list.
2.   Go to the **Bullets & Numbering** section in one of the following places:
    1.   For local formatting, the **Paragraph** panel.
    2.   For a reusable text style, the **Text Style Editor**.

3.   Set **Type** to _Bullet_.
4.   Select **Image File**![Image 5: Image bullet](https://images.ctfassets.net/3p2fxa94bzao/3nej209mcJd2ClNPCg1nSD/d373523cdeba6ebfd96ddbb7b92800fd/image_bullet_list.svg) , then browse to the image, select it, and click **Open**.
5.   Adjust **Scale** and **Offset** to size and position the bullets relative to the text.

1.   Select the list's paragraphs.
2.   Do one of the following: 
    *   On the context toolbar, deselect the list type that is already applied.
    *   On the **Paragraph** panel's **Bullets and Numbering** section, set **Type** to _No List_.

With paragraphs selected or an insertion point made, do one of the following:

1.   On the **Paragraph** panel's **Bullets and Numbering** section, select the required **Type**.
2.   (Optional) Type in the **Text** field to customize list item markers. Click the arrow at the left of the field to insert commonly used special characters, or click the adjacent ellipsis (…) to insert using the Glyph Browser. If the list is bulleted, replace the default bullet with your preferred glyph.

If it is numbered or lettered and you accidentally delete the serialization token, which represents a list item number or letter, type \# at the required position (or select **Current Level** on the menu of common special characters) to recreate it. 
3.   (Optional) Adjust the **Tab stop** and alignment settings to customize the position of the list text.
4.   Set advanced formatting and numbering options as required—see the [Paragraph panel](https://www.affinity.studio/help/panels-paragraph-panel/) topic.

The list's appearance automatically updates as you make changes on the panel.

When applying advanced settings, it's recommended to implement list formatting as a text style.

1.   On the **Text Styles** panel, create or edit a paragraph or group style.
2.   On the dialog that appears, select **Bullets and Numbering** in the **Paragraph** section.
3.   Set the list formatting and numbering options as required—see the [Paragraph panel](https://www.affinity.studio/help/panels-paragraph-panel/) topic.
4.   Click **OK**.

For a numbered or lettered list that continues after paragraphs or a bulleted list are included in between its items, set **Restart numbering** to _Below Current Level_.

To modify the color and size of list item markers, create a character style in advance and apply it using the **Style** setting on the **Bullets & Numbering** section on the **Paragraph** panel (if using local formatting) or the **Edit Text Style** dialog (if using a paragraph or group style).
