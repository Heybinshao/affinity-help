# Channels panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-channels-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Channels panel

The Channels panel displays color and alpha channels information for the whole image or a selected layer.

For Mac/Windows: On the **Window** menu, select **Pixel > Channels**.

The panel also lets you create and manipulate selections from channels and store selections as channels.

As well as the channel information for the image and current layer, you may also see the:

*   Current pixel selection
*   Mask alpha*
*   Adjustment layer alpha*
*   Live filter layer alpha*
*   Any stored selections (as spare channels) for future use.
*   Spare channel alpha
*   Selection raster alpha

* When selected on the **Layers** panel.

By default, all color channels are visible and editable.

The following options are available on the panel:

*   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/48gU5vr3XwFWtBjwhAJWTo/28e1a43a4063087555940fbc383932d4/reset-global.svg) **Reset**—reverts the channel settings back to default.
*   Channel thumbnail—displays the color channel as a thumbnail.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/cF2BHXXiRJQ4T9wSk1gLp/ffaec9e8b0d97be64b137e483fbdeedf/channel_visible.svg) **Visible**—hides/shows the channel.
*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/52wwmEt1j8O6TCIaPBrjd9/477c573cc18e65028a3fe8de9f965bfa/channel_editable.svg) **Editable**—protects/makes editable the channel.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/ihA65j8EK6SuLtjjXIyEr/cff54ac7e6c6dcdf1227f5d9b31db597/mask_all.svg) **Toggle Quick Mask**—toggles between selection and Quick Mask.
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/3oFuDFWu0y1VuALmR2VZIm/f04b279224a0dd2b56f9748955431ca9/channel_invert.svg) **Invert**—inverts the pixel selection.
*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/3m8ciDtLqf07Yrma1i0j4x/202c1d508104bbb0a1290c5be7725eae/trash_can.svg) **Delete**—removes the saved spare channel from the document.

More options are available for each channel.

**^(ctrl)**-click (Mac) / **right**-click (Windows) on a channel to:

*   Create selections from channels.
*   Add to, subtract from, and intersect channel with current selection.
*   Retrieve stored selections.
*   Load selections to current layer channel, mask, adjustment layer, or filter layer.
*   Create grayscale layers.
*   Create mask layers.
*   Invert selections, layer channels and masks.
*   Create, duplicate and rename spare channels from channels, layer channels, masks and pixel selections.
*   Mask channels using Quick Mask.

![Image 7](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

 The following options are available on the **Panel Preferences** menu:

*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
