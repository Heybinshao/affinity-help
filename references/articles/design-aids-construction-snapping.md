3.   Construction snapping for curves

Use construction snapping to help you build complex symmetrical curves, shapes or intersections accurately and easily.

Construction snapping lets you snap a node's control handle to useful construction angles relative to the adjacent node and opposing control handle (e.g., to make handles parallel to each other, perpendicular, to reflected angles, and more). You can also balance control handle lengths on adjacent nodes.

You can enable different types of construction snapping of control handles to various angles and alignments.

These snapping options operate independently of [global snapping](https://www.affinity.studio/help/design-aids-snapping/). They help avoid having to align control handles to grid or guide and offer additional accuracy and symmetry once nodes have been positioned using [Curve snapping](https://www.affinity.studio/help/design-aids-curve-snapping/) options.

1.   Select the **Pen Tool** or **Node Tool**.
2.   On the context toolbar's **Settings**![Image 7](https://images.ctfassets.net/3p2fxa94bzao/7e47FwYJ0eBW8yOWy3elSz/813ccca2419c99817334e5bb65c2a0db/cog_icon_2.svg) , enable **Perform construction snapping**.
3.   Drag a control handle such that it snaps to angles and alignments.

For reflected and parallel control handles, after snapping the control handle direction you can use a second action—holding the **⇧** key (Mac) / **Shift** key (Windows)—to snap the handle lengths to match the preceding or following handle (while maintaining the direction you already snapped to). This produces perfectly balanced control handles, indicated by the double markers.

![Image 8: Snap to reflected/mirrored angle balanced](https://images.ctfassets.net/3p2fxa94bzao/37WleyrNwZCkxxqH4gbsjZ/b9d6abd0269a73797c9b649031cf6a33/curve_snap_reflected_bal.png)

Sometimes you might see both single and double markers on the same control handle which means, respectively, that the control handle pairs are equal length and the control handle is the same length as the adjacent control handle.
