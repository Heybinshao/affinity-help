# Merge documents - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/advanced-merge-document/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Page layout](https://www.affinity.studio/help/page-layout/)
3.   Merge documents

In Affinity, you can add a section, selected pages, or all pages of another Affinity (.af) document to your current document.

This feature is only available in Affinity for desktop.

You can choose where to insert the merged pages in your current document. For example, this is useful to add a cover created as a separate document.

Merge documents when you want to use one document's pages or text styles, or both, in another document. For larger projects where you need to collate and manage the development of several documents and output them as a single publication, use the [Books](https://www.affinity.studio/help/advanced-about-books/) feature.

You can also merge from other file types. For example, Affinity (.af), IDML and PDF files.

1.   Do one of the following: 
    *   On the **Document** menu, select **Pages > Add Pages from File**.
    *   On the **Pages** panel, **^(ctrl)**-click (Mac) / **right**-click (Windows) on a page and select **Add from File**. Use this method to identify up front the position where you intend merged pages to be inserted.

2.   Browse to the file to merge into the current document, select it, then click **Open**.
3.   On the dialog that appears: 
    1.   Choose whether to add **All Pages**, specific **Page Numbers**, or a named **Section**. (Sections need to be created in advance in the incoming document.)
    2.   From **Add Pages**, choose where to place the merged content: before or after a page or section, replace existing pages, or append at the end.
    3.   If the merged pages are to be inserted or replaced, use **Pages or section** and the setting below it to identify the required position in the current document.
    4.   Check **Ignore Initial Section** to skip the incoming document's first section marker. This does not stop the merging of the section's pages.
    5.   Uncheck **Discard Unused Text Styles** if you want to carry over unused text styles from the incoming document. By default, unused text styles won't be merged into your current document.
    6.   Click **OK**.

You might see an **Imported Text Styles** dialog. Use it to manage new or conflicting incoming text styles.

![Image 1: Imported Text Styles dialog](https://images.ctfassets.net/3p2fxa94bzao/3oMInsM128hBUoQZVVgbgG/2913fcf5f14c29db7a36e1a8ba70d572/importedTextStyles.png)

*   If master pages and text styles are identical between the two documents, then those of the current document are used (no duplicate master pages or text styles will be added).
*   If master pages differ, the incoming master pages are merged into the current document and will still be assigned to incoming pages as before.
*   If text styles with the same name have different settings, you can either overwrite the current document's text style or rename the incoming style.
*   If a text style is unique to the incoming document, it will be added to the current document.

If the incoming document contains new master pages, sections and index entries, these will be carried over into the current document as well.
