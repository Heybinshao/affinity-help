**Super Resolution** is a premium feature

![Image 4: Canva Pro Feature](https://images.ctfassets.net/3p2fxa94bzao/3cDfFrl1AFrPewvudOOxnG/2310131f39f4a6dd67092f007be0b1b9/crown.svg)

. To use it, you need to be subscribed to the Canva Pro plan. To learn more about the premium features usage visit the [Canva AI & Affinity ML](https://www.affinity.studio/help/canva-ai-canva-ai-affinity-ml/) topic.

1.   In the **Canva AI Studio**, on the **Layers**panel, select the image layer you want to upscale.
2.   Select the **Super Resolution Tool**![Image 5: Super Resolution Tool](https://images.ctfassets.net/3p2fxa94bzao/6wgkaZEV2nBhNmGtsRNZS4/2ffbc88489aa3dfb6a22915db5fa514b/super_resolution.svg) .
3.   From the **Initial Downsample**pop-up menu, choose whether the image should be downsampled before upscaling.
4.   Adjust **Scale**to set the required enlargement amount.
5.   (Optional) Enable **Scale document to fit**to resize the document to match the upscaled result.
6.   (Optional) Use the preview controls to compare the result against the original image.
7.   Click **Apply**.

The Super Resolution Tool is best suited for low-quality images (below 2000px), such as those captured by older cameras or mobile phones. It upscales the images, enhances details, and reduces noise—resulting in cleaner, more visually appealing results.

Avoid applying aggressive edits to your image prior to using Super-Resolution, as this may negatively impact the output or introduce unwanted artifacts. Any sharpening should be done after applying the Tool, not before.

The following settings can be adjusted:

*   **Scale**—controls the upscaling percentage; drag the slider or enter the value manually into the field.
