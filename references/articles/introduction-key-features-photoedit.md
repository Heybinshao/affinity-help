# Key features - photo editing - Affinity Help Center

3.   Key features - photo editing

Photo editing in Affinity ranges from photo correction and enhancement, to out-and-out digital art. This discipline is carried out mainly using the Pixel Studio or Develop Studio, although other specialist Studios are available.

Here's an overview of the photo-related features in Affinity.

*   [Edit RAW files](https://www.affinity.studio/help/raw-raw/) in the Develop Studio
*   Re-enter the [Develop Studio](https://www.affinity.studio/help/workspace-develop-studio/) from image layers as well as any color format: CMYK, LAB, etc.
*   Non-destructive development of [linked/embedded](https://www.affinity.studio/help/media-embedding-vs-linking/) RAW images
*   Latest camera [RAW formats](https://www.affinity.studio/help/supported-raw-files/) supported
*   [Automatic lens correction](https://www.affinity.studio/help/filters-filter-lens-correction/) and [noise reduction](https://www.affinity.studio/help/adjustments-adjustment-noise-reduction/)
*   Save [adjustment presets](https://www.affinity.studio/help/panels-adjustments-panel/) for use on other images
*   Localised editing [using gradient and painted masks](https://www.affinity.studio/help/raw-using-masks-develop-studio/)
*   Tools for [correcting composition](https://www.affinity.studio/help/size-transform-cropping/) and removing imperfections
*   Options for pre-sharpening a RAW image ([Assistant settings](https://www.affinity.studio/help/workspace-settings/))
*   19 RAW development adjustments, including Chromatic Aberration Reduction, Contrast, Curves, Detail Refinement, and White Balance
*   Editable EXIF data
*   Live Develop Studio Assistant to auto-apply RAW Adjustments, Lens Correction and more

*   [Automatic levels, contrast, colors and white balance](https://www.affinity.studio/help/filters-filter-auto/)
*   [Live adjustments](https://www.affinity.studio/help/adjustments-adjustment-applying/), [filters](https://www.affinity.studio/help/filters-filters-applying/), [blend modes](https://www.affinity.studio/help/layers-layer-blend-modes/) and gradients
*   [Non-destructive layer resizing](https://www.affinity.studio/help/size-transform-image-size/) and [image transformation](https://www.affinity.studio/help/object-control-transform/)
*   [Open PSD/PSB documents and use 64-bit Adobe® Photoshop® compatible plug-ins](https://www.affinity.studio/help/filters-plugins/)
*   [Content-aware Inpainting Brush](https://www.affinity.studio/help/retouching-retouching-inpainting/) intelligently removes objects like magic
*   Edit tone/color and texture independently, retaining detail where needed with [Frequency Separation](https://www.affinity.studio/help/retouching-retouch-frequency-separation/)
*   Full range of [textured brush nozzles](https://www.affinity.studio/help/panels-brushes-panel/) that work across brush tools
*   Distort placed images and documents using non-destructive [Live Mesh Warp](https://www.affinity.studio/help/filters-filter-mesh-warp/) or [Perspective](https://www.affinity.studio/help/filters-filter-perspective/) filters
*   Dedicated [Liquify Studio](https://www.affinity.studio/help/workspace-liquify-studio/) for image warping
*   [Add shading and texture to an image or artwork](https://www.affinity.studio/help/retouching-retouch/) with Dodge, Burn, Smudge and Sharpen brush tools
*   [View, edit, export and import image metadata](https://www.affinity.studio/help/panels-metadata-panel/)
*   Live[equirectangular](https://www.affinity.studio/help/live-projection-equirectangular/) and [perspective](https://www.affinity.studio/help/live-projection-perspective/)projection

*   [Advanced layer handling](https://www.affinity.studio/help/layers-about-layers/) with unlimited layers
*   Drag and drop to organise layers and [adjustments](https://www.affinity.studio/help/adjustments-adjustment-applying/)
*   [Nest layers into groups](https://www.affinity.studio/help/object-control-group/) and groups within groups
*   [Clip layers](https://www.affinity.studio/help/layers-layer-clip/) by drag and drop
*   [Apply multiple masks](https://www.affinity.studio/help/layers-layer-masks/) for complex transparencies
*   Optionally move layers independently of their child layers or masks
*   [Create non-destructive live masks](https://www.affinity.studio/help/live-masks-live-layer-masks/) based on targeted hue ranges, luminosity ranges or frequency (band-pass)
*   [Fill layers](https://www.affinity.studio/help/layers-layer-fill/)
*   [Linked layers](https://www.affinity.studio/help/object-control-linking/)
*   [Blend modes](https://www.affinity.studio/help/layers-layer-blend-modes/) and tonal [blend options](https://www.affinity.studio/help/layers-layer-blend-options/)
*   Lossless [layer resizing](https://www.affinity.studio/help/size-transform-image-size/)
*   Use layer states for [quick access to different versions of your edit](https://www.affinity.studio/help/object-control-layer-states/)
*   Live Assistant to tune layer, mask, brush and adjustment behaviour

*   [Work with color and alpha channels](https://www.affinity.studio/help/channels-using-channels/), create spare channels, and use channels to edit selections
*   [Comprehensive object refining and output options](https://www.affinity.studio/help/selections-selections-refine/) including color decontamination
*   [Add/subtract/save/load selections](https://www.affinity.studio/help/selections-selections-brush/)
*   [Alpha-based selections](https://www.affinity.studio/help/selections-selections-range/) (Opaque/Transparent/Partial)
*   [Select based on color and tonal ranges](https://www.affinity.studio/help/selections-selections-sampled/)
*   Output refinement as a selection or mask
*   Select fine detail like hair and fur with advanced refining
*   Make [selections based on channels](https://www.affinity.studio/help/selections-selections-fromchannels/): work with color and alpha channels, create spare channels, and use channels to edit selections

*   Improve compositions with [control over cropping and aspect ratio](https://www.affinity.studio/help/size-transform-cropping/)
*   [Use crop presets](https://www.affinity.studio/help/tools-tools-raster-crop/) or save your own custom crops (desktop only)
*   [Straighten images](https://www.affinity.studio/help/size-transform-cropping/) simply by dragging across a horizon
*   Extend images in preparation for contentaware inpainting

*   Professional Brushes 
    *   On-page brush preview sets width, hardness, nozzle spacing and rotation
    *   [Create image brushes](https://www.affinity.studio/help/painting-custom-raster-brushes/) from any pixel selection
    *   [Customise opacity (accumulation), hardness, spacing, flow, shape, rotation, luminosity, and pressure sensitivity](https://www.affinity.studio/help/painting-raster-modify/)
    *   [Mimic natural media including watercolors, markers, oils, and more](https://www.affinity.studio/help/painting-raster-painting/)
    *   [Multi-brushes](https://www.affinity.studio/help/painting-raster-multi-brushes/) (combining brushes for a more interesting, less uniform brush stroke)
    *   Nozzle rotation using left and right arrow keys (before and during stroke application)
    *   Paint using high-quality, professional brush nozzles

*   Custom Brushes 
    *   [Customise brush behaviour](https://www.affinity.studio/help/painting-raster-modify/) and settings like wet edges, pressure sensitivity, dynamics, blend mode, and more
    *   Choose behaviour for pressure and velocity variance, corners, repeating areas and many other controls
    *   [Create completely custom raster brushes using your own textures](https://www.affinity.studio/help/painting-custom-raster-brushes/)

*   Stroke Stabilisation
*   [Paint with pressure](https://www.affinity.studio/help/curves-shapes-pressure/) using [graphics tablets](https://www.affinity.studio/help/extras-pen-tablet/) or Force Touch
*   [Edit Pressure Profiles](https://www.affinity.studio/help/curves-shapes-edit-pressure-profiles/) by Chart or directly on the stroke
*   Tablet controller support like tilt, angle, velocity and other inputs

*   Record [macros to automate repeated actions](https://www.affinity.studio/help/macros-batch-macros/) and [batch process files](https://www.affinity.studio/help/macros-batch-batchjobs/) (desktop only)
*   [Import macros](https://www.affinity.studio/help/addons-importing-addons/) previously exported
*   [Load and infer LUTs](https://www.affinity.studio/help/adjustments-adjustment-3d-lut/) as part of a Macro to speed up batch editing
*   [Share LUTs between platforms](https://www.affinity.studio/help/addons-exporting-addons/)

*   [Live Image Stacks](https://www.affinity.studio/help/stacking-stacks/)
    *   Combine and auto-align multiple images
    *   Long exposure simulation and [exposure blending](https://www.affinity.studio/help/stacking-stacks-exposuremerge/)
    *   [Creative 'time-lapse' and motion effects](https://www.affinity.studio/help/stacking-stacks-creative/)
    *   [Noise reduction](https://www.affinity.studio/help/stacking-stacks-noisereduction/) and clear moving subjects from scenes

*   [High Dynamic Range (HDR) Editing](https://www.affinity.studio/help/hdr-hdr-editing/)
    *   Automatically align images and remove ghosts
    *   [Tone Map HDR image](https://www.affinity.studio/help/hdr-hdr-tonemapping/)
    *   [Full OpenColorIO support](https://www.affinity.studio/help/clr-ocio/)
    *   Maintain a true 32-bit lossless workflow and preview full tonal range
    *   Edit HDR and EDR images with clipping warnings
    *   HDR and EDR Display Support (Desktop only)

*   [Focus Merging](https://www.affinity.studio/help/focus-merging-focusmerging/)
*   [Astrophotography](https://www.affinity.studio/help/astrophotography-astro-creating/)
*   [Batch Processing](https://www.affinity.studio/help/macros-batch-batchjobs/)
*   [Panorama Image Stitching](https://www.affinity.studio/help/panorama-panorama-stitching/)
