The Node Tool

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/2Tyrn620F9iCYiF39DxVOc/9de008f998af69eafee088eb5a3c5210/node_tool.svg)

 is used to edit existing curves, lines and shapes.

The Node Tool is available by default in Vector, Pixel and Layout Studios.

It can be added to other Studios. See 'Customizing tools' for details.

Tool shortcut key: **A**

The following options can be adjusted on the context toolbar:

*   **Fill**—click the color swatch to display a pop-up panel to update fill color.
*   **Stroke**—click the color swatch to display a pop-up panel to update stroke color.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/3rYvQ5X8bUYnIRpXvMBBlv/ee8198bb2731db49a0f3ec426d194fb2/stroke_width.svg) **Stroke width**—set a stroke width for the stroke using direct input or slider.
*   ![Image 3: Edit stroke settings](https://images.ctfassets.net/3p2fxa94bzao/LAIAniI5tfK3bknzYOUQB/9af81e28e315cea94436ab657c986f85/stroke.svg) **Edit stroke settings**—click to change stroke style, width, and alignment.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/1u8ioE0kk2O3hClti5GNFQ/cac15e5ba603ae52943e4d8e4bf2e2d7/convert_sharp.svg) **Sharp**—converts the selected node to a sharp node (for cusped corners).
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/1GgxCLnnzKXjbBMjq00c4O/c37f54e0eda9d66eaced34ad881c1a37/convert_smooth.svg) **Smooth**—converts the selected node to a smooth node (for a Bézier curve).
*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/5GBJ3hAEklQ9OB7JegR1Mx/ffa029d660ca57f2ba49581c12b758c9/convert_smart.svg) **Smart**—converts the selected node into a smart node (for a best-fitting curve).
*   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/1n9wi7A7Cwn1HEMNhetiwZ/82695e97aeb8e8179cdcb9521ffb7c5b/split_curve_at_selected_node.svg) **Split Curve** adds a new node at the midpoint of one of the curve segments of the currently selected node, depending on the current curve orientation (indicated by a red-line indicator). Use **Reverse Curve**![Image 8](https://images.ctfassets.net/3p2fxa94bzao/4aEenWCp3fgkYVwRQQF18p/5aec5f6e69b82891e16fd078aec2ddf8/action_reverse_curves.svg)  to change this curve orientation.
*   ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/3iEJTLrCxMb4ZR30sc8BZZ/e167fce74351f40bd361b8f51b32a074/action_break_curve.svg) **Break Curve**—opens the shape at the selected node.
*   ![Image 10](https://images.ctfassets.net/3p2fxa94bzao/2Gq5XAQINSYoHvUFwH5ZP5/b8478e2d20a8db7b1c48fba54d272f78/action_close_curve.svg) **Close Curve**—joins the start and end nodes to create an enclosed shape.
*   ![Image 11](https://images.ctfassets.net/3p2fxa94bzao/5NIosVN2amJnLIl9SsALzs/fa6749b753448d285834853da54cc9ff/action_smooth_curve.svg) **Smooth Curve**—modifies a line or shape, by adding and removing nodes, to create a rounder and softer curve effect.
*   ![Image 12](https://images.ctfassets.net/3p2fxa94bzao/6RJ3G6uqVxyuf2swmbJMaY/dd5e0d6f023a5f1e4e7e8e6c964c39a5/action_join_curves.svg) **Join Curves**—connects two separate curves together to make one curve.
*   ![Image 13](https://images.ctfassets.net/3p2fxa94bzao/4aEenWCp3fgkYVwRQQF18p/5aec5f6e69b82891e16fd078aec2ddf8/action_reverse_curves.svg) **Reverse Curve**—reverses the direction the curve was drawn in.
*   ![Image 14](https://images.ctfassets.net/3p2fxa94bzao/2M4Ydf8gakC0UC2AkzJgb2/27bd3ca0aa29a37a170701e86055aadd/transform_mode.svg) **Transform Mode**—when selected, creates a bounding box around the selected nodes, allowing them to be transformed as a group.
*   ![Image 15](https://images.ctfassets.net/3p2fxa94bzao/5krfOq8r5Vnk8qE0zpecXE/f66f66d96c880ca1832af3cc2cea9e4b/rotationctr.svg) **Enable Transform Origin**—displays a movable transform origin about which the selection box can be rotated.
*   ![Image 16](https://images.ctfassets.net/3p2fxa94bzao/yidHpEw4ai5NUXJKhxsjg/c95d4e824fecdf3a0691457adb8968b8/hide_selection_while_dragging.svg) **Hide Selection while Dragging**—when selected, the selection box is temporarily hidden when transforming. If this option is off, the selection box remains visible during transformation. The selected behavior persists across all objects unless it is manually switched.
*   ![Image 17](https://images.ctfassets.net/3p2fxa94bzao/r5jhdqkf0IHpsjOf39WC0/d08a2687c3652304bd7057dddc9498b2/alignment_mode.svg) **Show Alignment Handles**—when selected, displays alignment handles at the center and edges of the selected object. Hovering over these handles displays a floating guideline across the page. You can drag the handles to position the center or edges of the selected object in line with this guide.
*   ![Image 18](https://images.ctfassets.net/3p2fxa94bzao/4G0YdVM0GAgl4mLAGp4nyk/687c868ac34c376f27907dfdfe3d6e36/curves_box_mode.svg) **Selection Box From Curves**—when selected, the selection box encompasses and includes all curves that extend outside the array of currently selected nodes.
*   ![Image 19](https://images.ctfassets.net/3p2fxa94bzao/7e47FwYJ0eBW8yOWy3elSz/813ccca2419c99817334e5bb65c2a0db/cog_icon_2.svg) **Settings**—for advanced snapping and curve orientation control: 
    *   **Align to nodes of selected curves**—aligns any moving node you drag to any other node on the same or a different curve.
    *   **Snap to geometry of selected curves**—will snap moving node to the same or different curve's path or node.
    *   **Snap all selected nodes when dragging**—will snap multiple selected nodes, when dragging, to a "target" node on any selected curves.
    *   **Align handle positions using snapping options**—will snap a control handle using any of the snapping criteria currently set in Global snapping, e.g. to grid, guide, object geometry, key points, spread, margin, etc.
    *   **Perform construction snapping**—allows control handle snapping: 
        *   inline with adjacent node.
        *   to 90° from inline.
        *   to reflected angle with adjacent control handle.
        *   parallel to adjacent control handle.
        *   90° to parallel control handle.
        *   to logical triangle.

These options are independent of the global [snapping](https://www.affinity.studio/help/design-aids-snapping/) options.
*   **Show curve orientation**—displays the segment leading up to the end node in red to help visualize the direction of the closed shape's outline (used for winding fill mode); the drawing direction is away from the red-line indicator.

If a geometric shape is selected rather than a curve, the Node Tool's context toolbar will show options applicable to a selected geometric shape rather than the options listed above.

*   To select the Node Tool, press the **A** key.
