# Page headers and footers - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/pages-numbering-pages/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Page layout](https://www.affinity.studio/help/page-layout/)
3.   Page headers and footers

Most pages include a page number in the header or footer. Some show a section name.

These are added as fields on a master page's header or footer. Pages using the master will show correct information.

![Image 1: Page numbering](https://images.ctfassets.net/3p2fxa94bzao/5SPvKTywLhXtyBJAlv6xZ/721151ddad5aa4ec22f6823c0e9967b5/pagenumbering.png)

A page number and section name on a left-hand publication page.

Use the Section Manager to set page numbering and create sections with custom names (like _Preface_ and _Index_), starting page numbers, and numbering styles.

You can add a page number field to a single page or both facing pages of a spread—or any pages you wish in a multi-page spread.

Add page numbers as fields from the **Fields** panel or **Text** menu. Their text updates automatically.

To hide page numbers in early sections (e.g. Contents or Preface), avoid using a master page that includes page number fields on their pages.

Names that identify a page's place in a document are inserted as fields. They can show the page's section name (from the **Section Manager**).

Alternatively, use a **running header**. It shows text from the same or an earlier page and with a specific text style. The text repeats across pages. It updates when the style is used again.

The following options choose where the text comes from:

*   **Style**—chooses the text style the field uses.
*   **Use**—when the text style is applied multiple times on a page, you can choose which one (**First on page** or **Last on page**) the running header displays.

When a running header is set to **Last on page**, the field will not display a value on pages that do not contain any text that uses the chosen text style.

You can limit how much text a running header shows using its formatting options. This might be due to the source text being too long to display in full, or for other aesthetic reasons.

Running headers can transform their text's capitalization, or to simply repeat their source's capitalization.

The following formatting options are available:

*   **Include Paragraph Numbering**—when the text style is applied to numbered lists, turn on to include list item numbers in the running header or turn off to exclude them.
*   **Apply Limits**—chooses whether the running header's length is limited: 
    *   **End on**—chooses which characters will automatically end the running header, even if the style continues afterward.
    *   **Include End Character**—chooses whether to include or exclude the terminating end character in the running header.
    *   **Max Word Count**—set how many words the running header can show.
    *   **Use Ellipsis**—chooses whether an ellipsis should be displayed at the end of a running header whose length has been limited.

*   **Case Change**—chooses the text transformation to apply to the displayed text: **None**, **Upper**, **Lower**, **Title** or **Sentence**.

1.   On the **Pages** panel, double-click a master page.
2.   In the document view, create a text frame. You'll use it for a page number, a page name, or both.
3.   On the **Fields** panel, in the **Document Sections** group, do any of the following: 
    *   To insert a page number, double-click **Page Number**.
    *   To insert a section name, double-click **Name**.
    *   To insert a page name based on styled text, double-click **Running Header**.

On a master page, page numbers show as a hash symbol (#). Page names show as placeholder text: _<Section Name>_ or _<Running Header>_. When the master page is used on a publication page, these placeholders turn into real page numbers and names.

1.   On the **Pages** panel, click **Section Manager**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/2TDNSfgxFp4cONNjp2iTz1/13fb5495a1a4761675b891f48cec42d3/section_manager.svg) .
2.   On the **Number style** pop-up menu, choose a numbering format like numbers (1, 2, 3), Roman numerals (I, II, III), or letters (A, B, C).

*   Before adding the field to a page: On the **Fields** panel, find the **Document Sections** group. Next to **Running Header**, click **Default format**.
*   After adding the field to a page:**^(ctrl)**-click (Mac) / **right**-click (Windows) the field in the document text. Select **Edit Field**.
