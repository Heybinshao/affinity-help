3.   Global tonal adjustments

Global tonal adjustments affect the entire image or layer and are typically the first step in tonal editing. They establish overall exposure, contrast, and dynamic range before more targeted refinements are made.

![Image 1: After applying global adjustments to brighten up the scene.](https://images.ctfassets.net/3p2fxa94bzao/7FTmFXc7H0aPWx8ievFuiI/c50e2ff13897c11b7e00ad5a7080cd51/globalTonalAdjustments_after.jpg)

After applying global adjustments to brighten up the scene.

In Affinity, global tonal control is primarily achieved using adjustment layers. These allow you to refine tonal balance non-destructively and revisit changes at any time. The first stage of tonal editing is setting a balanced range between shadows and highlights. The following adjustments should be considered:

*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/3sUtJeUQMZ6GrVHc9V5TPv/19fd2cb45e125061fc1c3a451f05d31c/curves_adjustment_type.svg) **Curves**for precise tonal shaping. A gentle S-curve increases midtone contrast, while adjusting endpoints refines shadow and highlight boundaries.
*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/2BlFCLiDYRlPu3d67dykNp/ddaeec3ef156c516b7660ced6ad4426b/levels_adjustment_type.svg) **Levels**to define black and white points and adjust midtone brightness. This helps restore depth to flat images and prevent loss of detail in extreme tonal areas.

Some adjustments allow tonal redistribution without altering color.

*   Converting color to grayscale using the **Black & White**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/3PgOWd2qBooTcJXPAKxsk1/9209748380a579021b8067e31d47a007/black_and_white_adjustment_type.svg) adjustment allows finer tonal control via color channels.
*   Using the **HSL**![Image 5](https://images.ctfassets.net/3p2fxa94bzao/7GOVxSX9cIrGUggVNknZn/6a5d4570ad927da6f562e5cb1d87e97f/hsl_adjustment_type.svg) adjustment helps in correcting the perceived brightness of specific color ranges without changing the tone.

1.   On the **Layers**panel, select an image or pixel layer.
2.   Do one of the following:
    *   Set black and white points using **Levels**or **Curves**.
    *   Refine midtone contrast with **Curves**.
    *   Recover shadow or highlight detail using **Shadows / Highlights**live filter, if needed.

3.   Make subtle refinements using the **Exposure**adjustment.

*   Avoid excessive contrast that reduces editing flexibility.
*   Evaluate tonal distribution using the **Histogram**panel.
*   Compare before and after results regularly.
*   For quick access to commonly used adjustments and filters in one place, use the **Quick Adjustments**panel.
