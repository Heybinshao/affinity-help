The Shadows / Highlights

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/3s8XDsbkEYrU8HbclM9knU/2ef272566ec4e3f75bd5d9698253dbf4/shadows_highlight_live_filter.svg)

 filter allows for stronger manipulation of the shadow and highlight tonal regions in an image. It can be used to reduce contrast, boost shadow detail and recover highlight detail.

![Image 2: After](https://images.ctfassets.net/3p2fxa94bzao/5XgIJLBoWqVJtvFmPyMP38/f3a8ca34e6e8d3358e76e09de27623af/filter_shadowshighlights_after.jpg)

![Image 3: Before](https://images.ctfassets.net/3p2fxa94bzao/6JLRnZ30tjUJvUWdcPCY5G/317c803f9ef7ddf240c9d6270cd1287a/filter_shadowshighlights_before.jpg)

This filter can be applied as a destructive or non-destructive live filter.

Affinity provides several easy ways to adjust shadows and highlights:

*   Tonal adjustments: **Curves**, **Levels**, **Exposure**, **Brightness / Contrast**.
*   Filters: **Lighting**, **Portrait Lighting**, **Clarity**.
*   **Tone Mapping**: a dedicated workspace for high dynamic range (HDR) editing. 
*   Brush Tools: **Dodge Brush Tool** and **Burn Brush Tool** for selective adjustments.

For detailed information, see the dedicated topics.

To use the destructive version of the filter, select it from the **Pixel > Filters** menu. The live version can be accessed from:

*   the **Layers** panel by clicking **Live Filters**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/2ALwfgZXKqtubPaMdMHvlC/d4901c280214d88174d57188a9c56e21/filters_studio.svg) .
*   the **Pixel > New Live Filter Layer** menu.

Shadows / Highlights is also available as a tool in the Compositing Studio

![Image 5](https://images.ctfassets.net/3p2fxa94bzao/3HLsf5xx2FlnBTmx7VwAkX/eb93eb77aa0dc236a5edfe2d6e7ef9f7/compositing_studio.svg)

.

The following settings can be adjusted in the filter dialog:

*   **Version**
    *   **Default**—The improved version of this filter, introduced in version 1.7. Recommended for more natural-looking results.
    *   **1.6**—The classic version of this filter, retained for backwards compatibility with existing documents.

*   **Shadows Strength**—control how much shadow detail is boosted.
*   **Shadows Range**—specify the tonal range to boost. Moving the slider to the right will boost a greater range of shadow tones.
*   **Highlights Strength**—control how much highlight detail is recovered.
*   **Highlights Range**—sets the tonal threshold for recovering highlight detail. Move the slider to the right to recover a greater range of highlights.
