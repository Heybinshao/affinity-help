# Importing add-ons - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/addons-importing-addons/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Installation and setup](https://www.affinity.studio/help/installation-setup/)
3.   Importing add-ons

Add-ons stored as files must be manually imported into Affinity.

There are two ways to import add-ons:

*   Using the panel or part of the app's interface that corresponds to the add-on's type.
*   For files whose extension begins with _.af_, by selecting **Import Content** on the **File** menu.

Some content may be provided as one of several add-on types. For example, overlays may be provided as assets that can be dragged from the Assets panel as needed, or as image files that can be dragged and dropped from Finder (Mac) or File Explorer (Windows) into your documents.

As well as Affinity's own file formats, various industry standard file formats can be imported.

Add-ons may be supplied in the ZIP file format or similar and must be extracted before they can be imported.

For Mac: In Finder, double-click the archive to extract its contents to the same folder as it.

For Windows: In File Explorer, **right**-click the archive and select **Extract All**, then follow the on-screen instructions to extract the archive's contents to your required location.

For any type of add-on listed in the table below, follow the corresponding steps, then (except for fonts) browse to and select the add-on file to be imported and click **Open**.

When most types of add-on are imported, one or more new categories are created. One of these categories is automatically displayed on the corresponding panel.

![Image 12](https://images.ctfassets.net/3p2fxa94bzao/x0qUKV0QmljBpXjlKaAyD/48b1503c7d6cc8f05d91c6af70f31b85/persona_photo.svg)

 The following exceptions apply:

*   An individual LUT file—the LUT is added to your chosen category.
*   A macro category—the category is added to the Categories menu on the Macros panel and must be manually selected.
