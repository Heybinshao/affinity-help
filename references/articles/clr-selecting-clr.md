3.   Selecting colors

There are several ways of choosing colors for your projects.

An essential requirement for efficient workflow is the ability to access colors easily and intuitively. You may have a preferred method for color selection, so several choices are available:

*   Context toolbar—for selection of Fill and/or Stroke colors from the context toolbar that displays when a vector object is selected.
*   Color panel—for selection from color wheel, sliders, or boxes using different color models.
*   Swatches panel—for selection by swatch from different preset or custom categories, including PANTONE® Colors.
*   Color Picker Tool—for sampling colors anywhere on your screen; great for complementary color work.
*   Fill Tool—apply or edit a color gradient across your object. Choose from the tool's context toolbar.

, objects have fill and stroke color properties. In the Color and Swatches panels, the stroke color is represented by a cutout (donut) color selector. The fill is represented by a solid color selector. In the Pixel Studio, two solid color selectors indicate interchangeable Foreground and Background colors instead.

The active swatch is whichever is shown in front of the other. Choosing a new color will apply it to this swatch.

These swatches change appearance for some vector tools.

*   **Fill Tool**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/4AbVamuwkW3QLOJP3GQiV1/254daa0b4c76a58d6ef299e8068f0519/fill_tool.svg) : When selected, only one color selector swatch is shown to represent the color of the currently selected stop on the gradient.
*   **Image Brush Tool**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/4h6tAPjAsi96tS2iGpCxqP/cd04d47c9325109c475ad317cbfdeaa0/vector_brush_tool.svg) : When selected, the panel shows foreground and background swatches that can be swapped by clicking the adjacent double arrow.

For quick access, Fill and Stroke swatches are available from the context toolbar of any selected shape, line, or stroke. Opacity and noise are further color attributes which can be applied.

1.   Select the object.
2.   On the context toolbar, click either the 'Stroke' or 'Fill' swatch.
3.   On the pop-up menu, choose color from **Swatches**, **Color**, or **Gradient** tabs.

Using the Color tab, you have the option of selecting color using an HSL Color Wheel by default; RGB, RGB Hex, HSL, CMYK, LAB, Grayscale sliders; in 8 bit, 16 bit or percentage modes where applicable; or independent Hue, Saturation, or Lightness boxes.

With the **Color** panel, colors can be applied to an object or adopted by a tool just like the context toolbar. The panel is docked with other panels by default, but can be grouped with other panels in custom panel arrangements; it lets you save colors to a palette in the Swatches panel and uniquely presents recently used colors to pick from.

Some of the selection methods allow you to set color on the **Color** panel using values other than RGB. This doesn't change the working color profile of the document, but changes the input values for the colors. For example, if your working profile is an RGB profile, choosing 100% K (black) from the CMYK color model doesn't convert your document to CMYK. Instead the color applied will be an RGB approximation of 100% K (black). However, if you convert or export the document to a CMYK profile, the 100% K (black) will be honored.

1.   Click the Stroke or Fill swatch selector at the top left of the panel. These are called Foreground or Background swatches in the Pixel Studio.
2.   Click (or drag) for a hue on the outer ring.
3.   Click (or drag) in the inner triangle to set the combined Saturation and Lightness.

The relevant active swatch updates to the selected color.

Enter an RGB Hex value into the **#** setting.

Click **Panel Preferences** menu

 on the **Color** panel for alternative color models, slider inputs, and a choice of bit depths.

*   Click the double-headed arrow. The colors switch (but the active swatch selector remains the same).

You can switch color selectors by pressing the **X** key.

1.   Click the **Panel Preferences** menu ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/6UxpXBt5miovw347YaOPUz/6f8e3e8d9b379daa0bdc5a3ac6ff23e8/panel_preferences.svg) , and select **Sliders** from the menu.

3.   Select a different color model from the menu.

1.   Click the **Panel Preferences** menu ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/6UxpXBt5miovw347YaOPUz/6f8e3e8d9b379daa0bdc5a3ac6ff23e8/panel_preferences.svg) , and select **Tint** from the menu.
2.   Drag the slider to the left or right to increase or decrease the color tint, respectively.

*   Drag the **Opacity** slider to set the value. Click the **Switch** toggle button to apply **Noise** via slider as well as opacity.

*    Click the **Panel Preferences** menu ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/6UxpXBt5miovw347YaOPUz/6f8e3e8d9b379daa0bdc5a3ac6ff23e8/panel_preferences.svg) , and select one of the following: 
    *   **Add Color to Swatch**—adds the current color to the currently loaded palette in the Swatches panel.
    *   Select a chord type from the **Add Chord to Swatch** pop-up menu—adds a chord of the current color to the currently loaded palette in the Swatches panel.

The Swatches panel provides color swatch presets that are selectable from various categories. You can easily apply grays, solid colors, or gradient colors from presets; PANTONE spot color palettes are available too.

Do one of the following:

*   Choose a palette category from the category pop-up menu and click a color swatch in the palette.
*   Click a swatch from the **Recently used** swatches.
*   Click a **None** swatch to make the color completely transparent.

Hold down the **⌥** key (Mac) / **Alt** key (Windows) when selecting a swatch to honor the opacity and/or noise already applied to your object (i.e. only the color of the object will update).

The **Pixel** menu allows you to apply or edit a color fill across a pixel or vector layer or selected layer content.

1.   On the **Pixel** menu, select **Filters > Colors > Fill**.
2.    From the dialog, choose one of the following: 
    *   **Custom Color**—pick any color from the adjacent swatch using a pop-up HSL Color wheel.
    *   **Primary Color**—uses the currently set foreground color from the Color panel.
    *   **Secondary Color**—uses the currently set background color from the Color panel.
    *   **Inpainting**—restores damaged, lost, deteriorated or unwanted areas of the selection.
    *   **History**—reverts the selection back to a previous history state or a saved snapshot.

3.   (Optional) Reduce the **Opacity** to limit the fill strength.
4.   Click **Apply**.

For fast access to the currently set foreground or background colors in the Color panel, select **Fill with Primary Color** or **Fill with Secondary Color** from **Pixel > Filters > Colors** menu, respectively.

PANTONE® Color palettes are available, and will automatically become a global spot color in the document palette when applied. You can choose from Goe, GoeBridge and Color Bridge palettes as both coated and uncoated.

1.   On the **Swatches** panel (or pop-up Swatches panel), from the category pop-up menu, select your preferred PANTONE palette.
2.   (Optional) Use the search window to locate a specific color (e.g., 129) within that category.

To display the PANTONE® Color name and number, click on the **Swatches** panel's **Panel Preferences** menu and select **Appearance > Show as List**.
