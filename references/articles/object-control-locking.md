# Locking

You can lock layers and objects to prevent them from being transformed accidentally. Locked items still remain editable.

![Image 5: Locking](https://images.ctfassets.net/3p2fxa94bzao/7ssWXJtOilunqLTgmH22Ng/92ff804832d91e1eb7be0b640f3c3769/locking.jpg)

A locked item showing locked handles. The Layers panel shows a clickable locked icon for the same item.

[](https://www.affinity.studio/help/object-control-locking/#how-to-lock)

### How to lock

Desktop app

1.   On the **Layers** panel, select the object or layer content to be locked.
2.   Do one of the following: 
    *   Position the cursor to the left of the **Toggle visibility** button and click the **Toggle Lock** icon (  ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/52XYdXlyLW1ZAzUYGK6kqf/48bc9cd93adcdbf14804e0cab02cbcf0/lock_layer.svg)       ) that appears.
    *   On the **Layer** menu, select **Lock**.

Layers or objects which are locked show on the Layers panel with a lock symbol next to them. Selected locked layers or objects appear in the document view with crosses around the bounding box.

Opened images appear as a locked background layer by default.

[](https://www.affinity.studio/help/object-control-locking/#how-to-unlock)

### How to unlock

Desktop app

*   Click the **Toggle Lock** again, or use the **Layer** menu's **Unlock** item.

[](https://www.affinity.studio/help/object-control-locking/#how-to-unlock-all)

### How to unlock all

Desktop app

*   On the **Layer** menu, select **Unlock All**.

If any locked layers are selected before Unlock All is applied, only those layers will be unlocked, instead of all layers.

[](https://www.affinity.studio/help/object-control-locking/#shortcuts)

### Shortcuts

Desktop app

*   The **^(ctrl)⌘L** keys (Mac) / **Ctrl**+**Alt**+**Shift**+**L** keys (Windows) unlock all selected locked objects or every locked objects if no selections are in place.

[](https://www.affinity.studio/help/object-control-locking/#see-also:)
