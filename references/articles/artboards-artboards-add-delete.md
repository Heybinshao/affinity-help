# Adding and removing artboards - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/artboards-artboards-add-delete/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Graphic design](https://www.affinity.studio/help/graphic-design/)
3.   Adding and removing artboards

Artboards can be created with new documents or added to your current document at a preset or custom size at any time.

When creating a new document, you can automatically create your first artboard at this time.

Once you have a document open, you can add additional artboards in different ways:

*   using the original document's dimensions—perfect for creating multi-page documents
*   using preset sizes—perfect for device-specific designing
*   using the current selection's dimensions
*   at a custom size
*   by copying or [duplicating](https://www.affinity.studio/help/object-control-duplicate/) other artboards
*   by converting a selected object

Artboards can be deleted from your project at any time. Any objects placed on the artboard can either be kept or deleted (you're prompted to confirm which action you want to take via dialog). Kept objects will remain in their original position but will be on the pasteboard instead.

As an alternative to deleting an artboard, you can convert it into a standard object. In this situation, any objects on the artboard will be nested within the new object, thereby preserving your design.

1.   On the **File** menu, click **New**.
2.   From the dialog, select a preset category and preset from the scrolling list.
3.   (Optional) Adjust the settings in the dialog for a custom setup.
4.   Check **Create artboard**. Some categories (e.g., Devices) automatically offer presets as artboards.
5.   Click **Create**.

You can apply a drawing scale factor to artboards via the New Document dialog or **Document > Setup > Document Setup** by using the **Scale** tab.

The **Measure Tool** also lets you apply a **Drawing Scale** factor, along with scaling based on a known measurement.

1.   (Optional) With the **Move Tool**![Image 1](https://images.ctfassets.net/3p2fxa94bzao/3oigj5SSoPtnSw21egHEvD/b6ac975f2be7b3feb8e3e9867b378345/move_tool.svg) , select one or more objects.
2.   Select the **Artboard Tool**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/1U3kNff9CwQe3qKLyzLv1J/1f2c24b9a5a241682428987ae3a4ab34/artboard_tool.svg) 
3.   On the context toolbar, from the **Size** pop-up menu, select: 
    *   **Document**—to add an artboard at the current document's dimensions to the canvas.
    *   **Selection**—to add an artboard at the same size and position as the selected artboard or object(s). You may need to reposition the new artboard to give it its own space on the pasteboard.
    *   any other preset—to add another artboard at a device-specific preset's dimensions.

4.   On the context toolbar, click **Insert Artboard**.

In the Vector Studio

![Image 3](https://images.ctfassets.net/3p2fxa94bzao/2Mejuekyv1U5fQVTYLqGud/edc8c0247142081ce0079de3013e815d/persona_vector.svg)

, do one of the following with the **Artboard Tool** selected:

*    Using _Object data entry_: **⌘**-click (Mac) / **Ctrl**-click (Windows) on the page, then enter your artboard dimensions into the **Create Artboard** dialog. Optionally, set an anchor point to position the artboard in relation to the new anchor position, rather than the default or previously set anchor point. The last used settings will be remembered.You can also choose a preset artboard size instead of a custom size using the dialog. 
*   For sizing _by eye_: Drag on the pasteboard.

When using the Artboard Tool, the following modifier keys can be used:

*    The **⇧** key (Mac) / **Shift** key (Windows) constrains the artboard's proportions at the time of creation (to a square) or when resizing. 
*    The **⌘** key (Mac) / **Ctrl** key (Windows) resizes the artboard from its center. 
*    For Mac, the **⌃(ctrl)** key lets you rotate an artboard about its opposite handle. 
*   For Windows, pressing the right mouse button lets you rotate an artboard about its opposite handle.

*    With an artboard selected, do one of the following: 
    *    With the **Move Tool**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/3oigj5SSoPtnSw21egHEvD/b6ac975f2be7b3feb8e3e9867b378345/move_tool.svg)  or **Artboard Tool**![Image 5](https://images.ctfassets.net/3p2fxa94bzao/1U3kNff9CwQe3qKLyzLv1J/1f2c24b9a5a241682428987ae3a4ab34/artboard_tool.svg) , **⌘**-drag (Mac) / **Ctrl**-drag (Windows) the artboard. 
    *   On the **Edit** menu, select **Duplicate > Selection**.

*   Do one of the following:
    *   On the **Vector** menu, select **Convert Object to Artboard**.
    *   With the **Artboard Tool**![Image 6](https://images.ctfassets.net/3p2fxa94bzao/1U3kNff9CwQe3qKLyzLv1J/1f2c24b9a5a241682428987ae3a4ab34/artboard_tool.svg)  active, select **Size** to be _Selection_ on the context toolbar, then select **Insert Artboard**.

If an object has been converted to an artboard, that artboard remains editable as if it was the original object. For example, an artboard converted from a closed shape can still be edited as a closed shape and an artboard converted from artistic text can still be edited as text.

Do one of the following:

*   Double-click on the artboard's name (above the artboard) on the pasteboard, then enter a new name and click **Rename**.
*   On the **Layers** panel, double-click the selected artboard's current name, then enter a new name for the artboard.

1.    Do one of the following: 
    *   Using the **Artboard Tool**![Image 7](https://images.ctfassets.net/3p2fxa94bzao/1U3kNff9CwQe3qKLyzLv1J/1f2c24b9a5a241682428987ae3a4ab34/artboard_tool.svg) , click to select a single artboard or **⇧**-click (Mac) / **Shift**-click (Windows) to select multiple artboards. 
    *   On the **Layers** panel, select one or more artboards.

2.    Do one of the following: 
    *    Press the **⌫** key (Mac) / **Backspace** key (Windows). 
    *   On the **Layers** panel, click **Remove Layer**![Image 8](https://images.ctfassets.net/3p2fxa94bzao/3m8ciDtLqf07Yrma1i0j4x/202c1d508104bbb0a1290c5be7725eae/trash_can.svg) .

*   With the single artboard selected, from the **Vector** menu, select **Convert Artboard to Object**.
