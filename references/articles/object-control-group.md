# Grouping - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/object-control-group/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Grouping

Objects or layers can be grouped together to assist with easier management and design composition.

![Image 1: Grouped objects](https://images.ctfassets.net/3p2fxa94bzao/1u1PyrQFVjPP081yPz5N8A/9e5b547dbebfb8e61f526cd1fb291487/grouping_objects.png)

Grouped objects or layers remain together so they can be easily selected, moved, copied, and edited as if they are a single item. Furthermore, once a group is created, adjustments and masks can be applied to the group and will affect all the group contents within the group but not those outside the group.

Groups, and nested groups, can be broken apart at any time into their separate components. Ungrouping can be performed on individual groups, or across multiple or nested groups using a single command.

Resizing a group will maintain the aspect ratio by default, the opposite of resizing an individual object.

One or more groups can also belong to a 'parent' group, in which case they are nested groups.

1.   Select multiple objects.
2.   Do one of the following: 
    *   On the context toolbar, click **Group**.
    *   On the **Layer** menu, select **Group**.

1.   Do one of the following: 
    *   On the **Layers** panel, double-click the existing group's name.
    *   With the group selected, from the **Layer** menu, select **Rename**.

2.   Type a new name.
3.   Press **⏎** key (Mac) / **Return** key (Windows). 

1.   Select the group.
2.   Do one of the following: 
    *   On the context toolbar, click **Ungroup**.
    *   On the **Layer** menu, select **Ungroup**.

For groups within groups, you can expand or collapse all nested items including 'subgroup' items in a group by pressing the **⌥** key (Mac) / **Alt** key (Windows) and clicking the group layer's arrow.

1.   Select the object you wish to move out of the group.
2.   Right click on the object in the **Layers** panel, and from the menu, choose **Release**.

1.   Select a group containing nested groups.
2.   On the **Layer** menu, select **Ungroup All**.

All groups and nested groups are ungrouped, leaving all previously grouped objects as individual objects or layers.

*   Double-click on the object. If the object itself is in a group, the group will be selected first—double-clicking again will select the object.

To select nested content directly from the document view, select the **Move Tool**, then hold the **⌘** key (Mac) / **Ctrl** key (Windows) and right-click an object in the view. From the contextual menu that appears, select any content contained in the same group as (or deeper than) the object you clicked.

When using the Move Tool, **Auto-select** on the context toolbar allows you to choose between selecting groups and objects (or layers) inside them.

Related behaviors can be adjusted from [the app's settings](https://www.affinity.studio/help/workspace-settings/):

*   **General > Ask for name when creating Layers and Groups** will prompt for a name on group creation.
