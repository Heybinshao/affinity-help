Transforming is a general term to describe the repositioning, sizing (scaling), rotation, shearing or flipping of objects. Several choices are available:

*   By eye: Using the Move Tool or by dragging control/rotation handles.
*   Transform panel: For accurate repositioning, resizing, rotating and shearing objects via panel.

For desktop only, the following are possible:

*   Via the Toolbar: Several rotation and flipping operations are easily accessible.
*   Move data entry: For accurate repositioning, rotating, scaling and duplicating of objects and layer content by dialog.

1.   Select one or more objects or layers.
2.   On the **Transform** panel, change **X** and/or **Y** values.

1.   Select one or more objects or layers.
2.   Drag a corner or edge control handle on the selection's bounding box. The opposite handle is used as the anchor point.

2.   Do one of the following:

    *   For 10x the single unit of measurement: Press an arrow key with the **⇧** key (Mac) / **Shift** key (Windows) pressed.

As you nudge, dynamic measuring guides appear in the direction of travel.

You can change nudge distances via **Settings** (**Tools**).

1.   Select one or more objects.
2.   Press the **⏎** key (Mac) / **Return** key (Windows) to display a **Move / Duplicate** dialog.
3.   Enter new settings that will offset the object from its original position, with optional **Angle**, **Rotation** and **Scale** settings. **Distance** is the measurement between the original and moved object's centers.

The dialog also lets you duplicate by a set number of copies.

Check **Previous Settings** if you want to retain and use the last used transformation values entered into the dialog; uncheck to transform with new values.

The **Rotation** field will accept equations, so it's easy to set the correct rotation amount—simply enter the equation as, e.g. _360/6_ if you were setting up six positions, then set the **Number of copies** to be _≥5_ (as you already have one object).

You can use **Scale Override** on the **Transform** panel to control how certain attributes change when you resize objects, including stroke width, layer effect radii, shape corner radii, and text frame contents.

For consistent results when resizing grouped or nested objects, enable Scale Override and make sure you constrain the aspect ratio when resizing.

Each attribute on the Scale Override menu has a checkbox, which determines whether Scale Override applies to the attribute, and a scaling mode, which determines how scaling is handled.

If an attribute is unchecked, Scale Override is not applied to it. The attribute follows its own **Scale with object** setting on each object, even within groups or layer hierarchies.

Some attributes do not have an explicit **Scale with object** setting (for example, shape corner radii). When Scale Override is not applied, these attributes follow their default scaling behavior.

If an attribute is checked, Scale Override applies to it for the resized object and any nested layers, groups, or child objects:

*   **Scale with object**—forces the attribute to scale with the object, overriding individual object settings.
*   **Locked**—prevents the attribute from scaling, regardless of individual object settings.

Although Locked and an unchecked attribute can appear similar, Locked overrides all object settings, while an unchecked attribute does not.

1.   Select an object.
2.   On the **Transform** panel, enable **Scale Override**![Image 16](https://images.ctfassets.net/3p2fxa94bzao/4dlFUzBB90NXYBlxXzYLF2/a8f40c82b374772d3e256a94535daea2/scale_properties.png) .
3.   Resize via the object's handles with the **⇧** key (Mac) / **Shift** key (Windows) pressed.

1.   Select an object.
2.   On the **Transform** panel, click the **Scale Override**![Image 17](https://images.ctfassets.net/3p2fxa94bzao/4dlFUzBB90NXYBlxXzYLF2/a8f40c82b374772d3e256a94535daea2/scale_properties.png)  down arrow to check/uncheck the following settings: 
    *   **Line weights**—useful when working on vector objects with a stroke. For example, you can either force or prevent scaling while resizing with the setting set to **Scale with object** or **Locked**, respectively.
    *   **Shape corners**—to control the scaling of a shape's corners while resizing, you can either force (**Scale with object**) or prevent (**Locked** setting).
    *   **Layer effect radii**—to control the scaling of the radius of a layer effect added to an object.
    *   **Text frame contents**—to control the scaling of frame text while resizing; when set to **Locked** the container will scale while keeping text the same size. When set to **Scale with object** however, text will enlarge when resizing the container by its corner handles.

3.   Ensure **Scale Override**![Image 18](https://images.ctfassets.net/3p2fxa94bzao/4dlFUzBB90NXYBlxXzYLF2/a8f40c82b374772d3e256a94535daea2/scale_properties.png)  is enabled.
4.   Resize via the object's handles with the **⇧** key (Mac) / **Shift** key (Windows) pressed.
