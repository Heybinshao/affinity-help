# Ruler and column guides - Affinity Help Center

3.   Ruler and column guides

Guides are non-printing, non-exporting lines that 'float' over your page or artboard and assist with the positioning of items, especially when snapping is enabled. There are two types of guides to aid a variety of designs—ruler and column.

![Image 1: Guides](https://images.ctfassets.net/3p2fxa94bzao/4j4B30dzuUF0eprqWRCOHM/d1194195226cd0c77fc5b739f7ee5fa8/guides.jpg)

Text frame, footer text, and icons aligned to ruler guides.

Ruler guides allow you to add straight horizontal and vertical guide lines to help align content in your document. They can be created and positioned via a dialog or by dragging from a ruler.

![Image 2: Column guides](https://images.ctfassets.net/3p2fxa94bzao/7pFPZi4id73QGEDyEFpHie/462ffd3b9e1cbf05e6057a12dbf78af6/guides_column.jpg)

Text frames and graphics aligned to three-column guide.

Column guides allow you to specify a number of evenly spaced columns and rows and are perfect for designing page layouts. They can be created and positioned via a dialog only.

Do one of the following:

*   On the **View** menu, select **Margins and Guides**.
*   With the **Move Tool**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/3oigj5SSoPtnSw21egHEvD/b6ac975f2be7b3feb8e3e9867b378345/move_tool.svg)  selected, double-click an existing ruler guide in the document view. The guide will become selected.

Do one of the following:

*   With the **Move Tool** active, for 'by eye' placement, drag from either the horizontal or vertical [ruler](https://www.affinity.studio/help/design-aids-rulers/) which can be switched on via **View > Show > Rulers**.
*   On **Guides** settings, click **Add new horizontal guide**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/3acfBIGiUCk7Ogb2AeCimL/e54cca1f37a8b5e117b13c30fc3f5568/new_document_from_snapshot.svg)  or **Add new vertical guide**![Image 5](https://images.ctfassets.net/3p2fxa94bzao/3acfBIGiUCk7Ogb2AeCimL/e54cca1f37a8b5e117b13c30fc3f5568/new_document_from_snapshot.svg) .

Guides added to master pages will show on your publication pages as dashed guide lines, while guides placed on the publication page directly show as solid lines.

Guide positions will automatically update relative to a repositioned [spread origin](https://www.affinity.studio/help/design-aids-rulers/). For example, you can position the spread origin to the center of a spread and position guides relative to that zero point (e.g., vertical guides at -40mm and 40mm).

*   With the **Move Tool** active, drag a guide with the **⌘** key (Mac) / **Ctrl** key (Windows) pressed. 

Do one of the following:

*   Drag the guide with the **Move Tool** when you see the cursor change.
*   With any tool, ensure that **Show > Rulers** is switched on (via the **View** menu) and drag the guide marker directly from the horizontal or vertical ruler to reposition the guide.
*   On **Guides** settings, double-click on the value for the guide you want to edit and type a new position into the value field.

For both cloning and moving guides, a readout reports the distance from the spread origin (X or Y) and original guide position (Δ delta).

With **Snapping** enabled, you can snap back to the cloned or 'moving' guide's original position. This is useful for rechecking the drag distance (delta) before cloning/repositioning the guide.

Guide positions will automatically update relative to a repositioned [spread origin](https://www.affinity.studio/help/design-aids-rulers/).

*   On **Guides** settings, select the **Percent** option.

Percentages are calculated from the top-left of the document page.

*   Do one of the following: 
    *   Drag the spread origin from the ruler intersection to position it on the page. If snapping has been activated, the spread origin will be able to snap to objects on the page.
    *   On **Guides** settings, enter **X** and **Y** values into the **Spread Origin** section.

*   On the **View** menu, select **Show > Guides**. A check mark is displayed next to the menu item when the guides are visible.

If guides are hidden, they will automatically become viewable again if a new guide is added by dragging from a ruler.

Do one of the following:

*   With the **Move Tool** selected, drag the guide off the page.
*    With the **⌥** key (Mac) / **Alt** key (Windows) pressed, click on a guide. 
*   On **Guides** settings, click to select the value for the guide you want to delete and then click **Remove guide**![Image 6](https://images.ctfassets.net/3p2fxa94bzao/42nVPWLTjRveUCPBZpgCF8/f3e60815e9b7538a028d83d862e6e7d4/guides-delete.svg) .

*   On **Guides** settings, select **Remove All Guides**.

*   On the **View** menu, select **Lock Guides**.

The following modifier keys can be used:

*    The **⌘** key (Mac) / **Ctrl** key (Windows) clones a dragged ruler guide. 
*    The **⌥** key (Mac) / **Alt** key (Windows) deletes a clicked ruler guide. 
*    The **⇧** key (Mac) / **Shift** key (Windows) snaps a 'moving' guide to ruler units based on the spread origin. 
*    The **⇧****⌥** keys (Mac) / **Shift**+**Alt** keys (Windows) snap a 'moving' guide to the drag distance (delta) based on ruler units. 

Column guides allow you to specify a number of evenly spaced columns and rows and are perfect for designing web mockups and page layouts.

*   On **Guides** settings, set the following: 
    *   **Columns**—defines the number of vertical guides that will appear.
    *   **Rows**—defines the number of horizontal guides that will appear.
    *   **Gutter**—defines the size of the gutter.
    *   **Style**—select from **Filled** or **Outline**.

1.   On **Guides** settings, choose a **Color** for either.

*   On the **View** menu, select **Show > Column Guides**. A check mark is displayed next to the menu item when the guides are visible.

*   On **Guides** settings, reduce the number of **Columns** and **Rows** in the **Column Guides** section to _1_.
