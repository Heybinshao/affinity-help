# Multiple-page spreads - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/pages-multipage-spreads/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Page layout](https://www.affinity.studio/help/page-layout/)
3.   Multiple-page spreads

You can create spreads that contain more than two pages. This allows you to easily design trifold and gatefold spreads and documents such as accordion-fold brochures, for example.

![Image 1: A photo of various kinds of multi-page document](https://images.ctfassets.net/3p2fxa94bzao/5SIq1x0YzHEq7ynSd6IuCT/d31ecb475f08f9c48d1fa7e50371f8f0/multipage_examples.jpg)

Multi-page spreads can be created in two ways:

*   As a master page, from which you can create new spreads with the same page count, page dimensions, and spine location as the master.
*   By extending an existing spread with new publication pages, either by: 
    *   manually adding new pages at the required positions.
    *   moving existing pages by disabling **Reflow Pages** and then dragging and dropping them in the required positions.

If you need a particular multi-page spread setup as the starting point for multiple documents, create an appropriate document and save it as a template.

Using master pages to create multi-page spreads is advised for the “cleanest” results.

For any spread you create from a master, Affinity knows how many pages the spread should contain. “Ghost pages” are displayed if the spread contains fewer pages than expected.

![Image 2: Adding a four-page master with spine located at its center.](https://images.ctfassets.net/3p2fxa94bzao/4bSNyHB04DvaeBKhXGIkYC/57dd3fdc5e9d69012ebefa4f07a05c93/add_master_dialog_multipage.png)

Creating a four-page master with spine located at its center.

After creating a master, its spine location can't be edited.

If you're designing for the front and back of a multi-page spread with an off-center spine, create two masters with mirrored spine locations.

![Image 3](https://images.ctfassets.net/3p2fxa94bzao/3Cvdil0apezkiBtgXZEMg3/1ca221757bf214be056c7e5738e699a8/spine_locations_front_back_sides.png)

Spreads for the front and back of a folding document with an odd number of pages.

For quickness, existing spreads can be extended with new pages. You might prefer this over starting with a multi-page master if your document's pages will be only one multi-page spread. For example, when you're designing:

*   A book's dust jacket.
*   A magazine cover with a front cover flap.
*   A publication containing just one gatefold spread, such as a magazine.

![Image 4: Extending an existing spread of publication pages](https://images.ctfassets.net/3p2fxa94bzao/5iUlr5zHspqapbDsPBTtAL/d8246acee7eccd3d10416a775ce07c87/add_pages_extend.png)

Depending on the type of folding spread or document you're designing, you may need to edit the dimensions of certain pages.

In **Spread Properties**, you can select individual pages whose dimensions you wish to edit.

![Image 5: Selectively resizing some of a spread's pages](https://images.ctfassets.net/3p2fxa94bzao/2f6YcCF9bG7YTWRHIFoEFj/59f492ce4d413941ba99be57914c7540/spread_properties_selected_pages_resize.png)

If you export a press-ready PDF with **Include printers marks** and **Include crop marks** turned on, fold marks will be included too.

Before designing a multi-page spread's content, it is important to discuss your publication's requirements with your print provider.

For example, one panel of a trifold brochure needs to be narrower than the other two, but by how much depends on your chosen paper stock. Your print provider is best placed to provide the necessary advice.

1.   On the **Pages** panel, select **Add Master**![Image 6](https://images.ctfassets.net/3p2fxa94bzao/6bju7KVEsaDa5JdQ5r9Klm/3942375af19024a82a791a7f116fcec2/add_master_pages.svg) .
2.   On the dialog that appears: 
    1.   Set the master's **Page Count**.
    2.   Set the **Spine Location** by specifying a **Page** number and whether the spine should be located **Before** or **After** it.
    3.   Set other options as required.
    4.   Select **OK**.

On the **Pages** panel:

1.   Drag a master page from the **Master Pages** window.
2.   Hover to the left or right of an existing spread in the **Pages** window and drop.

A new spread with the same number of pages as the master is inserted, and the master is applied to all its pages.

1.   On the **Pages** panel, select **Add Pages**![Image 7](https://images.ctfassets.net/3p2fxa94bzao/40E05kD2SYXaUT8gELmImG/eab02af1b558ece3fa633a369815fb94/add_pages.svg) .
2.   On the dialog that appears: 
    1.   Set **Spread Wrapping** to **New Spread**.
    2.   Set the spread's **Number of Pages**.
    3.   Set the **Page** number at which to insert the spread and whether to insert before or after it.
    4.   Select **OK**.

1.   On the **Pages** panel, select **Add Pages**![Image 8](https://images.ctfassets.net/3p2fxa94bzao/40E05kD2SYXaUT8gELmImG/eab02af1b558ece3fa633a369815fb94/add_pages.svg) .
2.   On the dialog that appears:
    1.   Set **Spread wrapping** to **Extend Spread**.
    2.   Set the **Number of Pages** to insert.
    3.   Set the **Page** number at which to insert and whether to insert **Before** or **After** it.
    4.   Select **OK**.

On the **Pages** panel:

1.   On the panel's **Panel Preferences** menu ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg) , disable **Page Move Options > Reflow Pages**.
2.   Select the page(s) to use to extend an existing spread.
3.   Drag and drop the selection to the required position in the destination spread.
