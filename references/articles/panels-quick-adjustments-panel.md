# Quick Adjustments panel

Apply basic edits to your images using the Quick Adjustments panel.

[](https://www.affinity.studio/help/panels-quick-adjustments-panel/#where-to-find-it)

### Where to find it

For Mac/Windows: On the **Window** menu, select **General > Quick Adjustments**.

[](https://www.affinity.studio/help/panels-quick-adjustments-panel/#about-quick-adjustments-panel)

## About Quick Adjustments panel

Edits made using the Quick Adjustments panel can be applied to the currently selected object or image. These edits are non-destructive, meaning they can be altered at any time.

When you use a slider in the panel to make an adjustment, a corresponding adjustment or filter layer is automatically created in the Layers panel. Because each adjustment is separate, you can modify them individually later, and the changes will reflect immediately. If a slider is reset to its default position (value of 0), the corresponding adjustment layer is removed from the panel.

The Quick Adjustments panel is particularly useful for photographers who frequently re-develop RAW files. Previously, they would need to return to the Develop Studio to apply basic adjustments. Now, the same adjustments can be applied directly within the Quick Adjustments panel, significantly speeding up workflow.

[](https://www.affinity.studio/help/panels-quick-adjustments-panel/#options)

## Options

Desktop app

The following options are available on the panel:

*   **Exposure**—raises or lowers the overall exposure. It is used to correct overexposure / underexposure, or to obtain a high-key / low-key look.
*   **Brightness**—controls the lightness/darkness of the composition.
*   **Contrast**—controls the tonal range of the composition.
*   **Shadows**—controls how much shadow detail is revealed or hidden.
*   **Highlights**—controls how much highlight detail is revealed or hidden.
*   **Hue**—controls the color tint applied to the object or an image.
*   **Saturation**—increases or decreases color saturation.
*   **White Balance Temperature**—controls the overall temperature.
*   **White Balance Tint**—controls the overall color tint (tints either towards magenta or green).
*   **Sharpness**—controls the definition of edges and details in an image or object.
*   **Clarity**—sharpens the object or image by controlling local contrast at the edges.

 The following options are available on the **Panel Preferences** menu:

Desktop app

*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
