# Transparency - Affinity Help Center

3.   Transparency

Transparency can be applied in lots of ways.

![Image 1: Transparency examples](https://images.ctfassets.net/3p2fxa94bzao/4SmImwQdrX5nAFF7jYo0Gd/2ef22cb113a58b5bcadaf7366519da54/transparency.png)

(From left to right) Solid, Elliptical, Radial, Linear and Conical transparency types applied to a basic shape.

Here are the typical methods for its use.

*   As solid opacity, applied to strokes, fills and brush strokes.
*   As a transparency gradient, again applied to either stroke or fill. Using the same principles as gradient editing, you can introduce an independent gradient transparency path using the alpha channel in your design. You can introduce more than two alpha levels along the gradient path, adjust where each stop is positioned and/or control alpha transitions.
*   As layer opacity.
*   As a brush property.
*   As a layer effect property.

Opacity is the opposite of transparency. An object with 0% transparency is fully opaque (100% opacity), while 100% transparency means the object is invisible (0% opacity).

1.   Select an object.
2.   On the **Color** panel, choose a stroke or fill from the Stroke/Fill color selector.
3.   Drag the **Opacity** slider.

1.   Select the **Transparency Tool**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/4fbN9aRt00bOGUtfLPMili/0403f6742501bc1345c0be3a49e3a546/transparency_tool.svg) .
2.   Drag across your object to apply a transparency gradient.

As well as adding transparency gradients to objects, you can group those objects and then apply additional transparency to the group without affecting the individual objects' transparency.

1.   On the **Layers** panel, select a layer.
2.   Click the panel's **Opacity** down arrow and drag the slider to adjust.

1.   Do one of the following: 
    *   Select one or more objects or layers to edit opacity, including curves created from line tools or path brushes.
    *   Select any raster brush tool to set opacity in advance of painting.

2.    Press a numerical key, or two numerical keys in quick succession, to set the opacity. For example: 
    *   Press **4** for 40% opacity.
    *   Press **0** for 100% opacity.
    *   Press **4** and **5** for 45% opacity.
    *   Press **0** and **7** for 7% opacity.

1.   On the **Layers** panel, click **Layer Effects**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/4WJylimiHvA29KOENvEUQC/80598198347d79f39cf98c4f303dc8de/add_fx_layer.svg) .
2.   From the dialog, adjust the **Opacity** slider if available. Not all layer effects have the Opacity setting.
