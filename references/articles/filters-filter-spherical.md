## About the Spherical/Sphere filter

The filter remaps pixels so they follow a curved, spherical surface rather than a flat plane. Content near the centre of the image appears closer and more prominent, while areas toward the edges curve away, mimicking the way light behaves around a rounded object.

Depending on settings, the effect can:

*   Push content outward (convex distortion)
*   Pull content inward (concave distortion)
*   Create a subtle sense of depth rather than an obvious warp

This filter can be applied as a destructive or non-destructive live filter.

[](https://www.affinity.studio/help/filters-filter-spherical/#creative-and-practical-applications)

### Creative and Practical Applications

Some example scenarios for the use of this filter are:

*   **Simulating curved shapes**—Make flat artwork appear warped; useful for mockups involving bottles, lenses, domes, or spherical products.
*   **Lens and Distortion Effects**—Recreate wide-angle or fisheye-style distortion.
*   **Depth and Focus Control**—Draw attention toward the centre of an image, which enhances perceived dimensionality.
*   **Abstract and Surreal Effects**—Use stronger settings to create dreamlike or exaggerated distortions for artistic compositions.
*   **Highlight a Subject**—Use a gentle spherical bulge to emphasize a focal point without relying on contrast or color changes.

To use the destructive version of the filter, select it from the **Pixel > Filters > Distort** menu. The live version can be accessed from:

*   the **Layers** panel by clicking **Live Filters**  ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/2ALwfgZXKqtubPaMdMHvlC/d4901c280214d88174d57188a9c56e21/filters_studio.svg)       .
*   the **Pixel > New Live Filter Layer > Distort** menu.

### Settings

Desktop app

The following settings can be adjusted in the filter dialog:

*   **Intensity**—sets the type and value of the distortion. Negative values give a concave effect, positive values give a convex effect. Type directly in the text box or drag the slider to set the value.
*   **Radius**—controls the size of the effect. Type directly in the text box or drag the slider to set the value.
