3.   Synchronizing chapters

Affinity can sync swatches, text styles, table formats and master pages across a book's chapters. This ensures consistent presentation throughout the publication.

This feature is only available in Affinity for desktop.

Each of a book's chapters contains an independent copy of swatches, text styles, table formats and master pages.

Editing this data in one chapter puts the others out of sync. This may be part of your design. But often, you'll want to apply changes to other chapters&, e.g. when adjusting heading font sizes.

The **Books** panel lets you to do this easily. You run the process manually, but it's the quickest way to sync changes across chapters.

The first chapter you add becomes the book's **Style Source Chapter**. A key icon is shown next to it on the panel. This chapter holds your latest swatches, text styles, table formats and master pages.

You can choose a different Style Source Chapter at any time. This gives you flexibility to edit data and sync it to selected target chapters.

When the data in one or more chapters is outdated or incomplete, they can be synced with the Style Source Chapter.

Synchronization only goes one way—from the Style Source Chapter to target chapters. It doesn't change the Style Source Chapter.

Data found only in a target chapter is unchanged by syncing.

When you sync a target chapter, Affinity checks the following to work out what to copy or update:

*   If a document palette category, text style, table format or master page exists in the Style Source Chapter but not in the target chapter, it is copied from the Style Source Chapter to the target chapter.
*   If a named swatch, text style or table format exists in both chapters but has different settings, the target chapter's version is overwritten with the Style Source Chapter's version.
*   If both chapters have a master page with the same name, the Style Source Chapter's version is copied. This doesn't change how the page is used in the target chapter. In each chapter, the masters' names are unaltered, so consider renaming to help distinguish them.
*   If a document palette category exists in both chapters but the target chapter is missing some swatches, those swatches are copied to the target chapter. Swatches that exist only in the target chapter's category stay unchanged.

On the **Books** panel:

1.   Select a chapter.
2.   On the **Panel Preferences** menu ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg) , select **Set Style Source Chapter**.

On the **Books** panel:

1.   Select one or more chapters that aren't the Style Source Chapter.
2.    On the **Panel Preferences** menu ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg) , do one of the following: 
    *   If you know synchronization settings are as needed, select **Synchronize**.
    *    Otherwise, set which data types to sync: 
        1.   Select **Synchronize Settings**.
        2.   Enable/disable **Swatches**, **Text Styles**, **Table Formats** and **Master Pages** as required.
        3.   Select **Synchronize Now**.
        4.   Select **Close**.

Alternatively, after selecting chapters, select **Synchronize Chapters**
