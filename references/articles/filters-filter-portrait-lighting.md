2.   Portrait Lighting filter

The Portrait Lighting filter uses Machine Learning (ML) to simulate realistic light sources.

Portrait Lighting can be used to introduce additional light sources or selectively recolour an image. In monochromatic scenes, this allows emphasis to be placed on subjects using colour differentiation rather than tonal contrast.

The Portrait Lighting filter helps you quickly enhance portraits by simulating various professional lighting setups. With this feature, you can apply effects ranging from a simple, natural single-light scenario to sophisticated, multi-light studio arrangements. Whether your portraits were captured on-location or in a studio, this filter lets you creatively adjust and perfect lighting conditions directly within your images.

The **Depth Estimation** model must be downloaded prior to using the feature. The model is available in **Settings > Machine Learning Models** section.

Affinity's Machine Learning functionality is not generative and advocates human creativity.

The filter’s advanced controls allow you to realistically simulate different lighting characteristics, including intensity, direction, diffusion, ambiance, and lighting type. Digital artists and photographers can leverage these tools to either enhance existing lighting or completely replace costly physical setups. Additionally, the filter provides flexibility for creative experimentation, enabling you to adjust lighting conditions even after a photo shoot when recreating the original setup may not be practical.

You can also add or modify colored lighting effects, opening up possibilities for creative color grading directly within your image. This capability helps you replicate specific scenarios, such as neon-lit environments or scenes that traditionally require colored gels, without additional equipment or complexity.

This filter can be applied as a destructive filter. It can be found on the **Pixel > Filters > Lighting** menu.

The following settings can be adjusted:

*   **Diffuse**—controls the contribution of the base color and light.
*   **Specular**—controls the contribution of light reflected from a surface. The Specular color can be modified using the adjacent color swatch.
*   **Ambient**—controls the general, surrounding light present in an environment coming from the set sources via the adjacent color swatch.
*   **Light**—The counter displays the number of added light sources. You can _Add_, _Copy_, or _Remove_ a light source as needed by using the buttons located below it.
*   **Type**—sets the method for the light source; select either Point Light (default) or Spot Light.
*   **Color**—Sets the color for the added light source; you can utilize the color wheel, a HEX value, or the on-dialog color picker to specify the desired color.
*   **Radius**—controls the span of light from the selected light source.
*   **Distance**—based on the depth estimation of object contours, it regulates the range at which light can reach and reflect off a surface.
*   **Strength**—controls the intensity of the light source set.
*   **No Split View / Split View / Mirror**—select from these options to utilize quick previews before applying the filter to verify the output.
