3.   Fitting text to frames

Text may not perfectly fit its frame. If there's too much text, it overflows its frame. If there's too little text, the frame contains empty space.

Text can be made to fit its frame by:

*   Making the text frame larger.
*   Reducing the text's font size.
*   Creating an additional text frame and then linking the first frame to the new one.

When resizing a frame you can control whether:

*   Text remains at its set size and reflows through the frame.
*   Text scales as the frame is resized.
*   Empty space in the frame is removed, fitting the frame to its content.

Horizontal alignment is a paragraph attribute which can be altered via a text tool's context toolbar.

Vertical alignment of text within a frame is a frame attribute. Use it to align text centrally with adjacent graphics. It can be altered via the **Frame Text Tool**'s context toolbar.

*   With the text frame selected, resize its height and width independently by dragging any of its corner or edge handles.![Image 1: Reflowing text frame](https://images.ctfassets.net/3p2fxa94bzao/MD8x2vfRtgROtmlh2c2SR/a5dde34f5057a2a557985650437c06d1/frametext_reflow.png) 

The frame text will reflow within the resized frame. The font size will remain unchanged.

*   With the text frame selected, drag its scale handle, which extends from the bottom-right corner of the frame.![Image 2: Scaling text frame](https://images.ctfassets.net/3p2fxa94bzao/3ARi4yywNn9AsD9rQaMV3Y/249b37937daa1ca38e615f2729f0d7d4/frametext_scale.png) 

The frame text will resize in proportion to the frame's new dimensions.

After the text frame is resized, the scale handle will be filled with blue to indicate frame text scaling. This helps identify when you've scaled the text rather than reflowed it.

*   Double-click the blue-filled scale handle.

The text frame will retain its resized dimensions.

Do one of the following:

*   To remove space at the frame's top or bottom side, double-click the edge handle on the corresponding side. The frame's width is unchanged.
*   To remove space at the frame's left or right side, double-click the edge handle on the corresponding side. The frame's height is unchanged.

The opposite handle serves as the anchor point around which the frame is resized.

Do one of the following:

*   On the **Text** menu, hover over **Vertical Alignment**, then select **Top**, **Center**, **Bottom**, or **Justify**.
*   Use the **Frame Text Tool**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/1beIzVbPUpjWtvjB9f9uIQ/9643c257468e143cd018b12cb31d9a4a/frame_text_tool.svg)  to select the text frame. On the context toolbar, select a **Vertical text alignment**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/7xsUd82kEC85ekBtg62gGJ/4b2b1945b141f938fcb9bf3b85f0a4d9/top_align.svg)  option.
