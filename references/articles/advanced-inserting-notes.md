# Inserting notes

Footnotes, sidenotes and endnotes are inserted into documents using the Notes panel.

Upon inserting a note:

*   A reference is added at the insertion point.
*   Space for a note body is allocated at an appropriate position for the note's type and its **Note position** setting. See the "About notes" topic for details.
*   The insertion point is moved to the note body's position so you can enter text.

[](https://www.affinity.studio/help/advanced-inserting-notes/#note-order-and-serialization)

## Note order and serialization

Affinity automatically determines which reference is used to label a note, based on its position relative to other notes of the same type.

The correct serialization is maintained when new notes are inserted, or existing notes are moved or deleted.

For example, inserting an endnote between endnotes labeled 3 and 4 will result in the references of endnotes 4 and higher to be incremented by 1, and the new endnote's reference will be 4.

[](https://www.affinity.studio/help/advanced-inserting-notes/#how-to-insert-a-footnote--sidenote-or-endnote)

### How to insert a footnote, sidenote or endnote

Desktop app

1.   Position the insertion point where you want the note's reference to be.
2.    On the **Notes** panel: 
    1.   Select the required type: **Footnote**, **Sidenote** or **Endnote**.
    2.   Click **Insert Note**  ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/5UDv4vd3UuwclUaQA7oFjb/c4457d5fb770ac89006f17adb429f42e/note_insert.svg)       . The document view will refocus on the note body.

3.   Type the note body's text.

Inserting a note when a range of text is selected causes the note's reference to be positioned after the selection's last character.

[](https://www.affinity.studio/help/advanced-inserting-notes/#how-to-delete-a-footnote--sidenote-or-endnote)

### How to delete a footnote, sidenote or endnote

Desktop app

1.    Do one of the following: 
    *   Position the insertion point after the note's reference in story text.
    *   Select the note's reference.

2.    Press the **⌫** key (Mac) / **Backspace** key (Windows) to delete the reference and corresponding note body. 

Alternatively, for endnotes whose bodies are in a different text frame than their story text, delete the page(s) that contain the endnote bodies to delete them and their corresponding references.

[](https://www.affinity.studio/help/advanced-inserting-notes/#navigating-notes)

## Navigating notes

The Notes panel allows you to instantly refocus the document view from a note's reference to its corresponding body, or vice versa.

[](https://www.affinity.studio/help/advanced-inserting-notes/#how-to-move-from-a-note-s-reference-to-its-body)

### How to move from a note's reference to its body

Desktop app

1.   In story text, create an insertion point at the reference or make a text selection that includes the reference.
2.   On the **Notes** panel, click **Go to Body**  ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/5mgQeQhvViPsy8sKUFvtzR/2bd356bd9bff492cdbd55f9261c073b3/GoToNoteBody.svg)       .

If a text selection encompasses multiple references, **Go to Body** focuses the view on the first one's body.

[](https://www.affinity.studio/help/advanced-inserting-notes/#how-to-move-from-a-note-s-body-to-its-reference)

### How to move from a note's body to its reference

Desktop app

1.   Create an insertion point or make a text selection within the note body.
2.   On the **Notes** panel, click **Go to Reference**  ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/2LEdEWISNEgqTMz0SIyMg9/605121ec9c8aa014404f85de6dc0fc26/GoToNoteReference.svg)       .
