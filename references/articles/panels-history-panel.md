# History panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-history-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   History panel

The **History** panel lists changes made to your document. This lets you return to earlier points in time quickly and easily.

For Mac/Windows: On the **Window** menu, select **General > History**.

The History panel tracks changes and shows each state as a labeled entry in a list. The oldest state is listed topmost. New edits appear at the bottom.

You can save a document with its [history](https://www.affinity.studio/help/design-aids-undo/). This lets you return to earlier edits after reopening the document.

Selecting an earlier state and making a change creates a new timeline branch. It replaces the original edits after that point. You can cycle between branches.

If you don't save the document's history, the undo states are cleared when the document is closed.

The following options are available on the panel:

*   **Position**—points on the slider represent edits from creation or opening (left) to latest (right).
*   **States list**—shows the history of edits made to the document. The most recent edit is at the bottom of the list. On each entry: 
    *   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/2o691le3lFGxWujdpQyb2Q/eb79cf7909bb37f42921e6700b55c9a4/undo_brush_tool_on.svg) **Set Undo Brush Source**—enable the icon preceding an entry to set the chosen source from which the Undo Brush Tool can paint back to.
    *   **Description**—explains the edit made to the document. Click an entry to jump back/forward to that document state.
    *   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/2AVyEdE4mRO1vvFuCh7RKR/fc19d1c6903e5025cf1a691fe604ef57/cycle_future.svg) **Cycle future**—appears on states where history changed, storing edits in a timeline branch. Select the **Cycle future** icon next to a state to return to the branch. You can click this again to toggle between the different series of edits you made beyond this point.

![Image 3](https://images.ctfassets.net/3p2fxa94bzao/6UxpXBt5miovw347YaOPUz/6f8e3e8d9b379daa0bdc5a3ac6ff23e8/panel_preferences.svg)

 The following options are available on the **Panel Preferences** menu:

*   **Advanced**—shows history states with thumbnails and date/time.
*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
