3.   Soloing

Soloing temporarily hides all other objects or layers apart from the currently selected one. This allows you to focus on editing the selection without distraction.

Soloing an object is extremely useful for manipulating overlapping objects.

Solo mode lets you continue to edit the currently selected object or layer. If you create a new object or layer, the operation will automatically exit the selected object from solo mode.

*   On the **Layers** panel, hold down the **⌥** key (Mac) / **Alt** key (Windows) and click on the thumbnail of a layer entry.

To exit solo mode, **⌥**-click (Mac) / **Alt**-click (Windows) the layer's thumbnail again, click another layer not part of the isolated content, or click away from the selection in the document view.

**Zoom to selection** can be extremely useful before working in solo mode. Alternatively, double-click on the layer entry in the Layers panel to zoom to display the entire isolated selection.

When a group is soloed, you can perform the following operations without exiting the mode or affecting its focus:

*   Select and manipulate any of the group's items in context.
*   Create new objects within the group.

*   Do one of the following: 
    *   On the **Layers** panel: 
        1.   Expand the group by clicking its arrow.
        2.   Select one or more items inside the group.

    *   In the document view: 
        1.   Select the group.
        2.   Select an item in the group by double-clicking it.
        3.   (Optional) Hold the **⇧** key (Mac) / **Shift** key (Windows), then click other group items to add them to the selection. 

*   Do one of the following: 
    1.   Select an object in the group.
    2.   Select the group, then on the **Layer** menu, select **Arrange > Insert > Inside**.

*   Use a tool to create new objects.
