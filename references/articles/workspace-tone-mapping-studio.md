# Tone Map Studio

The Tone Mapping Studio lets you map an extensive 32-bit tonal range to output optimized for standard dynamic range displays.

[](https://www.affinity.studio/help/workspace-tone-mapping-studio/#where-to-find-it)

### Where to find it

**^(ctrl)**-click (Mac) / **right**-click (Windows) an image on the page and select **Tone Mapping Studio**.

The option will not be visible when the **View Tool**

![Image 3](https://images.ctfassets.net/3p2fxa94bzao/16xclkZTOokIeWj5LpEvxi/915d082ebd3ac857b57212d382357078/view_tool.svg)

 is active.

Although intended for 32-bit High Dynamic Range (HDR) imagery, you can use the Tone Mapping Studio to manipulate tones with non-HDR, 8-bit or 16-bit documents as well.

Switching to the Tone Mapping Studio gives you access to a set of dedicated tonal management tools capable of producing crisp, highly vivid results. The following examples illustrate some of the creative possibilities available:

[](https://www.affinity.studio/help/workspace-tone-mapping-studio/#hdr-merge)

## HDR Merge

For a set of photos captured with varied in-camera exposure bracketing settings (e.g., -1ev, 0ev, +1ev), you can use the Tone Mapping Studio tools after HDR merging to output a high dynamic range final image that can be displayed on a standard dynamic range monitor.

The tools available in the Tone Mapping Studio can extend and improve the range of tones and colors in what may initially appear as a flat or dull scene. A range of presets is available, or you can create your own after adjusting tone settings.

## Extreme and accurate contrast

Use the Tone Mapping Studio to control Tone Compression and enhance micro-contrast, revealing crisp detail across the image. This is particularly effective for urban and natural landscape compositions where fine detail is the main point of focus.

### How to open the Tone Mapping Studio

Desktop app

1.   On the **Layers**panel, select the image layer you want to work on.
2.   Do one of the following:
    *   **Ctrl**-click (Mac) / right-click (Windows) the image on the page, then select **Tone Map**from the pop-up menu.
    *   On the context toolbar, select **Tone Map**.

For best results, work with 32-bit HDR images. See [Merging to 32-bit HDR](https://www.affinity.studio/help/hdr-hdr-merging/) to learn how to create one from exposure-bracketed photos.
