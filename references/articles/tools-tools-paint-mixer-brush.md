The Paint Mixer Brush Tool

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/7D8ZHYCyXJOct97amT63S2/948c43847a87167d71aaabfad2d0dab1/paint_mixer_brush_tool.svg)

 is ideal for digitally simulating the mixing of wet paint applied to a canvas. As you drag across the page, the color currently on the brush blends with the color on the page, smudging and mixing them together.

The Paint Mixer Brush Tool is available by default in Pixel Studio, on the Paint Brush Tool's flyout.

It can be added to other Studios. See 'Customizing tools' for details.

The following options can be adjusted from the context toolbar:

*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/1DZ3BiVUNw49gMKmpfsxjY/cd1aedf8a4cd6086f5386c7898ba6846/slider_width.svg) **Size**—the brush (stroke) size in pixels. Type directly in the text box or drag the pop-up slider to set the value.
*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/6YT2BTrlyBpYlL2uIKpJtk/b378569b35626974ee7c0f69e47176c7/slider_flow.svg) **Flow**—how fast the brush effect is applied (1% is very slow, 100% is immediate). Type directly in the text box or drag the pop-up slider to set the value.
*   **More**—click to display the Brushes dialog to access advanced brush settings.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/2G6RXXZFvI6HUYZid36cJo/c0e6d0e34e179a4a70883fb3b37709c7/forcepressure.svg) **Force pressure**—click to control brush size with pressure if using a pressure-sensitive device. This overrides brush defaults.
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/hXJKoOWc1ddsm79bnmIB1/680cdbf78166330d64cf9a380735c6f1/slider_strength.svg) **Strength**—defines the extent to the smudging. Type directly in the text box or drag the pop-up slider to set the value.
*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/8brBaRlGyOXJ5Wr00WFIM/fcea48f24ffd0e39574f099c1c182d3e/loadbrush.svg) **Load Brush**—removes the mixed color currently on the brush and replaces it with the Foreground swatch color set on the Color panel.
*   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/1uM6eXKMk5TzFKJkImyNzt/774c5542cb5f222e62b638c5629d337e/cleanbrush.svg) **Clean Brush**—removes the mixed color currently on the brush, leaving a brush with no initial color applied to it.
*   ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/2pLcIkk8q4booVfBVcnbPe/b6e0b5c9b6712684aa306ea81deb44d3/autoloadbrush.svg) **Auto Load Brush**—when selected, each new stroke will automatically **Load Brush** as described above before pixels are applied to the page.
*   ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/548sIUKHEHosiYdx8yQ8jm/94402dc2342e9fabf87e376f3b5a2a3e/autocleanbrush.svg) **Auto Clean Brush**—when selected, each new stroke will automatically **Clean Brush** as described above before pixels are applied to the page.
*   **Mode**—selects a different color model for use with the brush. Choose from the following:
    *   **RYB**—a historical subtractive color model based on red, yellow and blue as primary colors.
    *   **RGB**—a standard additive color model based on red, green, and blue. Colors are mixed using light values, making this mode suitable for screen-based imagery and general digital painting.
    *   **CMYK**—a subtractive color model based on cyan, magenta, yellow, and black. This mode simulates ink-based color mixing and is useful when working toward print output.
    *   **Native**—uses the document’s current color space and blending behaviour. This ensures color mixing is consistent with the active document settings.
    *   **Pigment**—simulates real-world paint mixing, producing more natural and physically inspired color blends. Useful for painterly workflows where colors interact in a less predictable, more organic way.

*   ![Image 10](https://images.ctfassets.net/3p2fxa94bzao/48gU5vr3XwFWtBjwhAJWTo/28e1a43a4063087555940fbc383932d4/reset-global.svg) **Reset**—resets brush settings to their defaults.
*   ![Image 11](https://images.ctfassets.net/3p2fxa94bzao/7eblP76vdFdrp2uaZ3g2uC/4609ca56c51ddfe4b1aeb480e5ac5d9e/view.svg) **Symmetry settings**—offers various symmetry line control options.
    *   **Lines**—when set to greater than 0, repeats the brush stroke around a number of axes (defined by the symmetry value). The center axis point can be repositioned by click-dragging it.
    *   **Mirror**—with symmetry enabled, causes brush strokes to be mirrored along the X and Y axis.
    *   **Lock**—when checked, prevents the symmetry line from being moved.

The following settings are available on a pop-up dialog when accessed via right-clicking on the page:

*   **Rotation**—allows to set nozzle rotation.
*   **Blend mode**—sets the blend mode for the strokes.
*   **Size**—sets the stroke size in pixels. Drag the slider or type in a value in the field.
*   **Opacity**—sets the opacity level for the applied strokes. Drag the slider or type in a value in the field.
*   **Hardness**—sets how hard the edges of the brush are. The brush appears softer as the percentage decreases. Drag the slider or type in a value in the field.
*   **Flow**—controls how fast color is built up under your brush. Drag the slider or type in a value in the field.

This Brush Tool can be associated with a particular brush on the **Brushes** panel. For more information, see the [Modifying raster brushes](https://www.affinity.studio/help/painting-raster-modify/) topic.

*   The Paint Mixer Brush Tool has no keyboard shortcut by default, but one can be assigned via the app's settings.
*   When accessed via right-click on the page, holding the **⇧** key (Mac) / **Shift** key (Windows) restricts the on-dialog **Rotation**setting to 45°. Double-click the rotation point to reset it.
