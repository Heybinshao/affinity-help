The Column Marquee Tool

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/3riOFunV682pqAktNFFq2R/93f87d4db6cc10647a6f4f78f9d90074/column_marquee_tool.svg)

 allows you to specify a selection based on a vertical column shape.

The Column Marquee Tool is available by default in **Pixel Studio** on the Rectangular Marquee Tool's flyout.

It can be added to other Studios. See '[Customizing tools](https://www.affinity.studio/help/workspace-customizing-tools-panel/)' for details.

The Column Marquee Tool is applied by simply dragging on your image or pixel layer.

When dragging inside marquee to move a layer with previously made selections on a RAW or image layer, the layer will be automatically rasterized. You will be notified about this via the Assistant's pop-up message.

*   **Mode**—select from **New**, **Add**, **Subtract**, and **Intersect**.
*   **Width**—sets the width of the column.
*   **Feather**—reduces the sharpness of selection edges by partially selecting edge pixels.
*   **Antialias**—if this option is off, pixels at the edge of the selection are opaque. When selected (default), selection edges are smoothed by applying transparency to edge pixels.
*   **Refine**—click to display the [Refine Selection](https://www.affinity.studio/help/selections-selections-refine/) dialog to access advanced selection settings.

The four modes available from the context toolbar affect how your selection develops.

*   **New**—cancels all current selections and creates a new selection.
*   **Add**—adds areas to the current selection. If there is no selection in place, a new selection will be created.
*   **Subtract**—removes areas from the current selection.
*   **Intersect**—a new selection area is created from the overlap between the newly added selection area and the current selection.

*   To select the Column Marquee Tool, press the **M** key. This key cycles through related tools.
*   To create a range, press the **⌘** key (Mac) / **Ctrl** key (Windows) while dragging.
*   To add to the current selection, press the **⇧** key (Mac) / **Shift** key (Windows) while dragging.
*   To remove from the current selection, press the **⌥** key (Mac) / **Alt** key (Windows) while dragging.
*   To reposition the marquee, press the **⌘** key (Mac) / **Ctrl** key (Windows) while dragging inside the marquee.

Related behaviors can be adjusted from the app's settings:

*   **Tools > Select object when intersects with selection marquee**
