# How can I force Affinity to use my dedicated GPU? (Windows)

It's possible to specify which Graphics Card (GPU) is used within our app by going to **Edit**>**Settings**>**Performance** and selecting the relevant Graphics Card (GPU) from the Renderer dropdown menu.

However, sometimes, you may need to use Windows Graphic Performance Preference to force Affinity to use your Integrated Graphics Card (GPU) or Dedicated Integrated Graphics Card (GPU) if Affinity is crashing or failing to start because of out of date Graphics Card drivers.

[](https://www.affinity.studio/help/use-dedicated-gpu-windows/#you-can-use-window-s-graphic-performance-preference-in-graphics-settings-to-force-a-specific-app-to-use-your-integrated-or-dedicated-gpu.-)

## You can use Window's Graphic Performance Preference in Graphics Settings to force a specific app to use your Integrated or Dedicated GPU.

[](https://www.affinity.studio/help/use-dedicated-gpu-windows/#set-affinity-to-use-your-dedicated-or-integrated-gpu-in-windows-10)

### Set Affinity to use your dedicated or integrated GPU in Windows 10

Windows app

1.   Open the **Settings** app and go to **System**>**Display**
2.   Under the Multiple displays section, click**Graphics Settings**

[](https://www.affinity.studio/help/use-dedicated-gpu-windows/#heading-)

### **If you've downloaded from the EXE/MSI version:**

1.   Select **Desktop App** from the **Choose an app to set preference** dropdown menu
2.   **Browse** to the location of the **Affinity.exe** file
    1.   For example: C:\Program Files\Affinity\Affinity.exe

3.   Click **Add**

[](https://www.affinity.studio/help/use-dedicated-gpu-windows/#if-you-ve-downloaded-from-the-msix:)

### **If you've downloaded from the MSIX:**

1.   Select **Microsoft Store App** from the **Choose an app to set preference**dropdown menu
2.   Select **Affinity** from the **Select an app** dropdown menu and click **Add**

[](https://www.affinity.studio/help/use-dedicated-gpu-windows/#set-affinity-to-use-your-dedicated-or-integrated-gpu-in-windows-11)

### Set Affinity to use your dedicated or integrated GPU in Windows 11

Windows app

1.   Open the **Settings** app and go to **System**>**Display**
2.   Under the Related Settings section, click**Graphics**

[](https://www.affinity.studio/help/use-dedicated-gpu-windows/#if-you-ve-downloaded-from-the-exe-msi-version:)

### **If you've downloaded from the EXE/MSI version:**

1.   Select **Desktop App** from the **Add an app** dropdown menu
2.   Click**Browse** and navigate to the location of the **Affinity.exe** file
    1.   For example: C:\Program Files\Affinity\Affinity.exe

3.   Click **Add**

[](https://www.affinity.studio/help/use-dedicated-gpu-windows/#if-you-ve-downloaded-from-the-msix:)

### **If you've downloaded from the MSIX:**

1.   Select **Microsoft Store App** from the **Add an app** dropdown menu
2.   Click **Browse and**select **Affinity** from the list

[](https://www.affinity.studio/help/use-dedicated-gpu-windows/#next-step)

### **Next Step**

[](https://www.affinity.studio/help/use-dedicated-gpu-windows/#choose-gpu-preference)

### Choose GPU Preference

Windows app

1.   Now select **Affinity** and click **Options**
2.   Your Integrated GPU (Power Saving) and Dedicated GPU (High Performance) will be listed
3.   Select **High Performance** and click **Save**

When you next run Affinity it will use the GPU you've just set within Windows Graphics Settings.
