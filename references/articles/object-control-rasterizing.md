# Rasterizing - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/object-control-rasterizing/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Rasterizing

Shape, Curve, Text, and Image layers can be manually rasterized to create pixel layers.

Rasterization has various uses:

*   For when the appearance of complex vector gradients or effects needs to be honored, particularly for print artwork.
*   To convert a placed image layer to a pixel layer (for pixel manipulation).

By default, many brush tools rasterize image layers before painting.

After rasterization, objects can't be edited afterwards. Ensure shapes, curves and text are completely edited to your satisfaction beforehand.

Do one of the following:

*   On the **Pixel** menu, select **Rasterize > Rasterize**.
*   On the **Layers** panel, **^(ctrl)**-click (Mac) / **right**-click (Windows) a layer and select **Rasterize**.

Multiple objects, on adjacent or non-adjacent layers, can be rasterized simultaneously. Each selected layer is converted to a discrete pixel layer, i.e. the layers are not flattened.

In Pixel Studio

, when applying filters or retouch brushes to objects or layers, automatic rasterization occurs. This means the layers can't be edited as vectors afterwards. Ensure shapes, lines and text are completely edited to your satisfaction beforehand.

When rasterizing a layer that has layer effects applied to it, a dialog offers an option to **Preserve layer FX**. Clear the checkbox to include the effects in the rasterization process along with the layer's shape, curve or text content. Leave it checked to rasterize only the layer's content and still be able to edit the effects afterwards.

Do one of the following:

*   On the **Pixel** menu, select **Rasterize > Rasterize & Trim**.
*   On the **Layers** panel, **^(ctrl)**-click (Mac) / **right**-click (Windows) a layer and select **Rasterize & Trim**. 

Partly off-canvas objects will be trimmed with this operation; if completely off canvas, the object will be removed.

Do one of the following:

*   On the **Pixel** menu, select **Rasterize > Rasterize & Mask**.
*   On the **Layers** panel, **^(ctrl)**-click (Mac) / **right**-click (Windows) a layer and select **Rasterize & Mask**. 

*   Select the image within the document view or on the **Layers** panel.
*   On the **Layer** menu, select **Convert > To Image Resource** or **Convert > Convert > To Picture Frame** as needed.
