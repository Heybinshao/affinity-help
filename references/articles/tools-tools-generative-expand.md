1.   In the Canva AI Studio, select the **Generative Expand Tool**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/1slLxgI4QGySI2y9sLltXY/05e2a48c495356c2192852bcaef4621a/generative_expand.svg) .
2.   Drag the composition handles outward on the canvas to define the area you want to fill.
3.   On the context toolbar, set the **Image count**to choose how many variations are generated (up to eight).
4.   Click **Expand**on the context toolbar to generate the new content.
5.   Review the generated images. To start again with different handle positions, click **Reset**; to exit without generating, click **Cancel**.
6.   Refine the result from the **Layers**panel — the generated content is added as a new image layer above your original.

. To use it, you need to be subscribed to the Canva Pro plan. To learn more about the premium features usage visit the [Canva AI & Affinity ML](https://www.affinity.studio/help/canva-ai-canva-ai-affinity-ml/) topic.

The Generative Expand Tool does not have a default keyboard shortcut, but you can assign one manually if desired. See '[Customizing keyboard shortcuts](https://www.affinity.studio/help/workspace-customizing-shortcuts/)' for details.

The Generative Expand Tool extends your canvas beyond its current edges and fills the new area with AI-generated content that matches the surrounding image. The generated pixels are added as a new image layer with a corresponding mask above your composition, so your original image layers stay untouched and you can refine, reposition, or remove the expansion at any time.

The Generative Expand Tool is available when you have a pixel or image layer selected in the **Layers** panel. It can’t be used on vector layers, text layers, shape layers, or on images placed on artboards. If the tool appears unavailable, check that the active layer is a pixel or image layer and that you’re working in the Canva AI Studio.

The following options can be adjusted on the context toolbar:

*   **Expand**—starts the composition expansion process.
*   **Cancel**—exits and switches the tool to the View Tool.
*   **Image count**—determines how many images are rendered on output with the max number of eight.
*   **Reset**—resets the composition handles back to their default position.

*   To cycle composition overlay, press the **O** key.
*   To cycle the Fibonacci overlay orientation, press the **⇧O** key (Mac) / **Shift+O** key (Windows).
