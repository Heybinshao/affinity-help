3.   Modifying path brush strokes

A path brush stroke applied to the page remains fully editable and can be modified, while the stroke is selected.

For more advanced brush settings you can double-click a brush entry in the Path Brushes panel, with the option to save your brush stroke setting as a new brush preset.

This feature is only available in Affinity for desktop.

The following settings are available in the Brush dialog's **Stroke** section:

*   **Stroke Width**—sets the size of the stroke.
*   **Size Variance**—sets the amount of brush size deviation allowed as a stroke is painted.
*   **Opacity Variance**—sets the amount of transparency deviation allowed as a stroke is painted.
*   **Controller**—the pop-up menu varies the brush size and opacity according to a particular input: 
    *   For Mac: 'Pressure' for pen tablets and Force Touch-enabled devices, and 'Velocity' or 'Velocity Inversed' for mice/Trackpads. The last two velocity options simulate pressure relative to the speed of mouse movement.
    *   For Win: 'Pressure' for pen tablets, and 'Velocity' or 'Velocity Inversed' for mice.

*   Click the adjacent Ramp profile icon to select a standard profile from lower thumbnails or create your own using the ramp chart. Move circular nodes to reshape the ramp, add nodes to the ramp by clicking on the line, or select a node to delete a node with the **⌫** key (Mac) / **Backspace** key (Windows), simplifying the ramp. Check **Linear** for straight lines between all nodes; If unchecked (non-linear), nodes are connected using smooth curves.
*   The profile pop-up menu sets the behavior of the controller.
*   **Body**—determines the method with which the central section is drawn along the length of the stroke.
*   **Corners**—determines the method used to control how corners are drawn within the stroke.
*   **Head Offset**—sets the transition point at which the head section becomes the body section.
*   **Tail Offset**—sets the transition point at which the body section becomes the tail section.
*   Drag the red dotted lines on the lower preview to set the length of the brush body. As the lines are repositioned the Head and Tail Offset values will update.
*   **Reset**—returns all stroke settings to those of the saved brush preset.
*   **Save As**—saves the current stroke settings as a preset brush.
*   **Close**—exits the dialog and applies stroke settings to the selected object.

1.   In the Vector Studio , select the Path Brush Tool.
2.   **⌘**-click (Mac) / **Ctrl**-click (Windows) on the brush stroke, keeping the key held.
3.   On the context toolbar, click **More**.
4.   Adjust the settings in the dialog.
5.   Click **Close**.

You can paint on the page while the Brush dialog is open. The stroke will adopt the current settings in the dialog. This allows you to adjust the full brush settings as you paint for increased efficiency.

*   **^(ctrl)**-click (Mac) / **right**-click (Windows) the brush in the panel and choose **Reset Brush** from the pop-up menu.
