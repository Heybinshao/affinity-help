# Resource Manager panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-resource-manager-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Resource Manager panel

The Resource Manager provides an overview of the images and text files used in your Affinity document.

For Mac/Windows: On the **Document** menu, select **Resource Manager**. On desktop, Resource Manager is a regular window; it cannot be docked like a panel, but can be kept open while you continue to work in the app.

Use the Resource Manager to track media use in your document, view metadata, and manually update linked resources that have changed.

The following options are available on the panel:

*   **Resource Type**—sets the kind of resources that are listed on the window: _Images_ or _Text_.
*   **Resources list**—shows all placed resources of the selected type in your document. Each entry shows where a resource is used, along with its placement policy, status, and more. Select a resource to preview its content and metadata (e.g. original size, color space, and ICC profile) to the right.Instances of any resource that's used multiple times are grouped. To the left of a group, use **Expand**

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/1Ddu0OMS1hpMeFSbSvSbT5/c2afd02a205615b19cbaa4ede913dacc/singlearrowright.svg)  or **Collapse**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/1VeFStSayF4HG8qsmcixTm/3c3a700bb1d5c1152ffa7c06d45fd662/singlearrowdown.svg)  to show or hide the individual instances. 
*   **Locate**—jumps to the page on which the selected resource is placed in your document.
*   **Update** / **Refresh**—refreshes the selected linked/remote resource to the latest version.
*   **Relink**—appears in the place of **Update** for missing linked resources, allowing you to relink them. On the dialog that appears, you can: 
    *   choose a missing file to relink it.
    *   choose a folder to relink multiple files at once.

*   **Replace**—lets you relocate or replace the selected resource's file when it's missing. Select a replacement file using the dialog that appears.
*   **Make Linked** / **Embed**—lets you switch the selected resource between linked/remote and embedded. When making linked, Affinity tries to link to the file in its original location. If it's not there, use the dialog that appears to select a save location for the data.
*   **Collect**—allows you to gather selected linked resources into one folder. Select that folder using the dialog that appears.
*   **Show in Finder** (Mac) / **Show in Explorer** (Windows)—reveals the source file for the selected linked resource, if it is not missing.
*   **Open Stock URL**—opens the selected remote resource's address in your default web browser.
*   **Preview**—shows the resource's content to help confirm you've selected the correct entry.
*   **Metadata**—shows resource details including its original DPI, color space, and ICC profile.
