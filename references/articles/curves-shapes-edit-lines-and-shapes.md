3.   Edit lines, curves and shapes

Lines, curves and shapes are easily edited once created with the Pen Tool, Node Tool or shape tools.

Two editing methods are possible:

*   Using the Node Tool ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/2Tyrn620F9iCYiF39DxVOc/9de008f998af69eafee088eb5a3c5210/node_tool.svg) .
*   As you draw your curve or shape with the Pen Tool while pressing: 
    *   The **⌘** key (Mac).
    *   The **Ctrl** key (Windows).

Use the former for more prolonged editing operations, the latter for fine tuning and curve adjustment as you draw.

![Image 2: Line example](https://images.ctfassets.net/3p2fxa94bzao/2UdezHSgxc1AXYrxUjGf9g/1942572f23ccf40bab2b92aa8a8f1237/editline_example.png)

*   With the **Pen Tool** active, press the **⌘** key (Mac) / **Ctrl** key (Windows) to adjust nodes, control handles and segments when fine tuning of your curve is needed.

1.   Select the **Node Tool**![Image 9](https://images.ctfassets.net/3p2fxa94bzao/2Tyrn620F9iCYiF39DxVOc/9de008f998af69eafee088eb5a3c5210/node_tool.svg) .
2.   Select the line, curve or shape.
3.   Do one of the following to change the curvature of segments: 
    *   Click a node and drag to reposition.
    *   Drag a control handle to accentuate or lessen curvature. ![Image 10: Drag control handles](https://images.ctfassets.net/3p2fxa94bzao/4H0XqwumQQrrSGdoiQppJQ/3bd1207c382f72a636fae11c8b243252/editlines_directionHandles.png) 
    *   Click anywhere on a line segment and drag. ![Image 11: Drag on curve](https://images.ctfassets.net/3p2fxa94bzao/6ly70P97n4BdSlg7NkZKrm/49069e5dad1ebde46d9cc6f42e8dde1d/editlines_onCurve.png) 
    *   **⌥**-click (Mac) / **Alt**-click (Windows) a segment to straighten it. 
    *   **⌃(ctrl)**-click (Mac) / **Ctrl**-click (Windows) a segment to delete it, creating two separate curves within one curve object. 

To speed up your drawing workflow, with the Move Tool active, double-tapping on a curve will enable the Node Tool, which can be then used to edit that curve; double-tap with the selection area (but not on the curve) again to reactivate the Move Tool. The same tip applies to shapes.

When using the Node Tool, the following modifier keys can be used to speed up the workflow:

*   The **⇧** key (Mac) / **Shift** key (Windows) constrains node movement and control handle positioning to 45° intervals. It also extends a dragged control handle while keeping the control handle directions locked. 
*   The **⌥** key (Mac) / **Alt** key (Windows) changes the node type, on clicking, to a sharp node to create a cusp in the line. 
*   For Mac: The **⌃(ctrl)** key keeps both control handles locked in position while moving a node. 
*   For Windows: Pressing left- and right-mouse buttons keeps both control handles locked in position while moving the node.

When using the Move Tool, Pen Tool or Node Tool, the following keys can be used to speed up the workflow:

*   To decrease or increase stroke width by percentage, use the [ or ] keys, respectively. For smaller absolute increments instead, use an additional **⇧** key (Mac) / **Shift** key (Windows) modifier. 

1.   Press the **⌘** key (Mac) / **Ctrl** key (Windows) to edit curve or select the curve with the **Node Tool**![Image 12](https://images.ctfassets.net/3p2fxa94bzao/2Tyrn620F9iCYiF39DxVOc/9de008f998af69eafee088eb5a3c5210/node_tool.svg) .
2.   Place the cursor over the final node on the path that you want to continue.
3.   Click once to select the node.
4.   Release the **⌘** key (Mac) / **Ctrl** key (Windows)—or select **Pen Tool**—and click/drag to place new nodes as needed. This can be placed over an existing node on the same curve, creating coincidental overlapping nodes.

Do one of the following:

*   With the **Node Tool** active, select the node(s) and select **Sharp**![Image 13](https://images.ctfassets.net/3p2fxa94bzao/1u8ioE0kk2O3hClti5GNFQ/cac15e5ba603ae52943e4d8e4bf2e2d7/convert_sharp.svg) , **Smooth**![Image 14](https://images.ctfassets.net/3p2fxa94bzao/1GgxCLnnzKXjbBMjq00c4O/c37f54e0eda9d66eaced34ad881c1a37/convert_smooth.svg) , or **Smart**![Image 15](https://images.ctfassets.net/3p2fxa94bzao/5GBJ3hAEklQ9OB7JegR1Mx/ffa029d660ca57f2ba49581c12b758c9/convert_smart.svg)  from the context toolbar. 
*   **^(ctrl)**-click (Mac) / **right**-click (Windows) on the selected node and select from the same options.
*   Hold the **⌥** key (Mac) / **Alt** key (Windows) and click on the node to convert it to a **Sharp** node.

*   With the curve selected, click at the point where you want the node to be added.

Do one of the following:

*   **^(ctrl)**-click (Mac) / **right**-click (Windows) the node before the adjoining curve segment you want to add a midpoint node to and select **Split Curve After Node**![Image 16](https://images.ctfassets.net/3p2fxa94bzao/SWhhcyi7P9xZaJXlyOFDE/56a0c275bb369631b3c5564fb9f24c83/split_view.svg) .
*   Select a node, then click the same option on the context toolbar.

Which segment is split depends on the current curve orientation (indicated by a red-line indicator). Use **Reverse Curve**

![Image 17](https://images.ctfassets.net/3p2fxa94bzao/4aEenWCp3fgkYVwRQQF18p/5aec5f6e69b82891e16fd078aec2ddf8/action_reverse_curves.svg)

 to change this curve orientation or reselect an adjacent node to split from.

Do one of the following:

*   To _retain the curve's original geometry_ after deletion: with the **Node Tool** active, select the node and press the **⌫** key (Mac) / **Backspace** key (Windows), or **^(ctrl)**-click (Mac) / **right**-click (Windows) the node and choose **Delete Node** from the pop-up menu. This doesn't affect the remaining curve's nodes and control handle positions.
*   For a _'best-fitting' reshaped curve_ after deletion: with the **Node Tool** active, **^(ctrl)**-click (Mac) / **right**-click (Windows) the node and choose **Fit To Curve Delete Node** from the pop-up menu. This is useful if you want to retain the smoothness of a stabilized curve, perhaps drawn with the **Pencil Tool**.

Do one of the following:

*   With the **Node Tool** active, **^(ctrl)**-click (Mac) / **right**-click (Windows) the end node and select **Close Curve**![Image 18](https://images.ctfassets.net/3p2fxa94bzao/2Gq5XAQINSYoHvUFwH5ZP5/b8478e2d20a8db7b1c48fba54d272f78/action_close_curve.svg) .
*   With the **Node Tool** active, select the curve and click **Close Curve**![Image 19](https://images.ctfassets.net/3p2fxa94bzao/2Gq5XAQINSYoHvUFwH5ZP5/b8478e2d20a8db7b1c48fba54d272f78/action_close_curve.svg)  on the context toolbar.
*   With the **Node Tool** active, drag the end node and drop on top of start node when the pointer changes.
*   With the **Pen Tool** active, hold down the **⌘** key (Mac) / **Ctrl** key (Windows), **^(ctrl)**-click (Mac) / **right**-click (Windows) the end node and select **Close Curve**. 

Do one of the following:

*   With the **Node Tool** active, **^(ctrl)**-click (Mac) / **right**-click (Windows) the node at the point at which you want the curve to break and select **Break Curve**![Image 20](https://images.ctfassets.net/3p2fxa94bzao/3iEJTLrCxMb4ZR30sc8BZZ/e167fce74351f40bd361b8f51b32a074/action_break_curve.svg) .
*   With the **Node Tool** active, select a curve and one of its nodes, then click **Break Curve**![Image 21](https://images.ctfassets.net/3p2fxa94bzao/3iEJTLrCxMb4ZR30sc8BZZ/e167fce74351f40bd361b8f51b32a074/action_break_curve.svg)  on the context toolbar.
*   With the **Pen Tool** active, hold down the **⌘** key (Mac) / **Ctrl** key (Windows), then **^(ctrl)**-click (Mac) / **right**-click (Windows) the node and select **Break Curve**. 

*   Select **Smooth Curve**![Image 22](https://images.ctfassets.net/3p2fxa94bzao/5NIosVN2amJnLIl9SsALzs/fa6749b753448d285834853da54cc9ff/action_smooth_curve.svg)  on the context toolbar. This modifies a line or shape, by adding and removing nodes automatically around inflection points.

1.   With the **Node Tool** active (hold down the **⌘** key (Mac) / **Ctrl** key (Windows) if using the **Pen Tool**), hold down the **⇧** key (Mac) / **Shift** key (Windows) and select both curves. 
2.   Click **Join Curves**![Image 23](https://images.ctfassets.net/3p2fxa94bzao/6RJ3G6uqVxyuf2swmbJMaY/dd5e0d6f023a5f1e4e7e8e6c964c39a5/action_join_curves.svg)  on the context toolbar or **Vector** menu.

Do one of the following:

*   With the **Node Tool** active, **^(ctrl)**-click (Mac) / **right**-click (Windows) any node and select **Reverse Curve**![Image 24](https://images.ctfassets.net/3p2fxa94bzao/4aEenWCp3fgkYVwRQQF18p/5aec5f6e69b82891e16fd078aec2ddf8/action_reverse_curves.svg) .
*   With the **Node Tool** active, select any node and then **Reverse Curve**![Image 25](https://images.ctfassets.net/3p2fxa94bzao/4aEenWCp3fgkYVwRQQF18p/5aec5f6e69b82891e16fd078aec2ddf8/action_reverse_curves.svg)  on the context toolbar.
*   With the **Pen Tool** active, hold down the **⌘** key (Mac) / **Ctrl** key (Windows), then **^(ctrl)**-click (Mac) / **right**-click (Windows) the node and select **Reverse Curve**. 

The start node will be toggled from clockwise to counter-clockwise. With a closed curve selected, this direction can be viewed when **Show Orientation**

![Image 26](https://images.ctfassets.net/3p2fxa94bzao/5Gtd0Q6NyDJis4bL5REgP9/ef9966bad46dee0847a3ae15e114c5c4/show_orientation.svg)

 on the context toolbar is toggled on (default). With an open curve selected, the direction of the curve is swapped, ready for further drawing from the opposite end of the curve.

*   Drag a node from one curve directly over another on a second selected curve until the cursor changes to two overlapping squares, then wait until the node's handles adjust to their new positions.

*   On the **Vector** menu, select **Fill Holes**.

*   On the **Vector** menu, select **Remove Inner Curves**. **Vector > Fill Mode > Winding (Non-Zero)** must be enabled.

This operates on a per layer basis.
