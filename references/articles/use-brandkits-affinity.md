# Use your Brand Kit in Affinity - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/use-brandkits-affinity/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Canva integrations](https://www.affinity.studio/help/canva-integrations/)
3.   Use your Brand Kit in Affinity

You can access your Brand Kit directly from within the Affinity by Canva app and use your brand fonts, colors, logos, brand voice and image assets while designing. New pro image assets designed in Affinity can be added to your Brand Kit too.

You need an internet connection and a paid Canva subscription to use Brand Kits in Affinity.

![Image 1: Affinity’s Canva Brand Kit panel exposing Canva Brand Kit assets.](https://images.ctfassets.net/3p2fxa94bzao/6KAkK2XMl5xqjqfHSCsKSv/b191ce0c5b3d2e31d1c0bb4d36c6e5db/Screenshot_2026-04-10_at_7.28.28%C3%A2__PM.png)

Affinity’s Canva Brand Kit panel exposing Canva Brand Kit assets.

*   On the **Window** menu, select **Canva**, then select **Canva Brand Kits**.

*   On the **Status bar** at the bottom of the workspace, click **Toggle Brand Kits Panel**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/dmmDOubdrqfpjW2pge9sL/4b089c60d521e13fc72e3e66e18fb90e/icon-brand-kit-solid.svg) .

You can dock, move, resize the panel. It can be displayed in any default or custom Studio.

You can access all Brand Kit elements directly in the panel or from various locations in the Affinity user interface. Unsupported elements created in Canva will not show in the panel.

**Access elements from your Brand Kit**

Brand Kits, synced from Canva, may contain:

*   Fonts
*   Text styles (Title, Subtitle, Body) 
*   Color palettes
*   Image assets like logos, photos and graphics

**Accessing elements while you work**

*   **Fonts**: With any text tool selected, access from the Font Family pop-up menu on the context toolbar.
*   **Text styles:** With any text tool selected, access from the Paragraph pop-up menu on the context toolbar.
*   **Colors:** With the Swatches panel displayed, click its Palettes pop-up menu.

*   On the **Canva Brand Kits** panel, browse the Brand Kit pop-up menu, then select your chosen Brand Kit.

If you have edit permissions for the Brand Kit in Canva you can add image assets.

1.   Select the asset, i.e. a vector object(s) or raster layer content, in your Affinity document.
2.   Drag and drop it onto an Assets category in the **Canva Brand Kits** panel.
3.   On the **Export** dialog, choose a file format (typically PNG, but this can be JPG, SVG, and WebP).
4.   Select **Export**.

💡 Only the currently loaded Canva Brand Kit in the panel can be exported to. Swap to another Brand Kit if needed.

If you don’t have edit permissions for the Brand Kit in Canva, you’ll see a _You can't edit Brand Kits_ message.

1.   Select the asset.
2.   From the top right of your workspace, select the **Export** drop-down arrow.
3.   Choose a file format and file properties if needed.
4.   Change the Destination pop-up menu from _Ask for Location_ to _To Canva_.
5.   On the newly revealed pop-up menu, choose an **Assets** category from the current Brand Kit.

The advantage of using Quick Export is that your file format settings are remembered at each upload.

You can only create and edit Brand Kits in Canva. Any changes you make in Canva sync automatically to Affinity. You'll only see the edit option if you have edit permissions for the Brand Kit in Canva.

1.   On the **Canva Brand Kits** panel, select **Edit Brand Kit in Canva**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/5iOChGTdKjQVqHOcdsqZA0/6fefc7a0413254f40e53bc188bbe994c/viewBrandKitOnCanva.svg) .
2.   Make your changes in Canva.
3.   Return to Affinity to see your updated assets.

Brand Kits are a premium feature. They're available to Canva Pro, Canva Teams, Canva Business, Canva Enterprise, Canva Education, and Canva Nonprofits users.

1.   In Affinity, open the **Canva Brand Kits** panel.
2.   Select **Upgrade**.
3.   Complete the upgrade in your browser.
4.   Return to Affinity to access Brand Kits.

**If you’re on a free plan, you can upgrade to a premium plan directly within Affinity**[**here**](https://www.affinity.studio/help/upgrade-to-canva-pro-or-business/)**.**

If Brand Kit isn't loading, check your internet connection and restart Affinity. Brand Kits require an active internet connection to work.

If you can't add assets to Brand Kit, confirm you're a Team Admin or Brand Designer. Team members can't add assets to Brand Kits.

Each asset category has a 2,000-asset limit. If you've reached the asset limit, remove unused assets in Canva to free up space.

**Where is my Brand Kit?**All Brand Kits on Canva are listed in the Brand Kit list on the Canva Brand Kits panel. Just select the Brand Kit you want to load it. **Where can I create or edit Brand Kits?**You can only create and edit Brand Kits in Canva. Changes you make in Canva sync to Affinity.**What Brand Kit elements work in Affinity?**You can access logos, fonts, text styles, colors, and image assets. The following elements are not supported in Affinity:

*   Charts
*   Linked folders
*   Category guidelines
*   Guidelines doc
*   Components
*   Brand Templates added to the Brand Kit**Why are some of my Brand Kit fonts not displaying correctly?**A small number of fonts, including the Morisawa font family, aren't supported in Affinity because of font licensing rules.
