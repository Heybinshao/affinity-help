# Selecting by attribute - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/object-control-select-by-attribute/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Selecting by attribute

Affinity lets you select objects or layers that match the same attributes of a targeted object or layer.

These selection methods are complementary to traditional selection methods.

These powerful selection methods allow you to quickly make bulk changes to your design all at once, e.g. to convert objects that share a non-global color to use a global one.

The Select Same command selects all objects in your document that match an attribute on your currently selected object.

Select Same matches objects with the same Fill Color, Stroke Color, Fill & Stroke Color, Stroke Weight, Transparency, Blend Mode, Shape, Name, or Tag Color.

On desktop apps, Select Same can also match objects whose Width, Height, or Stroke Weight is less than, less than or equal, greater than, or greater than or equal to that of the currently selected object.

Selecting the same fill color across shapes.

The Select Layer command selects all objects of a matching type within your document. For example, you can select:

*   General: all groups, art text, frame text, path text, pixel layers, unfilled objects, transparent objects, and any objects according to their fill, stroke or opacity
*   For graphic design: artboards, symbols
*   For page layout: picture frames, tables

Selecting shapes with strokes applied.

Both commands also work well in conjunction with each other. For example, you could select multi-colored shapes according to their fill color (using Select Same), group them each in turn, and then select all of the groups (using Select Layer), for example, effectively organizing the layers in your document.

**Edit within current container** (on the **Layers** panel) determines the scope of Select Same and Select Layer.

When enabled, the commands select matching objects across all artboards or spreads in your document. When disabled, they select matching objects only on the current artboard or spread.

*   With a layer selected on the **Layers** panel, **^(ctrl)**-click (Mac) / **right**-click (Windows) it and choose **Select Same Name** or **Select Same Tag Color** from the pop-up menu.

*   With an object selected, from the **Layer** menu, choose **Select > Same** and select an attribute from the menu.

*   On the **Layer** menu, choose **Select > Layer** and select an layer type from the menu.

To specify whether Select Layer or Select Same will include or exclude hidden objects in its resultant selections, select or deselect Select Hidden Objects from the corresponding command's submenu.

When using the Select Layer command, the following modifier keys can be used to aid object selection:

*   The **⇧** key (Mac) / **Shift** key (Windows) adds matching objects to the current selection.
*   The **⇧⌥** keys (Mac) / **Shift**+**Alt** keys (Windows) combination selects matching objects only from within the current selection, i.e. non-matching objects are removed from the current selection.
*   The **⌥** key (Mac) / **Ctrl** key (Windows) removes matching objects from the current selection. 

For Mac only, when using the Select Same command to match objects by Width, Height or Stroke Weight, the **⌥** key modifies the **Less** option to **Less (or Equal)** and the **Greater** option to **Greater (or Equal)**. Windows apps offer separate Less (or Equal) and Greater (or Equal) menu options under **Select Same > Stroke Weight**.
