# OpenType font features - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/text-opentype-fonts/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   OpenType font features

Affinity provides support for OpenType font features. These extend the font's character set, which lets you present text with greater typographical control.

You can also apply OpenType fonts that include SVG-based glyphs to display color and detailed illustrations.

![Image 1: OpenType fonts example](https://images.ctfassets.net/3p2fxa94bzao/5rdrVky2ByyGARtU5dH2oi/b93c48e4b8cc6e74e336c08214badb40/opentype_fonts.png)

An example of an OpenType stylistic set using the font Gabriola.

Supported font features include ligatures, alternates, swash variants, stylistic sets, and figure positions.

Available font features differ between fonts. This depends on how the font was designed.

Typography options depend on the applied font having the necessary glyphs to support them.

Some OpenType fonts include built-in color artwork using SVG-based glyphs. These fonts can display color and detailed illustrations instead of standard outlines.

![Image 2: The word “glyph” shown in a stylized color font with gradient-filled, three-dimensional letterforms.](https://images.ctfassets.net/3p2fxa94bzao/1a3jE9Sjk0f9uqvAEu45w7/756a9b14f3fda9d2dd78583a4c86765c/opentype_color_svg.png)

An example color font, Nabla (available from Google Fonts), with several predefined palettes. Affinity lets you apply a custom palette.

Some color fonts support recoloring by responding to the text fill color or offering predefined color palettes. In these cases, the text remains fully editable and behaves like standard text.

You can also apply a Color Overlay to recolor fonts that don't support built-in recoloring, including bitmap-based fonts. This gives you more flexibility, but may affect how the text is displayed after export.

In some export formats, recolored text may be rasterized to preserve its appearance. This means it may no longer be treated as editable text in other apps or by assistive technologies.

1.   Apply a font that supports OpenType font features to your text.
2.   On the **Typography** panel, select the required options, such as standard ligatures, swashes, or alternates.

Ligature control is also available via the **Text** menu's **Ligatures** submenu.

When applying local formatting (context toolbar or **Character** panel) or editing a text style (**Text Style Editor**):

1.   Apply a color font to your text.
2.   Set **Font Color** to the required color.

If the font is multicolor and does not support palettes, only some parts of each glyph may change to that color; other parts remain unchanged because those colors are built into the font.

When applying local formatting (**Character** panel) or editing a text style (**Text Style Editor**):

1.   Apply a font that includes color palettes to your text.
2.   (Text Style Editor only) Select **Color & Decorations**, then enable **Apply Multicolor font settings**.
3.   Select **Font Color Palette** and select a predefined palette from the pop-up menu. (Hovering over each palette previews it on styled text.)
4.   (Optional) Select a swatch to modify the color, which creates a _Custom_ palette. Repeat to modify additional swatches.

Palette options are only shown when a font that includes color palettes is applied.

When applying local formatting (**Character** panel) or editing a text style (**Text Style Editor**):

1.   Apply a multicolor font to your text.
2.   (Text Style Editor only) Select **Color & Decorations**, then enable **Apply Multicolor font settings**.
3.   Set the **Color FX** option to _Blend Color_, _Blend Hue_, or _Blend Alpha_.

To remove a color overlay, set Color FX to _Off_.
