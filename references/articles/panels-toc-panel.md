# Table of Contents (ToC) panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-toc-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Table of Contents (ToC) panel

Use the Table of Contents panel to insert, update, and manage tables of contents (TOCs) in your document.

For Mac/Windows: On the **Window** menu, select **References > Table of Contents**

The following options for managing TOC content are available on the panel:

*   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/2m47rLOVPg6hgwZ5CEnjac/87c4ef9308c5f81c9be1c9cc3213a6d7/insertToc.svg) **Insert**—inserts a generated TOC at the insertion point in a text frame.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/1UA1wOj97gWuxMfjdy5Zkv/02dc0ef6081924027bda46ba268a834c/update_toc.svg) **Update**—updates the selected TOC (lower on the panel) based on uses of your chosen TOC text styles in document text.
*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/1nD6ADgbXI1nmPJudPqfxK/5bc1e86cd1bfc827010a170471e30113/updateAllTocs.svg) **Update All Tables of Contents**—updates all TOCs within your document.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/3m8ciDtLqf07Yrma1i0j4x/202c1d508104bbb0a1290c5be7725eae/trash_can.svg) **Delete**—deletes the selected TOC (lower on the panel).
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/5zZjqQ6w90u11JT5q1m0un/b199409dfc3c7dee5bbf3c327d48d20b/renameToc.svg) **Rename**—lets you give the selected TOC a more meaningful name.
*   **TOC**—selects an existing TOC that you want to edit. The document view will jump to the TOC's page location.
*   **Scope**—chooses whether the selected TOC is generated from styled text in the whole document or just the section containing the TOC.
*   **Type**—sets whether the selected TOC is general purpose or, if you'll be exporting to EPUB, the primary TOC, an images TOC, or a tables TOC (referring to tables created with the Table Tool).
*   **Look In**—choose whether the selected TOC's entries will be generated from all text frames in the scope or only the frames that are linked in a text flow.
*   **Stop at next TOC**—stops adding entries to the selected TOC at the point where the next TOC appears in the document.
*   **Include entries before TOC**—lets the TOC include entries for styled text that is before the selected TOC's location in the document, e.g., to include preface or introductory information.
*   **Include as bookmarks**—lets the TOC's entries be included as bookmarks in PDF and EPUB output.

A TOC Style stores:

*   your choice of paragraph styles that identify document text from which TOC entries will be generated.
*   settings that control how TOC entries are generated and formatted.

Multiple TOCs can share a TOC Style. You can also create and apply different TOC Styles as needed.

The following options for managing TOC styles are available on the panel:

*   **TOC Style**—chooses the set of formatting options and paragraph styles that are used to generate the selected TOC.
*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/2XLuXTwmEh714qaYONrPKP/6d26123960257b3233a3eb084188eda7/moremenuicon.svg) **TOC Style Options**—let you manage the document's TOC Styles: 
    *   **Create New**—adds a new TOC Style to the document and applies it to the selected TOC.
    *   **Delete**—removes the selected TOC Style from the document, and the document's first TOC Style is applied to the selected TOC.
    *   **Rename**—lets you assign a meaningful name to the selected TOC Style.

*   **Numbers before headings**—places page numbers before TOC entries' text. Otherwise, page numbers are shown after entries' text.
*   **Remove line breaks**—replaces line breaks in styled document text that generates a TOC entry with spaces. For example, a heading that contains a line break will appear as a single-line TOC entry.
*   **Include inline pins**—copies inline pinned objects from styled document text into the TOC.
*   **Separator**—sets glyphs you want to be shown between TOC entries' text and page number. Click the arrow to insert commonly used glyphs.
*   **Text styles**—set which document text is used as entries for the selected TOC. Select only the **Style Name**s you've applied to text you want included. For each, page numbers are shown in the TOC by default.
*   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/2XLuXTwmEh714qaYONrPKP/6d26123960257b3233a3eb084188eda7/moremenuicon.svg) **Text style options**—let you choose whether entries for the corresponding style **Include Page Number** and their **Indent Level** within the TOC.

![Image 8](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

 The following options are available on the **Panel Preferences** menu:

*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
