3.   Editing text

You can use any text tool to select and edit text on the page.

You can also insert special characters, such as paragraph, line, column, and frame breaks.

With a text tool selected, do one of the following:

1.   Select a text tool.
2.   Click in the text object at the required position to create an insertion point.
3.   (Optional) If the insertion point's position needs fine-tuning, use the arrow keys to move it.

1.   Select a range of text.
2.    To remove the selection from the document and store it on the Clipboard, do one of the following: 
    *    Press the **⌘****X** keys (Mac) / **Ctrl**+**X** keys (Windows). 
    *    On the selection, **^(ctrl)**-click (Mac) / **right**-click (Windows) and select **Cut**. 
    *   On the **Edit** menu, select **Cut**.

3.   Create an insertion point where you want to move the text.
4.    To insert the text from the Clipboard, do one of the following: 
    *    Press the **⌘****V** keys (Mac) / **Ctrl**+**V** keys (Windows). 
    *    On the text object, **^(ctrl)**-click (Mac) / **right**-click (Windows) and select **Paste**. 
    *   On the **Edit** menu, select **Paste > Paste**.

1.   Create an insertion point or select a range of text.
2.   Type to insert new text or overwrite the selected text, respectively.

As well as typing, text can be pasted from the Clipboard or imported from a file.

1.   Create an insertion point at the required position.
2.    Press the **⏎** key (Mac) / **Return** key (Windows). 

1.   Create an insertion point at the required position.
2.    Press the **⇧****⏎** keys (Mac) / **Shift**+**Return** keys (Windows). 

1.    Do one of the following: 
    *   To format all of an object's text, select the **Move Tool**![Image 7](https://images.ctfassets.net/3p2fxa94bzao/3oigj5SSoPtnSw21egHEvD/b6ac975f2be7b3feb8e3e9867b378345/move_tool.svg)  and then click the object to select it.
    *   To format some of an object's text, select a text tool and then select a range of the object's text.

2.   Set commonly used formatting options on the context toolbar.
3.   (Optional) Set advanced formatting options on the **Character** and **Paragraph** panels.

For information about advanced formatting, see _Character formatting_, _Paragraph formatting_, and _Using text styles_.

1.   Create an insertion point at the required position.
2.    On the **Text** menu, select **Insert > Breaks** and then select the required type of break: 
    *   **Column Break**—flows text to the next column of the text frame, or to the next text frame in sequence if there are no more columns in the frame.
    *   **Frame Break**—flows text to the next linked text frame in sequence.
    *   **Page Break**—flows text to the next linked text frame in sequence that occurs on a later page.
    *   **Odd Page Break**—flows text to the next linked text frame in sequence that occurs on an odd-numbered page.
    *   **Even Page Break**—flows text to the next linked text frame in sequence that occurs on an even-numbered page.

You can use text styles to insert page breaks automatically—e.g. at each new chapter's heading. In the corresponding paragraph or group style's **Flow** settings, set **Start** to the required type of break.

When a text tool is active, the **Esc** key behaves as follows:

*   With a text range selected, pressing the key deselects the text and makes an insertion point at the selection's end, allowing you to continue editing.
*   Without a text range selected but with an insertion point in text, pressing the key removes the insertion point and the text object becomes selected. (You can then press the **V** key to switch to the **Move Tool** to transform the object.)
*   With the text object selected, pressing the key deselects the object.
