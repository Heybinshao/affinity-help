# Overprinting

For professional printing, global colors can be made to overprint. By applying an overprint color to objects selectively you can control overprinting.

[](https://www.affinity.studio/help/clr-overprint/#about-overprinting)

## About overprinting

Overprinting means that you can print one ink color on top of another instead of, by default, the underlying color being 'knocked out' (removed). This prevents unwanted fringing being left around objects, e.g. text.

![Image 4: Knockout vs overprint](https://images.ctfassets.net/3p2fxa94bzao/33QZf009D3FqtrBiI5kNME/4f80824b7733126c77b9cd5b09d955f0/overprint.png)

(A) Unwanted knockout behavior (default) showing white fringing vs. (B) overprinting.

As a professional printing feature, overprint works when publishing PDFs using a CMYK color space and PDF/X compatibility.

You don't need to explicitly make an overprint for black, for black text or black graphics, as this is set by default. On PDF publishing, you can control black overprinting using the **Overprint black** option on export (for any PDF export options).

Overprinting it will cause colors to appear darker due to the opacity of inks used in professional printing. Some PDF viewers can simulate how this would appear, but always consult with your print provider for advice on its use.

[](https://www.affinity.studio/help/clr-overprint/#how-to-create-an-overprint-color-from-scratch)

### How to create an overprint color from scratch

Desktop app

1.   On the **Swatches** panel, select a Document palette from the palette pop-up menu. If no Document palette exists you can create one from the panel's **Panel Preferences** menu.
2.   From **Panel Preferences**  ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/6UxpXBt5miovw347YaOPUz/6f8e3e8d9b379daa0bdc5a3ac6ff23e8/panel_preferences.svg)       , select **Add Global Color**.
3.   Adjust the settings in the dialog.
4.   Select the **Overprint** option.
5.   Click **Add**.

![Image 6: Overprint color thumbnail](https://images.ctfassets.net/3p2fxa94bzao/3Dvo4I0kjSt0Srd0NOEoQd/49964e014b5d4d55be10b897c5444f82/overprintclr_thumbnail.png)

An overprint color swatch is indicated by a curved tab in the top-right corner of its color swatch.

You can check if an overprint color has been assigned to an object's stroke or fill by using the **Color** panel.

[](https://www.affinity.studio/help/clr-overprint/#how-to-make-an-existing-global-color-overprint)

### How to make an existing global color overprint

Desktop app

*   On the **Swatches** panel, **^(ctrl)**-click (Mac) / **right**-click (Windows) the global color swatch's thumbnail, then select **Overprint**. 

[](https://www.affinity.studio/help/clr-overprint/#see-also:)
