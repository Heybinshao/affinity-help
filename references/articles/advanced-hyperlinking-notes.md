# Hyperlinking notes

To improve the reading experience of PDF publications, Affinity can automatically generate hyperlinks that connect references and note bodies to each other.

Hyperlinked note references let readers jump from a reference in the main text to its note body. Readers can jump back to the reference.

[](https://www.affinity.studio/help/advanced-hyperlinking-notes/#default-settings)

## Default settings

Hyperlinks are not enabled for footnotes by default because their references and bodies are close together.

Hyperlinks help make footnotes easier to read. For example:

*   If your publication is read on a small device and zoomed in close to the page.
*   If a footnote body is long, it may move other notes to a later frame or a different page than their references.

[](https://www.affinity.studio/help/advanced-hyperlinking-notes/#how-to-add-hyperlinks-to-your-document-s-footnotes)

### How to add hyperlinks to your document's footnotes

Desktop app

On the **Notes** panel:

1.   Select **Footnotes**.
2.   Select **Document-wide**.
3.   On the **Format** section, check **Generate hyperlinks**.

Generated hyperlinks don't appear on the **Hyperlinks** panel, which is for managing only user-created hyperlinks.

[](https://www.affinity.studio/help/advanced-hyperlinking-notes/#see-also:)
