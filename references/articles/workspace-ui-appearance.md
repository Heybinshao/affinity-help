# Changing the UI appearance - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/workspace-ui-appearance/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Getting started](https://www.affinity.studio/help/getting-started/)
3.   Changing the UI appearance

Affinity has a dark User Interface (UI) by default. This makes it easier to accurately view and edit the colors in your projects, but you can adjust settings to tailor the UI to your personal preferences and accessibility needs.

![Image 1: Dark and Light UI Styles](https://images.ctfassets.net/3p2fxa94bzao/6VXiMa06MaFNk2i6zzRh4L/0f1be75b03ffc405c5e79a33bd047b3f/uiAppearance.png)

Dark vs light UI styles (English app example).

1.    Do one of the following: 
    *   For Mac: On the **Affinity** menu, select **Settings**.
    *   For Windows: On the **Edit** menu, select **Settings**.

2.   On the dialog that appears: 
    1.   Select **User Interface**.
    2.   Adjust settings from the dialog: 
        *   **Background Gray Level**—Adjusts the background of the document view.
        *   **Artboard Background Gray Level**—Adjusts the background of artboards.
        *   **Text Contrast**—Adjusts the brightness of text in the UI.
        *   **UI Brightness**—Adjusts the background gray levels of toolbars, panels and other window elements.
        *   **UI Contrast**—Choose between **Default**, which sets Text Contrast and UI Brightness to their highest and lowest values, respectively, and **High**, which sets Text Contrast and UI Brightness to their highest values.
        *   **UI Font Size**—Choose between **Default** and **Large**(Mac only).
        *   **Accent Color**—Choose the color used to highlight selected buttons and menu items.
        *   **UI Style—**Choose between **Dark**, **Light**, or **Default OS** (Mac only).

Affinity does not support Whole UI Scaling. However, tool handle size and UI font size can be scaled. The former can be set in Settings (Tools).

Tool handle sizes can be increased (and decreased) via the app's settings, making them more visible and easier to select.

1.   Do one of the following: 
    *   For Mac: On the **Affinity** menu, select **Settings**.
    *   For Windows: On the **Edit** menu, select **Settings**.

2.   On the dialog that appears: 
    1.   Select **Tools**.
    2.   Set **Tool Handle Size** to your preferred size.
