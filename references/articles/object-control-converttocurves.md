# Converting to curves - Affinity Help Center

3.   Converting to curves

You can convert geometric shapes, text, or pixel selections into curves and then adjust the resulting curve's nodes to make new object variations. Pixel content can't be converted to curves.

When preparing a design for professional printing, converting to curves ensures a shape’s gradient fill is rendered perfectly, while for text, the assigned font won’t be accidentally substituted (as it is no longer text). Objects converted to curves also means that their geometry can be customized without limitation.

Once an object has been converted to curves, it can no longer be edited in its conventional way. This can only be undone by undoing the operation using an Undo command or reverting its history. For example, for a star, you would not be able to change the number of points once it has been converted to curves. For text, the font can't be changed.

Geometric shapes drawn with shape tools can be converted to curves to allow the shape's outline to be modified without restriction. All geometric shapes have unique properties that can be customized into shape variants while maintaining their symmetry—converting to curves offers total editability at the expense of it still being considered a shape.

Like geometric shapes, any artistic or frame text can be converted to curves, losing its font properties in the process. The conversion lets you explore more creative possibilities otherwise impossible with font-based text.

Text converted to curves and then reworked to add a underlining flourish.

Affinity lets you convert any current pixel selection into an editable polycurve, i.e. a a curve consisting of two or more curves joined together. The pixel selection can come from:

*   a layer's content (e.g., painted strokes)
*   luminance
*   colour sampling
*   Canva AI selection tools
*   intersecting areas formed ‘on the fly’ from overlapping shapes

![Image 3](https://images.ctfassets.net/3p2fxa94bzao/4iXB2e5yHAVuOkN1iMYCPU/a42e6587599ecbc47c6d72dcbaf1acf1/converttocurves_pixelselection_after.png)

A pixel selection converted to curves creates a sharp-edged editable outline - great for silhouettes (shown) or as a vector mask.

It's used for creating adjustable vector masks as a single editable polycurve. Vector masks have the following benefits:

*   having edge sharpness
*   being able to edit the outline
*   easy creation of abstract shapes

They can be used for creating silhouettes from image outlines and clipping images inside the vector mask.

1.   Select one of more objects or make a pixel selection.
2.   Do one of the following: 
    *   Click **Convert to Curves** on the context toolbar.
    *   On the **Vector** menu, select **Convert to Curves**.

The shape is now made from curves and the **Node Tool** is automatically selected. Segments and nodes can be modified with the Node Tool.
