# Detect Horizontal Edges filter - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/filters-filter-detect-horizontal-edges/

1.   [Help Center](https://www.affinity.studio/help/)
2.   Detect Horizontal Edges filter

The Horizontal Edges filter isolates and strengthens horizontal edges while darkening the rest of the image. It’s useful for emphasising structure, separating layers of detail, or creating stylised effects where horizontal elements—such as horizons, floors, shelves, or architectural lines—are visually important.

![Image 1: After](https://images.ctfassets.net/3p2fxa94bzao/26oL1kTjIbm1cjhdBAPMhk/438d1a5342b28222fab09a17643092ed/filter_detectedgeshorizontal_after.jpg)

![Image 2: Before](https://images.ctfassets.net/3p2fxa94bzao/61Y0W3Cc7ILdzRrdxZWcf1/2700a88521560195c1a838dfb31cca55/filter_detectedgeshorizontal_before.jpg)

Because the filter focuses on horizontal direction, it isolates features like horizons, steps, ledges, layers, and stacked forms without equally emphasising vertical detail.

You may want to use this filter to identify horizontal alignment issues in photos or layouts, assess balance, symmetry, or perspective prior to level adjustments.

Use Horizontal Edges to guide your next editing steps—as the filter helps target edits to specific structural elements, it provides a base for creating selections or masks.

Experiment with layer blend modes at reduced opacity for optimal stylistic purposes.

The filter can be used in the following example scenarios:

*   **Landscape and Horizon Enhancement**—Use the filter to emphasise horizons, shorelines, or layered terrain before applying contrast, color grading, or atmosphere effects.
*   **Architectural and Interior Design**—Highlight floors, ceilings, shelves, stairs, or wall divisions to support perspective correction or layout refinement.
*   **Stylized Graphic Effects**—Combine the detected edges with blend modes or color fills to create graphic, poster-like, or technical illustration styles.
*   **Mask Generation**—Convert the horizontal edge outputs into a mask to apply adjustments—such as lighting or color changes—along horizontal planes only.
*   **Subtle Texture and Structure Overlays**—Overlay the edge result at low opacity to introduce visual structure and rhythm without overpowering the original image.

This filter can be found on the **Pixel > Filters > Detect** menu.

This filter has no customizable settings.

This filter works by detecting changes in RGB values. This means that some images will work better than others.
