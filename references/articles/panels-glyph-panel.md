# Glyph Browser panel - Affinity Help Center

3.   Glyph Browser panel

In typography, glyphs are visual representations of characters in a typeface, such as those used in Cyrillic or Latin scripts.

For Mac/Windows: On the **Window** menu, select **Text > Glyph Browser**.

The following options are available on the panel:

*   **Font Family**—the chosen font type (all valid installed fonts are listed).
*   **Font Style**—sets the font style, e.g., **Bold**.
*   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/52XYdXlyLW1ZAzUYGK6kqf/48bc9cd93adcdbf14804e0cab02cbcf0/lock_layer.svg) **Lock Font and Traits**—when unlocked, the panel font changes with your selected text. This helps you find glyphs from that font. When locked, the panel always shows the same font. This helps if you often use glyphs for a specific font, such as a symbol font like FontAwesome.
*   **Subset**—sets the chosen font subset to display glyphs from, e.g., **Basic Latin**, **Arabic**, **Greek Extended**.
*   **Search**—type a character name or Unicode value to find the corresponding glyph. For example, "G+0131", "U+00b0" or the phrase "degree" will all show the degree symbol.
*   **Recently Used**—lists your most recently inserted glyphs.

![Image 2](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

 The following options are available on the **Panel Preferences** menu:

*   **Size**—sets how big glyphs look on the panel; this affects only panel usability, not the glyph output to your document.
*   **Order**—switches between font **Glyph** and **Unicode** order.
*   **Clear Recently Used**—removes glyphs previously added to the bottom of the panel for reuse.
*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
