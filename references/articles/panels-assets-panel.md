# Assets panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-assets-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Assets panel

The Assets panel lets you store design elements for reuse in any Affinity document.

For Mac/Windows: On the **Window** menu, select **General > Assets**.

Assets are listed in the order you added them. You can manually reorder them by dragging them while holding down the **⌥** key (Mac) / **Alt** key (Windows).

You can export to and import from external files via the **Panel Preferences** menu.

It is also possible to reorder subcategories by dragging their entries up or down inside the category group.

The following options are available on the panel:

*   **Search**—filters the asset list to names that match your criteria. Type directly in the text box.
*   **Category**—shows the active category. Select which that is from the pop-up menu.
*   **Subcategory**—displays all assets in the named subcategory. Click a subcategory's title to collapse or expand the subcategory.

 The following options are available on the **Panel Preferences** menu:

*   **Create New Category**—adds a new, custom assets category to the panel.
*   **Rename Category**—lets you rename the selected category.
*   **Duplicate Category**—adds a second copy of the selected category to the panel.
*   **Delete Category**—removes the selected category (and all its assets) from the panel.
*   **Sort Categories By**—lets you sort assets categories by **Name** or **Date Added**.
*   **Create Subcategory**—adds a new subcategory to the selected category.
*   [**Import Assets**](https://www.affinity.studio/help/addons-importing-addons/)—lets you add an .afassets file and adds a new category to the panel pre-populated with subcategories and assets from your imported file. 
*   [**Export Assets**](https://www.affinity.studio/help/addons-exporting-addons/)—creates an *.afassets file containing the assets and subcategory structure from the selected category. 
*   **Expand All**—opens all subcategories in one operation.
*   **Collapse All**—closes all subcategories in one operation.
*   **Embed in Current Document**—embeds the assets into the document, so they're still available when you open it on another device (or on the same one if assets were deleted). When you open a document with embedded assets, you're asked whether to import them to the panel for use in all documents.
*   **Show As List**—if this option is off (default), assets are displayed as thumbnails in a grid with tooltips displaying their name. When enabled, assets show as named thumbnails in a list.
*   **Background**—lets you set the background color for the panel. This can improve previewing of some assets on the panel.
*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.

 The following options are available from subcategory options menus:

*   **Rename**—lets you rename the subcategory.
*   **Delete**—removes the subcategory (and all its assets) from the panel.
*   **Move Up**—repositions the subcategory above the previous one, so it is listed higher. (Not available if the subcategory is at the top of the list.)
*   **Move Down**—repositions the subcategory below the next one, so it is listed lower. (Not available if the subcategory is at the bottom of the list.)
*   **Sort By Name**—sorts assets in the subcategory by name. You can drag and drop individual assets within a subcategory to reorder them, or between subcategories to move them.
*   **Add from Selection**—adds the selected objects to the subcategory. Grouped objects are added as a single asset.
