# Swatches panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-swatches-panel/

3.   Swatches panel

The Swatches panel makes it easy to use predefined colors, and also to define, store and reuse your own selection of colors.

For Mac/Windows: On the **Window** menu, select **General > Swatches**.

Using the panel, you can:

*   Choose colors for the stroke and fills of objects, and foreground and background color for layers.
*   Store colors for future use.
*   Pick (sample) color from the current document.
*   Create and manage palettes.
*   Create global, spot and overprint colors.

The following options are available on the panel:

*   Color selectors (Stroke/Fill or Foreground/Background, depending on Studio, with color 'none' swatch and 'swap' arrow)
*   Color picker and picked color swatch
*   Category list (showing Application, left, and Document, right)
*   Category color palette swatches
*   Search
*   Panel Preferences
*   Opacity control
*   Recently used colors
*   None, Black, Mid-gray and White swatches
*   Add current color to palette as a global color
*   Add current color to palette
*   Registration color
*   Global color
*   Overprint color
*   Spot color

The following preferences are available on the **Panel Preferences**

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/6UxpXBt5miovw347YaOPUz/6f8e3e8d9b379daa0bdc5a3ac6ff23e8/panel_preferences.svg)

 menu:

*   **Add Global Color**—creates a color that can be updated simultaneously across all objects.
*   **Add Registration Color**—creates a color for assignment to an object as a registration mark (for professional CMYK printing).
*   **Add Application Palette/Add Document Palette/Add System Palette**—creates a new empty color palette for Affinity, the current document or the operating system.
*   **Rename Palette**—creates an identifiable palette name.
*   **Duplicate Palette**—makes a copy of the currently active palette.
*   **Delete Palette**—deletes the currently active palette.
*   **Set as Default for**—sets as the default used for specific color formats.
*   **Remove Default for**—reverts the default to the system default.
*   **Create Palette From Document**—creates a document palette from the colors in the current document (including from images).
*   **Create Palette From Image**—creates a document palette from the colors in an image external to Affinity.
*   **Appearance**—change swatch thumbnail size or view as a list.
*   **Sort**—display thumbnails based on alphabetic order or color.
*   **Import Palette**—imports an Affinity palette (.afpalette) file as a document, application or system palette.
*   **Export Palette**—exports the currently active palette as an Affinity palette (.afpalette) file.
*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.

Set the stroke (background) and fill (foreground) color selectors to black or white, respectively, by pressing the **D** key. This affects any vector objects that are selected.

Switch between the color selectors by pressing the **X** key.

To honor the opacity and/or noise already applied to a vector shape, line or text (i.e. only the color will update), hold down the **⌥** key (Mac) / **Alt** key (Windows) when selecting a new swatch.
