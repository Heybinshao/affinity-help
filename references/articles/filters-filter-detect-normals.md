# Normals filter - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/filters-filter-detect-normals/

2.   Normals filter

The Normals filter analyzes and evaluates your image to determine how textures are oriented in three-dimensional space.

. To use it, you need to be subscribed to the Canva Pro plan. To learn more about the premium features usage visit the [Canva AI & Affinity ML](https://www.affinity.studio/help/canva-ai-canva-ai-affinity-ml/) topic.

The Normals filter aids accurate and realistic image evaluation in terms of how light interacts with surfaces and textures. It then generates a three-dimensional XYZ lighting map represented in the output as a RGB color estimation.

Some of the practical uses of the filter may involve:

*   3D Rendering & Texturing: _Normal_ maps help simulate realistic lighting, shadows, and surface detail without adding actual geometry.
*   Photorealistic Effects: enhances visual depth by applying dynamic lighting effects that mimic real-world textures. Using the filter can further on help to simulate realistic shadows and lighting on a 3D surface.
*   Texture creation for games or digital art: used to quickly convert photographs into textures with realistic depth and interaction with lighting.

The **Depth Estimation** model must be downloaded prior to using the feature. The model is available in **Settings > Machine Learning Models** section.

Affinity's Machine Learning functionality is not generative and advocates human creativity.

This filter is applied as a destructive filter.

For a non-destructive workflow, apply the filter to a duplicate layer rather than the Background layer.

Access the filter from the **Pixel > Filters > Detect** menu.

The filter has no customizable settings.
