3.   Removing text styles

Text styles can be detached from selected text or throughout a document. A text style can also be removed entirely from a document.

There are a few things to consider when detaching and deleting text styles. Consider whether you want to:

*   Remove the text style from styled text or delete it entirely from the document.
*   Return styled text to the default settings or leave its current formatting unaffected.
*   Affect specific instances of text or all text to which a style is applied within the document.
*   Perform a combination of the above.

Each detachment or deletion method has a different impact on your document's text and text styles. Choose the method below based on the outcome you desire.

It's possible to detach and delete all text styles from your text, with the option of creating your own set of text styles from scratch and making it the default for new documents.

1.   Select a text range or create an insertion point.
2.   Do one of the following: 
    *   On the context toolbar, select _[No Style]_ on the **Character Style**![Image 1](https://images.ctfassets.net/3p2fxa94bzao/14s6gBEEfR9KoZKoyZzspq/1607b73812623d25a70f07f6fb3224ef/CharacterStyle.svg)  or **Paragraph Style**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/2Z1fGYfMPi7gUNPsxlpsuE/e9b6aca401c04ce90c5e05f5af722665/ParagraphStyle.svg)  pop-up menu as required.
    *   On the **Paragraph** or **Character** panel as required, select **[No Style]** on the text style pop-up menu.
    *   On the **Text Styles** panel, select ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/2Z1fGYfMPi7gUNPsxlpsuE/e9b6aca401c04ce90c5e05f5af722665/ParagraphStyle.svg) _[No Style]_ or ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/14s6gBEEfR9KoZKoyZzspq/1607b73812623d25a70f07f6fb3224ef/CharacterStyle.svg) _[No Style]_ as required.

To affect all the text in your document, select all the text objects in your document, then follow the procedure above.

1.   Select a text range or create an insertion point.
2.   On the **Text Styles** panel, select **Detach Paragraphs From <style name>** or **Detach Characters From "<style name>"** on the unwanted text style's options menu ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/2XLuXTwmEh714qaYONrPKP/6d26123960257b3233a3eb084188eda7/moremenuicon.svg) .

1.   Select the exact text range to affect or create an insertion point in the paragraph to affect.
2.   On the **Text** menu, select **Text Styles > Reapply Text Styles**.

1.   Select a text range or create an insertion point in the paragraph(s) to affect.
2.   On the **Text** menu, select **Text Styles > Reapply Base Styles**.

Do one of the following:

*   Select a text range or create an insertion point in text that uses the unwanted style. On the **Text Styles** panel, select **Delete Style**![Image 6](https://images.ctfassets.net/3p2fxa94bzao/3m8ciDtLqf07Yrma1i0j4x/202c1d508104bbb0a1290c5be7725eae/trash_can.svg) .
*   On the **Text Styles** panel, select **Delete "<style name>"** on the unwanted style's options menu ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/2XLuXTwmEh714qaYONrPKP/6d26123960257b3233a3eb084188eda7/moremenuicon.svg) .

Connected text styles means a group style or master text style, and any text styles that are based on it. For example, the _Bullet 1_ paragraph style and its subordinate _Bullet 2_ and _Bullet 3_ text styles in a new document.

*   On the **Text Styles** panel, select **Delete "<style name>" Group** on the unwanted group style's options menu ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/2XLuXTwmEh714qaYONrPKP/6d26123960257b3233a3eb084188eda7/moremenuicon.svg) .

*   On the **Text Styles** panel, select **Detach and Delete All Styles** on the **Panel Preferences** menu ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/6UxpXBt5miovw347YaOPUz/6f8e3e8d9b379daa0bdc5a3ac6ff23e8/panel_preferences.svg) .
