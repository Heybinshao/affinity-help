The Pencil Tool

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/Oo3L4bMwg6BKZDccrfZh4/3adc5cd791351ace78a4b780319834f8/pencil_tool.svg)

 is used to create a hand-drawn look by drawing freehand, variable width, lines as if you were drawing on paper.

The Pencil Tool is available by default in Vector Studio.

It can be added to other Studios. See 'Customizing tools' for details.

As you draw, nodes are created automatically along the stroke which can optionally be smoothed as you draw by enabling the **Stabilizer** feature. A **Sculpt** mode also lets you reform or continue your pencil stroke at any time, although you can use the Node Tool to edit too. When using a combination of sculpting and Use Fill, you can form conjoined pencil strokes that can take a fill with the stroke's concave area.

Its variable width lines can be controlled either by velocity—most useful when drawing with a mouse—or by pressure—for use when drawing with a pressure sensitive pen tablet.

Path brush styles are applied using the **Stroke** panel. For brush textures, pick a brush from the **Path Brushes** panel.

Tool shortcut key: **N**

The following options can be adjusted on the context toolbar:

*   **Stroke**—the color of your stroke. Click the color swatch to select from solid colors, a picked color, color gradients or from your preset or custom color swatches.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/3rYvQ5X8bUYnIRpXvMBBlv/ee8198bb2731db49a0f3ec426d194fb2/stroke_width.svg) **Stroke width**—set a stroke width for the stroke using direct input or slider.
*   ![Image 3: Edit stroke settings](https://images.ctfassets.net/3p2fxa94bzao/LAIAniI5tfK3bknzYOUQB/9af81e28e315cea94436ab657c986f85/stroke.svg) **Edit stroke settings**—click to set the stroke style, width, joins, cap ends, order and arrowhead settings via a pop-up panel.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/6as00LuiF3q37wCGmrTqsX/0c6eca8b458eb2003007b1d2df270b3c/sculpt_mode.svg) **Toggle Sculpt Mode—**when enabled, any selected pencil stroke can be reshaped or continued; the former by drawing new start and end stops anywhere along the pencil stroke, the latter by drawing from either stroke end node.
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/60YfZlrZiHv6JuKp7X8P5v/1e17e904da0827e67050f01d8b9235b5/slider_smooth.svg) **Curve fitting smoothness**—depending on the qualities of the initial stroke, you can fine-tune its curvature (or jagged nature) by setting the value. Drag left or right to keep the stroke as intended or smooth the stroke; nodes are added or removed.
*   **Stabilizer**—enables stroke stabilization using one of two modes: 
    *   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/1dQYbLS5to2P0NEVKWr05P/ed77646476b191fed3c1e20aaa13921d/stabiliser_rope.svg) **Rope mode**—drags the stroke end by a 'rope' to smooth the stroke but lets you introduce sharp corners at increasing rope _Length_ (radius) values by redirecting the slackened rope.
    *   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/4wgNDHLUHFBM5dfxTQYqrO/ae9cf7f82a75be64e0cc071f94e56a04/stabiliser_window.svg) **Window mode**—smoothes the stroke by averaging sampled input positions within a _Window_ whose size is configurable.

*   ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/6fO8gzxjlWSt51XW7W46Ki/ea5331b1921c1da85958815970e1cd76/fill_stroke.svg) **Use line style**—when enabled, the outer line of the shape drawn can be edited using the options in the **Stroke** panel.
*   ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/XVmIokaRehxGTwCGRU40b/addc7bc4201864a8f25e973bfbb30b88/use_fill_style.svg) **Use fill**—when enabled, the concave area of the line is filled with the color you select from the revealed **Fill** color swatch as you draw.
*   ![Image 10](https://images.ctfassets.net/3p2fxa94bzao/58wNyMZl0DuNFi96wwd2r6/c8656fa6079dda8976d13873f64e0565/keep_selected.svg) **Keep selected**—when enabled (default), the new stroke layer will be selected on creation. When disabled, the new object is deselected which prevents it from adopting the next object’s stroke/fill properties.
*   ![Image 11](https://images.ctfassets.net/3p2fxa94bzao/7e47FwYJ0eBW8yOWy3elSz/813ccca2419c99817334e5bb65c2a0db/cog_icon_2.svg) **Settings**—for auto closing and controller management: 
    *   **Auto close**—choose from the following options to make a closed shape from your stroke: 
        *   **Off**—when enabled, you can continue applying strokes without closing the curve when the cursor approaches close to the curve's start node; opposite to the "Always" option.
        *   **Near**—when enabled, you can close the curve when the cursor approaches close to the curve's start node. A 'dog bone' visual aid temporarily appears to indicate that closure will occur on mouse release
        *   **Far**—when enabled, you can close the curve when the cursor's position is further from the curve's start node.
        *   **Always**—when enabled, the curve is always closed, irrespective of the distance between the end points.

    *   **Controller**—controls whether the tool is sensitive to real pressure (_Pressure_) or speed of mouse movement (_Velocity_ or _Inverse Velocity_). Select _None_ to use neither.

The following shortcuts can be used with the Pencil Tool.

*   To select the Pencil Tool, press the **N** key.
