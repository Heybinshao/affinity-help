3.   About cross-references

A cross-reference points the reader to another part of the text—such as a chapter, note or figure. For example, "See Spring-Flowering Shrubs on page 32."

![Image 1: An example cross-reference](https://images.ctfassets.net/3p2fxa94bzao/71kvOTe8154yF0U3hYLkxV/9d77dc026da6fb29dde204dfdbf77e36/crossrefsExample.png)

A cross-reference that displays the numbered list item (A) and page number (B) of its target.

Cross-references are inserted into document text and managed using the **Cross-References** panel.

Each cross-reference in document text is a field, which allows its value to be easily updated as your publication's content changes.

When you insert a cross-reference, the **Insert Cross-Reference** dialog is shown.

![Image 2: Text options on the Insert Cross-Reference dialog](https://images.ctfassets.net/3p2fxa94bzao/5mtGeQmbeEHXJKsrefmEZ4/d41d1c294721d9d3cfb6065433f0162e/crossrefsInsert.png)

Text and other options on the Insert Cross-Reference dialog.

On the dialog:

*   Set a target (also referred to as 'linking to' it), which can be an existing anchor, paragraph or index mark.
*   Set the text to be displayed in your document, including fields that describe the target or its position.
*   Select a character style to apply to the cross-reference's text, overriding the formatting at its position in document text.

The options depend on how many cross-references you select on the **Cross-References** panel.

When one cross-reference is selected, you can edit any of its settings, i.e. the full range of target, text and formatting options that were available when inserting the cross-reference.

When multiple cross-references are selected, you can edit their text and formatting but not their targets. This helps you keep multiple cross-references consistent in text and style.

![Image 3: Edit Cross-Reference Format dialog](https://images.ctfassets.net/3p2fxa94bzao/1yQaOUt2728DtnTGlMIZtQ/c261fab2c574b6f6c4a618d5e6590bee/crossrefsEditFormat.png)

Editing multiple cross-references.

1.   Create an insertion point in text.
2.   Do one of the following: 
    *   On the **Cross-References** panel, click **Insert Cross-Reference**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/665YKq8jcBR3ikEaRtacni/a988199c33634ac644564cddad8df35e/add_item.svg) .
    *   In document text, **^(ctrl)**-click (Mac) / **right**-click (Windows) and select **Insert Cross-Reference**.

3.   On the dialog that appears: 
    1.   Select a target type from the **Link to** pop-up menu.
    2.   (Optional) Use the filter options to narrow down the targets list.
    3.   Select the required target from the targets list.
    4.   Set the **Text** to display in document text.
    5.   (Optional) Choose a character style from **Style override** and use **For** to pick where it applies.
    6.   Click **OK**.

Options for setting a cross-reference's text and formatting are explained in topics linked below.

On the **Cross-References** panel:

1.   Select one or more cross-references.
2.   Select **Edit Cross-Reference**![Image 5](https://images.ctfassets.net/3p2fxa94bzao/1M3Etf1yFAmmqIVBlHrPj9/36fb6363c058d1e134dc486b6a132dab/edit_item.svg) .
3.   On the dialog that appears: 
    1.   Set the target, text and formatting options as required.
    2.   Click **OK**.

Editing multiple cross-references simultaneously allows you to change their text and formatting but not their targets.

*   In document text, **^(ctrl)**-click (Mac) / **right**-click (Windows) the cross-reference's text and select **Expand Field**.

The cross-reference is removed from the **Cross-References** panel. Its value remains in the document as regular text and can be edited directly.

A cross-reference can also be converted to regular text by removing it on the **Cross-References** panel.

On the **Cross-References** panel:

1.   Select the cross-reference.
2.   Click **Go to Target**![Image 6](https://images.ctfassets.net/3p2fxa94bzao/5aTh6Tstw55CJPGXwiWXQH/5b1e2d1926b56a90966fb745d6439e82/cross_reference_target.svg) .

An insertion point is created at the target's position.

On the **Cross-References** panel:

1.   Select the cross-reference's entry.
2.   Click **Go to Cross-Reference**![Image 7](https://images.ctfassets.net/3p2fxa94bzao/5qqdddE6F6SjZ0RoHktRqa/ec0f3bfa048e1983f4428c0b034b04a6/cross_reference_source.svg) .

The document view jumps to the cross-reference's field. The field is selected.

On the **Cross-References** panel:

1.   Select the unwanted cross-references.
2.   Click **Remove Cross-References**![Image 8](https://images.ctfassets.net/3p2fxa94bzao/3qZ39scQTi6VW2IkIYeZWE/0e401420ef8c61d56f0e4daa744bc730/remove_cross_reference.svg) .
3.   Click **Yes** to convert the cross-reference's field to regular text.
4.    (Optional) To remove the resulting text from your document, do one of the following: 
    *   If the selected cross-references are in the same text object (including linked text frames), their text is automatically selected. Press the **⌫** key (Mac) / **Backspace** key (Windows) to remove it.
    *   If the selected cross-references are in different text objects, you'll need to inspect your document text and manually remove any unwanted text.

Alternatively, to remove a single cross-reference, **^(ctrl)**-click (Mac) / **right**-click (Windows) its field in document text, and then select **Cut** to remove it from document text and the **Cross-References** panel.
