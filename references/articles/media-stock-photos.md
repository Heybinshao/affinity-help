# Using stock photos

The Stock panel allows you to search various stock imagery websites to find images and then add them to the page.

[](https://www.affinity.studio/help/media-stock-photos/#how-to-search-for-stock-images)

### How to search for stock images

Desktop app

On the **Stock** panel:

1.   Select a stock imagery website from the pop-up menu.
2.   In the search box   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/5QCmupZO3Kpzd6SI5gVTvS/972495011c8b174b2ba48194de75b160/SearchFieldMagnify.svg)       , type in your keyword(s), then click the search icon or press the **⏎** key (Mac) / **Return** key (Windows).

The panel displays thumbnails of all images that match your search criteria.

You can clear search results by clicking in the search box and then clicking the cross icon

![Image 7](https://images.ctfassets.net/3p2fxa94bzao/2pqDtCcxHISGAtrcwNoXKf/40689d8e53c070f7ae077abccb338693/SearchFieldClose.svg)

.

For Pixabay searches, you can limit the search results to just vector artwork by checking the **Vector** checkbox.

[](https://www.affinity.studio/help/media-stock-photos/#how-to-add-a-stock-image-to-your-page)

### How to add a stock image to your page

Desktop app

1.   Drag the image's thumbnail from the **Stock** panel.
2.   Drop the thumbnail onto a page or a picture frame in the document view.

[](https://www.affinity.studio/help/media-stock-photos/#how-to-view-an-image-on-its-stock-imagery-website)

### How to view an image on its stock imagery website

Desktop app

1.   Select the image in your document.
2.   On the context toolbar, select **Open Stock URL**.

[](https://www.affinity.studio/help/media-stock-photos/#how-to-create-a-new-document-from-a-stock-image)

### How to create a new document from a stock image

Desktop app

1.   Drag an image thumbnail from the **Stock** panel.
2.   Drop the thumbnail on the Toolbar. If no documents are open, you can drop the image onto the empty workspace.

The **Pixel Studio**

![Image 8](https://images.ctfassets.net/3p2fxa94bzao/x0qUKV0QmljBpXjlKaAyD/48b1503c7d6cc8f05d91c6af70f31b85/persona_photo.svg)

 is automatically selected. The new document will have the same dimensions as the image.

[](https://www.affinity.studio/help/media-stock-photos/#see-also:)
