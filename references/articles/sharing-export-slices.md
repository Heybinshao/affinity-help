# Exporting slices - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/sharing-export-slices/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Export, share, and publish](https://www.affinity.studio/help/export-share-publish/)
3.   Exporting slices

Create export areas of all sizes from any part of your composition.

![Image 1: Slices in the Export Studio](https://images.ctfassets.net/3p2fxa94bzao/2convTjXneE9AxuRKhcpoP/2a99ddd0477211d8516bce40c970e2ec/slices_export.png)

The Slices panel's **Continuous** and **Export all formats for this item** features work in conjunction.

Slices checked for inclusion in exports are re-exported when the document's content changes, or when any slice is transformed or its options are changed.

1.   On the **Export Options** panel, select the **Defaults** tab.
2.   Adjust settings as appropriate.
3.   Jump back to the **Selection** tab when finished.

The settings will be used when your next slice is created.

Affinity comes equipped with a range of export **Presets** built in and ready to use. These may act as shortcuts to setting the desired outputs faster.

With a slice selected, you can change its export options to be different from that of other slices.

1.    On the **Slices** panel, click **Export Slices**
2.   Navigate to the required folder. (Create a New Folder, if required.)
3.   Click **Export**.

The export folder is remembered only for the current editing session.

1.   On the **Layers** panel, select a layer, group or object and click **Create Slice**.
2.    Do one of the following: 
    *   On the [Export Options panel](https://www.affinity.studio/help/panels-export-options-panel/), adjust export settings as appropriate.
    *   Jump to the [Slices panel](https://www.affinity.studio/help/panels-slices-panel/), expand the slice entry and alter the export format or choose an **Export preset** from the pop-up menu (PNG, JPEG, and Apple icon design presets only).

3.   (Optional) On the [Slices panel](https://www.affinity.studio/help/panels-slices-panel/), click the + icon under the export format entry to add an additional graphic export format.
4.   (Optional) On the [Slices panel](https://www.affinity.studio/help/panels-slices-panel/), click the indented + icon under the export size entries to add increasing levels of resolution (2x, 3x, etc.) to the export format.
5.    Do one of the following, to control what gets exported: 
    *   Select **Click to export all formats for this item**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/4qg755Uvb6Et00LaFyKR9M/f0bad9d640367cf61126810505039704/export_slice.svg) .
    *   Select **Click to export this format**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/4qg755Uvb6Et00LaFyKR9M/f0bad9d640367cf61126810505039704/export_slice.svg) . This exports all sizes specified for the selected slice.
    *   Select **Click to export this size**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/4qg755Uvb6Et00LaFyKR9M/f0bad9d640367cf61126810505039704/export_slice.svg) . This exports a specific export format for a slice at a specific size.
    *   Click **Export Slices (****_n_****)** to export all formats and sizes for all checked slices in the Slices panel.

6.   Navigate to and select the storage folder for the exported image(s) and then click **Export**.
7.   (Optional) On the **Slices** panel, select **Continuous** if you want to automatically re-export export areas if the document is subsequently changed. This option is only available if **Export Slices (****_n_****)** was selected above.

1.   Select the **Slice Tool**![Image 5](https://images.ctfassets.net/3p2fxa94bzao/XAjdyRXzevwDrEhrja0tH/2530aa6c6cb440988dfba5e9dae7a01d/slice_tool.svg) .
2.   Drag on the page to select areas.
3.   Repeat step two above, as required.

For precise sizing and positioning of slices created with the Slice Tool, use the supporting **Transform** panel directly within the Slice Studio to export to exact slice dimensions.

1.   With the **Slice Tool**![Image 6](https://images.ctfassets.net/3p2fxa94bzao/XAjdyRXzevwDrEhrja0tH/2530aa6c6cb440988dfba5e9dae7a01d/slice_tool.svg) , select a resized export area.
2.   On the context toolbar, select **Revert to auto sized**.

When using the Slice Tool, the following can be used:

*    The **⇧** key (Mac) / **Shift** key (Windows) constrains the area's proportions to a square. 
*    The **⌘** key (Mac) / **Ctrl** key (Windows), if pressed as you drag out a slice area, draws from the center of the original drag position (can be combined with the **⇧** key (Mac) / **Shift** key (Windows).
