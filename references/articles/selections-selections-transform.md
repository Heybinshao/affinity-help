# Moving and transforming pixel selections - Affinity Help Center

3.   Moving and transforming pixel selections

Once a selection has been made, it can be moved and transformed in a variety of ways.

If you have a selection in place, you can move and transform the pixels it encompasses, using the **Move Tool**. Furthermore, with the tool active, the **Transform** panel can also be used for precision working.

If you're looking to reposition a selection, but leave the pixel content untouched, you can use the Marquee tools. However, if you wish to transform your selection while leaving the pixel content untouched, you need to enter the **Quick Mask** mode. Once in this mode, you can resize, reposition, rotate or shear a selection using the Move Tool or Transform panel.

For pixel-accurate selection, the **Force pixel alignment** snapping option will snap pixel selection areas to full pixels when created, moved or modified. If this option is off, selections can occupy partial pixels. If [snapping](https://www.affinity.studio/help/design-aids-snapping/) is active, selection areas can snap to page edges and [guides](https://www.affinity.studio/help/design-aids-guides/) when being created (using the Marquee selection tools) or moved.

1.   With a selection in place, select the **Move Tool**![Image 1](https://images.ctfassets.net/3p2fxa94bzao/3oigj5SSoPtnSw21egHEvD/b6ac975f2be7b3feb8e3e9867b378345/move_tool.svg) .
2.   Resize, reposition, rotate or shear the selection on the page using the displayed handles or, for precision, use the settings on the **Transform panel**. The pixels within the selection will be moved and transformed to match the new selection.

Every time the selection is moved or transformed, new pixels may be included within the new selection area. These new pixels will then be moved and transformed if the above procedure is followed again.

1.   In the Pixel Studio ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/x0qUKV0QmljBpXjlKaAyD/48b1503c7d6cc8f05d91c6af70f31b85/persona_photo.svg) , with a selection in place, select any of the Marquee selection tools ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/1ooe7qXQrJMsHaSPO5hW6P/bb95ad59fe27d96a11e337e59fec3c92/rectangular_marquee_tool.svg) ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/7n4FzMUYzRDRFBUTZF7mhF/9afc976f5178728f63e40e6d1938e43d/elliptical_marquee_tool.svg) ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/3riOFunV682pqAktNFFq2R/93f87d4db6cc10647a6f4f78f9d90074/column_marquee_tool.svg) ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/2smIm7kcATxHnWy39C1swR/de9e37eab9972323b417df7debb1b814/row_marquee_tool.svg)  or the **Freehand Selection Tool**![Image 7](https://images.ctfassets.net/3p2fxa94bzao/5KiRiFTL8vPE9FR1Gf8IxU/63189dd8150a70456d6db61885fdcd6e/free_hand_selection_tool.svg)  .
2.   Drag inside the selection.

1.   In the Pixel Studio ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/x0qUKV0QmljBpXjlKaAyD/48b1503c7d6cc8f05d91c6af70f31b85/persona_photo.svg) , select pixels using any selection tool.
2.   On the **Edit** menu, select **Duplicate > Selection**.
3.   The selected content will be duplicated into a new layer. If content has been selected across multiple layers, the content will be duplicated into multiple separate new layers.

1.    Do one of the following: 
    *   Press **Q**.
    *   On the Toolbar, click **Toggle Quick Mask**![Image 9](https://images.ctfassets.net/3p2fxa94bzao/ihA65j8EK6SuLtjjXIyEr/cff54ac7e6c6dcdf1227f5d9b31db597/mask_all.svg) .
    *   On the **Select** menu, select **Edit Selection as Layer**.

2.   Select the **Move Tool**![Image 10](https://images.ctfassets.net/3p2fxa94bzao/3oigj5SSoPtnSw21egHEvD/b6ac975f2be7b3feb8e3e9867b378345/move_tool.svg) .
3.   Resize, reposition, rotate or shear the selection on the page using the displayed handles or, for precision, use the settings on the Transform panel.
4.   Repeat step one to exit the Quick Mask mode and display the selection as a marquee.

By default, the Quick Mask is presented in the workspace as a translucent, red overlay. The red areas are not included in the selection. For more information on using Quick Mask mode, see [Edit selection as layer using Quick Mask](https://www.affinity.studio/help/selections-edit-selection-as-layer/).
