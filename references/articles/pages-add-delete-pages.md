# Add and remove pages - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/pages-add-delete-pages/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Page layout](https://www.affinity.studio/help/page-layout/)
3.   Add and remove pages

You choose the number of pages when creating a document. Afterwards, use the **Pages** panel to add or remove pages.

Master pages serve as templates for your publication pages. You can add objects—like headers, footers, or background graphics—to a master page and then apply it to multiple publication pages.

Editing a master page instantly updates all pages that use it. If you need a one-off change on a particular page, you can always _override_ the master page's design there.

On the **Pages** panel:

1.    Do one of the following: 
    *   To add pages before or after a specific publication page, select that page's thumbnail.
    *   To add pages at the end of the document, deselect all pages by clicking an empty area of the panel.

2.   Select **Add Pages**![Image 1](https://images.ctfassets.net/3p2fxa94bzao/40E05kD2SYXaUT8gELmImG/eab02af1b558ece3fa633a369815fb94/add_pages.svg) .
3.   On the dialog that appears: 
    1.   Specify the **Number of Pages** to add.
    2.   Confirm where to add pages by setting the page number and choosing whether to insert them **Before** or **After** that page.
    3.   Select a master page to apply to the new pages (or _None_).
    4.   Select **OK**.

Alternatively, drag a master page from the **Master Pages** window and drop it before or after existing publication pages. This adds a new spread with the master's page count, size and design.

![Image 2: Using a master page to create a new spread before an existing one (left) or after an existing one (right).](https://images.ctfassets.net/3p2fxa94bzao/4HhAl3KpvLVbZb2JXhw6Ty/fa4e6aa14d42a88affdf9db5cf94ea61/create_spread_from_master.png)

1.   Select **Add Master**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/6bju7KVEsaDa5JdQ5r9Klm/3942375af19024a82a791a7f116fcec2/add_master_pages.svg)  on the **Pages** panel's **Master Pages** window.
2.   On the dialog that appears: 
    1.   (Optional) Type a **Name** for the master page.
    2.   If the document has facing pages, choose whether the master will have an **Ambidextrous** or a **Facing** page layout.
    3.   Set the master page's **Dimensions** and **Margins** as required.
    4.   Select **OK**.

On the **Pages** panel's **Pages** window:

1.   Select the thumbnails of the unwanted publication pages.
2.   Click **Delete Selected Pages**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/3m8ciDtLqf07Yrma1i0j4x/202c1d508104bbb0a1290c5be7725eae/trash_can.svg) .

On the **Pages** panel's **Master Pages** window:

1.   Select the thumbnail of the unwanted master page.
2.   Click **Delete Selected Master**![Image 5](https://images.ctfassets.net/3p2fxa94bzao/3m8ciDtLqf07Yrma1i0j4x/202c1d508104bbb0a1290c5be7725eae/trash_can.svg) .
