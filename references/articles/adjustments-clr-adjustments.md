# Color adjustments - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/adjustments-clr-adjustments/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Color adjustments

Color adjustments are used to modify the color of all, or a range of pixels within a composition. Depending on the adjustment, the modification can be subtle or extreme.

*   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/3PgOWd2qBooTcJXPAKxsk1/9209748380a579021b8067e31d47a007/black_and_white_adjustment_type.svg) [Black and White](https://www.affinity.studio/help/adjustments-adjustment-black-and-white/)—converts color to grayscale.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/7naXc2XAli5tbNRzWvu9Oe/e3d2764e18c4e873ef9b926ab82711c8/channel_mixer_adjustment_type.svg) [Channel Mixer](https://www.affinity.studio/help/adjustments-adjustment-channel-mixer/)—adjusts the color by modifying individual RGB channels.
*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/2JT4TAWkCB2kDb2H4Y9isT/263d94ba66f2459313c906d06db8cba1/colour_balance_adjustment_type.svg) [Color Balance](https://www.affinity.studio/help/adjustments-adjustment-clr-balance/)—adjusts the contribution of particular colors to a set tonal range.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/4QzExLnigChoVDdpYzksaS/ae91e28f115d20a86580d7bb5547bbb1/gradient_map_adjustment_type.svg) [Gradient Map](https://www.affinity.studio/help/adjustments-adjustment-gradient-map/)—uses the lightness value of pixels to recolor them using a specified gradient.
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/7GOVxSX9cIrGUggVNknZn/6a5d4570ad927da6f562e5cb1d87e97f/hsl_adjustment_type.svg) [HSL](https://www.affinity.studio/help/adjustments-adjustment-hsl/)—shifts the hue, saturation and luminosity values of pixels.
*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/2OU899qUtpe1JQ8FHhpK9K/40bf09548c3af40f2f06eed2057b7522/lense_filter_adjustment_type.svg) [Lens Filter](https://www.affinity.studio/help/adjustments-adjustment-lensfilter/)—emulates the use of a lens filter to tint the color.
*   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/1IAmB3WzvMtiiHpfDyrdsf/cee0135889fca881ce4a91df0af21f6b/ocio_adjustment_type.svg) [OCIO](https://www.affinity.studio/help/adjustments-adjustment-ocio/)—(OpenColorIO only) provides source and destination color space transforms with a valid OpenColorIO configuration.
*   ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/1mXiV5KikL6J52aobotdQu/78e7842efbe23bf13c0f7f6609c704c4/recolour_adjustment_type.svg) [Recolor](https://www.affinity.studio/help/adjustments-adjustment-reclr/)—converts color to monochrome using a specified tint.
*   ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/5pCdcS7eRLCyBYa1OyHpGX/a663142cc3e56cf060fbdd91be42d79c/selective_colour_adjustment_type.svg) [Selective Color](https://www.affinity.studio/help/adjustments-adjustment-selective-clr/)—subtly adjusts the color by modifying individual RGB, CMYK and lightness channels.
*   ![Image 10](https://images.ctfassets.net/3p2fxa94bzao/5IQ8upIORTyEwYCHtVrNw0/1f991e4adba008e294b64e1e03d58365/split_toning_adjustment_type.svg) [Split Toning](https://www.affinity.studio/help/adjustments-adjustment-split-toning/)—tints and recolors highlights and shadows.
*   ![Image 11](https://images.ctfassets.net/3p2fxa94bzao/5TBB2jnG1R2cTXv3FpYWIU/981f5fed72b7c7c91b567422f9fd536a/threshold_adjustment_type.svg) [Threshold](https://www.affinity.studio/help/adjustments-adjustment-threshold/)—converts any object or image into a two-tone, black and white image based on pixel lightness.
*   ![Image 12](https://images.ctfassets.net/3p2fxa94bzao/6GoMPcQS2VYcgXs9OuHYKj/d6b559d9abbe53f8ffe459c5ace6c300/vibrance_adjustment_type.svg) [Vibrance](https://www.affinity.studio/help/adjustments-adjustment-vibrance/)—adjusts the intensity of subtle colors without clipping color tones.
*   ![Image 13](https://images.ctfassets.net/3p2fxa94bzao/7vRaaVeQyacUhpWGE2lyrj/d861bb177f602639bb9f9a1675ca2bef/white_balance_adjustment_type.svg) [White Balance](https://www.affinity.studio/help/adjustments-adjustment-white-balance/)—removes undesirable color casts by adjusting the light temperature.
