3.   Keyboard shortcuts for the Vector Studio

To speed up your workflow, you can use keyboard shortcuts to quickly access features. The shortcuts below relate specifically to working in the Vector Studio—for example, drawing curves, editing curves after they're drawn, and painting with path brushes.

Shortcuts for other areas of the software are linked at the end of this page.

Many shortcuts are the same as those for equivalent features in other apps, and you can [customize them](https://www.affinity.studio/help/workspace-customizing-toolbar/) to suit your way of working.

In the tables below, a blank entry means no shortcut is assigned by default—you can add one in Affinity's settings. _N/A_ means the action is unavailable on the corresponding platform.

For temporary tool use, hold a tool shortcut with the mouse button pressed until you've finished using it.

Where tools share the same shortcut, such as the text tools, you can prevent unwanted toggling between tools. Go to Affinity's **Settings**, select **Tools**, and then enable **Use ⇧ modifier to cycle tools** (Mac) / **Use Shift modifier to cycle tools** (Windows).

These shortcuts modify how new curves are drawn.

| Action | Shortcut (Mac) | Shortcut (Windows) |
| --- | --- | --- |
| Edit line or brush strokes as you draw/paint | **⌘** | **Ctrl** |
| Create a straight line segment as you draw | **⌃**-drag | Drag + right-click |
| Snap a line's control handle to 45° intervals | **⇧**-drag control handle | **Shift**-drag control handle |
| Convert a node to a sharp corner | **⌥**-click | **Alt**-click |
| Convert a node to a sharp corner with mirrored control handle length | **⌥**-dragging | **Alt**-dragging |
| Create a new sharp node | **⇧**-click on any node | **Shift**-click on any node |
| Reposition last drawn node without affecting control handle position (maintains curvature in and out of the node) | **Spacebar**-click, then drag | **Spacebar**-click, then drag |

These shortcuts adjust existing curves and nodes.

| Action | Shortcut (Mac) | Shortcut (Windows) |
| --- | --- | --- |
| Convert to Smooth node | **⌃**-click | Right-click |
| Convert to Sharp node (cusp) | **⌥**-click or double-click off-curve control handle | **Alt**-click or double-click off-curve control handle |
| Cycle between sharp and smooth node types | double-click a node | double-click a node |
| Select previous/next node on a curve | [ and ] respectively | [ and ] respectively |
| Straighten a segment | **⌥**-click a segment | **Alt**-click a segment |
| Delete a segment | **⌃**-click a segment | **Ctrl**-click a segment |
| Delete a node (retaining curve's geometry) | **Backspace** | **Backspace** |
| Delete a node (for 'best-fitting' reshaped curve) | **⌥Backspace** | **Alt**+**Backspace** |
