# Text Styles panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-text-styles-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Text Styles panel

The Text Styles panel lists all the text styles in your document. You can apply apply, modify, and delete styles, and create new ones.

For Mac/Windows: On the **Window** menu, select **Text > Text Styles**.

The panel shows you which styles are applied to your current selection. You can apply paragraph and character styles at the insertion point or to selected text.

You can create new styles, refine existing ones, or delete them.

Furthermore, you can set default text styles and import styles from other projects.

For more information on using text styles, see [Using text styles](https://www.affinity.studio/help/text-text-styles/).

The following options are available on the panel:

*   **Current Formatting**—shows the formatting used on the selected text or at the insertion point. Click the arrow to the left to display overflowing information, if necessary.
*   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/1L27T36bjS1MWWXQ4z6145/ef9f6897cf692c432d33f5768574b1f2/ReapplyTextStyles_white.svg) **Reapply Text Styles**—removes local formatting from the selected text, ensuring it honors the Current Formatting perfectly.
*   **Text Styles list**—shows all the paragraph, character, and group styles in the document. The following details are shown on each entry: 
    *   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/2Z1fGYfMPi7gUNPsxlpsuE/e9b6aca401c04ce90c5e05f5af722665/ParagraphStyle.svg) ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/14s6gBEEfR9KoZKoyZzspq/1607b73812623d25a70f07f6fb3224ef/CharacterStyle.svg) **Type**—specifies whether the text style is a [paragraph, character or group type](https://www.affinity.studio/help/text-text-styles-types/).
    *   **Text style**—displays the name of the text style.
    *   **Keyboard shortcut**—displays the key combination that applies the text style. Nothing is shown if a shortcut is not assigned to the style.
    *   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/2XLuXTwmEh714qaYONrPKP/6d26123960257b3233a3eb084188eda7/moremenuicon.svg) **Options menu**—provides access to a pop-up menu with options to apply, edit, or otherwise manage the text style.

*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/7wiQbD1ibA3vlpml39LXTk/8616d9bcbc07f52bb64dbd92794c76d7/CreateParagraphStyle.svg) **Create Paragraph Style**—launches the **Edit Text Style** dialog ready for [creating a new paragraph style](https://www.affinity.studio/help/text-text-styles-create/).
*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/e9ygXJ48uOLoQPFpYDzBp/3a9f9551e6269447b3aec7630d416980/CreateCharacterStyle.svg) **Create Character Style**—launches the **Edit Text Style** dialog ready for [creating a new character style](https://www.affinity.studio/help/text-text-styles-create/).
*   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/5GILikO6vN1JIy1uVv0efy/3e3309bf5bd7bf421fdf174264861170/CreateGroupStyle.svg) **Create Group Style**—launches the **Edit Text Style** dialog ready for [creating a new group style](https://www.affinity.studio/help/text-text-styles-create/).
*   ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/4VpmZEGkkKhSMFt9KASE4k/88e5a75d1d83895f9c7815f799d7c2de/UpdateParagraphStyle.svg) **Update Paragraph Style**—redefines the current paragraph style to conform with the local formatting of the selected text.
*   ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/5kKiluiIpzqKK4E0ZBXd4o/4c284e1e554eb8ea5eded382b6c4a6ee/UpdateCharacterStyle.svg) **Update Character Style**—redefines the current character style to conform with the local formatting of the selected text.
*   ![Image 10](https://images.ctfassets.net/3p2fxa94bzao/3m8ciDtLqf07Yrma1i0j4x/202c1d508104bbb0a1290c5be7725eae/trash_can.svg) **Delete Style**—removes the selected paragraph or character style from the document and any instances of their application.

![Image 11](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

 The following options are available on the **Panel Preferences** menu:

*   **Show Hierarchical**—styles appear nested below styles which they are **Based on**.
*   **Show Samples**—when selected (default), a style's appearance mirrors what will be seen on the page. If this option is off, styles will all show as plain text.
*   **Sort By Type**—when selected (default), paragraph styles are listed first, followed by character styles. If this option is off, styles are listed purely in alphabetical order.
*   **Delete Unused Styles**—removes unusued text styles from the document.
*   **Detach and Delete All Styles**—when selected, deletes all styles and removes them from the panel.
*   **Save Styles as Default**—when selected, saves styles as default styles.
*   **Import Styles**—when selected, opens a pop-up dialog allowing you to select a style to import.
*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
