3.   Draw lines, curves and shapes

Lines, curves and shapes are easily created using the Pen Tool which operates in several modes that change the way the curve is drawn.

![Image 1: Example of curve drawing](https://images.ctfassets.net/3p2fxa94bzao/1Iv3VWcvGt37fm88YmZUTG/7a6bc96f74ae3346149805f1d0c7df20/drawline_example.png)

The Pen Tool is the go-to drawing tool for most graphic designers. It's multi-functional and versatile so you can draw simple straight lines, Bézier curves, ‘smart’ curves, and straight-edge polygon lines, independently and in combination, all without leaving the tool. Smart curves make it easier to draw curves but limit the flexibility you get from classic Bézier curve drawing; Bézier curve drawing, however, requires patience to master.

1.   Select the **Pen Tool**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/5yh8WdvU7rTqDSqQzwd7ds/3dec05a9bf475b37380b1f79e99125ee/pen_tool.svg) .
2.   On the context toolbar, select a **Mode**:
    *   **Pen Mode**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/5SCWES5nj7i7v5CYh09fON/55f74a43d6e63ed426c7f31952051153/pen_mode.png) —for **Bézier curves** and **polygonal lines**. Click-drag on the page to create repeated nodes that form Bézier curves; repositioning the displayed off-curve control handles at each node defines the shape of the next segment as you lay down nodes. Instead, click repeatedly for polygonal lines.
    *   **Smart Mode**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/5GBJ3hAEklQ9OB7JegR1Mx/ffa029d660ca57f2ba49581c12b758c9/convert_smart.svg) —for **best-fitting curves**. Click repeatedly on the page to lay down each node; a multi-segment curve is created without the need for control handle adjustment.
    *   **Polygon Mode**![Image 5](https://images.ctfassets.net/3p2fxa94bzao/7xL3MYnOxsff1SMhZ0KI4Q/6da01dd27dd8522d65c40e3a6ad83deb/polygon_mode.svg) —for a **polygonal line**. Click repeatedly on the page to lay down each node; a line is created with sharp nodes made up of straight segments.
    *   **Line Mode**![Image 6](https://images.ctfassets.net/3p2fxa94bzao/4UlRc9n52SzJGlsXOu3fEQ/c2d46fe177a4e49270e62191ff9b1863/line_mode.svg) —for a simple **straight line**. Click and drag on the page to create a simple single-segment straight line that self-terminates.

3.   Enable **Use line style**![Image 7](https://images.ctfassets.net/3p2fxa94bzao/6fO8gzxjlWSt51XW7W46Ki/ea5331b1921c1da85958815970e1cd76/fill_stroke.svg)  to use the currently set stroke properties in the **Stroke** panel, or **Use fill**![Image 8](https://images.ctfassets.net/3p2fxa94bzao/XVmIokaRehxGTwCGRU40b/addc7bc4201864a8f25e973bfbb30b88/use_fill_style.svg)  to automatically fill the concave area created by the curve with the current fill color.
4.   To terminate the curve without closing it, press the **P** key or **Esc** key; to continue the still selected curve again by selecting either end node and begin drawing. To close the curve, click on the starting node.

To draw a straight line of a specific rotation and/or length, with a single uncurved line selected using the **Move Tool**, on the **Transform** panel, adjust the **Rotation** and/or **Length** values.

More advanced context toolbar **Settings**

![Image 9](https://images.ctfassets.net/3p2fxa94bzao/7e47FwYJ0eBW8yOWy3elSz/813ccca2419c99817334e5bb65c2a0db/cog_icon_2.svg)

 can be used _in conjunction_ with any one of the four modes. See the [Pen Tool](https://www.affinity.studio/help/tools-tools-pen/) topic.

Before you draw, or once the curve is created, do one of the following:

*   In the Vector Studio![Image 10](https://images.ctfassets.net/3p2fxa94bzao/2Mejuekyv1U5fQVTYLqGud/edc8c0247142081ce0079de3013e815d/persona_vector.svg)  or Layout Studio![Image 11](https://images.ctfassets.net/3p2fxa94bzao/4BbduuJ3zEK1FT2Ohg1aLs/98f305a0ad579187aa758ae37dc956e6/layout_studio.svg) , on the **Stroke** panel, adjust the **Width**.
*   In the Pixel Studio![Image 12](https://images.ctfassets.net/3p2fxa94bzao/x0qUKV0QmljBpXjlKaAyD/48b1503c7d6cc8f05d91c6af70f31b85/persona_photo.svg) , on the Pen Tool context toolbar, click **Stroke properties** to edit **Width**.
*   Use the [ or ] keys (decrease or increase width, respectively) as you draw or edit a curve.

*   When creating the curve with the **Pen Tool**, click on the starting node to join it to the final node and create the shape.

When using the Pen Tool, the following modifier keys can be used to speed up the workflow as you draw:

*   The **⌘** key (Mac) / **Ctrl** key (Windows) temporarily activates the Node Tool for fine curve adjustments.
*   The **⇧** key (Mac) / **Shift** key (Windows) constrains control handles to 45° intervals in Pen Mode. In Smart Mode, node positioning is constrained instead.
*   Pressing the **⌥** key (Mac) / **Alt** key (Windows) then clicking on any node converts it to a sharp corner.
*   Pressing the **⌥** key (Mac) / **Alt** key (Windows) then dragging on any node converts it to a sharp node and mirrors control handle length.
*   Pressing the **⇧** key (Mac) / **Shift** key (Windows) then clicking on any node creates a new sharp node.
*   Pressing the **Spacebar** while clicking and dragging lets you reposition the last drawn node without affecting control handle position which maintains curvature in and out of the node.
*   Click on any node to delete it.

For Pen Tool, Node and shape tools, the following modifier keys can be used as you draw or when editing the object:

*   To decrease or increase stroke width by percentage, use the **[** or **]** keys, respectively. For smaller absolute increments instead, use an additional **⇧** key (Mac) / **Shift** key (Windows) modifier.
