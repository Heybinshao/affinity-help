# Drop caps

Drop caps are enlarged characters at the start of a paragraph. They drop below the first baseline and can give your page more personality and visual impact.

### How to apply drop caps as local formatting

Desktop app

1.   Create an insertion point or select the paragraphs you want to have drop caps.
2.   On the **Paragraph** panel's **Drop Caps** section: 
    1.   Check **Enabled**.
    2.   (Optional) Customize the drop cap's height in lines, distance to text, character style, and other options as required.

The same settings are available when editing a text style. On the dialog's **Paragraph** section, select **Drop Caps**.
