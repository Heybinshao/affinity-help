# Slices panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-slices-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Slices panel

The Slices panel allows you to export defined areas of your design to universally recognized image formats.

For Mac/Windows: On the **Window** menu, select **General > Slices**.

Once an export area has been defined, the **Slices** panel allows you to export the area at various sizes and formats.

The panel can be populated with one or more slices. Each slice possesses a single _export setup_, within which multiple _export formats_ (detailing file format and scaling options) may be stored. In turn, each export format can have multiple _export sizes_. This allows different graphics formats, of different sizes, to be exported from each slice simultaneously.

The following options are available on the panel:

*   **Batch builder**—creates Xcode JSON batches from multiple Apple Universal or Application icon slices. For Xcode UI development only.
*   **Export preset**—presents slice presets offering common graphics formats and options for Apple app icon design.
*   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/4Dgx3sdxShKexodNVwFFB1/6337a1ac75ba1dc844a15ea0a02c18d7/inv-exportcopyconfig.svg) **Copy export setup to clipboard**—copies a selected slice's export setup (including multiple export formats) to clipboard.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/3rQTrOJAwFheiS3LfJcelh/dd8c45ee48a121efe45a823ac1b4a0ca/inv-exportpaste.svg) **Replace export setup from clipboard**—pastes a copied slice's export setup from the clipboard to another selected 'target' slice.
*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/2ubBpBFdZk9S7IiUkCfIZ9/6da44ad73ad4a661d8ecd31e27a4d288/inv-exportpaste-add.svg) **Add Export format from clipboard**—pastes a copied export format selected from a slice's export setup and adds it to another slice's export setup.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/3m8ciDtLqf07Yrma1i0j4x/202c1d508104bbb0a1290c5be7725eae/trash_can.svg) **Delete**—removes the panel item and corresponding export area from the page.
*   **Continuous**—when selected, slices are re-exported automatically if the content within the slices is modified.
*   **Export Slices (****_n_****)**—exports all checked panel items.

The following options are available in the export setup for each slice entry:

*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/6OzchXwZTckX38WSrufHVW/2115fc8391abae5d2297fd948e6b36af/spread.png) **Page**—indicates that the export area is the entire page or all artboards.
*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/4pJ8aeUVvRoNY5R3IT7HJg/8d2e3af5494553207cf0262b5cd63445/Slice_Set.png) **Slice**—indicates an export area drawn with the Slice Tool.
*   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/1oaecsAYk2kaDjZVzXOMpe/c7b46dd53057189716ac89fd41fe98b2/icon_node.svg) **Slice (from item)**—indicates an export area created from an artboard, layer, group or object.
*   **Thumbnail**—visually indicates the area to be exported.
*   **Filename**—displays the name for the export area.
*   ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/9rstenG65qWb7jzhC83X9/df6defa0ca6b00f2d4f82ec5823bffa6/visibility_on.svg)  Active/Inactive—when enabled, the area is exported.
*   ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/4qg755Uvb6Et00LaFyKR9M/f0bad9d640367cf61126810505039704/export_slice.svg)  Export—exports the area represented by the panel item.

You can copy and replace export set up options from one slice to another using **Copy/Replace**.

![Image 10](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

 The following options are available on the **Panel Preferences** menu:

*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.

You can store multiple formats within every slice's export setup. The following options are available for each format:

*   **File format**—select a file format to be exported from the pop-up menu.
*   **Size scaling**—select scaling options (e.g., 1x, 2x, etc.) to set for the export format.
*   **Additional properties**—lets you choose a custom DPI and a path and filename made up of defined tokens or custom user variables.
*   **Export**—exports the slice using this export format.
