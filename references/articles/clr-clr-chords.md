# Color chords - Affinity Help Center

3.   Color chords

A color chord is a spread of harmonious colors which can be used in conjunction with each other to produce appealing designs.

Color chords are created by first choosing a base color and then picking a chord type (built on professional color theory).

![Image 1: Example color chords](https://images.ctfassets.net/3p2fxa94bzao/yPYbU9YvZ9RRAES2qtQTB/b16534c11625dc5cfb7711505b3e8444/colour_chords.png)

Example color chords created by applying different chord types to the base color in the top row.

Chord types are based on the HSL color wheel and include:

*   (A) **Complementary**—the base color and its opposite on the color wheel.
*   (B) **Split Complementary**—the base color and the colors adjacent to its opposite on the color wheel.
*   (C) **Analogous**—the base color and the colors adjacent to it on the color wheel.
*   (D) **Accented Analogic**—as for Analogous but, like Complementary, also includes the base color's opposite.
*   (E) **Triadic**—three colors spaced equally around the color wheel starting from the base color.
*   (F) **Tetradic**—four colors arranged around the color wheel in two complementary color pairs, starting from the base color. Otherwise known as 'Rectangle'.
*   (G) **Square**—four colors spaced equally around the color wheel starting from the base color.
*   (H) **Tints**—colors which vary in lightness from the base color to white.
*   (I) **Shades**—colors which vary in lightness from the base color to black.
*   (J) **Tones**—colors which vary in saturation from the base color to gray.

You'll find a wide range of color theory websites on the Internet.

1.   On the **Swatches** panel, from the category list pop-up menu, select a palette containing the base color.
2.   From the palette, **^(ctrl)**-click (Mac) / **right**-click (Windows) the base color swatch and then select a chord type from the **Create Color Chord** pop-up menu.

1.   (Optional) On the **Swatches** panel, click **Panel Preferences**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/6UxpXBt5miovw347YaOPUz/6f8e3e8d9b379daa0bdc5a3ac6ff23e8/panel_preferences.svg)  and choose an 'Add Palette' option.
2.   Do one of the following on the Color panel: 
    *   With no content selected, select a color from the color model's **Wheel** (HSL only), **Sliders**, or **Boxes**, or click the picked color swatch.
    *   Select page content containing the base color. Remember to select the appropriate color selector on the **Color** or **Swatches** panel.

3.   Click the **Panel Preferences** menu and select a chord type from the **Add Chord to Swatch** pop-up menu.

1.   Select a color from the **Color** panel or select an object on which to base a color chord.
2.   On the **Swatches** panel's **Panel Preferences**, select **Advanced**.
3.   Review the set of color chord types.
4.   Click **Lock**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/52XYdXlyLW1ZAzUYGK6kqf/48bc9cd93adcdbf14804e0cab02cbcf0/lock_layer.svg)  to prevent the colors from changing.
5.   Apply colors to objects from your chosen color chord type.
