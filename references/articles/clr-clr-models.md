# Color models

A screen uses varying amounts of light to create the colors that you see. In the physical world, inks are used to create the color on the page. Color is stored by turning colors into numbers. A color model is used to describe the numerical system used.

As not all devices have the same ability to display color, a color space is used to define the gamut (available range) of color. By working within a color space suitable for the intended output device, you can be confident that your colors will be able to be displayed as intended.

You can use an RGB workflow as default or take advantage of an end-to-end CMYK or Lab color-managed workflow as you create a new document instead.

[](https://www.affinity.studio/help/clr-clr-models/#about-color-models)

## About color models

Different color models represent color as numbers in different ways; you can choose one of four color models.

[](https://www.affinity.studio/help/clr-clr-models/#rgb-model)

### RGB model

The RGB model is an additive color model. The primary colors of light, Red, Green and Blue, are combined in various degrees to make other colors in the spectrum.

![Image 6: model_rgb](https://images.ctfassets.net/3p2fxa94bzao/1BjHHf1taGBJ8YtOFKT6ON/960abd0ed15220b538cea06e0c763296/model_rgb.png)

A representation of the RGB color model. This model is universal within digital cameras and electronic displays.

[](https://www.affinity.studio/help/clr-clr-models/#cmyk-model)

### CMYK model

The CMYK model is a subtractive model. Cyan, Magenta and Yellow are combined to make each color. A fourth ink, Black, is also used for extra control and can be used either on its own for a true black, or combined with the other inks for a rich black.

![Image 7: model_cmyk](https://images.ctfassets.net/3p2fxa94bzao/6aEpQhxg8CArChxIGbgkmO/0d835865ceffa1bddeb5c896b561b901/model_cmyk.png)

A representation of the CMYK color model. When the three colors are combined they make black. Black is also added as a separate color for extra tonal control.

The way that the color model is implemented is defined by the _color space_ that is chosen; this is possible by selecting a color profile.

[](https://www.affinity.studio/help/clr-clr-models/#lab)

### Lab

Lab color represents the theoretical range of human vision using three channels: Lightness (L), and two color channels of opposing values of 'red - green' (a) and 'yellow - blue' (b). It can be very useful when used creatively, especially as Lightness can be adjusted without any change to hue or saturation.

![Image 8: model_lab](https://images.ctfassets.net/3p2fxa94bzao/1o1PkGW3K7WkGauo0S9zAi/36764e1562734078239b5560de7aa3a3/model_lab.png)

A representation of the Lab color opposition model. Lightness (L) is controlled separately to the two color channels (a, b).

[](https://www.affinity.studio/help/clr-clr-models/#how-to-select-a-new-document-s-color-model)

### How to select a new document's color model

Desktop app

*   As you create a new document, select a **Color format** and **Color profile** from the dialog.

The **Color Format** of a document is a combination of a color model and a bit depth setting (8 or 16).

[](https://www.affinity.studio/help/clr-clr-models/#how-to-change-your-document-s-color-format-and-profile-at-any-time)

### How to change your document's color format and profile at any time

Desktop app

1.   On the **Document** menu, select **Setup > Document Setup**.
2.   On the **Color** tab, select a **Color Format** and/or **Color Profile** from the pop-up menu.
3.   Choose to **Assign** or **Convert** color formats/profiles to documents with unassigned or already assigned profiles, respectively.

Affinity converts each color from the old format to the new one—color/pixel values may change as a result.

Use **Convert Format / ICC Profile** and **Assign ICC Profile** directly on the **Document** menu (**Setup** submenu) for easier access if needed.

[](https://www.affinity.studio/help/clr-clr-models/#see-also:)
