# Bitmap fills - Affinity Help Center

3.   Bitmap fills

A bitmap fill consists of a raster image file applied as an object's fill or stroke, repeating in a tiled arrangement.

![Image 1: Gradient and bitmap fill examples](https://images.ctfassets.net/3p2fxa94bzao/8PktyZc9x4jRhcndsfawO/12a32631dd18dba8f8f1f08fe5ae9aff/bitmapPatternExample.png)

The same bitmap fill used at different scales.

A common use of bitmap fills is adding texture to a design.

The following image file formats can be used as bitmap fills: EXR, GIF, HDR, JPEG, JPEG-XL, PNG, TGA, TIFF, and WEBP.

When transforming an object, its bitmap fill (or stroke) can either rescale or remain unaffected.

You can choose whether transforming an object affects its bitmap fill's aspect ratio. This lets the bitmap image and its texture remain unaffected by shrinking or stretching.

![Image 2: Scale with Object](https://images.ctfassets.net/3p2fxa94bzao/40FgFzPbrJTF2PJN3njuk2/e1129f38f5240399fcc7215612cfba23/scale_with_object.png)

A bitmap fill's texture unaffected by stretching a square object.

1.   Use the **Fill Tool**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/4AbVamuwkW3QLOJP3GQiV1/254daa0b4c76a58d6ef299e8068f0519/fill_tool.svg)  to select an object.
2.   Do one of the following: 
    *   Drag a bitmap image file from your operating system's file manager and drop it on any of the following: 
        *   The swatch on the Fill Tool's context toolbar.
        *   The active color selector below the tools, on the **Swatches** panel, or on the **Color** panel.

    *   On the **Assets** panel, click an asset, e.g. a texture or a shape.
    *   On the **Stock** panel, click one of the images from your search results.

3.   Use the context toolbar options and the on-object nodes to modify the bitmap fill as required.

You can also create a bitmap fill using the **Move Tool**. With an object selected, drag the file of choice from Finder (Mac) / File Explorer (Windows) and drop it onto the active color selector below the tools, on the **Swatches** panel, or on the **Color** panel.

1.   Use the **Fill Tool**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/4AbVamuwkW3QLOJP3GQiV1/254daa0b4c76a58d6ef299e8068f0519/fill_tool.svg)  to select an object.
2.   On the context toolbar, set **Context** to _Fill_ or _Stroke_ as needed.
3.   Do one of the following: 
    *   To use an asset: On the **Assets** panel, click the required asset's thumbnail.
    *   To use a stock image: On the **Stock** panel, perform a search and then click the required image in the search results.

4.   Drag to reposition the fill origin, or drag on either axis node to adjust the scaling and rotation of the bitmap. Hold down one finger to constrain the angle to 45°.

1.   Use the **Fill Tool** active to select an object that uses a bitmap fill.
2.   On the context toolbar, do any of the following: 
    *   Click **Rotate** to change the orientation of the fill at 90° counter-clockwise intervals.
    *   Enable **Maintain aspect ratio** to ensure the bitmap fill is not stretched or squashed when edited.
    *   Set the **Extend** and **Quality** options as desired. The former controls how the bitmap is tiled (e.g. wrap, mirror, or repeat). The latter controls how the bitmap fill is resampled on object resize.
    *   Check **Scale with object** to allow for stretching or shrinking of the bitmap fill while resizing. Leave it unchecked to prevent stretching or shrinking, preserving the texture of the image.

1.   Use the **Fill Tool**![Image 5](https://images.ctfassets.net/3p2fxa94bzao/4AbVamuwkW3QLOJP3GQiV1/254daa0b4c76a58d6ef299e8068f0519/fill_tool.svg)  to select an object.
2.   On the context toolbar: 
    1.   Select either 'Stroke' or 'Fill', as appropriate, from the **Context** pop-up menu.
    2.   Do one of the following: 
        *   Set **Type** to _Bitmap_, then navigate to and open the required image.
        *   Drag a bitmap image file from your operating system's file manager and drop it on any of the following: 
            *   The swatch on the Fill Tool's context toolbar.
            *   The active color selector below the tools, on the **Swatches** panel, or on the **Color** panel.

Alternatively, select the Move Tool and then click the color selector that corresponds to the required context (stroke or fill), then drag and drop a bitmap image file onto that selector.
