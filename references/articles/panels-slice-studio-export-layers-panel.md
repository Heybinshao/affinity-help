3.   Export Layers panel (Slice Studio)

The Export Layers panel lets you create slices from entire artboards, layers, groups or selected objects.

For Mac/Windows: On the **Window** menu, select **General > Export Layers**.

The panel lets you target layers, artboards, groups or objects in your project that you want to specifically export. By selecting them, they can be made into slices from the same panel; the Create Slice option generates slices for the Slices panel from which raster images can be exported.

The following options are available on the panel:

*   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/1KcPUU3EDzdqAN6Xh2dvJ0/0e6825b4aaa0ef9b3aca90537a4b106f/export.svg) **Make item visible in export**—when enabled, the item is visible and can be exported. When disabled, the item is hidden and can't be exported.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/3Ta9CN8AjChHBofpcrYQ4T/f074b1c50636738e73fe09807ebc317e/export-on_copy.png) **Make item visible**—when enabled, the item is visible. When disabled, the item is hidden. The item can be exported in both states.
*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/7Mk5jz4pzwPhVhM6CPJAOg/b3d17c0013c768b2e5861e717791947e/edit_all_layers.svg) **Edit within current container**—allows selection of objects across all layers (rather than the current layer).
*   **Create Slice**—creates a slice from the selected artboard, layer, group or object in readiness for export.

For child objects, the visibility options may show as being partly grayed out if the parent object has the corresponding visibility option switched off.

![Image 4](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

 The following options are available on the **Panel Preferences** menu:

*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
