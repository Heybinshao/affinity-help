# Key features - page layout - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/introduction-key-features-pagelayout/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Getting started](https://www.affinity.studio/help/getting-started/)
3.   Key features - page layout

Affinity offers a powerful pro print solution for creating long-form books and magazines, as well as single page print deliverables. For page layouts, the Layout Studio hosts layout tools and core publishing features.

Here's an overview of the layout-related features in Affinity.

*   [Spread Setup](https://www.affinity.studio/help/pages-about-pages/)
    *   [Create multi-page spreads](https://www.affinity.studio/help/pages-multipage-spreads/), e.g. gatefold, trifold, and accordion fold
    *   Mixed spread orientations
    *   Scale content when resizing documents

*   [Master Pages](https://www.affinity.studio/help/pages-master-pages/)
    *   Use master pages to keep recurring layouts in sync
    *   [Edit frame content](https://www.affinity.studio/help/pages-edit-master-page-content/) independently of master page
    *   [Detach text and picture frames](https://www.affinity.studio/help/pages-detach-link-master-pages/) to independently resize/format
    *   [Apply multiple master pages](https://www.affinity.studio/help/pages-apply-master-pages/) per page
    *   Hierarchical master-on-master page support

*   [Merge documents](https://www.affinity.studio/help/advanced-merge-document/)
    *   Import selected pages with index marks, master pages, sections, and text styles

*   [Book creation and management](https://www.affinity.studio/help/advanced-about-books/) (desktop only) 
    *   [Output content](https://www.affinity.studio/help/advanced-outputting-books/) from separate documents as a single publication (book)
    *   [Intelligently update page, list and note numbers](https://www.affinity.studio/help/advanced-updating-numbers/) across book chapters
    *   [Sync text styles, table formats, swatches, and master pages](https://www.affinity.studio/help/advanced-syncing-chapters/) between book chapters 

*   [Artistic Text](https://www.affinity.studio/help/text-art-text/)
    *   Scaleable artistic text that’s perfect for headlines
    *   [Flow artistic text along curves](https://www.affinity.studio/help/text-path-text/), with start/end point control

*   [Text Frames](https://www.affinity.studio/help/text-frame-text/)
    *   Frame text that can flow [between multiple pages and linked frames](https://www.affinity.studio/help/text-linking-text-frames/)
    *   Create text frames that are rectangular, elliptical [or any shape](https://www.affinity.studio/help/text-shape-text/)
    *   [AutoFlow overset text](https://www.affinity.studio/help/text-flowing-text/) across linked frames and pages
    *   [Multi-column support](https://www.affinity.studio/help/text-frame-setup/) with column rules
    *   Control frame insets, gutter widths, and vertical alignment

*   Advanced features 
    *   [Comprehensive formatting](https://www.affinity.studio/help/text-text-styles/) and typesetting options
    *   [Wrap frame text around objects](https://www.affinity.studio/help/text-wrap-text/), with distance control and editable wrap outlines
    *   [Insert placeholder text](https://www.affinity.studio/help/text-filler-text/) that autofills its linked frames

*   [Queue images on a panel](https://www.affinity.studio/help/media-place-images/), then place click-by-click or [autoflow](https://www.affinity.studio/help/media-place-images-autoflow/)
*   [Search for royalty-free stock images](https://www.affinity.studio/help/media-stock-photos/) from Pexels and Pixabay
*   Choose which page to display from placed documents

*   [Tables of Contents (TOCs)](https://www.affinity.studio/help/advanced-toc/)
    *   Generate tables of contents based on applied text styles
    *   Set TOC scope to whole document or a specific section

*   [Index](https://www.affinity.studio/help/advanced-index/)
    *   Generate an index from inserted index marks
    *   Easily add word/phrase instances and cross-references

*   [Notes](https://www.affinity.studio/help/advanced-about-notes/)
    *   Insert footnotes, sidenotes and endnotes
    *   Comprehensive numbering, formatting, positioning and other styling options

*   [Cross-references](https://www.affinity.studio/help/advanced-about-crossrefs/)
    *   Insert cross-references to paragraphs, anchors and index marks
    *   Text can include target metadata, e.g. page number
    *   Automatically hyperlinked for interactive publications
    *   Save custom phrasings for consistent reuse

*   Publication structure 
    *   [Split documents into sections](https://www.affinity.studio/help/pages-adding-sections/) with custom names and page numbering
    *   [Add running headers](https://www.affinity.studio/help/pages-numbering-pages/) to provide a sense of place in a publication
    *   [Hyperlink to web/email addresses](https://www.affinity.studio/help/advanced-hyperlinks/), files, and in-document anchors
    *   [Insert fields](https://www.affinity.studio/help/advanced-fields/) to display document metadata and statistics

*   [Add hyperlinks that target in-document anchors](https://www.affinity.studio/help/advanced-anchors/) and to web/email addresses, and files
*   Automatically hyperlink table of contents (TOC) and index entries
*   [Output PDFs](https://www.affinity.studio/help/sharing-publish-pdffiles/) with bookmarks for TOC entries and anchors

*   Use tools to create [rectangular and elliptical picture frames](https://www.affinity.studio/help/media-picture-frames/)
*   Convert any geometric or pen-drawn shape to a picture frame
*   Intelligent image fitting to frame (Scale to Max/Min Fit)
*   Adjust framing with on-page pan, zoom and rotate controls

*   [Float objects alongside text](https://www.affinity.studio/help/object-control-pinning/) based on their pinned position
*   Position images and other objects inline with text
*   Position by eye or with absolute precision via the Pinning Panel
*   Pinned objects move as text reflows

*   [Present data in tabular form](https://www.affinity.studio/help/tables-create-tables/)
*   [Comprehensive cell formatting](https://www.affinity.studio/help/tables-edit-tables/) and autofit/distribute options
*   Save settings as [reusable table formats](https://www.affinity.studio/help/tables-create-custom-tables/)

*   [Efficiently move around multi-page documents](https://www.affinity.studio/help/pages-navigating-pages/)
*   Instantly switch between [favourite zoom levels](https://www.affinity.studio/help/design-aids-zoom/)
*   See your content cleanly in [Preview Mode](https://www.affinity.studio/help/design-aids-preview-mode/)
*   Ultra-responsive page scrolling

*   [Merge text and image links](https://www.affinity.studio/help/advanced-data-merge/) from XLSX spreadsheet, TSV, CSV, and JSON data sources
*   Merge records one per page (certificates, letters, greetings cards)
*   Merge records into repeating grid layouts (business cards, mailing labels, passes)
*   Fields can actively link to web addresses, email addresses, and file locations

*   [Convert resources from embedded to linked](https://www.affinity.studio/help/media-embedding-vs-linking/) (and vice versa)
*   Linked/embedded placed image policy at document setup
*   [Relink multiple missing 'same folder' images](https://www.affinity.studio/help/media-resource-manager/) in one operation
*   Display placed image or document status
*   [Missing font alert on document load](https://www.affinity.studio/help/text-managing-fonts/) to replace missing fonts
*   [Package fonts and linked images](https://www.affinity.studio/help/sharing-about-packaging/) for project portability
