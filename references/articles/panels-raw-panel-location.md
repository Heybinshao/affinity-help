# Location panel (Develop Studio; Mac only) - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-raw-panel-location/

3.   Location panel (Develop Studio; Mac only)

The Location panel allows you to review and set the GPS metadata of your RAW image.

This feature is only available in Affinity for desktop.

For Mac only: On the **Window** menu, select **Location**.

Raw images from cameras with built-in GPS capability will show the image location on the Location panel. For all other cameras, the image location can be set manually from the panel instead.

The current location's latitude and longitude are listed at the top-left of the panel.

The following options are available on the panel:

*   Click anywhere on the map to set the location of the pin. This information will then be integrated into your image's metadata
*   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/sg4X6Euiey1mW11s0OODi/1e017fed35d90573eaa849a498589226/address.png) **Address**—search for a location using an address.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/2bTG8loNxQ2ZbXEHRTLHSe/495434608dfdd21ee1b90e60f62a86e9/locate.png) **Locate**—sets the pin to your current location (see note below).
*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/YtIstAJxagUs6S0hV3kMs/9be82fc1107efe1926df3622571773f7/scale.png) **Scale guide**—displays the measurements used in the map.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/6iHy0VekZReyEX6LGvnTog/2c1b803d670dc8a8ae0644a183dc4825/compass.png) **Compass**—provides the ability to rotate the map for convenient navigation.
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/49CXmq7CUrfbr0yeA3gjuc/22717f6057b0f27caeca4ab057acb866/mapzoom.png) **Zoom**—provides the ability to zoom in or out of the map.
*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/99T6Axw3uc0bMYqZzHGPd/080231ad2ca100088530604b81c9689f/poi.png) **Points of Interest**—displays landmarks on the map.
*   Map views—sets the type of map shown on the panel. Select from the pop-up menu.

To use the **Locate** option, you must allow Apple's Maps app to find your location. This can be managed in **System Settings > Privacy & Security > Location Services**.

![Image 7](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

 The following options are available on the **Panel Preferences** menu:

*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
