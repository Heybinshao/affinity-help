# Index panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-index-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Index panel

The Index panel allows you to generate and structure an index for your document.

For Mac/Windows: On the **Window** menu, select **References > Index**.

Using the **Index** panel, you can create index topics (and sub topics) and cross-references between them.

You can also insert index marks into document text and connect them to index topics, which means the index will list the index mark's page number under that topic.

After you've added index topics and marks, you can use the panel to generate the index text and insert it into a text frame.

The following options are available on the panel:

*   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/2GmKBYdrnZmTrZlI4AB88/c38aab7d52f247673152b4a01ef6fe26/addIndexTopic.svg) **Add Topic**—adds a new index topic to the panel which can be searched for via right click. Enter a name and specify a parent topic by either typing and selecting from the autocomplete box or by expanding the pop-up menu. **Sort By** allows you to specify an alternative label to sort the topic differently to the displayed name (Topic Name). **See** allows you to create a cross reference.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/2ATQ7T79i1gahgbto1qWnl/3b4481d2d153ee3eea821f86ac458a82/insertIndexMarker.svg) **Insert Marker**—inserts an index mark to your page for the currently searched for text. The index mark is placed at the start of the indexed word. When you insert an index mark, the **Topic** name will be pre-filled with the word at the insertion point. Existing topics that may be similar to the word at the insertion point will also be suggested. Typing in the **Topic** box allows you to search existing topics. You can then select a topic from the suggestion list using either the cursor keys or the mouse. Selecting a sub topic will populate both the topic and the parent. If you are creating a new topic, you may specify either a new or existing **Parent Topic**. **Style Override** allows you to specify a character style to use for the page number when this index mark appears in the index.
*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/4Csq0TONKvChwqOje6T7Ql/62b36e35c441244839867e478d1c66a5/insertIndex.svg) **Insert Index**—inserts a generated index at the insertion point in a text frame.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/79VbGwtBOJyUUlEt6s7u3x/920f4a0dc20b61da7f4693fbba57d94a/update_index.svg) **Update**—refreshes an existing generated index to include newly added index topics/marks.
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/2VEFTlScVWcwuQHs4o1MVV/7c804de336fffaa56ce7bf33d7b948c3/showIndexMarks.svg) **Show/Hide Index Marks**—shows or hides index marks in text on pages.
*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/3m8ciDtLqf07Yrma1i0j4x/202c1d508104bbb0a1290c5be7725eae/trash_can.svg) **Delete**—deletes the selected topic/mark from the panel and on the page.
*   **Options**—affect how the generated index looks. Click to show or hide the following options. Changes you make appear immediately in the document: 
    *   **Language**—by default, the index is sorted in accordance with the language of the paragraph where it is inserted, but you can choose to override this by selecting an index language from the pop-up menu.
    *   **Include section headings**—when checked, the index topics will be divided up into sections based on their initial letter. The initial letter will be placed at the start of each section.
    *   **Group page ranges**—when checked, ranges of three or more consecutive page numbers will be grouped (for example, pages 1,2,3,4 will become 1–4).
    *   **Expand cross references**—when checked, cross references within the generated index will list the page number(s) of the reference target and not the text. If the target topic has sub topics it won't be expanded.
    *   **Labels and Separators**—allow you to customize various pieces of text that may appear within index entries: 
        *   **After Topic**—specify text to display between the topic name and any associated page numbers, e.g. the em space in 'Rice 9, 14, 18, 26'.
        *   **Between Items**—specify text to display between discrete page numbers/ranges, e.g. the commas in 'Wheat 93, 97–102, 104, 195'.
        *   **Between Ranges**—specify text to display between the first and last page numbers in page ranges, e.g. the en dash in 'Barley 132–135, 248'.
        *   **Before References**—specify text to display before an index entry's list of cross references, e.g. the em dash in 'Jasmine—See Rice.'
        *   **See** / **See Also**—specify the text to be used for cross reference labels. **See** text is used when a cross reference has no index marks of its own. **See Also** text is used when a cross reference has additional index marks of its own.
        *   **After See (Also)**—specify text to display between a **See**/**See Also** label and its list of cross-references, e.g. the colon and succeeding space in 'Grains See: Corn, Oats, Rice, Wheat'.
        *   **After References**—specify text to display after an index entry's list of cross references, e.g. the full stop in 'Jasmine—See Rice.'

Each **Labels and Separators** option allows commonly used special characters to be inserted into its text by clicking the arrow at the left of its box and then selecting from a menu. Special characters can also be inserted using your operating system's feature for typing emoji and symbols, or by copying and pasting.

    *   **Index Topic List**—shows added index topic marks. **^(ctrl)**-click (Mac) / **right**-click (Windows) any created index topic to locate a term in the document (select **Find in document**). 
    *   **Search**—lets you filter the topic list by typing a topic name or the start of one.

*   **Topics list**—shows all the topics and sub topics, sorted alphabetically as they'll appear in the generated index. Any topic can be collapsed or expanded using the arrow to the left of its name, which can help to navigate as your index grows. Under each topic is a list of references: all the index marks related to the topic, complete with page numbers and a few words of the surrounding text.

The following options are available from each index topic (and sub topic) in the topics list:

To access these options, **^(ctrl)**-click (Mac) / **right**-click (Windows) on an index topic.

*   **Edit Topic**—allows you to: 
    *   Rename the topic.
    *   Specify the parent topic (if any) that the selected topic falls under.
    *   Enter different text to be used when sorting options for the topic, e.g. to ignore words like “A” and “The” at the start of topic names.

*   **Add sub topic**—allows you to create a new topic that sits under the selected topic.
*   **Add cross reference**—allows you to create a cross reference for the selected topic.
*   **Find in document**—locates the topic and any related sub topics and allows you to jump straight to their location in the document.

![Image 7](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

 The following options are available on the **Panel Preferences** menu:

*   **Show Topics**—sets the topics list to show the index content as a high-level overview. Topic and sub topic names are shown in their hierarchy, but references (page numbers, surrounding text, and index mark positions) and cross-references are hidden.
*   **Show Topics and References**—sets the topics list to show the index context in full detail. Below each topic and sub topic, references and cross-references are listed.
*   **Panels**—opens a dialog which allows quick access to displaying other panels.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
