# Editing panoramas - Affinity Help Center

3.   Editing panoramas

If panorama stitching yields alignment errors or you simply require more control over how each image is stitched, you can further edit the panorama between the initial stitching and the final result.

1.   Create a new panorama following the instructions listed in [Stitching panoramas](https://www.affinity.studio/help/panorama-panorama-stitching/).
2.    When the initial stitching is complete, the panorama will be opened with a selection of tools available. 
3.   To correct alignment, use the **Transform Source Image Tool** and drag the corner handles of stack images to transform them. The center handle can also be dragged to alter the stack image's position.
4.   For more detailed editing, use the **Add to Source Image Mask Tool** to paint in areas that you want to use from the stack's surrounding images. Use the **Erase from Source Image Mask** to remove areas.
5.   Make your edits accordingly, then click **Apply** and the final panorama will be rendered.

When using **Add to Source Image Mask Tool** and **Erase from Source Image Mask Tool**, click on the correct stack image first to select it. Unused areas of a stack image are covered in a transparent overlay.

1.   From tools, select the **Transform Source Image Tool**![Image 7](https://images.ctfassets.net/3p2fxa94bzao/3oigj5SSoPtnSw21egHEvD/b6ac975f2be7b3feb8e3e9867b378345/move_tool.svg) .
2.   Click to select the frame to add reference areas to.
3.   From tools, select the **Add To Source Image Mask Tool**.
4.   Paint over the overlapping areas of individual frames to add reference regions to the currently selected frame.

1.   From tools, select the **Transform Source Image Tool**![Image 8](https://images.ctfassets.net/3p2fxa94bzao/3oigj5SSoPtnSw21egHEvD/b6ac975f2be7b3feb8e3e9867b378345/move_tool.svg) .
2.   Click to select the frame to remove the reference areas from.
3.   From tools, select the **Erase From Source Image Mask Tool**![Image 9](https://images.ctfassets.net/3p2fxa94bzao/1JePHOcZPgb6CwwmJi5c2b/14ccdc5a1fa7208f58fb9d35b264b302/eraser_tool.svg) .
4.   Paint over the areas you'd like to remove.

1.   From tools, select the **Transform Source Image Tool**![Image 10](https://images.ctfassets.net/3p2fxa94bzao/3oigj5SSoPtnSw21egHEvD/b6ac975f2be7b3feb8e3e9867b378345/move_tool.svg) .
