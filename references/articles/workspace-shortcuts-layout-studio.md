3.   Keyboard shortcuts for the Layout Studio

To speed up your workflow, you can use keyboard shortcuts to quickly access features. The shortcuts below relate specifically to working in the Layout Studio—for example, navigating between pages, editing text, and creating custom picture frames.

Shortcuts for other areas of the software are linked at the end of this page.

Many shortcuts are the same as those for equivalent features in other apps, and you can [customize them](https://www.affinity.studio/help/workspace-customizing-toolbar/) to suit your way of working.

In the tables below, a blank entry means no shortcut is assigned by default—you can add one in Affinity's settings. _N/A_ means the action is unavailable on the corresponding platform.

For temporary tool use, hold a tool shortcut with the mouse button pressed until you've finished using it.

Where tools share the same shortcut, such as the text tools, you can prevent unwanted toggling between tools. Go to Affinity's **Settings**, select **Tools**, and then enable **Use ⇧ modifier to cycle tools** (Mac) / **Use Shift modifier to cycle tools** (Windows).
