# Object defaults - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/object-control-object-defaults/

2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Object defaults

Object defaults are stored settings used to configure tools before you use them. They allow new objects—such as shapes, picture frames, artistic text, and frame text—to start with your preferred attributes.

Object defaults help you avoid setting the same fills, strokes, or text formatting every time you create objects.

For example, you might want new text frames to use a specific font family from your brand kit. Or your brand guidelines might specify that new picture frames should usually have a 1pt gray stroke.

Restore defaults to the active tool to make new objects start with them. Existing objects are only updated when you select them and _**revert**_ to saved defaults or _**reset**_ to factory defaults.

Tool settings are grouped into separate attribute categories—such as stroke and fill, artistic text, and frame text. Defaults are stored per attribute category, and saving settings for one category does not change the others.

The commands on the **Edit** menu let you copy, save, restore, or reset the settings used by the active tool.

*   **Synchronize From Selection**—copies the selected object’s attributes into the active tool settings. Those copied values stay in effect until you change the tool settings again.
*   **Save**—stores the current tool settings as defaults for the corresponding attribute category. These defaults are used in new documents and when you use **Revert**.
*   **Revert**—replaces the current tool settings with the saved defaults. If an object is selected, the saved defaults are also applied to the object.
*   **Factory Reset**—restores Affinity's factory defaults to the current document across all attribute categories. If an object is selected, its attributes are also replaced with the factory defaults. To use these defaults in future documents as well, select **Save**afterward.

Use **Synchronize From Selection** when you want to reuse settings from an existing object for new objects. To copy settings from an existing object onto other existing objects, use the **Style Picker Tool**.

Saving defaults affects future objects. Existing objects are changed only when one is selected and you use **Revert** or **Factory Reset**.

If you need to apply different object appearances to existing objects at any time, consider saving them as _**Styles**_ instead of using object defaults.

1.   Select an object with the required attributes.
2.   On the **Edit** menu, select **Defaults >****Synchronize From Selection**.

*   On the **Edit** menu, select **Defaults >****Save**.

The current tool settings become the saved defaults for the corresponding attribute category. These defaults are used in new documents and when you use **Revert**.

*   On the **Edit** menu, select **Defaults >****Revert**.The saved defaults are applied to the active tool. If an object is selected, its attributes are also replaced with the saved defaults.

On the **Edit** menu:

*   To restore factory defaults to the current document, select **Defaults > Factory Reset**.
*   To use the restored factory defaults in future documents as well, select **Defaults > Save**.

When you use **Factory Reset**, attributes of any selected object are also replaced with the factory defaults.
