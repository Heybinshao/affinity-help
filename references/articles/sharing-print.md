# Print - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/sharing-print/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Export, share, and publish](https://www.affinity.studio/help/export-share-publish/)
3.   Print

You can print your document in whole or in part, with options for choosing how output is laid out on paper.

The following layouts are available:

*   Single: your page is printed one per sheet.
*   Tiled: your page can be printed to a large format (e.g., posters, banners, etc.).
*   N-Up: 'gang' prints your page so multiple copies can be printed per sheet.
*   Book: pages are split into sections and then grouped together in readiness for printing. (This option is available when the document is page-based.)
*   Booklet: pages are printed evenly and imposed to allow folding and stapling, e.g. for newsletters and menus. (This option is available when the document is page-based.)

The printout will include all currently visible document content, as controlled on the **Layers** panel.

The **Print** dialog will honor the document's current page setup. Therefore, it is important to check your page setup settings before proceeding to print.

When printing, you may be warned about overflowing text in your publication. To resolve, use the Preflight feature to identify text frames that contain too much text.

You can set whether the document's [**bleed area**](https://www.affinity.studio/help/sharing-bleed/) is included in the printouts.

When exporting, printers marks can be displayed around the page edges. You can choose to display all or just some marks as needed, e.g. you might include crop and registration marks yet exclude page information.

When printing a page-based document containing multiple pages, it's possible to automatically impose your document using book or booklet binding methods. This is available whether you're outputting directly to a printer or to a PDF file. It acts as a 'stepping stone' before sending your publication for physical printing.

Imposition means your pages are flipped and reordered during printing to suit binding methods that combine multiple publication pages on larger sheets. When the sheets are printed, they can be assembled so that publication pages come together in their correct order.

These simple tips will help you get great results:

*   Set up a facing-pages document, i.e. made up of pages arranged across a spine.
*   Ensure your document's page count is divisible by four. Add blank end page(s) if needed.
*   Set up your book/booklet to the expected size of your document, i.e. if you want an A5 newsletter, set the page size to be A5. It's popular to impose this page size (as 2 pages/sheet) onto physical A4 sheets commonly loaded into desktop printers.

Affinity supports all the standard printing options available for your device's operating system along with the following settings:

*   **Actual Size**—the document's current image and canvas size is honored.
*   **Scale to Fit**—the image is temporarily scaled to fill the selected page size with no cropping taking place.
*   **Scale**—the image is printed at the temporary scale set in the adjacent input box.

If you intend on printing to **Actual Size**, we recommend checking your [image](https://www.affinity.studio/help/size-transform-image-size/) and [canvas](https://www.affinity.studio/help/size-transform-canvas-size/) size before proceeding to print.

1.   On the **File** menu, select **Print**.
2.   On the dialog that appears: 
    1.   Make sure the correct printer is selected.
    2.   (Optional) If you're printing a multi-page document and only want to print some pages: Set **Range*** to _Entire document_ (Mac) / _Document_ (Windows) and **Pages** to the page numbers/ranges needed. For example, you can use “1,3,5”, “1-5”, “1,3 4-6” or other combinations. 
    3.   (Optional) If you're printing a document containing artboards and only want to print some artboards: Set **Range*** as needed: 
        *   _Entire document_—All artboards are printed on a single sheet.
        *   _Selection_—Prints just the selected artboard.
        *   _Artboards_—Prints all artboards, each on a separate sheet.
        *   _<Artboard name_>—Prints only the named artboard.

    4.   Adjust other settings as needed.
    5.   Click **Print** (Mac) / **OK** (Windows).

* For Mac: Look in the dialog's **Range and Scale** section.

If the document preview on the dialog shows with a pink overlay, there is a mismatch between your Affinity document dimensions and the printer's currently set paper size.

1.   On the **File** menu, select **Print**.
2.   On the dialog that appears: 
    1.   For best results, set **Fit Type** to _Scale_ and **Scale** to _100%_.
    2.   Near the top of the settings (Mac) / In the **Layout** section (Windows), select the **Paper Size** you're printing on, e.g. A4 if your document pages are A5.
    3.   (Optional) If you're using a duplex printer, set **Double-sided** to: 
        *   **On** / **Flip long side** (Mac / Windows)—for long-edge binding, which is best for portrait documents.
        *   **On (Short Edge)** / **Flip short side** (Mac / Windows)—for short-edge binding, which is best for landscape documents.

    4.   In the **Document Layout** section (Mac) / **Layout** section (Windows), set **Model** to _Booklet_ or _Book_ as needed. This instructs the print process to impose the pages.
    5.   Adjust any other settings as needed.
    6.   Click **Print** (Mac) / **OK** (Windows).

To share the imposed document with others or take advantage of Adobe Acrobat editing features, you can save to PDF instead of printing directly.

*   For Mac: On the dialog's **PDF** pop-up menu, select _Save as PDF_.
*   For Windows: Set the dialog's **Printer** option to _Microsoft Print to PDF_.

1.   On the **File** menu, select **Print**.
2.   On the dialog that appears: 
    1.   In the **Document Layout** section (Mac) / **Layout** section (Windows), set **Model** to _Tiled_ or _N-Up_ as needed.
    2.   Adjust other settings as needed.
    3.   Click **Print** (Mac) / **OK** (Windows).
