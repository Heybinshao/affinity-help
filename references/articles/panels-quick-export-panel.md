You can open the panel as a floating window from the **Window > General** menu.

The **Quick Export** panel allows you to quickly specify your export options without needing to navigate complex settings or open additional dialogs and studios. It provides easy access to the most commonly used export options, along with ready-to-use presets for fast and effortless selection.

In addition to choosing the file type and size, you can specify the file name and export location. This includes the To Canva option, which seamlessly integrates Affinity with Canva, allowing Canva users to edit assets with Affinity’s professional-grade tools and then easily continue designing in Canva.

The following options are available on the dialog:

*   **File format**—allows you to select from most commonly used file formats.
*   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/1LWt5o9khhztKvAR1X7nrl/ef2b377be1fed97fec6fd996a9aee9c1/add_file_format_preset.svg) **Add File format**—click to manage which file format you'd like to appear in the list.
*   **File name**—by default, the file name is inherited from the selected layer, but this can be changed to a different, more suitable one.
*   **Size**—allows you to specify the dimensions of the exported file.
*   **Advanced**—takes you to the main Export dialog where more output options can be specified.
*   Selection area—allows you to select from **Whole Document**, **Selection Area**, or **Selection Only**, as required.
*   Export location—allows you to select from **Ask for Location**, **Alongside Document**, or **To Canva**, as required. Ensure you have saved your document for **Alongside Document**to be available.
*   **Show in Finder** (Mac) / **Show in Explorer** (Windows)—when checked (default), it shows the file in the formerly specified folder. This option applies only if Ask for Location or Alongside Document was selected in the Export location options above.
*   **Show in Browser**—when checked (default), it shows the file in the formerly specified folder in your Canva workspace. This option applies only if To Canva was selected in the Export location options above.
