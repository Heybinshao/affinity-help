#### Vector view mode

Drawn objects are displayed as vectors. This means that, regardless of the current zoom level, objects (and applied effects) are always presented with smooth vector edges and transitions.

[](https://www.affinity.studio/help/design-aids-view-modes/#pixel-view-mode)

#### Pixel view mode

During design, vector objects are presented as if they are constructed from individual pixels. This is an accurate representation of how your design will appear once exported and viewed as an image.

In Affinity's User Interface settings, you can set the default view mode to **Vector**, **Pixel**, or **Automatic**. Automatic opens in Vector view mode for documents with physical measurement units, and Pixel view mode for documents measured in pixels or when opening images.

[](https://www.affinity.studio/help/design-aids-view-modes/#retina-pixel-view-mode)

#### Retina Pixel view mode

As for Pixel mode above, but represents how your design will display on retina and high DPI displays.

[](https://www.affinity.studio/help/design-aids-view-modes/#outline--wireframe--view-mode)

#### Outline (wireframe) view mode

During design, page objects are presented as paths only (with no fills or strokes). All otherwise obscured paths are exposed, and selection behavior changes so grouped objects can immediately be selected just like ungrouped ones. In complex designs, this can be used to more easily target unlocked and locked objects for selection.

[](https://www.affinity.studio/help/design-aids-view-modes/#x-ray--wireframe--view-mode)

#### X-ray (wireframe) view mode

As for Outline view mode, but page objects still display their fills at reduced opacity. On more complex designs, perhaps when zoomed in, this helps to interpret the view better.

[](https://www.affinity.studio/help/design-aids-view-modes/#hairline-view-mode)

#### Hairline view mode

For CAD documents, Hairline mode displays designs as CAD apps would display them. All lines are displayed as thin lines so line weights are ignored, regardless of zoom level.

[](https://www.affinity.studio/help/design-aids-view-modes/#single---split-views)

### Single - split views

You can switch from the default single view to split view to compare any two combinations of view modes.

![Image 11: Views](https://images.ctfassets.net/3p2fxa94bzao/5k78pgdwokMdEbpc5uNDxS/10ca70791dbd887ffb10885f1b70fe28/views.png)

Single and split views. The latter showing a 'Vector - X-ray (wireframe)' view mode comparison.

[](https://www.affinity.studio/help/design-aids-view-modes/#single-view)

#### Single View

Presents the selected mode in isolation on a single page.

[](https://www.affinity.studio/help/design-aids-view-modes/#split-view)

#### Split View

Simultaneously presents two modes side-by-side on the same page, allowing for a visual comparison to be made. A sliding divider can be repositioned to view different areas of the design in either mode. Either view is selectable, allowing you to set different combinations of view modes.

[](https://www.affinity.studio/help/design-aids-view-modes/#view-mode-options)

### View mode options

These are not modes but additional options that can be applied to any view mode.

[](https://www.affinity.studio/help/design-aids-view-modes/#grayscale)

#### Grayscale

This gives the option of viewing your document in grayscale. This is useful when evaluating contrast and dynamic range more easily.

[](https://www.affinity.studio/help/design-aids-view-modes/#hide-effects)

#### Hide Effects

This hides any layer effects applied to your document. It helps to improves performance on more complex documents where extensive layer effects are used.

You can apply different option settings to different sides of a split view.

![Image 12: View mode options](https://images.ctfassets.net/3p2fxa94bzao/V1e9bZxeJZ36TmKtnNLF9/30998f4eed2da23f42d13d23a5b7abbc/viewmodeoptions.png)

Grayscale and Hide Effects view mode options when enabled.

[](https://www.affinity.studio/help/design-aids-view-modes/#how-to-toggle-vector-pixel-view-modes)

### How to toggle vector/pixel view modes

Desktop app

*   On the Toolbar, select a view mode: 
    *   **Vector view mode**  ![Image 13](https://images.ctfassets.net/3p2fxa94bzao/1FXt4CgId9c6cB6pkuLgkO/72468b125cd31b88eb9fb59dec9011a6/native_view_mode.svg)        to display as vectors with smooth vector edges and transitions. This is regardless of the current zoom level.
    *   **Pixels**  ![Image 14](https://images.ctfassets.net/3p2fxa94bzao/1n4pRbyrMjCqUBj05YUCGh/b0af3ab206306e133be4873c26c7872b/pixel_view_mode.svg)       —to display vector designs as individual pixels.

To reveal Wireframe and Retina pixel view mode options, **^(ctrl)**-click (Mac) / **right**-click (Windows) the View Mode control on the Toolbar and select **Advanced**.

[](https://www.affinity.studio/help/design-aids-view-modes/#how-to-display-specific-modes)

### How to display specific modes

Desktop app

*   On the **View** menu, select a view mode from the **Mode** flyout: 
    *   **Pixels**—to display vector designs as individual pixels.
    *   **Pixels (Retina)**—to display vector designs as individual pixels. Use for Retina displays.
    *   **Vector**—to display vector designs natively.
    *   **Wireframe view mode**—to display vector designs in either Outline or X-ray view modes depending on which was last selected via **View > Mode > Wireframe**.
    *   **Hairline**—displays designs as if viewed in CAD apps (stroke/line weights are ignored).

[](https://www.affinity.studio/help/design-aids-view-modes/#how-to-work-in-split-view)

### How to work in Split View

Desktop app

1.   On the **View** menu's **Mode** submenu, select **Split View**.
2.   Click one side of the divider. The divider label displays as black for the selected side (otherwise displayed as gray).
3.   On the **View** menu, select a mode from the **Mode** submenu for the selected view.

[](https://www.affinity.studio/help/design-aids-view-modes/#how-to-enable-or-disable-view-mode-options)

### How to enable or disable view mode options

Desktop app

*   On the **View** menu's **Mode** submenu, enable or disable **Grayscale** or **Hide Effects**.

[](https://www.affinity.studio/help/design-aids-view-modes/#settings)
