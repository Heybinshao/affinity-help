3.   Flooding pixel selections

Using the Flood Select Tool you can define selections of similar pixel color values with a single tap or click.

When using the Flood Select Tool, Affinity will analyze the target pixel and use its color value to create a selection which includes pixels of similar color.

![Image 1: Contiguous](https://images.ctfassets.net/3p2fxa94bzao/KyftJp4jxkD4VtoehkR1G/bfb042c170f257452a2009dd71a1a661/selections_flood_contiguous.jpg)

Difference in selection method with contiguous behaviour on.

![Image 2: Before](https://images.ctfassets.net/3p2fxa94bzao/5DtJ0tLBHtFW8SS1mUof7r/24216b4ca82238e8e99fb12eb46ee97c/selections_flood_before.jpg)

Before pixel area clicked to select a range.

The number of pixels selected is determined by the tool's **Tolerance** setting. The higher the tolerance the more variance allowed between the target and selected pixels. Therefore, a higher tolerance will likely lead to more pixels being included in the selection. This makes selecting an area of similar color and tone effortless.

By default, flood selecting is **contiguous**. This means pixels with similar color values must be adjacent to one another to be selected. Therefore, pixels must be directly connected to the target pixel (or other selected pixels) to be selected. If there is a high contrast edge between areas of similar color, the pixels on the opposite side of the edge will not be selected.

As an alternative, the contiguous behavior can be switched off. This means pixels of similar color to the target pixel will be selected regardless of their position within the image.

![Image 3: Non-contiguous](https://images.ctfassets.net/3p2fxa94bzao/76oyOoCnPGP02wFmkM15z5/fd1cd9bb9527fad00ccaf6fb5cc53bcf/selections_flood_noncontiguous.jpg)

Alternatively, you can subtract or intersect a 'flood selection' from the current selection using the other **Mode** options. For more information on the available selection modes, see [Creating pixel selections](https://www.affinity.studio/help/selections-selections-create/).

*   In the Pixel Studio ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/x0qUKV0QmljBpXjlKaAyD/48b1503c7d6cc8f05d91c6af70f31b85/persona_photo.svg) , with the **Flood Select Tool**![Image 10](https://images.ctfassets.net/3p2fxa94bzao/1MncS2iBwfNnp9EUQ8aaZz/efeeedb28e0a40e53ec50a94dd3d3b4a/magic_wand_tool.svg)  selected, on the context toolbar, ensure the **Contiguous** option is off.

The following modifier keys can be used to aid in the creation of selections:

*    Holding the **⌃(ctrl)** key (Mac) / **Ctrl** key (Windows) temporarily switches the mode to Add. 
*    Holding the **⌥** key (Mac) / **Alt** key (Windows) temporarily switches the mode to Subtract.
