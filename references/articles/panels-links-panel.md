# Links panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-links-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Links panel

The Links panel shows the link attributes for a selected linked layer.

*   On the **Window** menu, select **General > Links**. The **Links** panel is shown when you click the **Is Linked** icon ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/3bJU8ZoVU8zaChbpxAwOs/0adcd3cc25efdd7ab2859ce6496902a1/LayersTabLinkedIcon.png)  on any linked layer on the **Layers** panel.

The panel displays linked layer attributes that differ according to the type of linked layer selected. Any layer type can be a linked layer.

The attributes list is as follows:

*   **Transform***—Sharing the same moving, resizing, rotating and shearing operation between layer content simultaneously. For example, resizing linked shapes in proportion.
*   **Pixel content**—Sharing the same pixels between layers that update simultaneously on editing. For example, making a mask share the same pixel content as another mask.
*   **Blending mode & ranges**—Sharing the same blend mode and tonal blending. For example, swapping out a multiply blend mode for a soft light blend mode en masse amongst composite images.
*   **Opacity & visibility**—Sharing the same opacity level and Show/Hide settings between layers. For example, making multiple semi-transparent text frames that update with opacity changes.
*   **Layer effect parameters**—Sharing the same layer effect settings (shadow, bevel, color overlays). For example, multiple text captions can use a common drop shadow appearance that updates if the effect is modified.
*   **Adjustment parameters**—Sharing the same adjustment layer settings. For example, using the same white balance settings to uniformly 'warm' composited images.
*   **Live filter parameters**—Sharing the same live filter layer settings. For example, using uniform blurs on multiple background composited images.
*   **Vector shape parameters**—Sharing the same geometry between shapes. For example, rounded rectangles update simultaneously when the corner roundness is changed.
*   **Vector fill**—Sharing the same solid or gradient fill. For example, consistent color-to-transparency 'tail-off' radial and linear gradients applied to composited images.
*   **Vector line style**—Sharing the stroke width, color and style. For example, dotted lines on a travel map could change their dot pattern simultaneously.

*Use Link Drop to assign the Transform attribute from already existing linked layer content to unlinked layer content.

The following options are available on the panel:

*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/lxJAbXoDOwE7JL9d2Geak/536114f60cf07a983baa7f2edc479fa6/linkdrop.png) **Link Drop**—relinks the currently selected linked layer's attribute to another layer that is dragged over this target.
*   **Link attributes**— the attributes for the currently selected linked layer (see above).
*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/5MKcLv1phncFOVph8IzYK3/1de85c43ce50bcd6656e956ad12832b8/previous_spread.svg) ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/5Wpr6NGmLTO7Eops8nKscO/36bed17b1c84f01a0d27646355d19d31/next_spread.svg) **Select previous**/**Select next**—click to navigate between linked layers.
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/4MqUkAfvuAFZR4SPQStZDN/70de82d5d511892f681930a2f1cfba7f/unlink_gutters.svg) **Unlink**—click to remove the linked layer's attribute from layer linkage; edits to that attribute can then be made independently of other linked layers.

![Image 6](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

 The following options are available on the **Panel Preferences** menu:

*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
