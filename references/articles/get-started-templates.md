# Document templates - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/get-started-templates/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Getting started](https://www.affinity.studio/help/getting-started/)
3.   Document templates

Templates are predesigned documents from which new documents can be created and then edited.

No templates are shipped with your app by default.

Affinity allows you to create (export) and open document templates, which typically contain placeholder content. Templates have a .aftemplate file extension.

When saving a template, a preferred set of defaults will be saved with it. Text attributes, object properties, stroke/fill color, ruler and column guides, as well as grid setup, and more can be associated with a template.

From the New Document dialog, you can browse, search for, preview and edit existing document templates, as well as set up target template folders.

Template folders establish a 'target' folder in advance of exporting placeholder-rich files to it. It can be useful to store templates in a globally accessible location from which a design/publishing team can access a pool of managed documents.

If the template folder also contains Affinity documents you can treat those documents as templates too.

1.   On the **File** menu, select **New**.
2.   On the Welcome screen, select the **Home** button, and then the **My Templates** tab.
3.   Click **Add template folder**![Image 1](https://images.ctfassets.net/3p2fxa94bzao/665YKq8jcBR3ikEaRtacni/a988199c33634ac644564cddad8df35e/add_item.svg) .

A file browser window will appear, allowing you to specify a folder location.

*   On the **File** menu, select **Export > As Template**.

A pop-up dialog will appear, prompting you to enter a name and choose a location for your template (saved with an .aftemplate file extension). By default, the target template folder you set up previously will be used.

*   On the Welcome screen, select **My Templates**.
*   Double-click on a chosen template thumbnail.

A search bar in the dialog allows you to locate templates.

*   On the Welcome screen, select **My Templates**.
*   **^(ctrl)**-click (Mac) / **right**-click (Windows) a template thumbnail and choose **Edit**.

*   On the Welcome screen, select **My Templates**.
*   Select a folder, then click **Remove template folder**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/3m8ciDtLqf07Yrma1i0j4x/202c1d508104bbb0a1290c5be7725eae/trash_can.svg) .

The **Remove template folder** option won't be visible if the folder is a sub-folder of the top level folder that was added and therefore cannot be removed.
