The Area Tool

 lets you measure the area, total perimeter length or specific segment lengths of an object when you tap on any selected object(s).

1.   In the **Vector Studio**, select the **Area Tool**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/14d6btWBQFGQ47vlLEivq0/a94c8bed5a7352ab690975350b7eb48f/area_tool.svg) .
2.   Select the object or objects you want to measure.
3.   View the **Area**and **Perimeter**readouts on the context toolbar.
4.   To measure multiple objects together, keep them selected while using the tool.
5.   (Optional) Hover over an object’s edge to view perimeter measurements for specific segments.
6.   (Optional) Change the perimeter mode on the context toolbar to measure either full edges or cusped segments.
7.   (Optional) Adjust the drawing scale if you need measurements to reflect a real-world scale.

1.   In the **Vector Studio**, select the **Area Tool**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/14d6btWBQFGQ47vlLEivq0/a94c8bed5a7352ab690975350b7eb48f/area_tool.svg) .
2.   Select the object or artboard you want to measure.
3.   On the context toolbar, set the required **Drawing Scale**.
4.   Check the displayed **Area**and **Perimeter**values.
5.   (Optional) Adjust the scale using a known distance on the selected object.

As well as individual objects, you can measure multiple objects' areas by selecting them. The tool will also calculate object areas with holes in them, without the hole being included in the measurement.

The tool also lets you scale your document by either setting a scale factor (e.g., 1:100, 1cm:1km) or by scaling to a known distance (e.g., 10 meters) on a currently measured object dimension.

Area measurements are not permanently displayed, are non-printable and are not saved with your document.

The following options can be adjusted on the context toolbar:

*   **Drawing Scale**—sets the drawing scale for the document or currently selected artboard. By default, all measurements are made using this scale setting.
*   **Perimeter Mode**—calculates perimeter length, on hover over of any curve segment, using one of two modes: 
    *   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/3zyIW93rBDHAiglcvSbyEW/a5fcc66374ce167a3c9d082c2bb3a991/perimeter_fullEdges.svg) **Full edges**—measurements are based on the entire perimeter length, encompassing all of its segments.
    *   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/1DfjKvROfZ9OSAa4mEiIua/9fef58d989747e60f0eb739280e58b99/perimeter_cuspedSegments.svg) **Cusped segments**—measurements are based on the length of a specific hovered-over straight-line segment (i.e., cusped).

*   **Area**/**Perimeter**/**Including holes** readouts—displays these measurement types for one or more objects when they are selected.

Measurement readouts are displayed for **Area** and **Perimeter**. For one or more previously selected objects, Perimeter lengths can be tapped to include in or exclude from the measurement in either mode.

*   The Area Tool has no keyboard shortcut by default, but one can be assigned via the app's settings.
