# Edit selection as layer using Quick Mask

With Quick Mask enabled, you can review and modify a selection using pixel-editing tools.

![Image 4: Quick Mask](https://images.ctfassets.net/3p2fxa94bzao/5UYEptmxWvg2A0qCW6BWA0/58abf8bbc61cd2c28ae5bd78919bb7dc/quickmask_selection.jpg)

Previewing pixel selection with Quick Mask.

When entering this mode, your selection is temporarily presented as a pixel mask. Pixels can be added or erased using the standard painting and erasing tools.

*   Painting in black will erase areas from the selection.
*   Painting in white will add areas to the selection.
*   Painting in gray will vary the opacity of the selection depending on the tone of gray used.
*   Erased areas are always removed from a selection.

By default, the Quick Mask is presented in the workspace as a translucent red overlay. The red areas are not included in the selection. This default view can be changed to show the masked area as black, white or transparent depending on your preference.

Tools which can be used in conjunction with Quick Mask include, but are not limited to the following:

*   [Erase Brush Tool](https://www.affinity.studio/help/tools-tools-erase-brush/)
*   [Flood Erase Tool](https://www.affinity.studio/help/tools-tools-flood-erase/)
*   [Flood Fill Tool](https://www.affinity.studio/help/tools-tools-flood-fill/)
*   [Fill Tool](https://www.affinity.studio/help/tools-tools-gradient/)
*   [Paint Brush Tool](https://www.affinity.studio/help/tools-tools-paint-brush/)
*   [Paint Mixer Brush](https://www.affinity.studio/help/tools-tools-paint-mixer-brush/)
*   [Pixel Tool](https://www.affinity.studio/help/tools-tools-pixel/)

You can create a new selection from scratch using the painting tools by entering Quick Mask mode without a selection in place.

[](https://www.affinity.studio/help/selections-edit-selection-as-layer/#how-to-edit-a-selection-using-quick-mask-mode)

### How to edit a selection using Quick Mask mode

Desktop app

1.    Do one of the following: 
    *   Press **Q**.
    *   On the Toolbar, click **Quick Mask**  ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/ihA65j8EK6SuLtjjXIyEr/cff54ac7e6c6dcdf1227f5d9b31db597/mask_all.svg)       .
    *   On the **Pixel** menu, select **Pixel Selection > Edit as Layer**.

2.   Click or drag on the page using any pixel-editing tool.
3.   Repeat step one to exit Quick Mask mode and display the selection as a marquee.
4.   (Optional) To create a layer mask using the current selection, from the **Pixel** menu, select **New Mask Layer > Mask Layer**.

Use a hard-edged brush from the **Masking** category of the **Brushes** panel.

[](https://www.affinity.studio/help/selections-edit-selection-as-layer/#how-to-change-quick-mask-view)

### How to change Quick Mask view

Desktop app

*   On the Toolbar, from the **Quick Mask**'s pop-up menu, select an option.
