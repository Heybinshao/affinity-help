3.   Creating master pages

By placing a design element on a master page and then applying that master to other pages, you ensure that all the pages incorporate that element. Of course, each individual page can have its own independent 'foreground' elements.

Master pages can be populated by cutting and pasting content from a publication page to them, and by creating objects directly on them.

The default name assigned to a new master page can be changed to be more meaningful, e.g. 'Master B' could be renamed 'Intro master'.

The Pages panel lists only master pages contained in the current document. If you need to maintain a collection of many master pages, see the "Managing many master pages" topic for a suggested workflow.

1.   On the **Pages** panel, select **Add Master**![Image 1](https://images.ctfassets.net/3p2fxa94bzao/6bju7KVEsaDa5JdQ5r9Klm/3942375af19024a82a791a7f116fcec2/add_master_pages.svg) .
2.    On the dialog that appears: 
    1.   (Optional) Type a **Name** for the master page.
    2.   If the document has facing pages, choose whether the master page will have an **Ambidextrous** or a **Facing** page layout. (Ambidextrous means a page is not specifically a left-hand or right-hand page.)
    3.   Set the **Page Count** for the master.
    4.   If the spread has two or more pages, set the **Spine Location** among them, e.g. you can locate it after the first page in a four-page spread to have the spread only fold outwards to the right.
    5.   Set the master page's **Dimensions** and **Margins** as required.
    6.   Select **OK**.

On the **Pages** panel:

1.   Hold the **⌘** key (Mac) / **Ctrl** key (Windows) and drag a master page's thumbnail to the left or right of another one.
2.   Drop it when a blue line appears at the desired location.

Alternatively, **^(ctrl)**-click (Mac) / **right**-click (Windows) a master page's thumbnail and select **Duplicate** to create a copy immediately after the original.

When copying master pages, be careful not to drop one master onto another, which will apply the former to the latter.
