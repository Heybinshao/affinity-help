The Rounded Rectangle Tool

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/5rfBsCaksbMxMXrrsSl4tj/0fc9d7cc0ef19f3551b1c7c069055f23/rounded_rectangle_tool.svg)

 provides an easy way to create rectangles with rounded corners.

![Image 2: Rounded rectangle default](https://images.ctfassets.net/3p2fxa94bzao/6mjaUH3lIe0SiiTsvL3Bto/d10566f475a98dae2fae419fe38a84cb/shapes_roundedRectangle1.png)

Default shape and handle position (in red) before customization.

The Rounded Rectangle Tool is available by default in all Studios, on the shape tools flyout.

It can be added to your custom Studios. See 'Customizing tools' for details.

The **Rounded Rectangle Tool** has several options on the shape and on the context toolbar to enable the radius of the corners to be controlled.

![Image 3: Rounded rectangle alternatives](https://images.ctfassets.net/3p2fxa94bzao/2l7PLHPkn2WNuEXuSQm18S/54098d1e8e67fff490b29a59b2eb4ad8/shapes_roundedRectangle2.png)

Two possible outcomes when the options are customized.

You can add text inside or along the edges of objects created with this tool and Affinity's other shape tools. See the "Shape text" and "Text on a path" topics for details.

The following options can be adjusted from the context toolbar:

*   **Fill**—click the color swatch to display a pop-up panel to update fill color.
*   **Stroke**—click the color swatch to display a pop-up panel to update stroke color.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/3rYvQ5X8bUYnIRpXvMBBlv/ee8198bb2731db49a0f3ec426d194fb2/stroke_width.svg) **Stroke width**—set a stroke width for the stroke using direct input or slider.
*   ![Image 5: Edit stroke settings](https://images.ctfassets.net/3p2fxa94bzao/LAIAniI5tfK3bknzYOUQB/9af81e28e315cea94436ab657c986f85/stroke.svg) **Edit stroke settings**—click to change stroke style, width, and alignment.
*   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/3r0nypKaA5WwUhRidZ60F7/e75a1a686b28be34e9d4c8e77fc52f00/presets.svg) **Presets**—click to display a pop-up panel from which you may select an existing preset (if any are available) or create a new preset.
*   **Single radius**—when selected (default), allows you to modify all four corners simultaneously by setting one radius. If this option is off, you can set each corner radius individually and change corner type.
*   **Absolute sizes**—by default, the corner radius is specified as a percentage of the object and scales as the object is resized. When selected, this option allows you to specify the corner radius in units. If the object is resized, the corner radius remains the same instead of scaling with the object.
*   **Corner**—sets the style and radius of the rectangle's corners. You can choose a Rounded (fillet) ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/62u4munkFysxR5BisPn386/fb446aca69bbb1eba01b24da755e2a82/RRectRoundTL.svg) , Straight (chamfer) ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/59hsTvQzT8rIgygD67fCAZ/225932612c8a439d2a665c6db22a5b40/RRectStraightTL.svg) , Concave (scallop) ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/2HQCng7OnTvGXnwrHOChfH/261ede2468b4a1fdf00e3591d87ade6e/RRectConcaveTL.svg)  or Cutout ![Image 10](https://images.ctfassets.net/3p2fxa94bzao/ckZHjpzHpC9HnKcXFql5S/5f3e1b268cdb5ad736906b565ac8cbdd/RRectCutoutTL.svg)  option, or None ![Image 11](https://images.ctfassets.net/3p2fxa94bzao/7mMEjQI3j6ZM5SvFSkLCxY/05af2857d6e88e948e9ed9e9e8bd6ad9/RRectNoneTL.svg) . You can also alter the radius of your selected corner type by adjusting the percentage slider or manually entering a new percentage.
*   ![Image 12](https://images.ctfassets.net/3p2fxa94bzao/3TbUr2Rcs8WORkpB9F1k0k/ac87f174562fc2ec8a5e5ceb73693b92/convert_to_curves.svg) **Convert to Curves**—converts the selected object into a series of connected lines and nodes.
*   ![Image 13](https://images.ctfassets.net/3p2fxa94bzao/4VogDhXOgqw0F83jmJq0G8/6909b686388d52610397775cc0bbc4d7/multiple_transform.svg) **Transform Objects Separately**—when selected, where multiple objects are selected, they can be be resized, rotated and sheared independently of each other instead of transforming the bounding box.
*   ![Image 14](https://images.ctfassets.net/3p2fxa94bzao/58wNyMZl0DuNFi96wwd2r6/c8656fa6079dda8976d13873f64e0565/keep_selected.svg) **Keep selected**—when enabled (default), the new shape layer will be selected on creation. When disabled, the new object is deselected which prevents it from adopting the next object’s stroke/fill properties.
*   ![Image 15](https://images.ctfassets.net/3p2fxa94bzao/7e47FwYJ0eBW8yOWy3elSz/813ccca2419c99817334e5bb65c2a0db/cog_icon_2.svg) **Settings**—for general tool settings:
    *   **Enable Transform Origin**—displays a movable transform origin about which the shape can be rotated.
    *   **Hide Selection while Dragging**—when selected, the object's selection box is temporarily hidden when transforming the object. If this option is off, the selection box remains visible during transformation. The selected behavior persists across all objects unless it is manually switched.
    *   **Show Alignment Handles**—when selected, displays alignment handles at the center and edges of the selected object. Hovering over these handles displays a floating guideline across the page. You can drag the handles to position the center or edges of the selected object in line with this guide.

*   To select the Rectangle Tool: 
    *   In the Layout or Vector Studios, press the **M** key.
    *   In Pixel Studio, press the **U** key.

*   To reset any red handle to its default position, double-click it.

Related behaviors can be adjusted from the app's settings:

*   **Tools > Tool Handle Size**
