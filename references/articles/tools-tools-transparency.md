The Transparency Tool

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/4fbN9aRt00bOGUtfLPMili/0403f6742501bc1345c0be3a49e3a546/transparency_tool.svg)

 allows you to apply and edit transparency gradients to vector and text objects.

The Transparency Tool is available by default in the Vector and Layout Studios.

It can be added to other Studios. See 'Customizing tools' for details.

Gradient transparencies are represented by a path that shifts from solid to checkerboard coloring, connected by stops.

The transparency of each stop represents the opacity/transparency value of that point in the gradient, from fully opaque to fully transparent.

The Transparency Tool affects the gradient transparency of an object only—both stroke and fill are affected equally. It has no options for color, as distinct from the [Fill Tool](https://www.affinity.studio/help/tools-tools-gradient/).

Solid transparency can be applied from the **Color** panel or **Swatches** panel using the **Opacity** slider.

The following options can be adjusted on the context toolbar:

*   **Context**—for selected text frames only, the transparency can be applied to the frame **Text** or the **Frame** itself.
*   **Type**—converts the object's transparency type to **None**, **Linear**, **Elliptical**, **Radial**, **Conical**, **Mesh** and **Hash**.
*   Select, pick, and modify the object's gradient transparency—click the swatch to display a pop-up panel. See the [Gradient, bitmap and hatch fills](https://www.affinity.studio/help/clr-gradient-editor/) topic for more information on the settings available.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/55L4Wf8nuqMLfvn64sMJ1r/b2a90b752d4dc14d3b56954753b4b490/fill_-_rotate_gradient.svg) **Rotate**—rotates the applied gradient by 90°.
*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/0Z612ulJ7GvxqlmYLuqya/1b678b199f3a9148bdaefe9182deb1c5/fill_-_reverse_gradient.svg) **Reverse**—the end stops swap places. (All intermediate stops are also repositioned accordingly.)
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/5tfS38S77ouxJcQShz8H8e/3813187e9d1a2d26ec9a567d7112e744/scale.svg) **Maintain aspect ratio**—if this option is off (default), the end stops can be resized separately which changes aspect ratio. When selected, the end stops are locked to keep the aspect ratio (i.e. changing one will automatically update the other). This setting affects only **Elliptical** and **Bitmap** fills.
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/7qMZUu6h9ZvVJMKjwUW61a/35dd726698abf936d4a3f88294fc194d/anchor_to_spread.svg) **Anchor to document**—the transparency gradient's position does not move when the object it is applied to is repositioned.

*   To select the Transparency Tool, press the **Y** key.
