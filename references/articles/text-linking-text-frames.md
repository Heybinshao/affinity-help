3.   Linking text frames

You can flow text through a sequence of text frames by linking them. Linked frames can exist on the same page or across multiple pages.

![Image 1: After](https://images.ctfassets.net/3p2fxa94bzao/PFIIBomlawMm4jQGA67SP/c2c78d99211746fa4832a34eb4d3e2fa/linked_frames_after.jpg)

![Image 2: Before](https://images.ctfassets.net/3p2fxa94bzao/4kHS2jmxBbFXtcnrAiibHW/7801050c8cbe161fe43a289e36afdecd/linked_frames_before.jpg)

There are two basic ways to set up a linked sequence of text frames:

*   Link a sequence of empty frames, then add text to them.
*   Add text to a single frame, then create and link additional frames.

Either way, the imported text automatically flows through the linked frames in sequence.

If the insertion point is in the first or last line of a linked text frame, pressing the up or down arrow key moves the insertion point to the previous or next frame in sequence, respectively.

**Jump lines**, also known as continuation lines, direct the reader of a publication to where frame text continues—often on a different publication page.

To help readers navigate between linked text frames, you can use the **Next Frame** and **Previous Frame** page number fields in jump lines, e.g. "Continued on page 32".

Jump lines created using fields automatically update if the page numbers of the linked frames change.

1.   Select a text frame.
2.   Click the selected frame's 'previous' (top-left) or 'next' (bottom-right) triangular Text Flow button ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/CQBB4K69qIgRdmI3XoEuJ/1a5d8847437af00802b138c49b5898ea/frame_unlinked.png) .
3.    Do one of the following: 
    *   To link to an existing frame, click within that frame.
    *   To link to a new frame, drag on the page to create a frame of the required size.

Connecting lines are shown between linked frames when any of them is selected. Visibility of these lines can be toggled by selecting **Show > Text Flow** on the **View** menu.

If you click a Text Flow button and immediately change your mind about linking or unlinking, press the **Esc** key to cancel.
