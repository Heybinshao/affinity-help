3.   Marquee pixel selections

The marquee selection tools allow you to create selections based on standard geometric shapes, such as ellipses and rectangles.

![Image 1: Selection performed using the Elliptical Marquee Tool.](https://images.ctfassets.net/3p2fxa94bzao/7sFNdeTVmuIoEjOwS4wFWp/6a8c7f15e2b656c94d31c7364ed7fe99/elliptical_marquee.jpg)

A selection performed using the Elliptical Marquee Tool.

There are several marquee tools you can use to create pixel selections:

*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/1ooe7qXQrJMsHaSPO5hW6P/bb95ad59fe27d96a11e337e59fec3c92/rectangular_marquee_tool.svg) **Rectangular Marquee Tool**—creates a rectangular or square selection.
*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/7n4FzMUYzRDRFBUTZF7mhF/9afc976f5178728f63e40e6d1938e43d/elliptical_marquee_tool.svg) **Elliptical Marquee Tool**—creates an elliptical or circular selection.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/3riOFunV682pqAktNFFq2R/93f87d4db6cc10647a6f4f78f9d90074/column_marquee_tool.svg) **Column Marquee Tool**—creates a rectangular selection of the set pixel width which spans the entire image's height.
*   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/2smIm7kcATxHnWy39C1swR/de9e37eab9972323b417df7debb1b814/row_marquee_tool.svg) **Row Marquee Tool**—creates a rectangular selection of the set pixel height which spans the entire image's width.

For pixel-accurate selection, **Force Pixel Alignment** (found on the context toolbar) will snap pixel selection areas to full pixels when created, moved or modified. If this option is off, selections can occupy partial pixels.

Furthermore, if [snapping](https://www.affinity.studio/help/design-aids-snapping/) is active, selection areas can snap to page edges and [guides](https://www.affinity.studio/help/design-aids-guides/) when being created (using the Marquee Selection Tools) or moved.

*   In Pixel Studio, with a marquee selection tool ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/1ooe7qXQrJMsHaSPO5hW6P/bb95ad59fe27d96a11e337e59fec3c92/rectangular_marquee_tool.svg) ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/7n4FzMUYzRDRFBUTZF7mhF/9afc976f5178728f63e40e6d1938e43d/elliptical_marquee_tool.svg) ![Image 8](https://images.ctfassets.net/3p2fxa94bzao/3riOFunV682pqAktNFFq2R/93f87d4db6cc10647a6f4f78f9d90074/column_marquee_tool.svg) ![Image 9](https://images.ctfassets.net/3p2fxa94bzao/2smIm7kcATxHnWy39C1swR/de9e37eab9972323b417df7debb1b814/row_marquee_tool.svg)  selected, drag on your page.

The following shortcuts can be used to aid in the creation of selections:

*   Pressing the **⌘** key (Mac) / **Ctrl** key (Windows) while dragging constrains the drawn selection shape.
*    The **⇧** key (Mac) / **Shift** key (Windows) used while dragging, automatically adds to the current selection. 
*    The **⌥** key (Mac) / **Alt** key (Windows) used while dragging, automatically removes areas from the current selection. 
*    The **Spacebar** repositions a rectangular or elliptical marquee selection as it is being drawn. 
*   Pressing the **⌘** key (Mac) / **Ctrl** key (Windows) while dragging from inside the selected area, allows to move layer with the selection.

*   In Pixel Studio, with the **Column Marquee Tool**![Image 10](https://images.ctfassets.net/3p2fxa94bzao/3riOFunV682pqAktNFFq2R/93f87d4db6cc10647a6f4f78f9d90074/column_marquee_tool.svg)  or **Row Marquee Tool**![Image 11](https://images.ctfassets.net/3p2fxa94bzao/2smIm7kcATxHnWy39C1swR/de9e37eab9972323b417df7debb1b814/row_marquee_tool.svg)  selected, adjust **Width** (context toolbar).

The following shortcuts can be used to aid in the creation of selections:

*   Pressing the **⌘** key (Mac) / **Ctrl** key (Windows) while dragging creates a selection range.
*    The **⇧** key (Mac) / **Shift** key (Windows) used while dragging, automatically adds to the current selection. 
*    The **⌥** key (Mac) / **Alt** key (Windows) used while dragging, automatically removes areas from the current selection.
