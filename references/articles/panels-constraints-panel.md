# Constraints panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-constraints-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Constraints panel

Use the Constraints panel to control how objects are positioned and scaled on different artboards and layout sizes.

The outer box represents the container (parent object). The inner box represents the nested content (child object).

For Mac/Windows: On the **Window** menu, select **Vector > Constraints**.

Constraints help when designing for multiple devices. They save time and maintain accuracy. Objects can respond differently to resizing and transforming.

Use the **Constraints** panel to stop child objects from scaling when the parent object is resized. You can anchor the child object to its parent. Scaling and anchoring can apply to top, bottom, left, or right edges of the child.

The following options are available on the panel:

*   **Anchor lines**—when gray and broken (default), the child object is not anchored in the selected direction. When white and solid, the child object is anchored in the selected direction.
*   **Scaling arrows**—when white and solid (default), the child object will scale in that direction. A gray, broken arrow means it won't scale. A white, broken arrow means scaling is forced due to anchoring on both sides.
*   **Lock**—when highlighted, this indicator shows that the object has its aspect ratio locked, as a result of Min Fit or Max Fit (below) being enabled.
*   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/3mRmlAjx5OGdFFv1UXmp29/9ddae4701b5d40b8ca4c1782ea7a709e/constraints_minfit.png) **Min Fit**—when the parent object is resized disproportionately, the child object may scale so it always fits within its parent object (if unanchored).
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/3OiUfLlzSS1p4qt1p8egHI/8a9e525323b237934a53edfca82e0038/constraints_maxfit.png) **Max Fit**—when the parent object is resized disproportionately, the child object may scale but it will be allowed to be bigger than its scaled parent object, potentially clipping content from view.

![Image 3](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

 The following options are available on the **Panel Preferences** menu:

*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
