# Table panel - Affinity Help Center

3.   Table panel

The Table panel allows you to adjust the formatting of individual tables within your document. Tables are created using the Table Tool.

For Mac/Windows: On the **Window** menu, select **Table > Table**

On the **Table** panel, you can set up the formatting of your table. The Frame section refers to the color and stroke of the whole table, while the Stroke and Fill section refers to only the selected cells.

The following options are available on the panel:

*   **Fill**—sets the fill color of the entire table.
*   **Stroke Color**—sets the stroke color around the entire table.
*   **Stroke Properties**—sets the stroke width and stroke style around the entire table.
*   **Insets**—sets white space padding between table frame and table text.

*   **Cell Stroke Color**—sets the stroke color for the selected cell(s).
*   **Cell Stroke Properties**—sets stroke width and stroke style for the selected cell(s).

*   **Width**—adjusts the selected cell's width.
*   **Height**—adjusts the selected cell's height.
*   **Insets**—sets white space padding between cell edge and text within each selected table cell.

When deselected, they can be adjusted independently.

*   **Rotate 0 degrees**—(default) leaves the selection unrotated. If a selection has previously been rotated, clicking this will revert it to an unrotated state.
*   **Rotate 90 degrees**—rotates the selection 90° clockwise.
*   **Rotate 180 degrees**—rotates the selection 180° clockwise.
*   **Rotate 270 degrees**—rotates the selection 270° clockwise.

*   **Top Align**—sets the cell text alignment to adhere to the top margin.
*   **Center Align**—sets the cell text alignment to be equidistant from the top and bottom margins.
*   **Bottom Align**—sets the cell text alignment to adhere to the bottom margin.
*   **Justify**—sets the cell text alignment to both the top and bottom margins.
*   **Initial Advance**—sets the vertical spacing between the top of the table cell and the first text line's baseline; the distance can be the currently set **Leading**, a **Fixed** value, the font's **Point size** or other typographic values. Use this to ensure consistent spacing on bordered tables, tables on colored backgrounds, or for precise alignment with other elements.
*   **Minimum**—sets a minimum threshold value for initial advance. The value is global, i.e. not tied to any specific Initial Advance setting.

*   **Use Baseline Grid**—ticking this checkbox will enable the baseline grid.
*   **Start Position**—specify the offset of the first grid line from the origin at **Relative To**.
*   **Relative To**—specify what the baseline grid's starting position is in relation to. The Top of Page option is used for facing page spreads arranged vertically, e.g. you can restart the grid from the top of the second page in the spread.
*   **Grid Spacing**—specify how far apart consecutive horizontal grid lines are.
*   **Color**—click on the swatch to display a pop-up panel to set the line color. Drag the slider to set the opacity of the line color.

 The following options are available on the **Panel Preferences** menu:

*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.

See the **Table Formats** panel for details about creating and managing formats you can apply to multiple tables.

The following options are available for sorting the contents of tables:

On the **Text** menu, under **Table > Sort**:

*   **Sort by Row Ascending** / **Sort by Row Descending**—with a table row header selected, sorts the table content based on values in that row. If multiple rows are selected, the topmost row is used.
*   **Sort by Column Ascending** / **Sort by Column Desceending**—with a table column header selected, sorts the table content based on values in that column. If multiple columns are selected, the leftmost column is used.
*   **Sort Options**—opens a dialog where you can choose how table content is sorted: 
    *   **Case Sensitive**—disable if table contents do not require case-sensitive sorting.
    *   **Include Headers**—disable if header content is not to be included in the sorting process.
    *   **Treat Numbers as Text**—when enabled, numbers are not listed first in the sort order.

**Sort Ascending** and **Sort Descending** options are also available by hovering over a column or row heading and clicking the arrow that appears.
