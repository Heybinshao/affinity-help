# Tags panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-tags-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Tags panel

Use the Tags panel to add information to your document that improves the accessibility of exported PDFs and EPUBs.

On the **Window** menu, select **Layout > Tags**.

When you tag an image, you can use its stored XMP metadata as alt text. You can use any of these fields:

*   XMP:Title
*   XMP:Description
*   XMP:Headline
*   XMP:Alt Text (Accessibility)
*   XMP:Extended Description (Accessibility)

These fields are usually added to images using asset management software.

The following options are available on the panel:

*   **Alt Text Source** / **Ext. Description Source**—For an image, select an XMP field to use as its alt text / extended description. For any object, select _Custom_ to provide your own alt text.
*   **Language**—Sets the language of the alt text / extended description. Available when an image contains metadata for multiple languages. Select _None_ to use the image's default, language-independent value.
*   **Alt Text** / **Ext. Description Source—**Displays the alt text / extended description from the selected source, or lets you provide custom text.
*   **Summary Text**—Lets you provide a short description to use as a caption in Reflowable EPUB output, shown with an arrow that readers can click or tap to reveal the extended description. If no summary text is provided, _Description_ is displayed by default.
*   **EPUB Class**—Adds a class to the image in EPUB output so it can be styled with CSS.
*   **Summary Style**—Applies a paragraph style to the summary text.
*   **Description Style**—Applies a paragraph style to the extended description.
*   **Mark as Decoration**—Sets the object as decorative so it's ignored by assistive technologies, such as screen readers.

 The following options are available on the **Panel Preferences** menu:

*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
