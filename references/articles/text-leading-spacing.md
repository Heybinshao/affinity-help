3.   Leading and inter-paragraph spacing

Paragraph spacing is influenced by two methods: leading and inter-paragraph spacing.

Leading is the vertical spacing between lines that make up a paragraph. Inter-paragraph spacing is the spacing between consecutive paragraphs.

Using the latter avoids poor formatting techniques, such as typing additional paragraph breaks to create "padding".

Leading determines the distance from one text baseline—the line on which a line of text appears to sit—to the next.

Using leading is recommended because it can be applied to the entire paragraph and so keeps the paragraph's lines consistently spaced.

Leading Override can be used when some characters need special handling without affecting all lines of their paragraph. For example, some characters set at the same size but in different fonts may appear visually inconsistent.

In new documents, Affinity enables **Use modern leading calculation** on the **Paragraph** panel. It's also available in each text style's properties. This uses a font's actual vertical metrics to honor the designer's intent.

Documents from older Affinity apps stay in the legacy multiplier mode (font size × default multiplier), preserving their original layout until you enable modern leading.

Inter-paragraph spacing allows you to precisely determine the offset between a paragraph and its preceding and successive paragraphs.

On the context toolbar:

1.   On the **Paragraph Leading** setting's menu, select a spacing behavior (**Default**, **Exactly**, **% Height**, **At Least**, or **Multiple**).
2.   Do one of the following: 
    *   To apply a preset spacing value: Select a number on the Paragraph Leading setting's menu.
    *    Click the current value, type a new value (which can include decimals), then press the **⏎** key (Mac) / **Return** key (Windows). 

Leading options are also available when editing a text style. On the dialog's **Paragraph** section, select **Spacing**.

1.   Select the range of text that requires the override.
2.   On the **Character** panel's **Position & Transform** section, adjust **Leading Override**![Image 5](https://images.ctfassets.net/3p2fxa94bzao/4slL7FfHW3qvZxH68ALjai/ab691e8c832ab20f6660e94fe124ea57/char_leading.svg)  as required.

The override will be maintained if words in the affected range become split over multiple lines.

The same settings are available when editing a text style. On the dialog's **Character** section, select **Position & Transform**.

On the **Paragraph** panel's **Spacing** section:

1.   Adjust the **Space Before**![Image 6](https://images.ctfassets.net/3p2fxa94bzao/1hk6BIUndkcTsPFhWeUnfW/ed83a9a4f4ca36115701f30a8b46aae4/before_paragraph.svg)  and **Space After**![Image 7](https://images.ctfassets.net/3p2fxa94bzao/6iuJTV0HIbtLrYhCc2wspw/9f584534ff31da0fd4fc39fdd6866f7a/after_paragraph.svg)  settings as required.
2.   (Optional) Enable **Sum space before and after** and **Space between same styles** as required.

The same settings are available when editing a text style. On the dialog's **Paragraph** section, select **Spacing**.
