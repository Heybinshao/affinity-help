# Managing fonts - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/text-managing-fonts/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Managing fonts

Manage all fonts used in a document in one place. Use the Font Manager to check for missing fonts, review substitutions, and locate text that uses a font.

Affinity's Font Manager manages fonts already used in your document. To install new fonts on your device, refer to your operating system or third-party font manager documentation.

When you open a document that uses fonts not installed on your device, Affinity substitutes alternative fonts.

A pop-up message and the preflight indicator notify you of the issue. To keep the document looking correct, resolve the missing font. Alternatively, you can accept the substitutions.

The **Font Manager** lists fonts used in your document, their status (e.g. missing), and any substitutions.

A font's status will be one of the following:

*   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/2NQ8n3Otir68091EphJfFx/f469dd7e2151a97addfdba4f5febe623/status_ok.svg) **OK**—The font is available on your device and is currently applied to text in your document.
*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/2XNYsY7Vbd2XpXLew2ZD6J/5293b178dd9eafa33ac7f7c24048bfd2/status_missing.svg) **Missing**—The font is not available on your device. For this reason, if you need to open your document on a different device, you should check that the document's fonts are available there.
*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/1Ddu0OMS1hpMeFSbSvSbT5/c2afd02a205615b19cbaa4ede913dacc/singlearrowright.svg) **Unsupported characters used**—The text uses characters that are not supported by the substitute font.

A substitute font is used only temporarily for display. The missing font remains applied—it is still listed in Font Manager with the Missing status. If you install the missing font later, Affinity displays it instead of the substitute font.

You can also choose to replace a font. Substitution is used only temporarily for display while the original font is missing; replacement is a real edit—save the document and the change persists across editing sessions.

If a font is missing or lacks characters, Affinity chooses a substitute font automatically. You can choose a different substitute if you prefer.

On a text tool’s context toolbar, a prefixed character on a font name indicates a problem—for example, _? Roboto_ or _! Roboto_.

*   _?_ indicates a missing font that is substituted for display. The substitute can be confirmed in the Font Manager.
*   _!_ indicates that the font lacks characters required by the selected text. This can occur, for example, when trying different icon fonts or working with mixed-language content that includes unsupported diacritics.

On the **Font Manager** entry for the missing font:

1.   In the **Substitution** column, select an alternative font family.
2.   In the **Substitution Style** column, select a replacement font style, e.g. Bold or Italic.

On the **Font Manager**:

1.   Select the font's entry.
2.   Select **Locate**. 

The document view focuses on text that uses the font, which is automatically selected.

Repeat to cycle through other uses of the font.

On the **Find and Replace** panel:

1.   Next to the **Find** field, select **Formatting**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/7e47FwYJ0eBW8yOWy3elSz/813ccca2419c99817334e5bb65c2a0db/cog_icon_2.svg) , then select **Format**.
2.   On the dialog that appears, select the missing font family (and optionally style, weight, etc), then select **OK**.
3.   Next to the **Replace** field, select **Formatting**![Image 5](https://images.ctfassets.net/3p2fxa94bzao/7e47FwYJ0eBW8yOWy3elSz/813ccca2419c99817334e5bb65c2a0db/cog_icon_2.svg) , then select **Format**.
4.   On the dialog that appears, select the replacement font, then select **OK**.
5.   Select **Find**, then either:
    *   Select **Replace** to inspect matching results and replace them one at a time.
    *   Select **Replace All** to instantly replace all uses of the font.
