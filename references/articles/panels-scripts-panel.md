# Scripts panel - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/panels-scripts-panel/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Scripts panel

The Scripts panel contains all the scripts your AI assistant has generated and saved in Affinity. Click a script to run it on the current document.

For Mac/Windows:

*   On the **Window**menu, select **General > Scripts**.

When you use an AI assistant with Affinity to automate a workflow, it can save the resulting script to the Scripts panel. You do not need to re-prompt the assistant each time.

Each script has an auto-generated name and description. They can be edited if needed.

You can reorder scripts and move them between categories by dragging their entries up or down the list.

The following options are available on the panel:

*   **Category list**—shows your scripts organized by category, e.g. by function or project. For each category, you can:
    *   **Category name**—shows or hides the category's contents when clicked.
    *   **Options menu**—contains options to rename, duplicate, delete, and reorder categories.
    *   **Scripts list**—shows names and descriptions of scripts in the category. Click a script's row to run it. **^(ctrl)-click**(Mac) / **right**-click (Windows) an item to rename or delete it, or edit its description.

ICON The following options are available on category options menus:

*   **Rename New Category**—lets you rename the category.
*   **Duplicate Category**—creates a copy of the category (and all its scripts) on the panel, immediately below the original.
*   **Delete Category**—removes the category (and all its scripts) from the panel.
*   **Move Up**—repositions the category above the previous one, so it is listed higher. (Not available if the category is at the top of the list.)
*   **Move Down**—repositions the category below the next one, so it is listed lower. (Not available if the category is at the bottom of the list.)

ICON The following options are available on the **Panel Preferences** menu:

*   **Create New Category**—adds a new category to the panel.
*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
