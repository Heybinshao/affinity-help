# Embedding vs linking - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/media-embedding-vs-linking/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Page layout](https://www.affinity.studio/help/page-layout/)
3.   Embedding vs linking

When placing content in an Affinity document, you have control over whether files are embedded within the document or linked from their original locations.

![Image 1: Embedding vs linking](https://images.ctfassets.net/3p2fxa94bzao/65itrelXwOs9nKQXvKFmxN/3f53aa742294d118af20985d26eb9dc4/embedded_vs_linking.png)

A copy of the original file is embedded in the document. As a result, there is no means of checking if the original file is modified at a later date. The original file's data is always available to the document, even if the document is moved.

A link is created between the document and the original file to allow the resource to update if the file is modified. The linked file is not stored in the document.

If one or more linked files have been moved or renamed since you last opened your document, you'll be prompted to locate them the next time the document is opened.

It's good practice to keep linked files in a subfolder of your document's folder. This keeps your images in one place for easier management. If you move your document to a new location, the links to its resources' files will be maintained.

Embedding resources means the document is portable at the expense of a greater file size—all the resources are stored in the document. Linked resources give a much smaller document file size.

If the amount of embedded content placed in a document exceeds a specific 'size' threshold, you'll be asked whether to convert it to linked content automatically. If you agree to this, the document's placement policy will also change from **Prefer Embedded** to **Prefer Linked**, so future placed content will be linked by default.

When creating a new document:

1.   Select an **Image placement** policy: 
    *   _Prefer Embedded_—stores the file in your document.
    *   _Prefer Linked_—links to the file in its original location.

You can change the policy at any time via either of the following:

*   **File > Placement Policy**.
*   **Document > Setup > Document Setup**.

Content from a web browser or an app other than your operating system's file manager that's dragged and dropped into Affinity is embedded regardless of your document's placement policy.

1.   On the **Document** menu, select **Resource Manager**.
2.   On the dialog that appears: 
    1.   Select the resource you wish to modify.
    2.   Click **Make Linked** or **Embed** as appropriate.
    3.   (Optional) When making a resource linked, if the original file still exists at its original location, the resource is automatically linked to it. If the original file doesn't exist, navigate to a folder in which to save the file, then click **Link**.

Related behaviors can be adjusted from [the app's settings](https://www.affinity.studio/help/workspace-settings/):

*   **General > Automatically update linked resources when modified externally**
