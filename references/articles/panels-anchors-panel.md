# Anchors panel - Affinity Help Center

3.   Anchors panel

Anchors are used as destinations for hyperlinks in interactive publications, such as PDF and EPUB files. Use the Anchors panel to create, view, and edit anchors in your document.

For Mac/Windows: On the **Window** menu, select **References > Anchors**.

Using the **Anchors** panel, you can:

*   Create a new anchor at a chosen location in text or on an object.
*   Show anchors on all pages or a particular spread.
*   Jump to any anchor in your document.

The following options are available on the panel:

*   **Area**—selects the specific pages (or **All spreads**) whose anchors you want to see on the panel.
*   **Anchors list**—shows entries for each anchor in your document. Each entry shows: 
    *   Name—displays the name(s) of the displayed anchor(s). Select the anchor, then click its name to change it.
    *   ![Image 1](https://images.ctfassets.net/3p2fxa94bzao/1Poe3M93szDoJbr6Yy57jL/4ee88ee4b874bc7715a67b136fbc92b2/PDFBookmark.png) **Export as Bookmark**—when enabled, the anchor is included in PDF and EPUB output.

*   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/66KB5GJTom7TeffN5io0P4/8c85c068ee661c5fdd9f87824744619b/GoToAnchor.svg) **Go to Anchor**—navigates to the selected anchor's location in the document.
*   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/665YKq8jcBR3ikEaRtacni/a988199c33634ac644564cddad8df35e/add_item.svg) **New Anchor**—opens a dialog where you can add an anchor to the selection or at the insertion point.
*   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/3m8ciDtLqf07Yrma1i0j4x/202c1d508104bbb0a1290c5be7725eae/trash_can.svg) **Remove Anchor**—removes the selected anchor from the document.

![Image 5](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

 The following options are available on the **Panel Preferences** menu:

*   **Panels**—opens a dialog where you can quickly set the visibility of all panels in the current Studio.
*   **Close**—hides the current panel.
*   **Close Panel Group**—hides the current panel and any others grouped with it.
