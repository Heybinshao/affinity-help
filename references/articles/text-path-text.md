# Text on a path - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/text-path-text/

2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Text on a path

Path text is a variation of artistic text which follows a line, curve, or outline of a shape.

Applying text to a path lets you create diverse typographical designs.

![Image 1: Text on a path](https://images.ctfassets.net/3p2fxa94bzao/2vjLsZLuY2COXskAbxAZPj/9f0648dfd17e65f1b84e607fc606eda6/pathtext.png)

Before and after conversion to path text (and final design example).

You can create the path using any line, curve, or shape drawn with the line or shape tools. These include, but are not limited to, the [Pen Tool](https://www.affinity.studio/help/tools-tools-pen/), [Pencil Tool](https://www.affinity.studio/help/tools-tools-pencil/), and [Ellipse Tool](https://www.affinity.studio/help/tools-tools-ellipse/).

When a line, curve, or shape is converted to a path to accommodate text, the original object is discarded but its settings are applied to the text path and can be modified via the **Text Frame** panel.

If you wish to retain the original object and edit it independently of the path text, [duplicate](https://www.affinity.studio/help/object-control-duplicate/) it first.

Once path text has been created, you can adjust the start and end handles on the path to expand or restrict the portion on which text flows. The start and end handles are indicated by light green and orange triangles, respectively.

![Image 2: First path start and end handles](https://images.ctfassets.net/3p2fxa94bzao/1BeK8ty5p7sRN3xIDasjzy/a4ee102578dd72ad058152f3b963f3e1/pathtext_section1.png)

If path text extends beyond the start and end handles, it flows onto a second path (below) or wraps around to follow the path in the opposite direction. If this occurs, a second pair of handles appears—dark green and red. These let you adjust text flow on the second path.

Each pair of handles works in the same way.

![Image 3: Second path handles](https://images.ctfassets.net/3p2fxa94bzao/40RQRXVCOhJdJdnZW4QDey/09e7dc38019bd45b3516f551970f749e/pathtext_section2.png)

You can also control the distance between the text and the path (i.e. the baseline) and the direction in which the text flows along the path. Each path section can have a different **Baseline** value.

The path object can be reshaped at any time using the [Node Tool](https://www.affinity.studio/help/tools-tools-node/). If the object was made with a shape tool, you can modify it as if it was still the original geometric shape. When you reshape the object, the text automatically reflows along the new path.

For more information on reshaping a path object, see the [Edit lines, curves and shapes](https://www.affinity.studio/help/curves-shapes-edit-lines-and-shapes/) and [Draw and edit geometric shapes](https://www.affinity.studio/help/curves-shapes-draw-geometric-shapes/) topics.

As you drag path text handles, red perpendicular snapping lines appear. For example, with path text around an ellipse, you can snap to 90° intervals on its circumference and use alignment options to center the text precisely.

![Image 4: Path text snapping](https://images.ctfassets.net/3p2fxa94bzao/2vxelHzmjHRpdWJLO4NSXy/cd5002e62ce8dc28349da70d1013b18e/pathtext_snapping.png)

Any path text extending beyond the end handle of a secondary path is overset text. It is hidden by default, but can be shown, e.g. for editing, by clicking/tapping the adjacent red eye icon.

![Image 5: Hiding path text](https://images.ctfassets.net/3p2fxa94bzao/2mirpqBuiBvSnm5G2rbXQb/b10790340b503810423a3320515d2339/pathtext_hiding.png)

1.   Select a previously drawn line, curve, or shape.
2.   Select the **Artistic Text Tool**![Image 6](https://images.ctfassets.net/3p2fxa94bzao/3II7Q664u7QvdkQOEMJ4QP/d7b8ffe9e49063e8a5419ec5c90e1dac/Artistic_Text_Tool.svg) .
3.   Do one of the following: 
    *   For text running outside a shape or above a line, position the cursor outside (or above) the object's outline, where you'd like text to begin.
    *   For text running inside a shape or below a line (from right to left), position the cursor inside (or below) the object's outline, where you'd like text to begin.

4.   Click when the cursor changes to indicate path text will be created. The line, curve, or shape is converted to a path, and an insertion point is created.
5.   Type, paste, or import your text.

Alternatively, select a previously drawn line, curve, or shape and then, on the **Layer** menu, select **Convert > To Text Path**.

1.   Select the **Artistic Text Tool**![Image 7](https://images.ctfassets.net/3p2fxa94bzao/3II7Q664u7QvdkQOEMJ4QP/d7b8ffe9e49063e8a5419ec5c90e1dac/Artistic_Text_Tool.svg) .
2.   Select the path text.
3.   Drag each path text handle to the required position.

When positioning path text handles, the following modifier keys can be used:

*    The **⇧** key (Mac) / **Shift** key (Windows) constrains the distance between the start and end handles, moving the entire path, both handles and text simultaneously. 
*    The **⌥** key (Mac) / **Alt** key (Windows) ignores snapping points along the path. 
*    The **⌘** key (Mac) / **Ctrl** key (Windows) moves start and end handles symmetrically. 

When resizing a path object, you can control whether:

*   Text remains at its set size and reflows across the path.
*   Text scales as the path is resized.

With the path object selected, do one of the following:

*   To resize height and width independently, drag any of the object's corner or edge handles.
*   To resize height and width proportionally, hold the **⇧** key (Mac) / **Shift** key (Windows) and drag any of the object's corner or edge handles.![Image 8: Reflowing path text](https://images.ctfassets.net/3p2fxa94bzao/2EyPtYIRFaSs1A1LIbfBMe/7d7828a9385916f38545e24092b5e9bf/pathtext_reflow.png) 

*   With the path object selected, drag the object's scale handle (extends from the bottom-right corner of the selection).![Image 9: Scaling path text](https://images.ctfassets.net/3p2fxa94bzao/7dBBbMjwOaNnqaPaE7dLoO/12bec1f717824016c3ad72798d44ce6a/pathtext_scale.png)
