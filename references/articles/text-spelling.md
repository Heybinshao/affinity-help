# Spelling - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/text-spelling/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Spelling

Affinity's built-in spell checker ensures the text in your design contains no spelling mistakes before being published.

There are several ways to interact with the spell checker, including using the **Spelling** dialog or searching for and handling spelling errors directly on the page.

![Image 1: Example of a marked spelling mistake](https://images.ctfassets.net/3p2fxa94bzao/28Qs5s5Jx6Hiw2A2kJNwqv/ee07df6fc41dd839d1a382e5cec63b71/textMarkSpelling.png)

The following options are available on the **Spelling** dialog:

*   Current word—select and type to manually input a suggested correction.
*   Suggestions list—select a word from the list of suggestions to replace the current word.
*   **Change**—substitutes the misspelled word with the current word.
*   **Find Next**—displays the next misspelled word.
*   **Ignore**—ignores all instances of the misspelled word in the current document.
*   **Learn**—adds the current word to the dictionary. The word will be ignored in all documents.
*   **Define**—looks up the current word in the launched dictionary app (Mac only).
*   **Guess**—shows a list of possible alternatives for the current word.

*   On the **Text** menu, select **Spelling** and then select one of the following: 
    *   **Spelling Options**—to open the Spelling dialog, on which you can work through misspellings in the document.
    *   **Check Spelling**—to display and select the next misspelled word.

*   With one of the text tools selected, **^(ctrl)**-click (Mac) / **right**-click (Windows) the misspelled word and select an alternative from the pop-up menu.

You'll also be able to **Ignore Spelling** and **Learn Spelling** (which adds the spelling to the dictionary).

*   With one of the text tools selected, **^(ctrl)**-click (Mac) / **right**-click (Windows) the misspelled word and do one of the following: 
    *   Select **Ignore Spelling** to ignore all instances of the word in the current document. You can also select the word, then select **Spelling > Ignore Misspelled Word** on the **Text** menu. 
    *   Select **Learn Spelling** to add the word to the dictionary. The word will be ignored in all documents.

*   On the **Text** menu, deselect **Spelling > Check Spelling While Typing**.

In Affinity, you can assign a spelling language to all the text contained in a text object, whether that's a text frame, a table, or artistic text.

Shorter text ranges, such as whole paragraphs or individual sentences, can be given their own spelling language. For example, you might use this in a language learning book.

If the spell checker is marking every word, or many of them, as an error, the text object may have an incorrect or missing spelling language.

It's also possible to set a text object or text range to have no spelling language. For example, to suppress errors in the code of a programming book.

The default spelling language applied when you create a text object is also in your control through the use of Affinity's object defaults feature. This can be done for both text frames and tables together, and separately for artistic text.

1.   Do one of the following:
    1.   Select a text frame, a table, or artistic text by using the Move Tool![Image 2](https://images.ctfassets.net/3p2fxa94bzao/3oigj5SSoPtnSw21egHEvD/b6ac975f2be7b3feb8e3e9867b378345/move_tool.svg) .
    2.   Select the text range using the Frame Text Tool ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/1beIzVbPUpjWtvjB9f9uIQ/9643c257468e143cd018b12cb31d9a4a/frame_text_tool.svg) , Table Tool ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/U9027CHEs8YJPz3HslFFN/21c88099e755bed558908ec8f6cbd427/table_text_tool.svg) , or Artistic Text Tool ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/3II7Q664u7QvdkQOEMJ4QP/d7b8ffe9e49063e8a5419ec5c90e1dac/Artistic_Text_Tool.svg) . Drag from the start to the end of the range.

2.   On the **Character** panel, expand the **Language** section and set **Spelling** to the language you need.

1.   Create a new document.
2.   On the **Character** panel, expand the **Language** section.
3.   Create a text frame, then set **Spelling** on the Character panel as needed. (This will also affect tables.)
4.   Create artistic text and set Spelling as needed.
5.   On the **Edit** menu, select **Defaults > Save**.
