You can rotate with more precision using the **Transform** panel.

1.   Select multiple objects or layers, then target a rotated object using one of the following methods: 
    *   ensure the object previously rotated is selected _first_ using **⇧**-click (Mac) / **Shift**-click (Windows) or draw a marquee selection that encompasses it first.
    *   target a rotated object as a key object by **⌥**-clicking (Mac) / **Alt**-clicking (Windows). The selected key object will possess a strong outline.

2.   On the Toolbar, click **Alignment**![Image 9](https://images.ctfassets.net/3p2fxa94bzao/2sBtuXOz6xHeHKSpdRiV0E/52b485eb1e9c69adb61dfee2adefd40f/arrange.svg) , then set the **Make Same** option ![Image 10](https://images.ctfassets.net/3p2fxa94bzao/51BUT9FTqR8X9ufnce1lDH/d37c81b0f94129cd060e72b834cd7f84/match-rotation-mono.svg) , choosing **Rotation**.
3.   Click **Apply**.

1.   Select one or more objects.
2.   Select the **Move Tool**, then on the context toolbar's **Settings**![Image 11](https://images.ctfassets.net/3p2fxa94bzao/7e47FwYJ0eBW8yOWy3elSz/813ccca2419c99817334e5bb65c2a0db/cog_icon_2.svg) , select **Enable Transform Origin**. The origin shows centrally within the selected content.
3.   Drag the origin to a new position in the selected object, another object, or anywhere on the page.

Once you've moved the origin, you can rotate your object(s) about it as described above. If using the **Transform** panel, rotation is about this custom origin unless you choose to override this and use the panel's Anchor point selector instead.

You can snap the origin to the bounding box, center, key points, or the geometry of other objects (or even the same object).

*   Double-click the transform origin.

1.   With the **Move Tool**, select one or more objects or layers.
2.   Position the cursor close to one of the side handles and drag on the page.

You can shear with more precision using the **Transform** panel; this can optionally be about a custom transform origin.

*   Double-click the 'lollipop' rotation handle for undoing rotation only, or at any corner or edge handle when you see the rotation or shear cursor, respectively.

*   The **⇧** key (Mac) / **Shift** key (Windows) constrains rotation to 15° increments.
*   The **⌘** key (Mac) / **Ctrl** key (Windows) shears the opposite edge in the opposite direction by the same value.
*   For Mac: To retain its relative positioning and snapping, you can move an object by its custom transform origin; **^(ctrl)**-click _after_ you start dragging the origin.
*   For Mac: When rotating from an object or selection's corner handle, the **⌃(ctrl)** key temporarily repositions the transform origin to the opposite corner.
*   For Windows: When rotating from an object or selection's corner handle, holding the right mouse button temporarily repositions the transform origin to the opposite corner.
