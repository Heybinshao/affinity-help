# Color Map Mono Layers filter (Astrophotography)

The Color Map Mono Layers filter automatically color maps stacked monochrome astrophotography layers and applies suitable blend modes. It provides a quick way to combine separate channel data into a color image without manually assigning colors and layer interactions.

This feature is only available in Affinity for desktop.

[](https://www.affinity.studio/help/filters-filter-color-map-mono-layers/#about-color-map-mono-layers)

## About Color Map Mono Layers

Color Map Mono Layers is designed for astrophotography workflows where channel data has already been stacked as separate images or FIT files. When the layers are arranged in channel order, the filter automatically applies color mapping and configures blend modes to combine them into a composite color result.

For RGB workflows, arrange the layers in the order **Red**, **Green**, and **Blue**. If a luminosity layer is available, it can also be included in the stack. The filter then assigns the appropriate channel colors and sets blending behaviour based on the document format.

In linear formats such as **RGB/A UF/32-bit**, the layers are combined using linear addition blending. In bounded, non-linear formats such as **RGB/16**, screen blending is used instead. This allows the filter to adapt the result to the working color format automatically.

[](https://www.affinity.studio/help/filters-filter-color-map-mono-layers/#where-to-find-it)

### Where to find it

This filter can be found on the **Pixel > Filters > Astrophotography** menu.

Use **Color Map Mono Layers** when you already have separate stacked channel data and want to assemble a color image quickly without manually setting blend modes for each layer.

[](https://www.affinity.studio/help/filters-filter-color-map-mono-layers/#settings)

### Settings

This filter does not provide adjustable settings in a dialog. Its behaviour is determined by:

*   **Layer order**—layers should be arranged in the order Red, Green, Blue, and Luminosity (if applicable).
*   **Document format**—the filter chooses the blend mode automatically based on whether the document uses a linear or bounded color format.

For best results, ensure the channel layers are aligned and stacked correctly before applying the filter.

[](https://www.affinity.studio/help/filters-filter-color-map-mono-layers/#see-also:)
