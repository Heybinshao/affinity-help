# Pixel selections from channels - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/selections-selections-fromchannels/

2.   [Photo editing](https://www.affinity.studio/help/photo-editing/)
3.   Pixel selections from channels

You can create pixel selections based on a single or combination of channels. This feature is available from the Channels panel.

![Image 1: Selection from channel](https://images.ctfassets.net/3p2fxa94bzao/5XLVEIFxEE0uJ1xOpYxxlF/94abdea15d33fdeabc2b75c3d87dd1df/selection_from_channel.jpg)

Selection created from the image's red channel.

Pixels are selected based on the contribution that the chosen channel makes to its color value. If a channel only contributes partially to a pixel, that partial amount is selected (i.e., where a channel contributes 20% of the color to that pixel, that 20% is selected).

A selection marquee only appears around areas which are selected by more than 50%. Areas selected by 50% or less will not display a marquee at their edges.

*    On the **Channels** panel, **^(ctrl)**-click (Mac) / **right**-click (Windows) any channel and select **Load to Pixel Selection**. 

On the **Channels** panel:

1.   **^(ctrl)**-click (Mac) / **right** (Windows) any channel and select **Load to Pixel Selection**. 
2.   **^(ctrl)**-click (Mac) / **right** (Windows) any other channel and select **Add to Pixel Selection**. 
3.   Repeat step 2, as required for other channels.

Alternatively, you can subtract or intersect a channel from a selection using the other options on the **^(ctrl)**-click (Mac) / **right**-click (Windows) context menu. For more information on the available selection modes, see [Creating pixel selections](https://www.affinity.studio/help/selections-selections-create/).

1.   On the **Layers** panel, select a layer.
2.    In the **Channels** panel: 
3.   **^(ctrl)**-click (Mac) / **right**-click (Windows) a channel named after the selected layer (e.g. Background Red) and select **Create Spare Channel**
4.   **^(ctrl)**-click (Mac) / **right**-click (Windows) the newly created spare channel and select **Load to Pixel Selection**. 

*    With a pixel selection in place, **^(ctrl)**-click (Mac) / **right**-click (Windows) the 'Pixel Selection' entry and select **Create Spare Channel**. 

The selection is stored at the bottom of the Channels panel as a new Spare Channel entry.

*    On the **Channels** panel, **^(ctrl)**-click (Mac) / **right**-click (Windows) the Pixel Selection layer's channel, then click Invert ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/3oFuDFWu0y1VuALmR2VZIm/f04b279224a0dd2b56f9748955431ca9/channel_invert.svg)  from the pop-up menu.
