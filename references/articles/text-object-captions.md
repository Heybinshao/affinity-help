# Object captions - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/text-object-captions/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Object captions

You can add a caption to an object, such as a shape, placed image, picture frame, or table, to describe or explain the content. Affinity creates a text frame at your chosen side and distance from the object, which stays attached as you edit.

![Image 1: Image with its caption positioned to the left in a page layout](https://images.ctfassets.net/3p2fxa94bzao/31mknfmzkG9URuvxsGG4Gu/b245069b0c50ba480b24c7d8ee7321ac/objectCaptions.png)

An object caption can be positioned on any edge and formatted using a paragraph style.

Captions can automatically be sequentially numbered (or lettered) and used as cross-reference targets elsewhere in your document text, such as pointing the reader to a figure or table.

Caption text can include standard and special characters. It can also include fields, such as counters for automatic figure numbering—e.g. Figure 1, Figure 2, and so on.

Fields can also display metadata, including an image's color profile, color space, alt text, and extended description.

You can choose which of an object's four sides a caption is shown on. The caption will be positioned along the outside of that edge. The position can be customized with horizontal and vertical offset values.

A caption's text frame can be rotated manually. This allows you to change the direction of text flow—for example, from bottom to top on a left-side caption.

Normally, a caption text frame is tethered to its object, meaning it moves/resizes with it. Moving, resizing, or rotating a caption text frame will untether it, so it will no longer move with the object.

Affinity provides _Figure_ and _Table_ counters in each document. You can add your own named counters as needed, and choose the characters used by each counter, e.g. _1, 2, 3, 4…_ or _A, B, C, D…_.

Counter values are determined by layer order on the Layers panel, not by object positions on the page. The lowest captioned object is numbered first, and values increase upward in the stack.

You can apply a paragraph style to a caption to give it your desired appearance—font family, font size, decorations, and all the usual visual settings that paragraph styles allow.

For example, you can use a paragraph style's Alignment property to center or right-align captions within their frame.

1.   Select the object.
2.   On the **Layer** menu, select **Add Caption**.
3.   On the dialog that appears:
    *   Type your caption text in the **Caption**box.
    *   Set **Alignment**to the side of the object on which the caption should be displayed. Select from _Above Object_, _Below Object_, _Left of Object_, and _Right of Object_.
    *   (Optional) Click the downward arrow in the **Caption**box to insert fields or metadata (if the object is an image).
    *   (Optional) Select the **Counter Type**—or create a new one—that the object belongs to for numbering purposes.
    *   (Optional) Set **Horizontal Offset**and **Vertical Offset**to the distances you want the caption to be positioned from its object.

Although it's possible to apply text styles and local formatting directly to a caption on the page, this is not equivalent to applying a paragraph style via the dialog, and may result in a loss of formatting if you intermix both methods.

1.   Select a captioned object.
2.   On the **Layer**menu, select **Edit Caption**.

You can also edit an existing caption's text and paragraph style directly on the page.

When adding or editing a caption:

1.   In the **Caption**box:
    1.   Create an insertion point.
    2.   Click the downward arrow, then select a field 1, e.g. _Caption Counter_ or _Alt Text_.

2.   (Optional) If you inserted a caption counter, select the required **Counter Type**, e.g. _Figure_ or _Table_.

1 Fields are shown with chevrons around their names.

When adding or editing a caption:

1.   Click **Counter Types**, ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/5zWAd2dqBX9xxThhCAljcd/6d16d802c3f109ac744342e7347d51eb/listbullet.svg)  then select **New Type**.
2.   On the dialog that appears, type a name for the counter, then select **OK**.
3.   Set **Format**to the characters to use for object/caption numbering, e.g. _1, 2, 3, 4…_ or _a, b, c, d…_.
4.   (Optional) If you want the counter to reset at the object whose caption you're editing, enable **Restart numbering**.

When adding or editing a caption:

1.   Set **Alignment**to the side of the object on which the caption should be displayed. Select from _Above Object_, _Below Object_, _Left of Object_, and _Right of Object_.
2.   Set **Horizontal Offset**and **Vertical Offset**to the distances you want the caption to be positioned from its object.

The caption's text frame will match the width or height of its object.

When adding or editing a caption:

*   From the **Paragraph Style**menu, select the required style.

You can also select the caption text frame and apply a paragraph style directly on the page.
