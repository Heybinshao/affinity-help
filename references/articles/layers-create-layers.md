# Creating layers - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/layers-create-layers/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Creating layers

You can create layers to help organize your design.

Do one of the following:

*   On the **Layers** panel, click **Container Layer**![Image 1](https://images.ctfassets.net/3p2fxa94bzao/1spd7cWUc4OJw0BrJfmq22/fb5b386d6dde2ceb509bbde9b50c19ab/add_layer.svg) .
*   On the **Vector** menu, select **New Container Layer**.

The layer will be positioned in the layer stack _directly above_ the selected layer or _at the top_ of the layer stack if no layers are selected.

*   On the **Layers** panel, drag one layer over another layer's name and drop to make it a child layer.

Do one of the following:

*    On the **Layers** panel, **⌥**-click (Mac) / **Alt**-click (Windows) **Container Layer**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/1spd7cWUc4OJw0BrJfmq22/fb5b386d6dde2ceb509bbde9b50c19ab/add_layer.svg) . 
*   **⌃(ctrl)**-click (Mac) / **right**-click (Windows) the selected object and choose **Move Selection to New Layer**. 

Do one of the following:

*    In Pixel Studio![Image 3](https://images.ctfassets.net/3p2fxa94bzao/x0qUKV0QmljBpXjlKaAyD/48b1503c7d6cc8f05d91c6af70f31b85/persona_photo.svg) , paint with the **Paint Brush Tool** or other brush tool. The new pixel layer will contain the brush stroke.
*   On the **Layers** panel, click **Pixel Layer**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/2tb2Y3kgsXSew9BPP8NUN1/278302d8ad7b533abc80d931474e9069/add_pixel_layer.svg) . The layer will be placed directly above any selected layer or at the top of your layer stack if no layer is selected.

Do one of the following:

*   With the **Move Tool** enabled, **⌘**-drag (Mac) / **Ctrl**-drag (Windows) the selected object or layer content on the page.
*   For Mac: **⌥**-drag the selected item up or down in the layer stack.
*   For Windows: **Alt**-drag the selected item up or down in the layer stack.
*   With a pixel selection area in place, from the top menu, select **Edit >****Duplicate > Selection**.
*   With an object or layer selected, from the the top menu, select: 
    *   **Edit > Duplicate > Layer**.
    *   **Edit > Copy**, then **Edit > Paste**.

The last option can also be performed between documents.

You can duplicate an object to another 'floating' document by dragging and dropping its layer onto the target's document view.
