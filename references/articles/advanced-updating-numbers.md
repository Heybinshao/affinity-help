# Updating page, list and note numbers - Affinity Help Center

3.   Updating page, list and note numbers

On the Books panel, you can make a chapter continue numbering or start at a number you choose.

This feature is only available in Affinity for desktop.

This topic covers numbering in multi-chapter books. For adding page number fields to a document, see the Fields topic. For adding a table of contents to a document, see the Table of contents topic.

You can also update the numbering of lists and endnotes so they continue across chapters.

When a chapter is added to a book, its page numbering continues from the preceding chapter by default.

Any chapter's numbering can be set to start at a number of your choice. For example, after a book's front matter, which may be numbered using lower-case Roman numerals, the first proper chapter would start at page 1.

Page numbering is recalculated only when chapters are updated via the Books panel. If editing a chapter document changes its number of pages, use the Books panel to ensure correct page numbering throughout your book.

If a list is **Global** and **Restart Numbering** is _Manual Only_, item numbers continue from earlier lists. You set this on the **Paragraph** panel, in the **Bullets and Numbering** section.

On the Books panel, you can make these lists continue numbering from earlier chapters.

If endnotes are placed at the end of the book, their numbering continues across chapters. To do this, set **Restart every** to _Book_ on the **Notes** panel, in the **Positioning** section.

For example, if the first chapter's endnote bodies are numbered from 1 to 4, the second chapter's would then continue at 5, and so on.

When you export or print a book, Affinity updates the page, list and note numbers automatically.

Numbering updates as you edit—for example, when you add or remove chapters or pages. You can choose to repaginate manually if you prefer.

While editing, numbering of global lists and end-of-book endnotes updates only when you ask for it.

On the **Books** panel's **Panel Preferences** menu

![Image 1](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

:

1.   Hover over **Update Numbers**.
2.   Confirm the state of **Update Page Numbers Automatically**: 
    *   If checked, page numbers will update automatically.
    *   If unchecked, you'll need to update page numbers manually when required.

3.   (Optional) Select the option to change it, if needed.

On the **Books** panel's **Panel Preferences** menu

![Image 2](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg)

:

1.   Hover over **Update Numbers**.
2.   Confirm the state of **Update Numbers Before Output**: 
    *   If checked, all numbers will update automatically when you print or export the book.
    *   If unchecked, you'll need to update all numbers manually when you print or export, if required.

3.   (Optional) Select the option to change it, if needed.

On the **Books** panel:

1.   Select the chapters whose numbering you want to update.
2.   On the **Panel Preferences** menu ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/6xHYQYa3ePyLnNbDC3c5Ey/56d26d75e40a2d195e578a41b2b16612/panel_preferences.svg) , hover over **Update Numbers**.
3.   Select the option for the numbers you want to update: **Page Numbers**, **List Numbers**, **Note Numbers** or **All Numbers**.
