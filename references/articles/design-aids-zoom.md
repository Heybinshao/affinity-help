# Zooming - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/design-aids-zoom/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Design fundamentals](https://www.affinity.studio/help/design-fundamentals/)
3.   Zooming

Zooming into areas of your document is an essential part of the editing and design process. Several zooming options are possible.

*   While using your design tool, press and hold the **Z** key, then drag right or left to zoom in or out, respectively, then release the key to return to your tool.

Do one of the following:

*   Click the **Zoom Tool**![Image 1](https://images.ctfassets.net/3p2fxa94bzao/6jmWPErECQEdSLoFK86wRd/4df92fffdb8d65af90c0a607ed39cdb2/zoom_tool.svg)  and then: 
    *   Drag on the page—right to zoom in or left to zoom out.
    *   Click on the page to zoom in a step.
    *   **⌥**-click (Mac) / **Alt**-click (Windows) on the page to zoom out a step.
    *   **⌥**-drag (Mac) / **Alt**-drag (Windows) on the page to zoom into an area defined by a marquee.

*   On the **View** menu, select options from the **Zoom** submenu.
*   Hold the **⌥** key (Mac) / **Alt** key (Windows) and scroll your mouse wheel (if available).
*   For Windows: Hold the **Ctrl** key and scroll your mouse wheel (if available).
*   Zoom in or out using the options in the **Navigator** panel.

The following shortcuts can be used:

*   **Zoom In** using **⌘+** (Mac) / **Ctrl+** (Windows).
*   **Zoom Out** using **⌘-** (Mac) / **Ctrl-** (Windows).
*   **Zoom to Fit** using **⌘0** (Mac) / **Ctrl**+**0** (Windows).
*   **Zoom to Width** using **⌥⌘0** (Mac) / **Alt+Shift**+**0** (Windows), where document pixels map directly to screen pixels.
*   **Zoom to 100%** using **⌘1** (Mac) / **Ctrl**+**1** (Windows), where document pixels map directly to screen pixels. Use 2, 3 or 4 for 200%, 400% or 800% zoom, respectively.
*   **Zoom to Selection** using **⇧⌘0** (Mac) / **Ctrl**+**Alt**+**0** (Windows) or double-click **Layers** panel thumbnail.
*   **Actual Size** using **⌘8** (Mac) / **Ctrl**+**8** (Windows).
*   **Pixel Size** using **⌘9** (Mac) / **Ctrl**+**9** (Windows).

For more advanced zoom controls, you can use the panel for setting more exact zoom levels or storing view points (i.e., saved pan/zoom combinations) that remember your previous view settings. Great when focusing on specific areas of your design.

Do one of the following:

*   Click **Zoom In**![Image 2](https://images.ctfassets.net/3p2fxa94bzao/3gZcn8kkr8NL37NtHocGE9/8a3633b0b8051b8080492ac3e3050e13/zoomin.png)  or **Zoom Out**![Image 3](https://images.ctfassets.net/3p2fxa94bzao/6SbuEz4Iq3pkKjZ6Hhnuon/abcccf6c52b36c794c3ed04d34f4e472/zoomout.png) .
*   Drag the slider to change the zoom level.
*    Click the numerical zoom level, type a new value, then press the **⏎** key (Mac) / **Return** key (Windows). 

*   Drag the view rectangle around in the panel. The document view displays the area enclosed in the view rectangle.

1.   Set your desired zoom level and view position.
2.   From **Panel Preferences**![Image 4](https://images.ctfassets.net/3p2fxa94bzao/6UxpXBt5miovw347YaOPUz/6f8e3e8d9b379daa0bdc5a3ac6ff23e8/panel_preferences.svg) , select **Save Current View Point**.

If the view point is the first one saved for the current document, a pop-up menu will appear on the panel.

1.   From the pop-up menu, select a view point.
2.   From **Panel Preferences**![Image 5](https://images.ctfassets.net/3p2fxa94bzao/6UxpXBt5miovw347YaOPUz/6f8e3e8d9b379daa0bdc5a3ac6ff23e8/panel_preferences.svg) , select **Remove Selected View Point**.

1.   From the pop-up menu, select a view point.
2.   From **Panel Preferences**![Image 6](https://images.ctfassets.net/3p2fxa94bzao/6UxpXBt5miovw347YaOPUz/6f8e3e8d9b379daa0bdc5a3ac6ff23e8/panel_preferences.svg) , select **Rename View Point**.
3.   Type a new name for the view point, then click **OK**.

Do one of the following:

*   From the pop-up menu, select the view point you wish to move to. The document view will automatically change.
*   To move between view points sequentially, you can use **Move to Previous View Point** and **Move to Next View Point** from the **View** menu.

Commands for moving between view points are mappable to custom keyboard shortcuts; see [Customizing shortcuts](https://www.affinity.studio/help/workspace-customizing-shortcuts/) for more information.

Related behaviors can be adjusted from the app's settings:

*   **General > Limit initial zoom to a maximum of 100%**
*   **Tools > Use 'scrubby' zoom** Choose whether dragging with the Zoom Tool zooms around the cursor (scrubby zoom) or creates a 'zoom to' marquee.
