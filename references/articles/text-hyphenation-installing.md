# Managing spelling and hyphenation dictionaries - Affinity Help Center

3.   Managing spelling and hyphenation dictionaries

Spelling and hyphenation dictionaries are included for most languages supported by Affinity, except for Chinese and Japanese. New dictionaries can be downloaded and installed manually.

This feature is only available in Affinity for desktop.

1.   Go to LibreOffice's GitHub page (https://github.com/LibreOffice/dictionaries).
2.   Select the folder for the required language.
3.   Select the file or files for the required dictionary:
    *   For a spelling dictionary, there are two files with names in the formats xx_XX.dic and xx_XX.aff (or, sometimes, just xx.dic and xx.aff), where xx_XX indicates the language's locale ID.
    *   For a hyphenation dictionary, the file's name will be in the format hyph_xx_XX.dic (or, sometimes, just hyph_xx.dic), where xx_XX indicates the language's locale ID.

4.   Depending on the file's size, you will see either a **Raw**or **Download**button. Hold **⌥** (Mac) / **Alt** (Windows) and click the button to download the hyphenation dictionary.
5.   If your browser appends an additional file extension, e.g. .txt, to the download's name, remove that extension so the filename ends with .dic or .aff as expected.

1.   In Finder, hold **⌥** and select **Go > Library**.
2.   Open the **Spelling**subfolder.
3.   Place the spelling dictionary files in the subfolder.
4.   Quit and reopen Affinity.

The newly installed dictionary is available in the **Spelling** pop-up menu in the **Character** panel's **Language** section.

1.   In Finder, hold **⌥** and select **Go > Library**.
2.   Open the **Spelling**subfolder.
3.   Create a subfolder and name it after the hyphenation dictionary's locale ID, i.e. where the dictionary's filename is in the format hyph_xx_XX.dic, the subfolder should be named xx_XX.
4.   Place the hyphenation dictionary in the subfolder.
5.   Quit and reopen Affinity.

The newly installed dictionary is available in the **Hyphenation** pop-up menu in the **Character**panel's **Language** section.
