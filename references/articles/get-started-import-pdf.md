# Importing PDF documents - Affinity Help Center

> 官方来源：https://www.affinity.studio/help/get-started-import-pdf/

1.   [Help Center](https://www.affinity.studio/help/)
2.   [Getting started](https://www.affinity.studio/help/getting-started/)
3.   Importing PDF documents

When you import a PDF, it opens as a new Affinity document. Your edits are saved to a new Affinity (.af) file, not back to the original PDF. You can _export_ the document as a new PDF. What you can edit depends on how the PDF was originally created—if text and vectors were kept editable on export, they remain editable in Affinity; if the PDF was flattened or rasterized, the content arrives as images. If unsure, check the export settings of the app that created it. If the PDF contains document properties (metadata) such as Title, Author, Subject, and Keywords, these are retained on import and can be viewed on the Fields panel via **Window > References**. PDF files can also be placed into an existing document rather than opened as a new one—for example, to add an illustration or an advertisement.

1.   On the **File** menu, click **Open**.
2.   Select the file you want and click **Open**.
3.    From the PDF Options dialog, you can choose: 
    *   **Load all pages/Load pages**—all pages or specific pages (by page number) can be imported.
    *   **DPI**—sets the resolution for the document. The Estimate option reads and uses the resolution of the PDF file.
    *   **Color space**—sets the document color space (e.g., RGB or CMYK) that PDF contents will use. The Estimate option senses the PDF file's color space and uses that.
    *   **Favor editable text over fidelity**—if text is to remain more editable at the expense of accurate design reproduction.
    *   **Group lines of text into text frames**—If separate text lines can be treated as a single text frame to aid text flow.
    *   **Replace missing fonts**—when checked, missing fonts are substituted with the suggested replacement font family/style or a font family/style of your choosing.

For imported multi-page PDF files, each page is placed:

*   on its own artboard (in Vector Studio or Pixel Studio).
*   as its own separate page (in Layout Studio).

On importing a PDF that has fonts that are unavailable on your computer, if you choose to check **Replace missing fonts** at this stage, you won't be able to swap the fonts at a later date via **Font Manager**. To replace missing fonts later, ensure you uncheck the option.

Adobe PDF files can be easily placed into an existing document. When placing multi-page PDFs, you can choose which page you wish to display using the context toolbar.

Do one of the following:

*   For Mac: Open Finder and drag the PDF file to an off-page area of your workspace.
*   For Windows: Open File Explorer and drag the PDF file to an off-page area of your workspace.

Related behaviors can be adjusted from [the app's settings](https://www.affinity.studio/help/workspace-settings/):

*   **Color > Convert opened files**. On opening, a file's color space is preserved by default, but you can convert it to the default working color space with this option.
