# Slice Studio

A Studio is a workspace that groups tools and panels specific to a design discipline or way of working. The Slice Studio

![Image 3](https://images.ctfassets.net/3p2fxa94bzao/3vfODAvo895dTN5bFMTLNs/68e3d14904308a323dbf48d056fcf21d/persona_slice.svg)

takes a slice-based approach to outputting parts of your page in one, mass export operation.

The Slice Studio is hidden by default. To show it, open the Studio Manager

![Image 4](https://images.ctfassets.net/3p2fxa94bzao/7Hu0cvRLYlLOr92OfbxbF8/0890713fd47bb10637197141cdc62f77/studio_manager_help.svg)

 and turn on Slice Studio. (You may need to scroll down to see it.)

Here's a quick overview of some of the ideas you can adopt when using the workspace.

[](https://www.affinity.studio/help/workspace-slice-studio/#export-multiple-assets-simultaneously)

## Export multiple assets simultaneously

The same object(s), artboard(s), raster layer content or group(s) in a composition can be exported as **slices** in multiple sizes (1x, 2x and 3x) and file formats depending on the intended output and next steps. Layer content can be prepared and made into slices easily via the Studio's Export Layers panel. For UX and UI app and web developers, Affinity makes the mass export of UI-based elements, such as buttons and icons, a breeze.

Example: An app icon's design can be exported in a number of sizes to support a range of devices. A number of presets are provided to accommodate this workflow. For example, you can choose the iPadOS Application Icon preset to have your assets exported in multiple size scaling options all at once.

![Image 5: Slices exported as multiple assets](https://images.ctfassets.net/3p2fxa94bzao/7vzsVJrjIUA86Q3qTfxQbW/528d40bc147fc334220de91374768ae8/assets_slices.jpg)

Multiple assets exported to various sizes.

[](https://www.affinity.studio/help/workspace-slice-studio/#raster-content-extraction)

## Raster content extraction

You can use slices to export any drawn, rectangular areas. This is particularly useful for exporting and working with raster content, as you can specify a number of options for your slices: file format, resolution, and output Builder are all found on the Slices panel.

Example: Raster content from a number of other images can be extracted and exported to be used on a brand new composite project.

![Image 6: Slices exported as multiple assets](https://images.ctfassets.net/3p2fxa94bzao/5mA16s9Gy8JQXYWeZpdl2i/dee7ee9f86b5fd2706d6ff503444c775/composite-export.jpg)

Multiple raster images exported and combined in a new composite.
