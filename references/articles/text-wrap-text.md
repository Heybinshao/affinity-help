# Text wrapping - Affinity Help Center

2.   [Page layout](https://www.affinity.studio/help/page-layout/)
3.   Text wrapping

Text wrapping lets you control how frame text flows around objects that partially or fully overlap it, such as placed images, picture frames, shapes, and even other text frames.

![Image 1: Text wrapping](https://images.ctfassets.net/3p2fxa94bzao/2Q4hCjXaIPAosPrV49LuSQ/5f0124867b91fd62f04c9eae588f4fcd/textwrap.jpg)

The distance at which text wraps around an object's outline can be set independently for each side.

The wrap outline around an object can be edited to precisely define the extent of wrapping.

An object with a text wrap applied affects overlapping frame text whether the object is visible or hidden.

To prevent a specific text frame's content wrapping around overlapping objects, select the text frame and then enable **Ignore Text Wrap** on the **Text Frame** panel's **General** section.

1.   Select the overlapping object you want frame text to wrap around.
2.   On the **Text** menu, select **Text Wrap > Show Text Wrap Settings**.
3.    On the dialog that appears, select a **Wrap Style**: 
    *   ![Image 2](https://images.ctfassets.net/3p2fxa94bzao/6F0aTrMqZjisayWjRpjwLL/d48018238e8a48ffc54dda1667c7224a/wrapnone.png) **None**—text will not wrap around the object.
    *   ![Image 3](https://images.ctfassets.net/3p2fxa94bzao/viDwe3ba3wpQzr5bUhgq7/2e48743ddb5f41c2d87c961ade489269/wrapjump.png) **Jump**—text will appear above and below the object.
    *   ![Image 4](https://images.ctfassets.net/3p2fxa94bzao/5AT3m5ZBiUcJeDVbAh5Aj8/ab4e778bc2eaa765a3af47a6213dd65b/wrapsquare.png) **Square**—text will wrap around a rectangle which bounds the object.
    *   ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/6Ulw9fmdXnPFAfcAepUZpH/f29e86b98955f8781ff6de3dbc676f82/wraptight.png) **Tight**—text will wrap tightly outside the object’s outline.
    *   ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/aRmHYGA04wdmO6wkGOMFa/ce9970a12003bc1215db573eb321df5b/wrapinside.png) **Inside**—text will wrap tightly inside the object’s outline.
    *   ![Image 7](https://images.ctfassets.net/3p2fxa94bzao/1O1nDc2qIkeYIbb8gcDOHq/17c7f1df0d3b03fa662f4d887dccb0ab/wrapedge.png) **Edge**—text will avoid the edges of the object.

4.   For Square or Tight style only: Choose to wrap to **Both Sides**![Image 8](https://images.ctfassets.net/3p2fxa94bzao/1za9TeWYIxwD5iouzgYNur/592d52874a8227c5979a81bc11e5d35a/wrapbothsides.png)  or the **Largest Side**![Image 9](https://images.ctfassets.net/3p2fxa94bzao/4KTorX3TdIs5kRzcS6ft9N/545e764a887ec3142c67a1f884bf4631/wraplargestside.png) .
5.   Use the **Distance From Text** options to set the space between the frame text and the object's edges (or the object's wrap outline, if this has been edited).

1.   Select the object whose wrap outline you want to edit.
2.   On the **Text** menu, select **Text Wrap > Edit Wrap Outline**. The **Node Tool**![Image 10](https://images.ctfassets.net/3p2fxa94bzao/2Tyrn620F9iCYiF39DxVOc/9de008f998af69eafee088eb5a3c5210/node_tool.svg)  is automatically selected, and nodes are displayed around the object's edges in the document view.
3.   Reshape the object's wrap outline by dragging nodes (and control handles) into your chosen positions.

Additional nodes can be added to the wrap outline by clicking at an empty position on it. To remove a node, click it and then press the **⌫** key (Mac) / **Backspace** key (Windows).

*   On the **Text** menu, select **Text Wrap > Reset Wrap Outline**.

1.   On the **View** menu, select **Top Toolbar > Customize**.
2.   On the window that appears, locate the **Wrapping** group. It consists of three icons (![Image 11](https://images.ctfassets.net/3p2fxa94bzao/64Mk4Drjd4mawKXD5kBnjj/fbd19f9fee334691627da6c8c225c474/edit_wrap_settings.svg) ![Image 12](https://images.ctfassets.net/3p2fxa94bzao/6sZhEl0N85Grk3cSyA2fgf/bd15adf9d863871cc7c2236d20d5147d/edit_wrap_outline.svg) ![Image 13](https://images.ctfassets.net/3p2fxa94bzao/4ZRmW3uoqYydzZSfSmE9lj/510eb866158b5a1195a8ae03ee0eef53/reset_wrap_outline.svg) ) that correspond to items under **Text Wrap** on the **Text** menu.
3.   Drag the group onto the Toolbar at the top of Affinity's main window. Existing toolbar items will shift to accommodate it. Drop when it's where you want it.
4.   On the window that opened, select **Done**.
