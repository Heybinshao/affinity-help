# Detaching and linking master pages

Where a master page is applied, you can usually edit only the contents of its picture and text frames. Other operations, such as transforming objects, are restricted unless you detach or link the master page.

**Detaching** breaks the connection between the master page and its elements. You can then move or resize objects and change frame settings, such as the number of columns or stroke.

**Linking** lets you edit the master page directly from a page to which it is applied. This updates the master page and all other pages where it's used.

Alternatively, an applied master page can be **locked** so its objects on the target page can't be edited at all.

![Image 4: Detach master page](https://images.ctfassets.net/3p2fxa94bzao/6T1RvEtea55xNBkd7V1Txj/824faf4f103d15eaf8ca4cacf7240a7e/masterpages_detachmaster.jpg)

Master page (top) with placeholder frames (brown). Publication page (bottom) shows frames detached (green) to allow resizing and frame property adjustment and text frame (blue) with edited content.

### How to detach or link a master page

Desktop app

1.   On the **Layers** panel, select the master's layer (e.g. 'Master A - 2 Pages').
2.   Select the **Move Tool**  ![Image 5](https://images.ctfassets.net/3p2fxa94bzao/3oigj5SSoPtnSw21egHEvD/b6ac975f2be7b3feb8e3e9867b378345/move_tool.svg)        and choose an **Edit** option on the context toolbar: 
    *   **Detached**—Changes to inherited content will affect only the current page/spread. The master page and other pages to which it's applied are unaffected.
    *   **Linked**—Changes to inherited content will also affect the master page and other pages to which it is applied.

3.   Click **Finish** on the bar across the top of the document view to commit your edit. The applied master page returns to the default 'Edit Frame Content' behavior.

The Edit options are also available:

*   by **^(ctrl)**-clicking (Mac) / **right**-clicking (Windows) the master's layer.
*   on the **Layer** menu, under **Master Page**.

[](https://www.affinity.studio/help/pages-detach-link-master-pages/#how-to-lock-an-applied-master-page)

### How to lock an applied master page

Desktop app

On the **Layers** panel, do one of the following:

*   Select the master's layer and then select **Lock/Unlock**  ![Image 6](https://images.ctfassets.net/3p2fxa94bzao/52XYdXlyLW1ZAzUYGK6kqf/48bc9cd93adcdbf14804e0cab02cbcf0/lock_layer.svg)       .
*   **^(ctrl)**-click (Mac) / **Ctrl**-click (Windows) the master's layer and select **Lock**.
